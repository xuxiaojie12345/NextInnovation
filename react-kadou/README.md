# react-kadou

要員の**週別プロジェクト稼働（割当）管理**を行うための画面 UI プロジェクトです。
構成・技術スタックは既存の `react-ud` を参照しています。

## 技術スタック

- React 18 + TypeScript (Create React App / react-scripts 5)
- UI: Ant Design (antd 5) + @ant-design/icons
- 日付: dayjs
- データ: フロント内のモックデータ（バックエンド未接続）

## セットアップ & 起動

```bash
npm install     # 依存パッケージのインストール
npm start       # 開発サーバー起動 (http://localhost:3000)
```

## 画面（現在の実装）

`src/WorkStatus/WorkStatus.tsx`

- **要員 × 週 のグリッド**：行 = 要員、列 = 1週間（月曜〜日曜）
- **1ページ = 3か月（四半期）**：7月〜9月のような四半期単位で週列を表示し、前後の四半期へ移動可能
- ヘッダーは「月」→「週（開始日〜終了日）」の2段構成で、月をまたぐ週は日数が多い方の月に分類
- **セルの入力値はプロジェクト名**（固定リストから選択・色分け表示、未割当は「－」）
- 行ごとの集計：担当プロジェクト数（ユニーク件数）・割当週数
- 最終行に週ごとの割当人数と割当延べ（人週）合計を表示
- 「要員を追加」モーダルで要員を追加可能
- モック初期データ：開始済みの週（月曜 <= 今日）に要員ごとの主担当プロジェクトを自動セット（未来週は空欄 = 計画入力）

## 今後の拡張イメージ

- バックエンド（api-ud 相当）との API 接続（`/api/kadou/**`）
- プロジェクトマスタの管理画面・休日（祝日）マスタ
- 1週間に複数プロジェクトを割当可能にする（タグ入力）
- 週次の稼働率・月間集計、PDF / Excel 出力
