2. 背景 (Background)
   本模块的核心功能和目标
   该模块是Upload&Delete template页面，核心实现Template模板文件的上传、删除操作，同时提供跳转至HDoc Template Check画面的入口，支持用户完成rtf格式Template文件的校验操作，帮助用户高效完成指定文件夹内模板文件的管理维护。
   安全性或特殊要求（如有）
   所有涉及模板文件的上传、删除操作都保留操作留痕，删除操作前增加二次确认步骤，防止用户误删重要模板文件；上传的文件仅能写入指定文件夹，删除操作仅可针对指定文件夹内的模板文件执行，避免越权访问或修改其他路径下的业务文件。
   用户体验方面的考虑
   操作触发后及时给出对应级别的提示信息，错误场景给出明确的报错提示，删除操作通过告警提示用户确认操作，成功执行操作后返回清晰的完成反馈，同时所有控件默认处于激活状态，操作路径简洁直观，降低用户的操作学习成本。

4. 业务逻辑与校验规则 (Business Logic & Checks)
   4.1 处理流程
    按步骤描述每个主要功能的处理流程，格式如下：
      4.1.1 初期表示：
      	画面可以正常显示，所有控件默认处于激活状态，所有输入项初始值为空。
      4.1.2 开始：用户点击Upload按钮
      空值校验等 (Frontend Check)：
       若用户未选择任何Template File直接点击Upload按钮：
        设置Message = NO FILE UPLOADED
        终止流程
      4.1.3 API调用 (Backend Check)：
        调用UD12UploadDeletetemplatApi.UD12UploadFlie接口，将选中的Template文件上传至指定Market对应的文件夹中
      4.1.4 结果处理：
       成功：TEMPLATE XXX WAS SUCESSFULLY UPLOADED TO MARKET JPN，信息级别为Information
       失败：返回对应的文件上传失败错误提示，信息级别为Error

      4.1.5 开始：用户点击Delete按钮
      提示校验等 (Frontend Check)：
       触发确认弹窗，设置Message = Do you really want to delete template?，信息级别为Warning
       若用户选择取消操作：
        终止流程
      4.1.6 API调用 (Backend Check)：
        调用UD12UploadDeletetemplatApi.UD12DeleteFlie接口，删除选中Market对应的文件夹内选定的Template文件
      4.1.7 结果处理：
       成功：TEMPLATE XXX WAS SUCESSFULLY DELETE FROM MARKET JPN，信息级别为Information
       失败：返回对应的文件删除失败错误提示，信息级别为Error

      4.1.8 开始：用户点击Check Template (Only for rtf files)链接
      跳转处理：直接跳转至「HDoc Template Check」画面，画面加载后所有控件正常显示
      4.1.9 开始：用户在HDoc Template Check画面选择Template文件后点击Check按钮
      4.1.11 结果处理：
       成功：返回模板校验通过提示
       失败：返回模板校验失败对应的问题提示
   4.2 校验详细规格表
   | No. | 检查时机 | 检查对象 | 检查条件 | 错误消息 (Message Content) | 动作 |
   |-----|---------|---------|---------|--------------------------|------|
   | 1 | 点击Upload按钮时 | 上传操作 | 未选择任何Template文件直接点击Upload按钮 | NO FILE UPLOADED | 弹出Error级别提示，终止后续上传流程 |
   | 2 | 上传操作执行完成时 | 上传操作 | Template文件正常上传完成 | TEMPLATE XXX WAS SUCESSFULLY UPLOADED TO MARKET JPN | 弹出Information级别提示，刷新页面可查看已上传的文件列表 |
   | 3 | 点击Delete按钮时 | 删除操作 | 点击Delete按钮触发操作 | Do you really want to delete template? | 弹出Warning级别二次确认弹窗，等待用户确认或取消 |
   | 4 | 删除操作执行完成时 | 删除操作 | Template文件正常从指定文件夹删除完成 | TEMPLATE XXX WAS SUCESSFULLY DELETE FROM MARKET JPN | 弹出Information级别提示，刷新页面更新Templates下拉选项的可选内容 |

     Response Error (400)

   UD12UploadDeletetemplatApi.UD12UploadFlie
     功能：将用户选中的Template文件上传至指定Market对应的文件夹内
     Method：POST
     Endpoint：/api/ud012/UD12UploadDeletetemplatApi/UD12UploadFlie

     Request [请求格式]
     form-data格式，包含market编码和待上传的文件流
     请求示例
     market: "JPN"
     file: 待上传的template.rtf文件

     Response Success (200)
     {
       "code": 200,
       "msg": "TEMPLATE XXX WAS SUCESSFULLY UPLOADED TO MARKET JPN",
       "data": null
     }

     Response Error (400)
     {
       "code": 400,
       "msg": "NO FILE UPLOADED",
       "data": null
     }

   UD12UploadDeletetemplatApi.UD12DeleteFlie
     功能：删除指定Market对应文件夹内用户选中的Template文件
     Method：POST
     Endpoint：/api/ud012/UD12UploadDeletetemplatApi/UD12DeleteFlie

     Request [请求格式]
     json格式，包含market编码和待删除的模板文件名
     请求示例
     {
       "market": "JPN",
       "templateName": "XXX.rtf"
     }

     Response Success (200)
     {
       "code": 200,
       "msg": "TEMPLATE XXX WAS SUCESSFULLY DELETE FROM MARKET JPN",
       "data": null
     }
