2. 背景 (Background)
 本模块的核心功能和目标
  本模块是Existing HDoc Variables页面，核心功能是基于前画面传入的检索条件展示Homologation Variables的检索结果列表，支持用户完成记录选择、返回检索条件画面、打印检索结果、跳转关联指定记录的Homologation Variables画面、导出CSV文件、跳转查看指定用户信息的全流程操作，实现现有HDOC变量数据的快速查询与关联业务跳转，满足业务人员高效处理HDOC系统变量数据的需求。
 安全性或特殊要求（如有）
  仅可对HDOC_VARIABLES表执行查询（R）操作获取规则信息，禁止对该表执行任何新增、修改、删除类的操作，保障系统核心变量规则数据的安全性与稳定性。
 用户体验方面的考虑
  所有操作按钮默认保持活性状态，控件文字对齐方式统一配置保证画面布局规整；跳转前画面时自动保留历史检索条件与已选记录内容，打印、导出操作无需额外二次确认即可直接执行，最大程度降低用户重复录入信息的操作成本。

4. 业务逻辑与校验规则 (Business Logic & Checks)
   4.1 处理流程
    按步骤描述每个主要功能的处理流程，格式如下：
      4.1.1 初期表示：
      	画面正常表示，从前画面获取传入的检索条件，基于该条件查询HDOC_VARIABLES表加载对应的检索结果列表，同时展示检索结果总件数。
      4.1.2 开始：Select按钮触发
     选中记录校验 (Frontend Check)：
       若未勾选任意列表行记录：
        设置Message = Please first check the records that need to be selected.
        终止流程
      用户勾选列表中的目标记录后点击Select按钮：
       直接跳转回前的Existing HDoc Variables画面，自动将已选中记录的内容填充至对应展示区域。
      4.1.3 开始：Back按钮触发
      用户点击Back按钮：
       直接跳转回前的Existing HDoc Variables检索条件画面，自动将之前录入的检索条件填充至对应输入区域。
      4.1.4 开始：Print按钮触发
      用户点击Print按钮：
       直接调用系统打印能力，将当前画面展示的所有检索结果发起打印。
      4.1.5 开始：Down按钮触发
      用户点击Down按钮：
        （式样不明暂不做任何处理）
      4.1.6 开始：Excel按钮触发
      用户点击Excel按钮：
       直接将当前检索结果导出为CSV文件输出到用户本地。
      4.1.7 开始：Created by user列的Link触发
      用户点击列表中Created by user列的链接：
       直接跳转至EDB User View画面，加载对应用户的信息完成展示。
      4.1.8 API调用 (Backend Check)：
        调用queryExistingHDocVariables API
      4.1.9 结果处理：
       成功：正常加载全部匹配的变量检索结果
       失败：弹出系统数据加载异常提示，终止画面渲染

5. 接口定义 (API Specification)
请为每个API提供：

   UD11HdocvariablesApi.UD11Search
     功能：根据传入的检索条件查询HDOC_VARIABLES表内匹配的变量规则数据，返回结果列表用于画面渲染展示
     Method：GET
     Endpoint：/hdoc/ud11/UD11HdocvariablesApi/UD11Search

  Request [请求格式]
  {
   "variable": "001",
   "type": "User Defined",
   "description": "description",
   "createdByUser": "UD001",
   "date": "2022-11-24"
  }

     Response Success (200)
     [成功响应示例]
     {
       "code": 200,
       "message": null,
       "data": {
         "totalCount": 10,
         "variableList": [
           {
             "variable": "SAMPLE_VAR001",
             "type": "RULE",
             "descr": "descr",
             "registerUser": "USER001",
             "registerDatetime": "2022-11-24"
           }
         ]
       }
     }

     Response Error (500)
     [错误响应示例]
     {
       "code": 500,
       "message": "System error. Please contact administrator.",
       "data": null
     }
