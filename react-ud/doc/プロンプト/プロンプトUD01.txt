2. 背景 (Background)
 本模块的核心功能和目标：实现系统登录的身份校验能力，用户输入UserID和Password后按下Login按钮触发ISAM认证，完成用户身份的合法性验证，保障系统访问安全。
 面向的用户群体：持有系统合法账号的HDOC业务使用者。
 用户体验方面的考虑：输入错误时即时展示对应错误提示信息，引导用户修正输入内容，所有输入控件默认活性状态，支持常规操作逻辑。
 安全性或特殊要求：UserID仅允许半角英数字输入，Password允许半角英数字+符号输入，所有认证请求通过ISAM AuthenticationApi完成读取校验，不直接在前端存储或校验用户核心凭证信息。

4. 业务逻辑与校验规则 (Business Logic & Checks)
 4.1 处理流程
    4.1.1 初始表示：
        画面正常展示，UserID输入框、Password输入框、Login按钮处于活性状态，Message区域初始为空。
    4.1.2 触发条件：用户按下Login按钮
        空值校验等 (Frontend Check)：
         若UserID为空白：
          设置Message = Username and password are required.
          终止流程
         若Password为空白：
          设置Message = Username and password are required.
          终止流程
    4.1.3 API调用 (Backend Check)：
         调用 AuthenticationApi，执行用户信息认证的读取校验
    4.1.4 结果处理：
         成功：完成登录流程，进入系统菜单页面
         失败：设置Message = We didn't recognize the username or password you entered. Please try again.
 4.2 校验详细规格表
| No. | 检查时机 | 检查对象 | 检查条件 | 错误消息 (Message Content) | 动作 |
|-----|---------|---------|---------|--------------------------|------|
| 1 | 按下Login按钮 | 用户ID | 用户ID为空白 | Username and password are required. | 展示警告级提示，终止后续认证流程 |
| 2 | 按下Login按钮 | 密码 | 密码为空白 | Username and password are required. | 展示警告级提示，终止后续认证流程 |
| 3 | 调用ISAM认证接口返回时 | 用户存在校验 | 用户ID或者密码不正确 | We didn't recognize the username or password you entered. Please try again. | 展示错误级提示，返回登录页面等待用户重新输入 |

5. 接口定义 (API Specification)
 AuthenticationApi
 功能：对输入的UserID和Password进行用户身份合法性校验，读取匹配已登记的用户认证信息
 Method: POST
 Endpoint: /api/ud01/AuthenticationApi

 Request [请求格式]
 {
  "userId": "string",
  "password": "string"
 }

 请求示例
 {
  "userId": "AD001",
  "password": "P@ssw0rd123"
 }

 Response Success (200)
 {
  "code": 200,
  "message": null,
  "data": {
   "userId":"AD001"
  }
 }

 Response Error (401)
 {
  "code": 401,
  "message": "We didn't recognize the username or password you entered. Please try again.",
  "data": null
 }
