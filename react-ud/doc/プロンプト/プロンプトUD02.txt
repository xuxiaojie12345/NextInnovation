2. 背景 (Background)
  本模块的核心功能和目标
  本模块是HDOC系统菜单画面，核心功能是基于登录注册用户的权限，动态展示对应可访问的功能菜单链接，为用户提供进入系统各功能页面的统一入口。目标是实现菜单的精准权限过滤，仅向用户开放其有权限操作的功能项，保障系统功能访问的合规性与便捷性。
  安全性或特殊要求
  必须严格执行权限校验逻辑，注册用户不具备权限的功能不得在菜单中展示。
  用户体验方面的考虑
  所有菜单链接统一左对齐展示，页面布局整齐易读；所有可访问的菜单链接默认保持激活状态，用户点击即可直接跳转对应功能页面，操作路径简洁流畅。

        终止流程

        调用获取用户菜单权限API，关联读取HDOC_FUNCTION_AUTH用户功能权限表，仅执行查询(R)操作获取用户权限数据。

       成功：返回当前用户的所有可访问权限菜单列表，正常渲染菜单画面

5. 接口定义 (API Specification)
   GetUserPermissionsApi
     功能：根据当前登录用户标识，从用户功能权限表HDOC_FUNCTION_AUTH中查询该用户持有的所有功能操作权限，返回对应的可访问菜单列表
     Method：GET
     Endpoint：/api/ud02/GetUserPermissionsApi

     Request [请求格式]
     {
       "userId": "string"
     }
     [请求示例]
     GET /api/ud02/GetUserPermissionsApi?userId=UD001

     Response Success (200)
     [成功响应示例]
     {
       "code": 200,
       "message": "success",
       "data": {
       "permissions": [
         "Generate",
         "Admin",
         "User Administration",
         "Documentation"
       ]}
     }

     Response Error (403)
     [错误响应示例]
     {
       "code": 403,
       "message": "YOU (XXXXXXXX) ARE NOT AUTHORIZED TO ACCESS THIS PAGE"
       "data": null
     }
