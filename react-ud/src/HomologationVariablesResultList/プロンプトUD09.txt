作成者: UD 劉

概要处理:
1. 同族变量画面
   根据前画面的搜索条件，显示搜索结果。
   (1) 勾选记录后，按下「选择」按钮，跳转到前一个「同族变量」画面。
       自动显示选中记录的内容。
   (2) 按下「返回」按钮，跳转到前一个「同族变量」画面。
       自动显示搜索条件。
   (3) 按下「打印」按钮，打印搜索结果。
   (4) 按下「删除选中」按钮，删除选中的记录。
   (5) 点击记录的'Created by user'列的链接，跳转到「EDB User View」画面。

2. EDB User View搜索结果画面
   EDB User View画面：根据前画面的UserID，显示用户信息。
