## 1. 背景 (Background)

本模块用于配置用户权限，从Saviynt系统获取用户信息，管理用户的功能权限和市场权限。

- **核心功能和目标**：
  1. 用于配置用户权限。
  2. 从Saviynt系统获取用户信息。
  3. 管理用户的功能权限和市场权限。
- **面向的用户群体**：系统管理员、权限管理人员。
- **用户体验方面的考虑**：
  1. 提供直观的权限配置界面。
  2. 支持批量权限操作。
  3. 显示用户已有权限状态。
- **安全性或特殊要求**：
  - 确保权限操作的安全性和一致性。
  - 防止未授权的权限修改。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

所有权限操作逻辑均在用户点击相应按钮时执行。

### 3.1 处理流程

#### 3.1.1 用户信息获取功能 (User Info)

- **功能说明**：输入userid，点击【User info】按钮，从 Saviynt 系统获取对应用户名称；从用户功能权限表读取该用户已有权限。
- **开始**：点击 User Info 按钮。
- **前置处理**：获取用户输入的 UserID。
- **空值校验 (Frontend Check)**：
  - 若 `UserID` 为空：
    - 设置 `Message` = `"请输入用户ID"`
    - **终止**流程。
- **操作步骤**：
  1. 输入 UserID。
  2. 点击 User Info 按钮。
  3. 系统调用 AuthenticationApi 获取用户名称。
  4. 调用 `UD17HDocUserAdministrationApi` 的 `UD17Userinfo` 方法获取用户权限信息。
  5. 显示用户信息，用户已有权限的 checkbox 默认选中，用户已有市场排到前列高亮显示。
- **API调用 (Backend Check)**：
  - 调用 `UD17HDocUserAdministrationApi`。
- **结果处理**：
  - 成功：显示用户信息及已有权限。
  - 失败：显示错误消息，如 `"We didn't recognize the userid you entered. Please try again."`。

#### 3.1.2 更新角色权限功能 (Update Role)

- **功能说明**：点击【Update Role】按钮，完成用户权限更新。
- **开始**：点击 Update Role 按钮。
- **前置处理**：确保 UserID 已输入。
- **空值校验 (Frontend Check)**：
  - 若 `UserID` 为空：
    - 设置 `Message` = `"请输入用户ID"`
    - **终止**流程。
- **操作步骤**：
  1. 确保 UserID 已输入。
  2. 配置所需权限（Checkbox）和对应市场（Pull-downList）。
  3. 点击 Update Role 按钮。
  4. 系统调用 `UD17HDocUserAdministrationApi` 的 `UD17UpdateRole` 方法。
  5. 显示更新结果。
- **API调用 (Backend Check)**：
  - 调用 `UD17HDocUserAdministrationApi`。
- **结果处理**：
  - 成功：显示更新结果。
  - 失败：显示错误消息，如 `"We didn't recognize the userid you entered. Please try again."`。

#### 3.1.3 删除角色权限功能 (Delete Role)

- **功能说明**：点击【Delete Role】按钮，清空该用户名下全部权限。
- **开始**：点击 Delete Role 按钮。
- **前置处理**：确保 UserID 已输入。
- **空值校验 (Frontend Check)**：
  - 若 `UserID` 为空：
    - 设置 `Message` = `"请输入用户ID"`
    - **终止**流程。
- **操作步骤**：
  1. 确保 UserID 已输入。
  2. 点击 Delete Role 按钮。
  3. 系统调用 `UD17HDocUserAdministrationApi` 的 `UD17DeleteRole` 方法。
  4. 显示删除结果。
- **API调用 (Backend Check)**：
  - 调用 `UD17HDocUserAdministrationApi`。
- **结果处理**：
  - 成功：显示删除结果。
  - 失败：显示错误消息，如 `"We didn't recognize the userid you entered. Please try again."`。

## 4. 接口定义 (API Specification)

### 4.1 UD17Userinfo

- **功能**：获取用户权限信息。
- **Method**: `POST`
- **Endpoint**: `/api/user-admin/userinfo`

#### Request

```json
{ "userid": "string" }
```

#### Response Success (200)

```json
{
  "code": 200,
  "msg": "获取成功",
  "data": {
    "username": "string",
    "permissions": [
      { "role": "Standard User", "markets": ["-EU"] },
      { "role": "Rule Admin", "markets": ["-DE", "-FR"] }
    ]
  }
}
```

#### Response Error (404)

```json
{
  "code": 404,
  "msg": "We didn't recognize the userid you entered. Please try again.",
  "data": null
}
```

### 4.2 UD17UpdateRole

- **功能**：更新用户权限。
- **Method**: `POST`
- **Endpoint**: `/api/user-admin/update-role`

#### Request

```json
{
  "userid": "string",
  "permissions": [{ "role": "string", "markets": ["string"] }]
}
```

#### Response Success (200)

```json
{ "code": 200, "msg": "权限更新成功", "data": null }
```

#### Response Error (404)

```json
{
  "code": 404,
  "msg": "We didn't recognize the userid you entered. Please try again.",
  "data": null
}
```

### 4.3 UD17DeleteRole

- **功能**：删除用户全部权限。
- **Method**: `POST`
- **Endpoint**: `/api/user-admin/delete-role`

#### Request

```json
{ "userid": "string" }
```

#### Response Success (200)

```json
{ "code": 200, "msg": "权限删除成功", "data": null }
```

#### Response Error (404)

```json
{
  "code": 404,
  "msg": "We didn't recognize the userid you entered. Please try again.",
  "data": null
}
```

## 5. 异常处理 (Exception Handling)

| 异常场景           | 处理方式         | Message 显示内容                                                |
| :----------------- | :--------------- | :-------------------------------------------------------------- |
| **用户ID不存在**   | 显示错误消息     | `We didn't recognize the userid you entered. Please try again.` |

## 6. 实现注意事项 (Implementation Notes)

1. **状态管理**：
   - 使用 React State 管理 `userid`, `username`, `permissions`, `selectedMarkets`, `message`, `isLoading`。
   - 管理各个权限复选框的选中状态和对应的市场下拉框选项。
   - 实现表单验证状态管理，确保 UserID 长度不超过10位。
   - 在 User Info 操作后更新用户权限显示状态。
   - 在 Update Role 和 Delete Role 操作后刷新权限状态。
2. **安全性**：
   - 对 UserID 输入进行长度验证，限制最大10位。
   - 所有 API 请求必须通过 HTTPS 发送。
   - 不在前端日志中打印敏感数据。
3. **UI 细节**：
   - User Info、Update Role、Delete Role 按钮在 `isLoading` 期间应设为 `disabled`，防止重复提交。
   - 用户已有权限的 checkbox 在获取用户信息后应默认选中。
   - 用户已有市场应排到前列高亮显示。
   - 错误消息（Message）Label 仅在出错时显示，建议使用红色文字。
   - 对于不存在的用户ID，提供明确的错误提示。
   - 实现权限操作的安全验证机制，确保只有授权用户才能执行权限修改操作。
4. **UI 细节**：
   - User Info、Update Role、Delete Role 按钮在提交过程中应设为 disabled 状态，防止重复提交。
   - UserID 输入框应限制最大长度为10个字符。
   - 权限复选框应正确显示用户已有的权限状态。
   - 市场下拉框应从 MARKET_MASTER 表获取选项，并将用户已有的市场排到前列高亮显示。
   - 操作按钮应有明确的视觉反馈，区分不同的功能。
   - 错误消息应以醒目方式显示，建议使用红色文字。
