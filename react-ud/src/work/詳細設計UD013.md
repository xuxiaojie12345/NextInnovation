## 1. 背景 (Background)

本模块提供HDoc模板文件的校验功能，支持用户选择模板文件并执行校验，提取文件中的变量信息并统计变量数量。

- **核心功能和目标**：提供HDoc模板文件的校验功能，支持用户选择模板文件并执行校验，提取文件中的变量信息并统计变量数量。
- **面向的用户群体**：系统管理员、开发人员、运维人员等需要校验HDoc模板文件的用户。
- **用户体验方面的考虑**：
  1. 提供直观的界面布局，方便用户选择和校验模板文件。
  2. 显示校验结果，让用户了解模板文件中的变量信息。
  3. 提供下载校验后模板的功能。
- **安全性或特殊要求**：
  - 确保文件读取的安全性，防止恶意文件读取。
  - 验证文件格式和内容的安全性。
  - 限制可读取的文件类型。

## 6. 实现注意事项 (Implementation Notes)

1. **状态管理**：
   - 使用 React State 管理 Template File 的选择状态和校验结果。
   - 校验结果包括提取的变量列表、变量数量统计等。
   - 校验完成后，显示 Download checked template 链接供用户下载。
2. **安全性**：
   - 对上传的模板文件进行格式和类型校验，仅允许支持的模板文件类型。
   - 对文件内容进行安全检查，防止恶意脚本注入。
   - 校验文件大小，防止过大的文件导致性能问题。
3. **UI 细节**：
   - Check 按钮点击前需校验文件是否已选择。
   - 校验过程中应显示加载状态，防止重复点击。
   - 校验完成后应清晰展示变量统计结果。
   - Download checked template 链接在校验完成后才可点击。
   - 错误消息应以醒目方式显示，建议使用红色文字。

## 6. 实现注意事项 (Implementation Notes)

1.  **状态管理**：
    - 使用 React State 管理 file、variables、variableCount 等状态。
    - 实现文件读取和解析结果的状态管理。
    - 实现校验进度和状态的管理。
    - 在校验完成后更新变量统计结果的显示。
2.  **安全性**：
    - 对上传的文件类型进行严格验证，只允许特定类型的模板文件（如 .rtf, .doc 等）。
    - 对上传的文件大小进行限制，防止过大的文件处理。
    - 对文件内容进行安全扫描，防止恶意代码注入。
    - 不在前端直接执行文件内容，只进行文本提取和分析。
    - 验证文件中提取的变量格式，确保符合预期的 $variable$ 格式。
3.  **UI 细节**：
    - Check 按钮在提交过程中应设为 disabled 状态，防止重复提交。
    - 文件上传时应显示进度指示器。
    - 校验完成后应清晰显示提取的变量列表和统计数量。
    - Download checked template 链接应在校验完成后启用。
    - 错误消息应以醒目方式显示，建议使用红色文字。
    - 确保文件读取过程的用户友好性，提供适当的等待提示。
