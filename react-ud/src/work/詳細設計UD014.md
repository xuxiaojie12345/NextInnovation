## 1. 背景 (Background)

本模块展示已存储的模板文件列表，支持用户选择市场后查看对应市场目录下的所有文件，并提供文件下载功能。

- **核心功能和目标**：展示已存储的模板文件列表，支持用户选择市场后查看对应市场目录下的所有文件，并提供文件下载功能。
- **面向的用户群体**：系统管理员、开发人员、运维人员等需要管理和下载模板文件的用户。
- **用户体验方面的考虑**：
  1. 提供直观的界面布局，方便用户选择市场和查看模板文件。
  2. 显示详细的文件信息（文件名、使用情况、最后修改时间、文件大小）。
  3. 提供便捷的文件下载功能。
  4. 根据市场筛选文件列表，提高查找效率。
- **安全性或特殊要求**：
  - 确保文件下载的安全性，防止恶意文件下载。
  - 验证文件路径的安全性，防止路径遍历攻击。
  - 控制用户对文件的访问权限。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

所有文件列表显示和下载逻辑均在用户交互时执行。

### 3.1 处理流程

1.  **开始**：页面加载完成。
2.  **前置处理**：准备获取市场列表。
3.  **API调用 (Backend Check)**：
    - 调用 `UD08HomologationVariablesApi` 的 `UD08SelectMarketmaster` 方法。
4.  **结果处理**：
    - **成功**：将市场列表填充到 SelectMarket 下拉列表。
    - **失败**：显示具体错误消息。

5.  **开始**：选择 [SelectMarket] 下拉列表中的市场项。
6.  **前置处理**：获取用户选择的市场信息。
7.  **空值校验 (Frontend Check)**：
    - 若 `SelectMarket` 为空：
      - 设置 `Message` = `"请选择市场"`
      - **终止**流程。
8.  **API调用 (Backend Check)**：
    - 若校验通过，调用 `UD14SearchresultistApi` 的 `UD14SelectHdocuserdefinedrules` 方法，将选择的 Market 作为参数传给 API。
9.  **结果处理**：
    - **成功**：显示对应市场的文件列表（文件名、使用情况、最后修改时间、文件大小）。
    - **失败**：显示具体错误消息。

10. **开始**：点击 [Filename] 链接。
11. **前置处理**：获取被点击文件的路径信息。
12. **操作步骤**：
    - 用户点击数据表格中的文件名链接。
    - 系统获取被点击文件的信息。
    - 将文件信息作为参数，调用 API，通过文件服务器下载文件。
13. **API调用 (Backend Check)**：
    - 调用 `UD14SearchresultistApi` 的 `UD14downfile` 方法，将选择的文件信息作为参数传给 API。
14. **结果处理**：
    - **成功**：提供文件下载。
    - **失败**：显示具体错误消息。

### 3.2 校验详细规格表

| No. | 检查时机   | 检查对象     | 检查条件       | 错误消息 (Message Content) | 动作                         |
| :-: | :--------- | :----------- | :------------- | :------------------------- | :--------------------------- |
|  1  | 选择市场时 | SelectMarket | 市场未选择     | 请选择市场                 | 显示错误消息，不执行查询操作 |
|  2  | 文件下载时 | 文件路径     | 文件路径不安全 | 文件路径不安全，无法下载   | 显示错误消息，阻止下载操作   |
|  3  | 文件下载时 | 文件权限     | 用户无访问权限 | 您没有权限访问此文件       | 显示错误消息，阻止下载操作   |

## 4. 接口定义 (API Specification)

### 4.1 UD08SelectMarketmaster

- **功能**：获取市场主数据信息。
- **Method**: `POST`
- **Endpoint**: `/api/ud08/selectmarketmaster`

#### Request

无参数

#### Response Success (200)

```json
{
  "code": 200,
  "msg": "查询成功",
  "data": {
    "markets": [{ "market": "JPN" }, { "market": "USA" }]
  }
}
```

#### Response Error (400)

```json
{
  "code": 400,
  "msg": "获取市场列表失败",
  "data": null
}
```

### 4.2 UD14SelectHdocuserdefinedrules

- **功能**：根据市场获取用户定义规则信息。
- **Method**: `GET`
- **Endpoint**: `/api/ud14searchresultist/selecthdocuserdefinedrules`

#### Request

```json
{
  "market": "string"
}
```

#### Response Success (200)

```json
{
  "code": 200,
  "msg": "查询成功",
  "data": {
    "rules": [{ "variable": "VARIABLE_NAME" }]
  }
}
```

#### Response Error (400)

```json
{
  "code": 400,
  "msg": "获取用户定义规则失败",
  "data": null
}
```

### 4.3 UD14downfile

- **功能**：通过文件服务器下载文件。
- **Method**: `GET`
- **Endpoint**: `/api/ud14searchresultist/downfile`

#### Request

```json
{
  "filePath": "string",
  "fileName": "string"
}
```

#### Response Success (200)

文件流（二进制下载）

#### Response Error (400)

```json
{
  "code": 400,
  "msg": "文件下载失败",
  "data": null
}
```

## 5. 异常处理 (Exception Handling)

| 异常场景             | 处理方式                   | Message 显示内容             |
| :------------------- | :------------------------- | :--------------------------- |
| **市场未选择**       | 阻止查询操作，显示错误消息 | 请选择市场                   |
| **文件路径不安全**   | 阻止下载操作，显示错误消息 | 文件路径不安全，无法下载     |
| **用户无访问权限**   | 阻止下载操作，显示错误消息 | 您没有权限访问此文件         |
| **文件不存在**       | 阻止下载操作，显示错误消息 | 文件不存在，无法下载         |
| **网络连接失败**     | 重试机制，显示网络错误消息 | 网络连接失败，请检查网络设置 |
| **数据库连接异常**   | 记录日志，显示系统错误消息 | 系统暂时不可用，请稍后再试   |
| **市场列表获取失败** | 显示获取失败消息           | 获取市场列表失败，请稍后重试 |

## 6. 实现注意事项 (Implementation Notes)

1. **状态管理**：
   - 使用 React State 管理 `market`, `files`, `usedVariables`, `isLoading`。
   - 管理 SelectMarket 下拉框选项，从 MARKET_MASTER 表获取数据。
   - 在组件挂载时调用 `UD08SelectMarketmaster` API 获取市场列表。
   - 在选择市场时调用 `UD14SelectHdocuserdefinedrules` API 获取文件列表和使用情况。
2. **安全性**：
   - 对文件下载路径进行安全验证，防止路径遍历攻击（如 `../` 等）。
   - 实现文件访问权限验证机制。
   - 对文件路径进行白名单验证，只允许访问指定目录下的文件。
   - 所有 API 请求必须通过 HTTPS 发送。
   - 不在前端日志中打印敏感数据。
3. **UI 细节**：
   - Filename 列应显示为可点击的链接，支持文件下载功能。
   - DataTable 应正确显示文件名、使用情况、最后修改时间和文件大小信息。
   - 当没有选择市场时，文件列表区域应显示提示信息。
   - 选择市场后应正确显示对应市场的文件列表。
   - 错误消息应以醒目方式显示，建议使用红色文字。

     "data": {

     {

     }
     }
