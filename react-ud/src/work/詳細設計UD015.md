## 1. 背景 (Background)

本模块用于输入底盘号（Chassis Number）后查询并展示VIN Plate的详细信息，提供多种操作功能，包括查看信息、设置重新生成状态、设置完成状态以及更改信息类型，支持基础信息和高级信息（含重量数据）两种类型管理。

- **核心功能和目标**：
  1. 输入底盘号（Chassis Number）后查询并展示VIN Plate的详细信息。
  2. 提供多种操作功能，包括查看信息、设置重新生成状态、设置完成状态以及更改信息类型。
  3. 支持基础信息和高级信息（含重量数据）两种类型管理。
- **面向的用户群体**：生产线操作员、质量控制人员、系统管理员。
- **用户体验方面的考虑**：
  1. 提供直观的界面布局，清晰区分输入区域和结果显示区域。
  2. 实时反馈操作结果，确保用户能够及时了解操作状态。
  3. 提供明确的错误提示，帮助用户快速定位和解决问题。
- **安全性或特殊要求**：
  - 对于不存在的底盘号提供明确警告。
  - 确保数据库操作的安全性和一致性。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

所有操作逻辑均在用户点击相应按钮时执行。

### 3.1 处理流程

#### 3.1.1 View Info（查看VIN Plate信息）

- **功能说明**：输入底盘号后点击【View Info】按钮，展示VIN Plate详细信息。
- **开始**：点击【View Info】按钮。
- **前置处理**：获取用户输入的底盘号。
- **空值校验 (Frontend Check)**：
  - 若 `Chassis number` 为空：
    - 设置 `Message` = `"请输入底盘号"`
    - **终止**流程。
- **操作步骤**：
  1. 在 `Chassis number` 输入框中录入底盘号。
  2. 点击【View Info】按钮。
  3. 系统调用 `UD15ViewInfo` 接口获取VIN Plate详细信息。
  4. 在页面上显示VIN Plate的详细信息。
- **API调用 (Backend Check)**：
  - 调用 `UD15SelecthdocsenddatavinplateApi` 的 `UD15ViewInfo` 方法。
- **结果处理**：
  - 成功：显示VIN Plate详细信息。
  - 失败：显示错误消息，如 `"Chassis number XXX not found."`。

#### 3.1.2 Set Regenerate（设置重新生成状态）

- **功能说明**：将对应底盘状态更新为0（新增）。
- **开始**：点击【Set Regenerate】按钮。
- **前置处理**：获取用户输入的底盘号。
- **空值校验 (Frontend Check)**：
  - 若 `Chassis number` 为空：
    - 设置 `Message` = `"请输入底盘号"`

- **操作步骤**：
  1. 在 `Chassis number` 输入框中录入底盘号。
  2. 点击【Set Regenerate】按钮。
  3. 系统调用 `UD15SetRegenerate` 接口将该 Chassis 的 STATUS 更新为0（新规追加）。
  4. 显示操作结果。

## 5. 异常处理 (Exception Handling)

| 异常场景               | 处理方式                   | Message 显示内容                |
| :--------------------- | :------------------------- | :------------------------------ |
| **底盘号为空**         | 阻止操作，显示错误消息     | 请输入底盘号                    |
| **底盘号长度超过15位** | 阻止操作，显示错误消息     | 底盘号长度不能超过15位          |
| **底盘号不存在**       | 显示错误消息               | `Chassis number XXX not found.` |
| **网络连接失败**       | 重试机制，显示网络错误消息 | 网络连接失败，请检查网络设置    |
| **数据库连接异常**     | 记录日志，显示系统错误消息 | 系统暂时不可用，请稍后再试      |

## 6. 实现注意事项 (Implementation Notes)

1. **状态管理**：
   - 使用 React State 管理 `chassisNumber`, `vinPlateInfo`, `status`, `type`, `error`, `isLoading`。
   - 实现表单验证状态管理，确保底盘号长度不超过15位。
   - 在 View Info 操作时更新显示的VIN Plate详细信息。
   - 在各种状态更新操作后刷新显示状态。
2. **安全性**：
   - 对底盘号输入进行长度验证，限制最大15位。
   - 所有 API 请求必须通过 HTTPS 发送。
   - 不在前端日志中打印敏感数据。
   - 对于不存在的底盘号，提供明确的错误提示。
3. **UI 细节**：
   - View Info、Set Regenerate、Set OK、Change to Basic Info、Change to Advanced Info 按钮在 `isLoading` 期间应设为 `disabled`，防止重复提交。
   - Chassis number 输入框应限制最大长度为15个字符。
   - 错误消息（Error Message）Label 仅在出错时显示，建议使用红色文字。
   - Error Message 标签应正确显示错误信息。
   - 各个信息标签（Chassis number、Plate type、Status等）应正确显示从API返回的数据。
   - 操作按钮应有明确的视觉反馈，区分不同的功能。
   - 错误消息应以醒目方式显示，建议使用红色文字。
