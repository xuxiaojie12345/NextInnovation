## 1. 背景 (Background)

本模块展示特定底盘号（Chassis No）对应的车辆详细规格信息。包括车型、生产周次、VIN、发动机号等关键数据。

- **面向的用户群体**：内部业务操作人员、质量管理人员、技术支持人员。
- **用户体验方面的考虑**：
  1. 清晰展示各项车辆参数。
  2. 交互性提示：将光标移至车型变体（Variant，即 SYMBOL_STR）选项上时，会弹出提示框（Tooltip）并显示对应的详细说明内容（Description）。

> **SYMBOL_STR (No.8) 的数据检索与显示逻辑备注**：
>
> 1. 数据检索：
>    步骤①：查询 HDOC_REC_DATA_VDA_VARIANTS 表。
>    检索条件：Chassis no
>    取得内容：FAMILY_ID, VARIANT_ID
>    步骤②：查询 HDOC_REC_DATA_KOLA_VARIANT 表。
>    检索条件：步骤①中取得的 FAMILY_ID, VARIANT_ID
>    取得内容：SYMBOL, FUNCTION_GROUP
> 2. 结果显示格式化：
>    取得 SYMBOL 的前8位字符。
>    若不足8位，则在右侧补充半角空格（左对齐）。
> 3. 排序/组合逻辑（用于后端处理或多条记录时）：
>    将 FUNCTION_GROUP 左侧补充半角空格至4位。
>    拼接 FAMILY_ID (3位)。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

### 3.1 处理流程

#### 3.1.1 画面初始化与数据加载 (Initial Load)

- **开始**：页面加载完成 (OnLoad)，获取到 Chassis no。
- **操作步骤**：
  1. 用户进入 VDA - Vehicle Specification 画面。
  2. 系统接收前画面传入的 Chassis no。
  3. 系统调用 UD07VehicleSpecificationApi。
  4. 后端执行多表关联查询或分步查询（OM, VDA General, VDA Variants, KOLA Variant），并按规则格式化 SYMBOL_STR。
  5. 界面渲染所有 Label 字段。
- **结果处理**：
  - 成功：页面正确显示所有字段，Tooltip 数据已准备好。
  - 失败：在页面显眼位置显示错误消息。

#### 3.1.2 变体说明提示 (Tooltip Display)

- **功能说明**：用户查看车型变体代码时，提供详细描述的快速预览。
- **操作步骤**：
  1. 用户将鼠标光标移至 SYMBOL_STR 标签上。
  2. 系统触发 Tooltip 显示事件。
  3. 界面在光标附近弹出提示框，显示该变体对应的 DESCRIPTION 内容。
  4. 用户移开鼠标。
  5. 提示框消失。
- **结果处理**：
  - 成功：Tooltip 正确显示 DESCRIPTION 内容。
  - 失败：无（前端 UI 行为，不涉及 API 调用）。

## 4. 接口定义 (API Specification)

### 4.1 UD07VehicleSpecificationApi

- **功能**：获取车辆详细规格信息，包括 OM, VDA, KOLA 等多源数据。
- **Method**：GET
- **Endpoint**：/api/ud07/vehiclespecification

#### Request [json]

```json
{
  "Serie": "string",
  "Number": "string"
}
```

#### Response Success (200)

```json
{
  "code": 200,
  "message": "Success",
  "data": {
    "model": "Model X",
    "builtWeek": "2023-45",
    "productType": "SUV",
    "vin": "WDB...",
    "engineNo": "M274...",
    "countryOfOperation": "DE",
    "symbolStr": "SYM001  ",
    "description": "Standard Engine Variant",
    "sNoteNo": "S12345"
  }
}
```

#### Response Error (400/500)

```json
{
  "code": 404,
  "message": "Data Not Found",
  "data": null
}
```

## 5. 异常处理 (Exception Handling)

| 异常场景             | 处理方式              | Message显示内容                                |

## 6. 实现注意事项 (Implementation Notes)

1.  **状态管理**：
    - 使用 React State 管理 chassisNo, model, builtWeek, productType, vin, engineNo, countryOfOperation, symbolStr, description, sNoteNo, isLoading 等状态。
    - 在组件挂载时调用 UD07VehicleSpecificationApi API 获取显示数据。
    - 实现 chassisNo 的解析逻辑，将其拆分为 serie 和 number 部分。
2.  **安全性**：
    - 所有 API 请求必须通过 HTTPS 发送。
    - 不在前端日志中打印敏感数据。
    - 对从后端获取的数据进行适当的安全处理，防止 XSS 攻击。
3.  **UI 细节**：
    - SYMBOL_STR 标签需要添加鼠标悬停事件处理，显示 DESCRIPTION 的 Tooltip。
    - Tooltip 应在鼠标悬停时显示，在鼠标离开时隐藏。
    - 所有 Label 应正确显示从 API 获取的数据。
    - 错误消息应以醒目方式显示，建议使用红色文字。
    - 确保页面布局合理，信息展示清晰易读。
