## 1. 背景 (Background)

本模块是系统的主导航入口，左侧侧边栏展示所有功能菜单。用户可以通过点击菜单项快速导航到不同功能页面。

- **目标**：作为系统的主导航组件，提供清晰的层级结构，让所有功能对所有用户开放，无需权限筛选。
- **面向用户**：所有已登录的系统用户。
- **用户体验**：清晰的层级结构，所有功能对所有用户开放，无需权限筛选。
- **安全性**：无特殊权限控制，依赖全局登录状态确保只有合法用户可访问。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

所有导航逻辑均在用户点击菜单项时执行。

### 3.1 处理流程

1.  **开始**：页面加载 / 用户点击菜单
2.  **前置处理**：确认用户已登录（依赖全局状态）。
3.  **菜单渲染 (Rendering)**：
    - 直接渲染预定义的完整菜单结构。
    - 所有菜单项均设置为可见且可点击。
4.  **点击跳转 (Navigation)**：
    - 用户点击 Link。
    - 触发路由跳转至目标页面。
5.  **结果处理**：
    - **成功**：路由跳转至对应功能页面。
    - **失败**：(通常不会发生，除非路由配置错误) 显示 404 或通用错误。

### 3.2 校验详细规格表

| No. |  检查时机  |   检查对象   |        检查条件        |      错误消息 (Message Content)      |             动作             |
| :-: | :--------: | :----------: | :--------------------: | :----------------------------------: | :--------------------------: |
|  1  |  页面加载  | 全局登录状态 | `isLoggedIn == false`  | Session expired. Please login again. | 路由守卫拦截，重定向到登录页 |
|  2  | 点击菜单项 |   目标路由   | `Route does not exist` |           Page not found.            |        显示 404 页面         |

## 6. 实现注意事项 (Implementation Notes)

1.  **状态管理**：
    - 使用 React State 管理菜单展开/收起状态。
    - 菜单项激活状态应与当前路由匹配。
2.  **UI 细节**：
    - Menu 组件应固定在页面左侧，滚动时保持位置不变。
    - 菜单项应支持多级嵌套结构，清晰显示层级关系。
    - 激活的菜单项应有视觉高亮效果，便于用户识别当前位置。
3.  **性能优化**：
    - 菜单渲染应高效，避免不必要的重渲染。
    - 对于深层嵌套的菜单，考虑懒加载机制。
