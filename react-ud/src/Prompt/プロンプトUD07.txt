SYMBOL_STR (No.8) 的数据检索与显示逻辑备注：

1.数据检索：
  步骤①：查询 HDOC_REC_DATA_VDA_VARIANTS 表。
    检索条件：Chassis no
    取得内容：FAMILY_ID, VARIANT_ID
  步骤②：查询 HDOC_REC_DATA_KOLA_VARIANT 表。
    检索条件：步骤①中取得的 FAMILY_ID, VARIANT_ID
    取得内容：SYMBOL, FUNCTION_GROUP
2.结果显示格式化：
  取得 SYMBOL 的前8位字符。
  若不足8位，则在右侧补充半角空格（左对齐）。
3.排序/组合逻辑（用于后端处理或多条记录时）：
  将 FUNCTION_GROUP 左侧补充半角空格至4位。
  拼接 FAMILY_ID (3位)。

       结果处理：
         成功：Tooltip 正确显示 DESCRIPTION 内容。
