5. 接口定义 (API Specification)

 【UD11HdocvariablesApi】的接口定义如下：
 
  UD11Search
  功能： 根据查询条件获取HDoc变量信息
  Method： GET
  Endpoint： /api/ud11hdocvariables/search

  Request [JSON]
  {
  "variable": "string",
  "type": "string",
  "description": "string",
  "createdByUser": "string",
  "date": "string"
  }

  Response Success (200)
  {
  "code": 200,
  "msg": "查询成功",
  "data": {
    "variables": [
      {
        "variable": "VARIABLE1",
        "type": "VDA",
        "description": "Sample description",
        "createdByUser": "admin",
        "date": "2024-12-19 10:00:00"
      }
    ],
    "count": 1
   }
  }

  Response Error (400)
  {
  "code": 400,
  "msg": "无效的查询条件，请重新输入",
  "data": null
  }
