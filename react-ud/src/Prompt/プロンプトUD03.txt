2. 背景 (Background)
 请描述：
  本模块的核心功能和目标：本模块是生成认证文件的入口画面。用户在此输入底盘系列号（Chassis series）、底盘号（Chassis no）并选择文档类型（Document type）,系统会根据输入的底盘信息自动加载可用的文档类型列表，并在提交后跳转至文档生成画面。
  面向的用户群体：需要生成车辆认证文件（Homologation Documents）的工程人员或管理人员。
  用户体验方面的考虑：
    1.自动回填：页面加载时自动显示上次使用的检索条件，减少重复输入。
    2.动态加载：点击或加载时根据底盘信息动态获取文档类型，确保选项的有效性。
    3.清晰反馈：若底盘号不存在或数据异常，立即在错误区域提示。
  安全性或特殊要求：输入字段需严格限制字符类型（半角英文、半角数字），防止注入或格式错误。

4. 业务逻辑与校验规则 (Business Logic & Checks)

   4.1 处理流程

   4.1.1 页面初始化与数据获取 (Initialization & Data Fetching)
    功能说明：页面加载时，恢复上次的检索条件，并调用 API 获取文档类型列表。
    操作步骤：
      开始：页面加载完成 (OnLoad)。
      前置处理：
        1. 页面加载，从本地存储（Local Storage/Session）读取上次的 Chassis series, Chassis no, Document type 并填充到对应控件。
        2. 立即调用 API UD03SelectHdocdocumentlistApi（无参数）。
      API调用 (Backend Check)：
        请求：GET /api/auth/UD03SelectHdocdocumentlistApi
      结果反馈：
        成功且数据非空：解析 API 返回的文档类型列表，更新 Document type 下拉框选项。若上次选择的值在列表中，则保持选中；否则清空或选中第一项。清空 error message area。
        成功但数据为空 (0件)：在 error message area 显示错误消息 "Chassis no is not exists"。下拉框置空或禁用。
        失败 (Network/Error)：在 error message area 显示系统错误消息。

   4.1.2 提交校验与跳转 (Submit Validation & Navigation)
    功能说明：校验用户输入，并将参数传递至下一画面。
    操作步骤：
      开始：用户点击 Submit 按钮。
      前置处理：获取所有表单字段的当前值。
      空值校验 (Frontend Check)：
        若 Chassis series 为空：
          设置 Message = "Chassis series is required."
          终止流程。
        若 Chassis no 为空：
          设置 Message = "Chassis no is required."
          终止流程。
        若 Document type 未选择（值为空）：
          设置 Message = "Document type is required."
          终止流程。
      结果处理：
        校验通过：
          保存当前输入到本地存储（作为下次"上次设定值"）。
          携带参数 { chassisSeries, chassisNo, documentType } 跳转到「Generate document」画面。
        校验失败：
          画面不跳转，在 error message area 显示错误消息。

   4.1.3 重置 (Reset)
    功能说明：清空当前表单内容及错误提示，恢复到未输入的初始状态，清除本地存储的历史记录。
    操作步骤：
      开始：用户点击 [Reset] 按钮。
      处理过程：
        1. 系统清空 Chassis series, Chassis no, Document type。
        2. 清除 error message area。
        3. 清除本地存储的上次检索条件。

   4.1.4 帮助 (Help)
    功能说明：跳转到帮助页面。
    操作步骤：
      开始：用户点击 [Help] 按钮。
      处理过程：
        1. 系统迁移到 Help 画面。
