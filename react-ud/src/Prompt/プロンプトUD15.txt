2. 背景 (Background)

核心功能和目标
  1.输入底盘号（Chassis Number）后查询并展示VIN Plate的详细信息
  2.提供多种操作功能，包括查看信息、设置重新生成状态、设置完成状态以及更改信息类型
  3.支持基础信息和高级信息（含重量数据）两种类型管理
面向的用户群体

  2.质量控制人员
  3.系统管理员
用户体验方面的考虑

  2.实时反馈操作结果，确保用户能够及时了解操作状态
  3.提供明确的错误提示，帮助用户快速定位和解决问题
安全性或特殊要求
  1.对于不存在的底盘号提供明确警告
  2.确保数据库操作的安全性和一致性

5. 业务逻辑与校验规则 (Business Logic & Checks)

 5.1 处理流程

  5.1.1 View Info（查看VIN Plate信息）
    功能说明：输入底盘号后点击【View Info】按钮，展示VIN Plate详细信息。
    开始: 点击【View Info】按钮
    前置处理: 获取用户输入的底盘号
    空值校验等 (Frontend Check):
      若`Chassis number`为空：
        设置Message = "请输入底盘号"
        终止流程
    操作步骤:
      1. 在`Chassis number`输入框中录入底盘号。
      2. 点击【View Info】按钮。
      3. 系统调用`UD15ViewInfo`接口获取VIN Plate详细信息。
      4. 在页面上显示VIN Plate的详细信息。
    API调用 (Backend Check):
      调用`UD15SelecthdocsenddatavinplateApi`的UD15ViewInfo方法
    结果处理
      成功: 显示VIN Plate详细信息
      失败: 显示错误消息，如"Chassis number XXX not found."

  5.1.2 Set Regenerate（设置重新生成状态）
    功能说明：将对应底盘状态更新为0（新增）。
    开始: 点击【Set Regenerate】按钮
    前置处理: 获取用户输入的底盘号

        设置Message = "请输入底盘号"

    操作步骤:

      2. 点击【Set Regenerate】按钮。
      3. 系统调用`UD15SetRegenerate`接口将该Chassis的STATUS更新为0（新规追加）。
      4. 显示操作结果。
    API调用 (Backend Check):
      调用`UD15SelecthdocsenddatavinplateApi`的UD15SetRegenerate方法
    结果处理
      成功: 显示操作结果
      失败: 显示错误消息，如"Chassis number XXX not found."
