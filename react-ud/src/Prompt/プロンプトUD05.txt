4. 业务逻辑与校验规则 (Business Logic & Checks)
请提供：
   4.1 处理流程

      4.1.1 画面初始化与数据加载
       开始：画面加载时，接收前画面传入的 Chassis no 和 Market。
       操作步骤：
         1. 用户进入 Modify Document 画面，系统接收前画面传入的 Chassis no 和 Market。
         2. 系统调用 UD05ModifyDocumentApi 中的 UD05SelectVariableModification 方法，获取 Variant 情报和 Modify 情报。
         3. 界面渲染 DataTable，展示 Variable, Description, Current value。
         4. Modified value 列初始化：若后端返回已有修改值则填充，否则为空
         5. 显示 Chassis no 和 Market 标签。
       结果处理：
         成功：页面渲染变量列表及已有修改值。
         失败：显示后端返回的错误消息。
  
      4.1.2 变量修改与保存
       功能说明：用户在 Modified value 列输入新值，点击 Save 按钮提交修改。
       操作步骤：
         1. 用户在 “Modified value” 输入框中填入新的数值或文本。
         2. 用户点击 “Save” 按钮。
         3. 收集所有 “Modified value” 列的非空输入值。
         4. 系统进行前端校验：
            - 若所有 “Modified value” 均为空（即未填写任何字段）：设置 Message = "NO UNRELEASED VERSION EXISTS!"，终止流程。
            - 若存在至少一个非空修改值：继续执行保存逻辑。
         5. 调用 UD05ModifyDocumentApi 中的 UD05UpdateHdocAdcaModification 方法，传入 Variable 和修改后的 Modified value，将修改后的值更新到数据库。
       结果处理：
         校验失败：显示错误消息 "NO UNRELEASED VERSION EXISTS!"，不提交请求。
         保存成功：携带参数 Chassis no 跳转至 “Save Modifications” 画面，展示修改内容摘要。
         失败：显示后端返回的错误消息。

      4.1.3 辅助功能
       功能说明：底盘详情查看。
       操作步骤：
         1. 点击 “Chassis no” 链接：弹出窗口或跳转新页面展示对应 Chassis 的详细信息。
       结果处理：
         成功：弹出窗口或跳转新页面展示 Chassis 详细信息。
         失败：显示后端返回的错误消息。

   4.3 校验详细规格表
   | No. | 检查时机 | 检查对象 | 检查条件 | 错误消息 (Message Content) | 动作 |
   |-----|---------|---------|---------|--------------------------|------|

   | 2   | 点击 Save 按钮 | Modified value 长度 | 单个字段超过 500 字符 | Input exceeds maximum length of 500 characters. | 显示错误消息，聚焦该字段 |

           {
             "variableName": "string",
             "description": "string",
             "currentValue": "string",
             "modifiedValue": "string or null"
           }
         ]
       }
     }

     UD05ModifyDocumentApi的UD05UpdateHdocAdcaModification方法
     功能：将修改后的值更新到数据库。
     Method：POST
     Endpoint：/api/ud05/updatemodification

     Request [json]
     {
       "chassisNo": "string",
       "modifications": [
         {
           "variableName": "string",
           "newValue": "string"
         }
       ]
     }
     Response Success (200)
     {
       "code": 200,
       "message": "Success",
       "data": {
       }
     }
     Response Error ([400])
     {
      "code": 400,
      "message": "Validation Failed",
      "data": {
      }
     }
