4. 业务逻辑与校验规则 (Business Logic & Checks)
请提供：
   4.1 处理流程
    按步骤描述每个主要功能的处理流程，格式如下：

    4.1.1 用户信息获取功能 (User Info)
    功能说明：输入userid，点击【User info】按钮，从 Saviynt 系统获取对应用户名称；从用户功能权限表读取该用户已有权限。
      开始：点击User Info按钮
      前置处理：获取用户输入的UserID
      空值校验等 (Frontend Check)：
        若UserID为空：
          设置Message = "请输入用户ID"
          终止流程
      操作步骤：
        1. 输入UserID。
        2. 点击User Info按钮。
        3. 系统调用AuthenticationApi获取用户名称。
        4. 调用UD17HDocUserAdministrationApi的UD17Userinfo方法获取用户权限信息。
        5. 显示用户信息，用户已有权限的checkbox默认选中，用户已有市场排到前列高亮显示。
      API调用 (Backend Check)：
        调用UD17HDocUserAdministrationApi
      结果处理：
        成功：显示用户信息及已有权限。
        失败：显示错误消息，如"We didn't recognize the userid you entered. Please try again."

    4.1.2 更新角色权限功能 (Update Role)
    功能说明：点击【Update Role】按钮，完成用户权限更新。
      开始：点击Update Role按钮
      前置处理：确保UserID已输入
      空值校验等 (Frontend Check)：
        若UserID为空：
          设置Message = "请输入用户ID"
          终止流程
      操作步骤：
        1. 确保UserID已输入。
        2. 配置所需权限（Checkbox）和对应市场（Pull-downList）。
        3. 点击Update Role按钮。
        4. 系统调用UD17HDocUserAdministrationApi的UD17UpdateRole方法。
        5. 显示更新结果。
      API调用 (Backend Check)：
        调用UD17HDocUserAdministrationApi
      结果处理：
        成功：显示更新结果。
        失败：显示错误消息，如"We didn't recognize the userid you entered. Please try again."

    4.1.3 删除角色权限功能 (Delete Role)
    功能说明：点击【Delete Role】按钮，清空该用户名下全部权限。
      开始：点击Delete Role按钮
      前置处理：确保UserID已输入
      空值校验等 (Frontend Check)：
        若UserID为空：
          设置Message = "请输入用户ID"
          终止流程
      操作步骤：
        1. 确保UserID已输入。
        2. 点击Delete Role按钮。
        3. 系统调用UD17HDocUserAdministrationApi的UD17DeleteRole方法。
        4. 显示删除结果。
      API调用 (Backend Check)：
        调用UD17HDocUserAdministrationApi
      结果处理：
        成功：显示删除结果。
        失败：显示错误消息，如"We didn't recognize the userid you entered. Please try again."

   4.2 结果处理：
       成功：示相应的操作成功消息
