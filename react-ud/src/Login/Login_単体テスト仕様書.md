> 本测试式样书基于【Login_詳細設計.md v1.1】作成。
> 测试对象：`src/Login/Login.tsx`、`src/Login/api/authApi.ts`、`src/Login/utils/validators.ts`。
> 技术栈：React 19 + TypeScript + Zod 校验 + axios。
> 注：当前工程使用 `MockAuthenticationApi`（`USE_MOCK = true`），测试时可直接利用其规则构造成功/锁定/失败场景。
