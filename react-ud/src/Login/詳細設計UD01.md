# 4. 功能描述 (Functional Description)

## 4.1 Login登陆
功能说明：用户点击Login登录按钮，跳转到menu画面。
操作步骤：
1. 用户打开系统登录页面，输入userid和password
2. 点击Login登陆按钮，调用AuthenticationApi进行用户信息验证
3. 系统验证用户并返回认证结果
4. 登录成功：跳转至系统主菜单界面，用户可以开始使用系统功能
   登录失败：在登录界面显示相应的错误信息，如用户名或密码错误，提示用户重新输入

# 5. 业务逻辑与校验规则 (Business Logic & Checks)

## 5.1 处理流程

### 开始：点击Login登陆按钮
### 前置处理：获取userid，password
### 空值校验等 (Frontend Check)：
- 若userid为空的场合：
  - 设置Message = "Username and password are required."
  - 终止流程，不调用API
- 若password为空的场合：
  - 设置Message = "Username and password are required."
  - 终止流程，不调用API
- 若userid或password输入不正时：
  - 设置Message = "We didn't recognize the username or password you entered. Please try again."
  - 终止流程，不调用API

### 5.1.2 API调用 (Backend Check)：
- 若校验通过，调用 "AuthenticationApi"，API参数(userid，password)。

## 5.2 结果处理：
- 成功：用户验证成功后跳转到menu画面
- 失败：用户验证失败后跳转到login画面

## 5.3 校验详细规格表

| 2 | 点击Login按钮 | password | password为空 | Username and password are required. | - |
| 3 | 点击Login按钮 | userid，password | userid或password输入不正 | We didn't recognize the username or password you entered. Please try again. | - |

# 6. 接口定义 (API Specification)

## AuthenticationApi
- 功能：对接收到用户登录信息进行验证
- Method：POST
- Endpoint：/api/auth/login

### Request
```
{
  "userid": "string",
  "password": "string"
}
```

### Response Success
```
[
  {
    "code": 200,
    "data": {
      "userInfo": { ... },
      "message": "success"
    }
  }
]
```

### Response Error (401)
```
{
  "code": 401,
  "data": {},
  "message": "Invalid credentials"
}
```
