项目名称: UD HDoc & VBI(UDBI) 替换项目

系统名称: HDOC
画面ID: Search User
画面名称: Search User
创建日期: 2022-11-30
创建者: UD 刘

概要处理:
1. 初始显示
   １. Search HDoc User画面
   搜索用户。
   (1) 输入Userid，点击“Search”按钮，从Saviynt获取用户名，从用户Market权限表获取用户的Market。
   (2) 输入User，点击“Search”按钮，首先从Saviynt获取Userid，然后根据Userid从用户Market权限表获取用户的Market。
   (3) 勾选“Not set”，点击“Search”按钮，搜索所有用户。
   (4) 勾选“Rule”，点击“Search”按钮，搜索拥有Rule Admin权限的用户。
   (5) 勾选“Template”，点击“Search”按钮，搜索拥有Template Admin权限的用户。

2. Search HDoc User检索结果画面
   2. Search HDoc User检索结果画面
   显示用户的检索结果。
