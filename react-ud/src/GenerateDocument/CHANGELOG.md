# Generate Document (UD04) - 更新日志

## [1.0.0] - 2026-05-21

### Added
- 初始版本发布
- 实现文档信息显示功能
  - 显示底盘系列号、底盘编号、订单号、构建周次、规格周次
  - 显示市场信息和主市场（固定为-EU）
  - 显示S-Note编号和提示信息
  - 显示轮胎载重指数
  - 显示ADCA变更状态和警告信息
  - 显示模板信息和替换参数
  - 提供文档下载链接
  - 显示系统时间和程序版本
- 实现页面初始化功能
  - 从URL参数或localStorage获取底盘号
  - 调用UD04SelectGeneratedocumentApi API获取数据
  - 处理API响应并显示数据
- 实现ADCA变更状态判断功能
  - 根据ACT字段值显示不同的链接样式
  - ACT="Y"时显示红色警告和可点击的Modify Doc链接
  - ACT="N"时不显示警告和链接
- 实现文档下载功能
  - 点击Generated document链接触发文件下载
  - 下载.trf格式文件
- 实现跳转功能
  - Analyze Rules链接跳转到分析规则页面
  - Modify Doc链接跳转到修改文档页面（仅当ADCA变更激活时）
- 实现异常处理
  - 底盘号不存在时显示错误消息
  - 网络错误时显示通用错误消息
  - API返回500时显示系统错误消息
  - 文件下载失败时显示错误消息
- 实现响应式设计
  - 支持桌面端和移动端
  - 字体大小和布局自适应屏幕宽度

## 版本说明

### 语义化版本控制

本项目遵循[语义化版本控制 2.0.0](https://semver.org/lang/zh-CN/)

版本号格式：`MAJOR.MINOR.PATCH`

- **MAJOR**: 不兼容的 API 变更
- **MINOR**: 向后兼容的功能新增
- **PATCH**: 向后兼容的问题修正

### 更新类型

- **Added**: 新增功能
- **Changed**: 功能变更
- **Deprecated**: 即将废弃的功能
- **Removed**: 已移除的功能
- **Fixed**: 问题修复
- **Security**: 安全性修复
