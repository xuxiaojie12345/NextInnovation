# API 配置说明

## 配置真实 API 服务器

### 1. 修改环境变量文件

#### 开发环境 (`.env.development`)
```env
# 将以下地址修改为实际的 API 服务器地址
REACT_APP_API_BASE_URL=http://your-api-server.com:8080
```

#### 生产环境 (`.env.production`)
```env
# 将以下地址修改为实际的 API 域名
REACT_APP_API_BASE_URL=https://api.yourdomain.com
```

### 2. 配置项说明

| 环境变量 | 说明 | 默认值 | 示例 |
|---------|------|--------|------|
| `REACT_APP_API_BASE_URL` | API 基础地址 | - | `http://localhost:8080` |
| `REACT_APP_API_TIMEOUT` | API 超时时间（毫秒） | `10000` | `30000` |
| `REACT_APP_ENV` | 环境标识 | - | `development` / `production` |

### 3. 跨域问题处理

如果 API 服务器和前端不在同一个域，需要后端配置 CORS：

#### 后端 CORS 配置示例（以 Spring Boot 为例）：
```java
@Configuration
public class CorsConfig implements WebMvcConfigurer {
    @Override
    public void addCorsMappings(CorsRegistry registry) {
        registry.addMapping("/api/**")
                .allowedOrigins("http://localhost:3000")  // 前端地址
                .allowedMethods("GET", "POST", "PUT", "DELETE")
                .allowedHeaders("*")
                .allowCredentials(true);
    }
}
```

#### 或者使用 Nginx 反向代理：
```nginx
location /api/ {
    proxy_pass http://your-api-server:8080/;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
}
```

### 4. 验证配置

启动项目后，可以通过以下方式验证 API 配置：

1. **检查网络请求**：
   - 打开浏览器开发者工具
   - 切换到 Network 标签
   - 查看 API 请求的 URL 是否正确

2. **测试接口连通性**：
   - 尝试登录功能
   - 检查是否成功调用后端 API

### 5. 注意事项

⚠️ **重要提示**：
- 修改 `.env` 文件后必须重启开发服务器（`npm start`）
- 环境变量必须以 `REACT_APP_` 开头才能被 Create React App 识别
- `.env` 文件不会被 Git 跟踪，请确保团队协作时同步配置
- 生产环境部署前请确认 API 地址配置正确

### 6. 常见问题

#### Q: 修改配置后不生效？
A: 需要重启开发服务器，运行 `npm start`

#### Q: 如何切换不同的环境？
A: 
```bash
# 开发环境
npm start

# 生产构建
npm run build
```

#### Q: 如何查看当前的 API 配置？
A: 在浏览器控制台运行：
```javascript
console.log(process.env.REACT_APP_API_BASE_URL)
```
