 2. 背景 (Background)

本模块是 VOLVO 公司内部工程数据库系统中用于生成车辆认证文件（Homologation Document）的核心功能。用户通过输入车辆系列、底盘号和文档类型，触发后台服务生成特定的认证文件。

   核心功能和目标：
       提供一个简洁的表单界面，让用户输入生成认证文件所需的必要参数。
       根据用户输入的参数，调用后端服务生成对应的文档（如 VIN Plate, CEMT 等）。
       显示生成过程中的分析规则、替换参数及最终结果，并提供下载链接。
   面向的用户群体：
       已登录的 VOLVO 内部员工、工程师、质量控制人员等需要生成认证文件的用户。
   用户体验方面的考虑：
       界布局清晰，将输入区域与结果展示区域分离。
       使用 `Submit` 和 `Reset` 挂晰地引导用户操作流程。
       在 `Help` 挂钮旁提供帮助文档链接，便于用户查阅详细说明。
       在 `error message area` 区域明确显示错误信息，提升问题排查效率。
   安全性或特殊要求：
       权限控制：若用户无权访问此功能，需拦截并显示“YOU (XXXXXXXX) ARE NOT AUTHORIZED TO ACCESS THIS PAGE”警告。
       数据校验：对输入的 Chassis series 和 Chassis no 进行格式和存在性校验。
       会话管理：确保所有请求都携带有效的 Session/Token。

 4. 功能描述 (Functional Description)

 4.1 初始化表示 (Initial Display)
功能说明：页面加载时，初始化表单控件，为用户提供一个空白的输入环境。

操作步骤：
1.  用户从菜单进入 "Generate Homologation Document" 页面。
2.  系统读取当前用户的权限。
3.  若用户有权限：
       渲除 `Chassis series`, `Chassis no` 字段。
       将 `Document type` 下拉框设置为默认值 "Dimension Plate"。
       设置 `error message area` 为空。
       显示 `Support Mail` 标签。
4.  结果反馈：成功加载初始状态的表单。

 4.2 生成文档 (Generate Document)
功能说明：用户输入查询条件并点击 `Submit` 挂钮，系统执行文档生成逻辑。

操作步骤：
1.  用户在 `Chassis series` 和 `Chassis no` 输入框中填写内容。
2.  用户在 `Document type` 下拉框中选择一个文档类型。
3.  用户点击 `Submit` 挂钮。
4.  结果反馈：
       成功：系统调用后端 API，生成文档。页面跳转至 "Generate document" 结果页面，显示详细的生成信息、分析规则、替换参数和最终的文档内容。
       失败：若校验失败（如 Chassis no 不存在），在 `error message area` 显示错误信息（如 "Chassis no is not exists"），不跳转。

 4.3 重置表单 (Reset Form)
功能说明：用户点击 `Reset` 挂钮，清除当前输入的所有内容。

操作步骤：
1.  用户点击 `Reset` 挂钮。
2.  结果反馈：`Chassis series`, `Chassis no` 字段被清空，`Document type` 下拉框恢复为默认值 "Dimension Plate"。

 4.4 查看帮助 (View Help)
功能说明：用户点击 `Help` 挂钮，查看该功能的使用指南。

操作步骤：
1.  用户点击 `Help` 挂钮。
2.  结果反馈：页面跳转至 "HDoc Help" 页面，显示用户手册、快速指南等帮助信息。

 5. 业务逻辑与校验规则 (Business Logic & Checks)

 5.1 处理流程

开始：用户点击 `Submit` 挂钮。

前置处理：
   获取 `Chassis series`, `Chassis no`, `Document type` 的当前值。

5.1.1 值校验等 (Frontend Check)：
   若 `Chassis series` 为空或仅含空白字符：
       设置 `error message area` = "Chassis series is required."
       终止流程
   若 `Chassis no` 为空或仅含空白字符：
       设置 `error message area` = "Chassis no is required."
       终止流程
   若 `Document type` 未选择（即值为空）：
       设置 `error message area` = "Document type is required."
       终止流程

5.1.2 API调用 (Backend Check)：
   调用 `GenerateDocumentApi.generate` 接口。

5.2 结果处理：
   成功：跳转至 "Generate document" 结果页面。
   失败：
       若返回错误码 `404` 或 `400` 且消息为 "Chassis no is not exists"：
           设置 `error message area` = "Chassis no is not exists"
       若返回其他错误码（如 `401`）：
           设置 `error message area` = "System error. Please try again later."

 5.3 校验详细规格表

| No. | 检查时机 | 检查对象 | 检查条件 | 错误消息 (Message Content) | 动作 |
|-----|---------|---------|---------|--------------------------|------|
| 1   | 点击 Submit | Chassis series | 值为空或仅含空白 | Chassis series is required. | 显示 Warning，聚焦字段 |
| 2   | 点击 Submit | Chassis no | 值为空或仅含空白 | Chassis no is required. | 显示 Warning，聚焦字段 |
| 3   | 点击 Submit | Document type | 未选择 | Document type is required. | 显示 Warning，聚焦字段 |
| 4   | API 返回 | Chassis no | 数据库中不存在 | Chassis no is not exists | 显示 Error，不跳转 |

 6. 接口定义 (API Specification)

 generateDocumentApi.generate

功能：根据提供的车辆信息和文档类型，生成相应的认证文件。
Method：POST
Endpoint：`/api/hdoc/generate`

Request [请求格式]
```json
{
  "chassisSeries": "string", // 半角英数字，Max 5
  "chassisNo": "string",     // 半角数字，Max 10
  "documentType": "string"    // 来自 HD_DOC_DOCUMENT_LIST 的 DocType
}
```

Response Success (200 OK)
```json
{
  "code": 200,
  "data": {
    "chassisNo": "JPCT 028321",
    "ordernumber": "19146492",
    "buildWeek": "2020186",
    "specWeek": "202018",
    "market": "AUS",
    "masterMarket": "-EU",
    "frontLoadIndex": "FTLI-152",
    "frontSpeedIndex": "FTSI-",
    "driveLoadIndex": "DTLI-143",
    "driveSpeedIndex": "DTSI-L",
    "analyzeRules": [
      "After def change detected. Document need to be modified."
    ],
    "replacingParameters": [
      "Information parameter: YPGVW_2 Market: AUS overrides -EU"
    ],
    "errors": [
      "ERROR: RULE_EPC_4_8.",
      "ERROR: for variable RULE_EPC_4_8ERROR: Can not find RULE_EPC_4_8. No match in user defined rules.."
    ],
    "generatedDocument": "base64_encoded_document_content",
    "downloadUrl": "/downloads/document_123.pdf"
  },
  "message": "Success"
}
```

Response Error (404 Not Found)
```json
{
  "code": 404,
  "message": "Chassis no is not exists"
}
```

Response Error (401 Unauthorized)
```json
{
  "code": 401,
  "message": "You are not authorized to access this resource."
}
```
