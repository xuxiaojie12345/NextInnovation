## 2. 背景 (Background)

### 核心功能和目标
本模块用于显示当前登录用户的详细信息，主要功能包括：
- 从Saviynt系统获取并显示用户信息
- 展示用户ID、负责人、职位和邮箱等信息
- 提供清空输入内容和返回前页面的功能

### 面向的用户群体
需要查看自己账户信息的系统用户

### 用户体验考虑
- 清晰的信息展示界面
- 简洁的操作按钮
- 支持快速返回前页面

### 安全性要求
- 仅显示当前登录用户的信息
- 所有字段为只读，不可编辑
- 支持HTTPS安全传输

## 4. 功能描述 (Functional Description)

### 4.1 页面初始化功能
**功能说明**：页面加载时从Saviynt系统获取当前用户信息并显示

**操作步骤**：
1. 页面加载时，系统调用AuthenticationApi获取当前登录用户的信息
2. API返回成功后，将用户信息显示在对应的字段中
3. Userid字段显示用户ID
4. Responsible字段显示负责人
5. User Position字段显示用户职位
6. E-mail字段显示邮箱地址
7. 若API调用失败，显示错误消息

### 4.2 清空功能
**功能说明**：用户点击Clear按钮，清空所有显示的用户信息

**操作步骤**：
1. 用户点击Clear按钮
2. 系统清空Userid字段的显示内容
3. 系统清空Responsible字段的显示内容
4. 系统清空User Position字段的显示内容
5. 系统清空E-mail字段的显示内容
6. 所有字段恢复为空状态

### 4.3 返回功能
**功能说明**：用户点击Back按钮，返回到前一个页面

**操作步骤**：
1. 用户点击Back按钮
2. 系统执行浏览器后退操作或导航到前一个页面
3. 若无法确定前一个页面，则导航到默认首页或菜单页面

## 5. 业务逻辑与校验规则 (Business Logic & Checks)

### 5.1 处理流程

#### 5.1.1 页面初始化流程
**开始**：页面加载

**处理步骤**：
- 调用AuthenticationApi获取当前用户信息
- 等待API响应
- **成功**：
  - 从响应中提取userid字段，显示在Userid文本框中
  - 从响应中提取responsible字段，显示在Responsible文本框中
  - 从响应中提取userPosition字段，显示在User Position文本框中
  - 从响应中提取email字段，显示在E-mail文本框中
  
- **失败**：
  - 显示错误消息"Failed to load user information. Please try again."
  - 所有字段保持为空

#### 5.1.2 Clear处理流程
**开始**：用户点击Clear按钮

**处理步骤**：
- 清空Userid字段的值
- 清空Responsible字段的值
- 清空User Position字段的值
- 清空E-mail字段的值
- 不调用任何API，仅前端清空显示

#### 5.1.3 Back处理流程
**开始**：用户点击Back按钮

**处理步骤**：
- 执行浏览器history.back()操作返回前一个页面
- 或者使用React Router的navigate(-1)方法
- 若历史记录为空或无法返回，则导航到默认页面（如Menu页面）

### 5.2 校验详细规格表

本页面无校验规则，所有字段均为只读显示，无用户输入验证需求。

## 6. 接口定义 (API Specification)

### AuthenticationApi
**功能**：获取当前登录用户的详细信息

**Method**：GET

**Endpoint**：/api/authentication/userinfo（具体路径需根据实际API定义）

**Request**：无请求参数（从会话或Token中获取当前用户信息）

**Response Success (200)**：
```json
{
  "success": true,
  "userid": "string",
  "responsible": "string",
  "userPosition": "string",
  "email": "string"
}

**Response Error (500)**：
```json
{
  "success": false,
  "message": "Internal server error"
}
```

| 异常场景 | 处理方式 | Message显示内容 |

| 未预期的JavaScript错误 | 使用try-catch包裹关键代码，记录错误日志，显示系统错误 | "System error. Please contact administrator." |
