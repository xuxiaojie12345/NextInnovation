## 2. 背景 (Background)
本模块用于展示当前登录用户的详细信息，从Saviynt系统获取用户数据并以只读形式呈现。

**核心功能和目标**：
- 页面加载时自动从Saviynt系统获取当前登录用户的信息
- 展示用户的基本信息包括：Userid（用户ID）、Responsible（负责人）、User Position（职位）、E-mail（邮箱）
- 提供Clear按钮清空显示内容
- 提供Back按钮返回到前一个画面

**面向的用户群体**：所有已登录系统的用户

**用户体验方面的考虑**：界面简洁清晰、信息一目了然、操作便捷

**安全性或特殊要求**：仅展示当前登录用户的信息，不涉及敏感数据修改，所有数据均为只读

## 4. 功能描述 (Functional Description)

### 4.1 初始显示
**功能说明**：加载EDB User View画面，自动从Saviynt系统获取当前登录用户信息并展示。

**操作步骤**：
1. 页面加载时自动调用AuthenticationApi从Saviynt系统获取当前登录用户的信息
2. 将获取到的用户信息填充到对应字段：
   - Userid：显示用户ID（如t009667）
   - Responsible：显示负责人姓名（如Mats Gustafsson）
   - User Position：显示职位名称（如Senior Solution Leader）
   - E-mail：显示邮箱地址（如mats.e.gustavsson@volvo.com）
3. 所有字段以只读形式展示，用户不可编辑
4. Clear和Back按钮处于可用状态

### 4.2 清空功能（Clear）
**功能说明**：清空所有显示字段的内容。

**操作步骤**：
1. 用户点击「Clear」按钮
2. 系统清空所有字段的显示内容：
   - Userid字段清空
   - Responsible字段清空
   - User Position字段清空
   - E-mail字段清空
3. 字段清空后保持只读状态，用户仍不可编辑

### 4.3 返回功能（Back）
**功能说明**：返回到前一个画面。

**操作步骤**：
1. 用户点击「Back」按钮
2. 系统执行页面跳转，返回到调用本画面的前一个页面
3. 不保存任何数据，直接跳转

## 6. 接口定义 (API Specification)

### AuthenticationApi
- **功能**：从Saviynt系统获取当前登录用户的详细信息
- **Method**：GET
- **Endpoint**：/api/auth/saviynt/current-user

**Request [请求格式]**：
```json
{
  "action": "getCurrentUser"
}
```

**Response Success (200)**：
```json
{
  "success": true,
  "user": {
    "userId": "t009667",
    "responsible": "Mats Gustafsson",
    "userPosition": "Senior Solution Leader",
    "email": "mats.e.gustavsson@volvo.com"
  }
}
```

**Response Error (401)**：
```json
{
  "error": "Unauthorized",
  "message": "用户未登录或会话已过期"
}
```

**Response Error (500)**：
```json
{
  "error": "Internal Server Error",
  "message": "Failed to retrieve user information from Saviynt"
}
```
