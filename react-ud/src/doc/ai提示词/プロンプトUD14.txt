## 2. 背景 (Background)
本模块用于展示各市场下的模板文件列表，支持按市场筛选并查看模板文件的详细信息及使用状态。

**核心功能和目标**：
- 用户可选择特定市场（Market）
- 显示所选市场文件夹下的所有模板文件
- 展示文件名、使用状态、最后修改时间、文件大小等信息
- 点击文件名链接可下载对应模板文件
- Used列显示该模板是否在HDOC_USER_DEFINED_RULES表中被引用

**面向的用户群体**：系统管理员、配置工程师及生产准备人员

**用户体验方面的考虑**：界面简洁清晰、信息一目了然、操作便捷

**安全性或特殊要求**：仅允许授权用户访问，只读操作不涉及数据修改

## 4. 功能描述 (Functional Description)

### 4.1 初始显示
**功能说明**：加载List Templates画面，展示市场选择下拉列表和空的表格区域。

**操作步骤**：
1. 页面加载时初始化"Select Market"下拉列表，从MARKET_MASTER表获取所有可用市场
2. 表格区域初始为空，不显示任何文件信息
3. "Select Market"下拉列表默认值为空
### 4.2 市场选择与文件列表加载
**功能说明**：用户选择市场后，系统自动加载该市场文件夹下的所有模板文件并展示详细信息。

**操作步骤**：
1. 用户在"Select Market"下拉列表中选择一个市场（如AUT、JPN等）
2. 系统调用API获取所选市场文件夹下的所有文件信息
3. 同时查询HDOC_USER_DEFINED_RULES表，检查每个文件名是否被引用
4. 将结果以表格形式展示，包含以下列：
   - Filename：文件名（带下载链接）
   - Used：若文件名存在于HDOC_USER_DEFINED_RULES表的VARIABLE字段中，显示该变量名；否则为空
   - Last Mod,：文件最后修改时间
   - Size：文件大小（单位：Kb）
5. 若所选市场下无文件，表格显示为空但保留表头

### 4.3 文件下载功能
**功能说明**：用户点击文件名链接可下载对应模板文件。

**操作步骤**：
1. 用户点击表格中某行的Filename列的文件名链接
2. 系统将该文件作为附件发送给用户
3. 浏览器触发文件下载，文件名为原始文件名

## 5. 业务逻辑与校验规则 (Business Logic & Checks)

### 5.1 处理流程

**开始**：页面加载触发

**前置处理**：
- 初始化"Select Market"下拉列表，从MARKET_MASTER表获取所有市场

### 5.2 结果处理
- **成功**：正常渲染表格，显示所有文件信息
- **失败**：显示"系统内部错误，请联系管理员"

## 6. 接口定义 (API Specification)

### UD14SearchresultistApi
- **功能**：获取指定市场下的模板文件列表及使用状态信息
- **Method**：GET
- **Endpoint**：/api/v1/ud14/list-templates

**Request [请求格式]**：
```json
{
  "market": "AUT"
}
```

**Response Success (200)**：
```json
{
  "success": true,
  "files": [
    {
      "filename": ".m003432.txt",
      "used": "",
      "lastModified": "2022-01-10 18:29",
      "size": "317 Kb",
      "downloadUrl": "/download/templates/AUT/.m003432.txt"
    },
    {
      "filename": ".m003432.txt.170629.backup",
      "used": "TEMPLATE-VIN-PLATE",
      "lastModified": "2017-06-29 16:50",
      "size": "377 Kb",
      "downloadUrl": "/download/templates/AUT/.m003432.txt.170629.backup"
    }
  ],
  "totalCount": 2
}
```

**Response Error (400)**：
```json
{
  "error": "Invalid input",
  "message": "Market parameter is required"
}
```

**Response Error (500)**：
```json
{
  "error": "Internal Server Error",
  "message": "Failed to retrieve file list"
}
```
