# UploadDeleteTemplate 详细设计提示词

## 1. 基本信息
- **模块名称**：UploadDeleteTemplatePage
- **文档编号**: DES-UploadDeleteTemplatePage-001
- **作成日期**：2026-05-20

## 2. 背景 (Background)

### 核心功能和目标
本模块用于管理HDoc模板文件的上传和删除操作，主要功能包括：
- 支持选择并上传模板文件到指定市场文件夹
- 支持从指定市场文件夹删除模板文件
- 提供模板检查链接跳转到HDoc Template Check页面
- 市场下拉列表动态加载可用市场选项
- 模板下拉列表根据所选市场动态加载该市场下的模板文件

### 面向的用户群体
需要管理认证系统模板文件的授权用户，如系统管理员、配置管理人员等

### 用户体验考虑
- 清晰的文件上传界面
- 明确的操作反馈消息
- 删除操作前的确认提示
- 便捷的模板检查跳转功能

### 安全性要求
- 需要用户登录认证后才能访问
- 文件上传需要进行类型和大小验证
- 支持HTTPS安全传输协议

## 4. 功能描述 (Functional Description)

### 4.1 页面初始化功能
**功能说明**：页面加载时初始化市场下拉列表和模板下拉列表

**操作步骤**：
1. 页面加载时，从后端获取可用的市场列表
2. 将市场列表填充到两个Market下拉列表中
3. 模板下拉列表初始化为空或禁用状态
4. 清空错误消息和成功消息区域

### 4.2 文件上传功能
**功能说明**：用户选择模板文件和市场后点击Upload按钮，将文件上传到指定市场文件夹

**操作步骤**：
1. 用户点击Template File输入框选择文件
2. 用户从Market下拉列表中选择目标市场
3. 用户点击Upload file按钮
4. 前端校验：检查是否选择了文件
   - 若未选择文件，显示错误消息"NO FILE UPLOADED"并终止流程
5. 构建FormData对象，包含文件和market参数
6. 调用文件上传API（POST方法）
7. 等待API响应

**后端处理**：
- 验证文件类型和大小
- 将文件保存到指定市场的文件夹中
- 返回成功响应

**结果处理**：
- **成功**：
  - 显示成功消息"TEMPLATE XXX WAS SUCESSFULLY UPLOADED TO MARKET JPN"
  - XXX为上传的文件名，JPN为选择的市场代码
  - 可选择清空文件选择框
  
- **失败**：
  - 显示错误消息
  - 保持当前表单数据不变

### 4.3 模板删除功能
**功能说明**：用户选择市场和模板后点击Delete按钮，从指定市场文件夹删除模板文件

**操作步骤**：
1. 用户从Market下拉列表中选择市场
2. 系统根据所选市场动态加载该市场文件夹下的模板文件列表
3. 模板文件列表填充到Templates下拉列表中
4. 用户从Templates下拉列表中选择要删除的模板
5. 用户点击Delete按钮
6. 显示确认对话框"Do you really want to delete template?"
   - 若用户点击取消，终止流程
   - 若用户点击确认，继续执行
7. 构建请求参数，包含market和template参数
8. 调用文件删除API（POST方法）
9. 等待API响应

**后端处理**：
- 验证文件和路径存在性
- 从指定市场的文件夹中删除文件
- 返回成功响应

**结果处理**：
- **成功**：
  - 显示成功消息"TEMPLATE XXX WAS SUCESSFULLY DELETE FROM MARKET JPN"
  - XXX为删除的文件名，JPN为选择的市场代码
  - 刷新Templates下拉列表
  
- **失败**：
  - 显示错误消息
  - 保持当前表单数据不变

### 4.4 模板检查链接功能
**功能说明**：用户点击"Check Template (Only for rtf files)"链接，跳转到HDoc Template Check页面

**操作步骤**：
1. 用户点击链接
2. 使用React Router navigate函数跳转到/HDocTemplateCheck路由
3. HDoc Template Check页面显示模板检查功能

### 4.5 市场选择联动功能
**功能说明**：用户在Delete区域的Market下拉列表中选择市场后，自动加载该市场下的模板文件列表

**操作步骤**：
1. 用户从Market下拉列表中选择市场
2. 触发onChange事件
3. 调用API获取该市场文件夹下的所有模板文件列表
4. 将文件列表填充到Templates下拉列表中
5. 若该市场下无文件，Templates下拉列表显示为空或提示"No templates available"

## 6. 接口定义 (API Specification)

### 6.1 获取市场列表API
**功能**：获取可用的市场列表

**Method**：GET

**Endpoint**：/api/template/markets（具体路径需根据实际API定义）

**Request**：无请求参数

**Response Success (200)**：
```json
[
  {
    "marketCode": "JPN",
    "marketName": "Japan"
  },
  {
    "marketCode": "USA",
    "marketName": "United States"
  }
]
```

**成功响应参数说明**：
- marketCode：市场代码，字符串类型，最大长度3字符，对应MARKET_MASTER表的MARKET字段
- marketName：市场名称，字符串类型

**Response Error (500)**：
```json
{
  "message": "Internal server error"
}
```

### 6.2 获取模板文件列表API
**功能**：根据市场代码获取该市场文件夹下的模板文件列表

**Method**：GET

**Endpoint**：/api/template/files/{marketCode}（具体路径需根据实际API定义）

**Request**：
- 路径参数：marketCode（字符串类型，必填，市场代码）

**Response Success (200)**：
```json
[
  {
    "fileName": "template1.rtf",
    "filePath": "/templates/JPN/template1.rtf"
  },
  {
    "fileName": "template2.docx",
    "filePath": "/templates/JPN/template2.docx"
  }
]
```

**成功响应参数说明**：
- fileName：文件名，字符串类型
- filePath：文件路径，字符串类型

**Response Error (500)**：
```json
{
  "message": "Internal server error"
}
```

### 6.3 文件上传API
**功能**：上传模板文件到指定市场文件夹

**Method**：POST

**Endpoint**：/api/template/upload（具体路径需根据实际API定义）

**Request**：
- Content-Type: multipart/form-data
- 表单参数：
  - file：文件对象，必填
  - market：市场代码，字符串类型，必填

**Response Success (200)**：
```json
{
  "success": true,
  "message": "TEMPLATE template1.rtf WAS SUCESSFULLY UPLOADED TO MARKET JPN",
  "fileName": "template1.rtf",
  "market": "JPN"
}
```

**Response Error (400)**：
```json
{
  "success": false,
  "message": "Invalid file type or size"
}
```

**Response Error (500)**：
```json
{
  "success": false,
  "message": "Internal server error"
}
```

### 6.4 文件删除API
**功能**：从指定市场文件夹删除模板文件

**Method**：POST

**Endpoint**：/api/template/delete（具体路径需根据实际API定义）

**Request**：
```json
{
  "market": "JPN",
  "fileName": "template1.rtf"
}
```

**请求参数说明**：
- market：市场代码，字符串类型，必填
- fileName：文件名，字符串类型，必填

**Response Success (200)**：
```json
{
  "success": true,
  "message": "TEMPLATE template1.rtf WAS SUCESSFULLY DELETE FROM MARKET JPN",
  "fileName": "template1.rtf",
  "market": "JPN"
}
```

**Response Error (404)**：
```json
{
  "success": false,
  "message": "File not found"
}
```

**Response Error (500)**：
```json
{
  "success": false,
  "message": "Internal server error"
}
```

| 异常场景 | 处理方式 | Message显示内容 |
