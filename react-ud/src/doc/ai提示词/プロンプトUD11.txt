# ExistingHDocVariablesResultList 详细设计提示词

## 1. 基本信息
- **模块名称**：ExistingHDocVariablesResultListPage
- **文档编号**: DES-ExistingHDocVariablesResultListPage-001
- **作成日期**：2026-05-20

## 2. 背景 (Background)

### 核心功能和目标
本模块用于显示Existing HDoc Variables页面的搜索结果列表，主要功能包括：
- 根据前画面传递的搜索条件显示匹配的变量定义列表
- 支持选择单条记录并返回前画面
- 支持将选中记录的Variable作为参数跳转到Homologation Variables页面
- 支持打印搜索结果
- 支持导出CSV文件
- 支持返回前画面并保留搜索条件
- 显示搜索结果总数

### 面向的用户群体
需要查看和管理认证系统变量定义的授权用户，如系统管理员、配置管理人员等

### 用户体验考虑
- 清晰的数据表格展示
- 便捷的记录选择和操作功能
- 明确的搜索结果计数显示
- 支持批量操作和导出功能

### 安全性要求
- 需要用户登录认证后才能访问
- 支持HTTPS安全传输协议

## 4. 功能描述 (Functional Description)

### 4.1 页面初始化功能
**功能说明**：页面加载时接收前画面传递的搜索条件，调用API获取并显示搜索结果列表

**操作步骤**：
1. 页面加载时，从URL参数或state中获取前画面传递的搜索条件
2. 搜索条件可能包含以下字段：
   - variable：变量名
   - type：类型
   - description：描述
3. 调用UD11HdocvariablesApi的UD11Search方法（POST `/api/ud11/search`）获取匹配的变量定义列表
4. 将数据显示到DataTable中
5. 计算记录总数，更新Count字段显示"Number of lines found: XXX"
6. 若API返回空列表，Count显示"Number of lines found: 0"

### 4.2 选择记录并返回功能（Select按钮）
**功能说明**：用户选择表格中的某条记录后点击Select按钮，返回到前画面并自动填充选中记录的内容

**操作步骤**：
1. 用户在DataTable中选择一条记录（通过单选方式或行点击）
2. 系统记录选中行的索引或主键信息
3. 用户点击Select按钮
4. 校验是否有选中的记录
   - 若未选择任何记录，显示错误消息并终止流程
5. 获取选中记录的完整数据
6. 将数据存储到state或sessionStorage中
7. 返回到/ExistingHDocVariables页面
8. 前画面检测到返回标志，从state或sessionStorage中读取选中的数据
9. 自动填充到对应的输入字段中：
   - variable → Variable文本框
   - type → Type下拉列表
   - description → Description文本框
   - userid → Created by user文本框
   - registerDatetime → Date文本框

### 4.3 返回功能（Back按钮）
**功能说明**：用户点击Back按钮返回到前画面，并保留搜索条件

**操作步骤**：
1. 用户点击Back按钮
2. 保存当前页面的搜索条件到state或sessionStorage中
3. 返回到/ExistingHDocVariables页面
4. 前画面检测到返回标志，从state或sessionStorage中读取搜索条件
5. 自动填充到对应的输入字段中

### 4.4 打印功能（Print按钮）
**功能说明**：用户点击Print按钮打印当前的搜索结果列表

**操作步骤**：
1. 用户点击Print按钮
2. 调用浏览器原生window.print()方法
3. 浏览器打开打印预览对话框
4. 用户选择打印机并执行打印
5. 打印内容包括页面标题、DataTable中的所有数据行、Count字段的统计信息

### 4.5 Down按钮
Down按钮仅实装样式，不实装机能。

### 4.6 导出CSV功能（Excel按钮）
**功能说明**：用户点击Excel按钮导出当前搜索结果列表为CSV文件

**操作步骤**：
1. 用户点击Excel按钮
2. 系统调用导出API或前端生成CSV
3. 设置响应头Content-Type为text/csv
4. 设置Content-Disposition为attachment
5. 浏览器触发文件下载
6. 文件名建议格式：HDOC_Variables_YYYYMMDD.csv

### 4.7 用户链接跳转功能
**功能说明**：用户点击Created by user列中的链接，跳转到EDB User View页面查看用户详细信息

**操作步骤**：
1. 用户在DataTable中找到Created by user列
2. 该列显示为蓝色可点击链接
3. 用户点击链接
4. 获取该行记录的registerUser字段值
5. 使用React Router navigate函数跳转到/EDBUserView/:username路由
6. 传递用户名作为路由参数
7. EDB User View页面从路由参数中获取用户名，调用API获取该用户的详细信息并显示

## 6. 接口定义 (API Specification)

### 6.1 UD11HdocvariablesApi - UD11Search方法
**功能**：根据搜索条件查询变量定义列表

**Method**：POST

**Endpoint**：/api/ud08/search（具体路径需根据实际API定义）

**Request**：
```json
{
  "variable": "VAR001",
  "type": "VDA",
  "description": ""
}

**Response Success (200)**：
```json
[
  {
    "variable": "VAR001",
    "type": "VDA",
    "description": "Test variable description",
    "userid": "admin",
    "registerDatetime": "2022-12-02 05:11:45"
  },
  {
    "variable": "VAR002",
    "type": "User Defined",
    "description": "Another variable",
    "userid": "user1",
    "registerDatetime": "2022-12-03 10:20:30"
  }
]

**Response Error (500)**：
```json
{
  "message": "Internal server error"
}
```

## 7. 异常处理 (Exception Handling)

| 异常场景 | 处理方式 | Message显示内容 |
|---------|---------|----------------|
| 网络连接失败 | 捕获网络异常，显示通用错误消息 | "System error. Please contact administrator." |
| API超时 | 设置超时时间（建议10秒），超时后显示错误 | "System error. Please contact administrator." |
| UD11Search返回空列表 | 显示零结果消息 | "Number of lines found: 0" |
| UD11Search返回500 | 显示系统错误消息 | "System error. Please contact administrator." |
| JSON解析失败 | 捕获解析异常，显示系统错误 | "System error. Please contact administrator." |
| 未预期的JavaScript错误 | 使用try-catch包裹关键代码，记录错误日志 | "System error. Please contact administrator." |
| 用户未登录 | 检查会话状态，跳转到登录页面 | "Please login first" |
| 未选择记录点击Select | 显示选择提示消息 | "Please select a record." |
| Down按钮 | 仅实装样式，不实装机能 | - |
