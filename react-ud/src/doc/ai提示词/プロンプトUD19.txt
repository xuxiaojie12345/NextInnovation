## 2. 背景 (Background)
本模块的核心功能和目标：提供用户搜索功能，支持通过Userid、User、Market等条件搜索用户，并可按权限类型（Not set、Rule Admin、Template Admin）过滤搜索结果。从HDOC_USER_INFOR表获取用户信息，从HDOC_MARKET_AUTH表获取用户市场权限

面向的用户群体：系统管理员、需要查询和管理用户信息的业务人员

用户体验方面的考虑：提供多种搜索条件组合；清晰的搜索结果展示；显示搜索结果数量

安全性或特殊要求：需要用户登录认证

## 4. 功能描述 (Functional Description)

### 4.1 页面初始化
功能说明：页面加载时获取Market下拉列表数据
操作步骤：
1. 页面加载完成后，调用`UD19SearchResultListApi`的`UD19SelectMarketMaster`方法（operation=GET_MARKET_LIST）
2. 从MARKET_MASTER表获取所有Market数据
3. 填充到Market下拉列表中
4. 清空其他输入字段
5. 单选按钮组默认不选中任何选项

### 4.2 通过Userid搜索
功能说明：输入Userid后点击Search按钮，从数据库检索用户信息
操作步骤：
1. 用户在Userid输入框中输入用户ID（半角英数字，最大10字符）
2. 用户点击Search按钮
3. 调用`UD19SearchResultListApi`的`UD19SearchHdoc`方法（operation=SEARCH_USER），传递参数serid
4. 后台接收serid，以serid对应的值作为关联查询的条件（INNER JOIN），从HDOC_USER_INFOR（取得项目 userid、username）和HDOC_MARKET_AUTH（market）使用动态SQL，将参数serid对应的值作为WHERE条件（userid = serid）进行检索
5. 在DataTable中显示搜索结果（Userid、User、Market），在COUNT字段显示搜索结果数量

### 4.3 通过User搜索
功能说明：输入User后点击Search按钮，从数据库检索用户信息
操作步骤：
1. 用户在User输入框中输入用户名（半角英数字，最大32字符）
2. 用户点击Search按钮
3. 调用`UD19SearchResultListApi`的`UD19SearchHdoc`方法（operation=SEARCH_USER），传递参数user
4. 后台接收user，通过user检索取得HDOC_USER_INFOR表中对应的userid，将取得的userid作为关联查询的条件（INNER JOIN），从HDOC_USER_INFOR（取得项目 userid、username）和HDOC_MARKET_AUTH（market）使用动态SQL，将取得的userid作为WHERE条件进行检索
5. 在DataTable中显示搜索结果（Userid、User、Market），在COUNT字段显示搜索结果数量

### 4.4 Not set选项搜索
功能说明：选择Not set单选按钮后点击Search，搜索所有用户
操作步骤：
1. 用户选择Not set单选按钮
2. 用户点击Search按钮
3. 调用`UD19SearchResultListApi`的`UD19SearchHdoc`方法（operation=SEARCH_USER），查询HDOC_MARKET_AUTH内连接HDOC_USER_INFOR（INNER JOIN），userid作为关联条件
4. 从HDOC_USER_INFOR获取userid、username，从HDOC_MARKET_AUTH获取market
5. 在DataTable中显示所有用户的搜索结果
6. 在COUNT字段显示总记录数

### 4.5 Rule选项搜索
功能说明：选择Rule单选按钮后点击Search，搜索具有Rule Admin权限的用户
操作步骤：
1. 用户选择Rule单选按钮
2. 用户点击Search按钮
3. 调用`UD19SearchResultListApi`的`UD19SearchHdoc`方法（operation=SEARCH_USER），从HDOC_USER_INFOR（取得项目 userid、username）、HDOC_MARKET_AUTH（market）使用动态SQL，将参数Rule和选择的market作为WHERE条件进行检索
4. 在DataTable中显示搜索结果
5. 在COUNT字段显示记录数

### 4.6 Template选项搜索
功能说明：选择Template单选按钮后点击Search，搜索具有Template Admin权限的用户
操作步骤：
1. 用户选择Template单选按钮
2. 用户点击Search按钮
3. 调用`UD19SearchResultListApi`的`UD19SearchHdoc`方法（operation=SEARCH_USER），从HDOC_USER_INFOR（取得项目 userid、username）、HDOC_MARKET_AUTH（market）使用动态SQL，将参数Template和选择的market作为WHERE条件进行检索
4. 在DataTable中显示搜索结果
5. 在COUNT字段显示记录数

### 4.7 组合条件搜索
功能说明：支持多个搜索条件组合使用
操作步骤：
1. 用户可以同时输入Userid/User、选择Market、选择权限类型
2. 点击Search按钮后，将所有条件传递给API
3. API根据所有条件进行过滤查询
4. 返回符合条件的用户列表

## 6. 接口定义 (API Specification)

### UD19SearchResultListApi

统一API名称空间，包含以下方法：**UD19SelectMarketMaster**（市场列表查询）、**UD19SearchHdoc**（用户搜索）。

---

### 6.1 UD19SelectMarketMaster - 市场列表查询

**功能**：获取所有可用市场列表，用于填充Market下拉列表

**Method**：POST

**Endpoint**：/api/ud19/UD19SearchResultListApi

**Request**：
```json
{
  "operation": "GET_MARKET_LIST"
}
```

**Response Success (200)**：
```json
{
  "code": 200,
  "message": "success",
  "data": [
    { "market": "AUS", "description": "Australia" },
    { "market": "USA", "description": "United States" }
  ]
}
```

**Response Error (500)**：
```json
{
  "code": 500,
  "message": "Internal server error",
  "data": null
}
```

### 6.2 UD19SearchHdoc - 用户搜索

**功能**：根据条件搜索用户，支持Userid、User、权限类型（Rule/Template）及Market组合查询

**Method**：POST

**Endpoint**：/api/ud19/UD19SearchResultListApi

**Request**：
```json
{
  "operation": "SEARCH_USER",
  "serid": "string (可选，最大10字符，半角英数字)",
  "user": "string (可选，最大32字符，半角英数字)",
  "market": "string (可选)",
  "type": "string (可选，RULE_ADMIN/TEMPLATE_ADMIN)"
}
```

**Response Success (200)**：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "count": 5,
    "users": [
      {
        "userid": "USER001",
        "user": "John Smith",
        "market": "AUS"
      },
      {
        "userid": "USER002",
        "user": "Jane Doe",
        "market": "USA"
      }
    ]
  }
}
```

**Response Error (500)**：
```json
{
  "code": 500,
  "message": "Internal server error",
  "data": null
}
```
```

Response Error (500)
```json
{
"code": 500,
"message": "查询失败，请稍后重试"
}
```

## 7. 异常处理 (Exception Handling)

| 异常场景 | 处理方式 | Message显示内容 |
|---------|---------|----------------|
| UD19SearchResultListApi网络错误 | 捕获异常，显示友好提示 | 网络连接失败，请稍后重试 |
| UD19SearchResultListApi超时 | 设置超时时间，超时后提示 | 请求超时，请检查网络连接 |
| UD19SearchResultListApi数据库异常 | 记录日志，返回通用错误 | 系统异常，请联系管理员 |
| 用户不存在 | 显示提示信息 | 未找到该用户 |
| 无匹配记录 | 显示空结果 | 未找到符合条件的用户 |
| 权限不足 | 检查用户登录状态 | 请先登录后再操作 |
