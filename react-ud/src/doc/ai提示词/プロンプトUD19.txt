## 2. 背景 (Background)

### 核心功能和目标
本模块用于搜索和展示HDoc系统用户信息。用户可以通过多种条件（Userid、User、Market、权限类型）进行组合搜索，查看用户的详细信息包括Userid、用户名和关联的Market。该功能主要用于用户管理和权限查询，帮助管理员快速定位特定用户及其权限配置。

### 面向的用户群体
- 系统管理员
- 具有用户管理权限的业务人员
- 需要查询用户信息的授权用户

### 用户体验方面的考虑
- 提供多种搜索条件组合，支持灵活查询
- 搜索结果以表格形式清晰展示
- Market下拉列表默认显示常用选项（-EU）
- 实时显示搜索结果数量
- 支持双向搜索（通过Userid查User，或通过User查Userid）

### 安全性或特殊要求
- 需要从Saviynt系统获取用户信息（通过AuthenticationApi）
- 需要从多个数据库表获取权限信息
- 支持按权限类型过滤（Rule Admin、Template Admin等）
- 所有用户数据均为只读展示

## 4. 功能描述 (Functional Description)

### 4.1 页面初始化

**功能说明**: 页面加载时自动获取Market列表并初始化界面

**操作步骤**:
1. 页面加载触发初始化事件
2. 调用后端API `UD08GetMarketListApi`，从MARKET_MASTER表获取所有Market列表
3. 将Market列表填充到Market下拉列表中
4. 设置Market下拉列表默认值为'-EU'
5. 设置RadioBox默认状态：Not set选中，Rule和Template未选中
6. 清空Userid和User输入框
7. 初始化DataTable为空状态
8. COUNT显示为0

**结果反馈**: 
- 成功：Market下拉列表正确填充，默认值为'-EU'
- 失败：若获取Market列表失败，显示错误提示"获取Market列表失败"

### 4.2 Userid搜索

**功能说明**: 用户输入Userid后点击Search按钮，查询该用户的详细信息

**操作步骤**:
1. 用户在Userid输入框中输入用户ID（半角英数字，最大10字符）
2. 用户可选择Market下拉列表（可选）
3. 用户选择RadioBox（Not set/Rule/Template，可选）
4. 用户点击Search按钮
5. 系统执行前端校验：
   - 检查Userid是否为空
   - 检查Userid格式是否正确（半角英数字）
   - 检查Userid长度是否超过10字符
6. 调用后端API `UD08SearchByUseridApi`，传入Userid、Market、权限类型参数
7. API内部逻辑：
   - 调用AuthenticationApi从Saviynt系统获取对应的User信息
   - 从HDOC_FUNCTION_AUTH表查询该Userid的功能权限
   - 从HDOC_MARKET_AUTH表查询该Userid的Market权限
   - 根据选择的权限类型过滤结果（若选择了Rule或Template）
   - 根据选择的Market过滤结果（若选择了具体Market）
8. 将查询结果填充到DataTable中
9. 更新COUNT显示搜索结果数量

**结果反馈**: 
- 成功：DataTable显示搜索结果，COUNT显示记录数
- 失败：
  - Userid不存在：显示"Userid XXX不存在"
  - 无匹配结果：显示"未找到匹配的用户"
  - 其他错误：显示具体错误消息

### 4.3 User搜索

**开始**: 用户点击Search按钮（Userid有值）

**前置处理**: 
- 获取Userid、Market、权限类型参数
- 去除Userid首尾空格，转换为大写

**空值校验 (Frontend Check)**:
- 若Userid为空或仅包含空格：
  - 设置Message = "Userid不能为空"
  - 终止流程
- 若Userid包含非半角英数字字符：
  - 设置Message = "Userid只能包含半角英数字"
  - 终止流程
- 若Userid长度超过10字符：
  - 设置Message = "Userid长度不能超过10字符"
  - 终止流程

**API调用 (Backend Check)**:
- 调用`UD08SearchByUseridApi`
- 请求参数：
  ```json
  {
    "userid": "SWE",
    "market": "-EU",
    "permissionType": "NOT_SET"
  }
  ```
- API内部逻辑：
  1. 调用AuthenticationApi从Saviynt系统获取User信息

     - NOT_SET：不过滤

  5. 根据market过滤（若market不为空）：
     - 仅保留包含指定Market的记录
  6. 组装结果列表

**结果处理**:
- 成功：
  - 将结果填充到DataTable
  - 更新COUNT显示记录数
  - 若无结果：显示"未找到匹配的用户"

## 6. 接口定义 (API Specification)

### 6.1 UD08GetMarketListApi

**功能**: 获取Market列表

**Method**: GET

**Endpoint**: `/api/ud08/market-list`

**Request**: 无

**Response Success (200)**:
```json
{
  "code": 200,
  "message": "success",
  "data": [
    "-EU",
    "-UD",
    "1AD",
    "1CZ",
    "1ES",
    "1IT",
    "1PO",
    "1PT",
    "1RU",
    "1SE"
  ]
}
```

**Response Error (500)**:
```json
{
  "code": 500,
  "message": "获取Market列表失败",
  "data": null
}
```

### 6.2 UD08SearchByUseridApi

**功能**: 根据Userid搜索用户

**Method**: POST

**Endpoint**: `/api/ud08/search-by-userid`

**Request Body**:
```json
{
  "userid": "SWE",
  "market": "-EU",
  "permissionType": "NOT_SET"
}
```

**参数说明**:
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| userid | String | Y | 用户ID，最大10字符 |
| market | String | N | Market代码，若为空则不过滤 |
| permissionType | String | Y | 权限类型：NOT_SET/RULE/TEMPLATE |

**Response Success (200)**:
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "count": 2,
    "users": [
      {
        "userid": "SWE",
        "user": "Kurt Bjork",
        "market": "-EU,1AD,1CZ"
      },
      {
        "userid": "e2090ru",
        "user": "Ivanova Anna",
        "market": "-EU,1RU"
      }
    ]
  }
}
```

**Response Error (400/500)**:
```json
{
  "code": 400,
  "message": "Userid SWE不存在",
  "data": null
}
```

### 6.3 UD08SearchByUserApi

**功能**: 根据User搜索用户

**Method**: POST

**Endpoint**: `/api/ud08/search-by-user`

**Request Body**:
```json
{
  "user": "Kurt Bjork",
  "market": "-EU",
  "permissionType": "NOT_SET"
}
```

**参数说明**:
| 参数名 | 类型 | 必填 | 说明 |

```json
    "users": [
      {
        "userid": "SWE",

        "market": "-EU,1AD,1CZ"

    ]
  }
}
```

```json
{
  "code": 400,
  "message": "User Kurt Bjork不存在",
```

## 7. 异常处理 (Exception Handling)

| 异常场景 | 处理方式 | Message显示内容 |
|---------|---------|----------------|
| Userid为空 | 前端校验拦截，不发起API请求 | "Userid不能为空" |
| Userid格式错误 | 前端校验拦截，不发起API请求 | "Userid只能包含半角英数字" |
| Userid长度超限 | 前端校验拦截，不发起API请求 | "Userid长度不能超过10字符" |
| User为空 | 前端校验拦截，不发起API请求 | "User不能为空" |
| User格式错误 | 前端校验拦截，不发起API请求 | "User只能包含半角英数字" |
| User长度超限 | 前端校验拦截，不发起API请求 | "User长度不能超过32字符" |
| Userid在Saviynt中不存在 | API返回400错误，前端显示错误消息 | "Userid XXX不存在" |
| User在Saviynt中不存在 | API返回400错误，前端显示错误消息 | "User XXX不存在" |
| 无匹配结果 | API返回成功但count=0，前端显示提示 | "未找到匹配的用户" |
| 无Rule Admin用户 | API返回警告，前端显示提示 | "未找到Rule Admin权限的用户" |
| 无Template Admin用户 | API返回警告，前端显示提示 | "未找到Template Admin权限的用户" |
| 获取Market列表失败 | API返回500错误，前端显示错误消息 | "获取Market列表失败" |
| Saviynt系统连接异常 | API返回500错误，前端显示通用错误消息 | "Saviynt系统连接失败，请稍后重试" |
| 数据库连接异常 | API返回500错误，前端显示通用错误消息 | "系统错误，请稍后重试" |
| API超时 | 前端捕获超时异常，显示超时提示 | "请求超时，请检查网络连接后重试" |
| 网络异常 | 前端捕获网络异常，显示网络错误提示 | "网络连接失败，请检查网络设置" |
