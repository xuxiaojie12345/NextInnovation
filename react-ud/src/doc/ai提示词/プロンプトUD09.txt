## 1. 基本信息
- **模块名称**：HomologationVariablesResultListPage
- **文档编号**: DES-HomologationVariablesResultListPage-001

## 2. 背景 (Background)

### 核心功能和目标
本模块用于显示Homologation Variables页面的搜索结果列表，主要功能包括：
- 根据前画面传递的搜索条件显示匹配的变量规则列表
- 支持选择单条记录并返回前画面
- 支持批量删除选中的记录
- 支持打印搜索结果
- 支持返回前画面并保留搜索条件
- 显示搜索结果总数

### 面向的用户群体
需要查看和管理认证变量的授权用户，如系统管理员、质量管理人员等

### 用户体验考虑
- 清晰的数据表格展示
- 便捷的记录选择和操作功能
- 明确的搜索结果计数显示
- 支持批量删除操作

### 安全性要求
- 需要用户登录认证后才能访问
- 删除操作需要确认或权限控制
- 支持HTTPS安全传输

## 4. 功能描述 (Functional Description)

### 4.1 页面初始化功能
**功能说明**：页面加载时接收前画面传递的搜索条件，调用API获取并显示搜索结果列表

**操作步骤**：
1. 页面加载时，从URL参数或state中获取前画面传递的搜索条件
2. 调用UD08Search API，传递搜索条件作为请求参数
3. API返回成功后，将数据显示到DataTable中
4. 计算并显示搜索结果总数到Count字段
5. 若发生错误，显示错误消息

### 4.2 选择记录功能
**功能说明**：用户选择表格中的某条记录后点击Select按钮，返回到前画面并自动填充选中记录的内容

**操作步骤**：
1. 用户在DataTable中选择一条记录（通过单选或多选方式）
2. 用户点击Select按钮
3. 系统将选中记录的完整数据保存到state或sessionStorage
4. 使用React Router导航回/HomologationVariables页面
5. 前画面从state或sessionStorage中读取选中的数据
6. 前画面自动将数据显示到对应的输入字段中

### 4.3 返回功能
**功能说明**：用户点击Back按钮返回到前画面，并保留搜索条件

**操作步骤**：
1. 用户点击Back按钮
2. 系统将当前搜索条件保存到state或sessionStorage
3. 使用React Router导航回/HomologationVariables页面
4. 前画面从state或sessionStorage中读取搜索条件
5. 前画面自动将搜索条件显示到对应的输入字段中

### 4.4 打印功能
**功能说明**：用户点击Print按钮打印当前的搜索结果列表

**操作步骤**：
1. 用户点击Print按钮
2. 系统触发浏览器打印功能
3. 调用window.print()方法
4. 浏览器打开打印预览对话框
5. 用户选择打印机并执行打印

### 4.5 批量删除功能
**功能说明**：用户选择多条记录后点击Delete selected按钮，批量删除选中的记录

**操作步骤**：
1. 用户在DataTable中选择一条或多条记录（通过复选框）
2. 用户点击Delete selected按钮
3. 系统获取所有选中记录的主键信息（Product class、Number、Market）
4. 调用UD09DeleteHdocuserdefinedrules API，传递选中记录的主键列表
5. API执行删除操作
6. 根据API返回结果显示相应消息
7. 成功：显示成功消息，重新加载列表数据
8. 失败：显示错误消息，保持当前列表不变

### 4.6 用户链接跳转功能
**功能说明**：用户点击Created by user列中的链接，跳转到EDB User View页面查看用户详细信息

**操作步骤**：
1. 用户在DataTable中找到Created by user列
2. 该列显示为蓝色可点击链接
3. 用户点击链接
4. 系统跳转到/EDBUserView/:username路由
5. 传递用户名作为路由参数
6. EDB User View页面显示该用户的详细信息

## 5. 业务逻辑与校验规则 (Business Logic & Checks)

### 5.1 处理流程

#### 5.1.1 页面初始化流程
**开始**：页面加载

**处理步骤**：
- 从URL参数或state中获取搜索条件
- 搜索条件可能包含：Product class、Number、Market、Variable等字段
- 调用UD08Search API（POST方法）
- 传递参数：搜索条件对象
- 等待API响应

**结果处理**：
- **成功**：
  - 解析API返回的数据列表
  - 将数据显示到DataTable中
  - 计算记录总数
  - 更新Count字段显示"Number of lines found: XXX"
  - 清空错误消息区域
  
- **失败（无匹配数据）**：
  - DataTable显示为空
  - Count字段显示"Number of lines found: 0"
  - 可选择显示提示信息"No records found"
  
- **服务器错误**：
  - 在错误消息区域显示"System error. Please contact administrator."
  - DataTable保持为空

#### 5.1.2 选择记录流程
**开始**：用户点击Select按钮

**前置处理**：
- 检查是否有选中的记录
- 若无选中记录，显示错误消息

**处理步骤**：
- 获取选中记录的完整数据
- 将数据存储到state或sessionStorage中
- 使用React Router navigate函数返回/HomologationVariables页面
- 可选：传递标志位表示是从选择操作返回

**前画面处理**：
- 前画面检测到返回标志
- 从state或sessionStorage中读取选中的数据
- 自动填充到对应的输入字段中

#### 5.1.3 返回流程
**开始**：用户点击Back按钮

**处理步骤**：
- 获取当前页面的搜索条件
- 将搜索条件存储到state或sessionStorage中
- 使用React Router navigate函数返回/HomologationVariables页面
- 可选：传递标志位表示是从返回操作回来

**前画面处理**：
- 前画面检测到返回标志
- 从state或sessionStorage中读取搜索条件
- 自动填充到对应的输入字段中

#### 5.1.4 打印流程
**开始**：用户点击Print按钮

**处理步骤**：
- 调用window.print()方法
- 浏览器打开打印预览对话框
- 用户选择打印机和执行打印
- 打印内容包括DataTable中的所有数据和Count信息

#### 5.1.5 批量删除流程
**开始**：用户点击Delete selected按钮

**前置处理**：
- 检查是否有选中的记录
- 若无选中记录，显示错误消息"Please select at least one record to delete."
- 终止流程

**处理步骤**：
- 获取所有选中记录的主键信息（Product class、Number、Market）
- 构建删除请求参数数组
- 调用UD09DeleteHdocuserdefinedrules API（POST方法）
- 传递参数：选中记录的主键列表
- 等待API响应

**后端处理**：
- 遍历主键列表，逐条删除记录
- 若某条记录不存在，跳过或删除失败
- 返回删除成功的记录数和失败的记录数

**结果处理**：
- **成功**：
  - 显示成功消息"X records deleted successfully."
  - 重新调用UD08Search API刷新列表数据
  - 更新Count字段显示新的记录数
  
- **部分成功**：
  - 显示消息"X records deleted, Y records failed."
  - 重新调用UD08Search API刷新列表数据
  
- **全部失败**：
  - 显示错误消息"Failed to delete records. Please try again."
  - 保持当前列表不变
  
- **服务器错误**：
  - 显示错误消息"System error. Please contact administrator."
  - 保持当前列表不变

### 5.2 校验详细规格表

| No. | 检查时机 | 检查对象 | 检查条件 | 错误消息 | 动作 |
|-----|---------|---------|---------|---------|------|

| 5 | UD09DeleteHdocuserdefinedrules API调用后 | 删除操作 | 部分记录删除失败 | "X records deleted, Y records failed." | 显示消息，刷新列表 |
| 6 | UD09DeleteHdocuserdefinedrules API调用后 | 删除操作 | 全部记录删除失败 | "Failed to delete records. Please try again." | 显示错误消息，保持列表不变 |

## 6. 接口定义 (API Specification)

### 6.1 UD09DeleteHdocuserdefinedrulesApi
**功能**：根据搜索条件查询用户自定义规则列表

**Method**：POST

**Endpoint**：/api/ud09DeleteHdocuserdefinedrules/search

**Request**：
```json
将画面项目产品类别、编号、市场、变量（模糊查询）、值（模糊查询）、变体字符串1（模糊查询）、变体字符串2（模糊查询）、备注（模糊查询）、Add（模糊查询）、Delete（模糊查询）、创建用户（模糊查询）、日期（模糊查询）请求参数，以JSON格式发送至后端服务。

```

**请求参数说明**：
- productClass：产品类别，字符串类型，可选
- number：编号，字符串类型，可选
- market：市场，字符串类型，可选
- variable：变量名，字符串类型，可选
- 所有字段均为可选，未提供的字段不参与筛选

**Response Success (200)**：
```json
{
            "code": 200,
            "msg": "搜索用户定义规则成功",
            "data": [
                {
                    "pc": "xx",
                    "num": 1,
                    "market": "xxx",
                    "val": "xxx",
                    "vs": "xxx",
                    "vs2": "xxx",
                    "addDate": "xxx",
                    "deleteDate": "xxx",
                    "registerUser": "xxx",
                    "registerDatetime": "xxx"
                }
            ]
        }```

**成功响应参数说明**：
- pc：产品类别，字符串类型，对应HDOC_USER_DEFINED_RULES表的PC字段
- num：编号，字符串类型，对应HDOC_USER_DEFINED_RULES表的NUM字段
- market：市场，字符串类型，对应HDOC_USER_DEFINED_RULES表的MARKET字段
- variable：变量名，字符串类型，对应HDOC_USER_DEFINED_RULES表的VARIABLE字段
- val：变量值，字符串类型，对应HDOC_USER_DEFINED_RULES表的VAL字段
- vs：变体字符串1，字符串类型，对应HDOC_USER_DEFINED_RULES表的VS字段
- vs2：变体字符串2，字符串类型，对应HDOC_USER_DEFINED_RULES表的VS2字段
- addDate：添加日期，字符串类型，对应HDOC_USER_DEFINED_RULES表的ADD_DATE字段
- deleteDate：删除日期，字符串类型，对应HDOC_USER_DEFINED_RULES表的DELETE_DATE字段
- registerUser：注册用户，字符串类型，对应HDOC_USER_DEFINED_RULES表的REGISTER_USER字段
- registerDatetime：注册日期时间，字符串类型，对应HDOC_USER_DEFINED_RULES表的REGISTER_DATETIME字段

**排序规则**：
- 默认按pc、market、num三个字段升序排序

**Response Error (500)**：
```json
{
  "message": "Internal server error"
}
```

### 6.2 UD09DeleteHdocuserdefinedrules
**功能**：批量删除用户自定义规则记录

**Method**：DELETE

**Endpoint**：/api/ud09DeleteHdocuserdefinedrules/deleteSelected

**Request**：
```json
[
  {
    "productClass": "PC01",
    "number": "1234567890",
    "market": "DE"
  },
  {
    "productClass": "PC02",
    "number": "0987654321",
    "market": "FR"
  }
]
```

**请求参数说明**：
- 请求体为JSON数组，每个元素包含一条记录的主键信息
- productClass：产品类别，字符串类型，必填
- number：编号，字符串类型，必填
- market：市场，字符串类型，必填

**Response Success (200)**：
```json
{
            "code": 200,
            "msg": "删除用户定义规则成功",
            "data": {
                "pc": "xx",
                "num": 1,
                "market": "xxx"
            }
        }```

**成功响应参数说明**：
- success：布尔类型，表示操作是否成功
- deletedCount：整数类型，成功删除的记录数
- failedCount：整数类型，删除失败的记录数
- message：消息内容，字符串类型
```

**Response Error (500)**：
```json
{
  "success": false,
  "message": "Internal server error"
}
```
