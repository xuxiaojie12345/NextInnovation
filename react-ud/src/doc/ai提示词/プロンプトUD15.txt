## 2. 背景 (Background)

### 核心功能和目标
本模块用于查看和管理车辆底盘相关信息，主要功能包括：
- 输入底盘号查询VIN Plate详细信息
- 更新底盘状态为"0"（新規追加）
- 更新底盘状态为"1"（xml doc 作成済み）
- 将底盘状态更新为"0"并设置TYPE为"1"（basic）
- 将底盘状态更新为"0"并设置TYPE为"2"（ADVANCED with weights）

### 面向的用户群体
需要管理和维护车辆底盘信息的授权用户，如数据管理员、质量管理人员等

### 用户体验考虑
- 简洁的操作界面，五个功能按钮清晰明了
- 明确的错误提示信息
- 快速的状态更新操作

### 底盘号格式要求
- 输入格式为`系列号-编号`（使用中划线`-`分隔），例：`JPCT-1234567890`
- 后端通过`-`拆分得到SERIE和CHNR分别查询数据库

### 安全性要求
- 底盘号必须存在于系统中才能执行操作
- 防止非法字符输入
- 支持HTTPS安全传输

## 4. 功能描述 (Functional Description)

### 4.1 查看VIN Plate信息功能
**功能说明**：用户输入底盘号后点击View Info按钮，系统查询并显示VIN Plate详细信息

**操作步骤**：
1. 用户在Chassis number字段输入底盘号
2. 用户点击View Info按钮
3. 系统调用 **UD15SelecthdocsenddatavinplateApi** 的 **UD15ViewInfo** 方法（operation=viewInfo）
4. 若底盘号存在，将API返回的TYPE、STATUS、MSG、REGISTER_DATETIME、DOC_READY、DOC_SENT、XML_DOC分别显示到对应的Label控件
5. 若底盘号不存在，显示警告消息"Chassis number XXX not found."，清空各显示字段

**功能**：根据底盘号查询VIN Plate详细信息

**Endpoint**：/api/ud15/UD15SelecthdocsenddatavinplateApi

```json
  "operation": "viewInfo"
}
```
