## 2. 背景 (Background)
本模块用于管理HDoc系统中的变量（Variables）配置，支持对变量的查询、新增、修改和删除操作。  
核心功能包括：
- 根据Variable、Type、Description等条件进行搜索
- 显示变量的创建人与时间
- 支持新增、更新、删除变量记录
- 提供导出CSV文件功能

面向用户群体为系统管理员、配置工程师及合规审核人员。  
用户体验方面需保证输入字段清晰、操作按钮明确、错误提示及时。  
安全性要求：仅允许授权用户执行增删改操作，所有变更需记录操作人与时间。

## 4. 功能描述 (Functional Description)

### 4.1 初始显示
**功能说明**：加载Existing HDoc Variables画面的搜索条件界面，展示所有可输入字段和操作按钮。  
**操作步骤**：
1. 页面加载时初始化所有字段为空。
2. Type下拉列表默认显示“VDA”和“User Defined”两个选项。
3. 所有文本框默认为空，按钮处于可用状态。

---

### 4.2 搜索功能
**功能说明**：根据用户输入的Variable、Type、Description条件执行搜索。  
**操作步骤**：
1. 用户在对应字段中输入或选择条件。
2. 点击「Search」按钮。
3. 若成功，跳转至“Existing HDoc Variables”搜索结果页面。
4. 若失败，显示错误消息：“系统内部错误，请联系管理员”。

---

### 4.3 清除功能
**功能说明**：清除所有已输入的内容。  
**操作步骤**：
1. 用户点击「Clear」按钮。
2. 所有输入框内容被清空。
3. 下拉菜单恢复初始状态。

---

### 4.4 返回功能
**功能说明**：返回前画面。  
**操作步骤**：
1. 用户点击「Back」按钮。
2. 页面跳转至前画面。

---

### 4.5 新增功能
**功能说明**：将新记录添加到HDOC_VARIABLES表中。  
**操作步骤**：
1. 用户填写Variable字段（必填）。
2. 填写Type、Description等其他字段。
3. 点击「Add」按钮。
4. 系统校验输入内容：
   - 检查Variable是否已存在（主键冲突）
5. 若校验通过，调用 `UD10HdocvariablesApi` 接口执行插入操作。
6. 成功后显示提示：“记录添加成功”。
7. 失败则显示错误消息：“Variant already exists. Please enter the correct content”。

---

### 4.6 更新功能
**功能说明**：修改已有记录的信息。  
**操作步骤**：
1. 用户选择要修改的记录（可通过搜索获取）。
2. 修改相关字段内容。
3. 点击「Update」按钮。
4. 系统校验：
   - 检查该记录是否存在
5. 若校验通过，调用 `UD10HdocvariablesApi` 接口执行更新操作。
6. 成功后显示提示：“记录更新成功”。
7. 失败则显示错误消息：“Variant does not exist. Please enter the correct content”。

---

### 4.7 删除功能
**功能说明**：删除指定记录。  
**操作步骤**：
1. 用户选择要删除的记录。
2. 点击「Delete」按钮。
3. 系统校验该记录是否存在。
4. 若存在，调用 `UD10HdocvariablesApi` 接口执行删除操作。
5. 成功后显示提示：“记录删除成功”。
6. 失败则显示错误消息：“Variant does not exist. Please enter the correct content”。

---

### 4.8 导出Excel功能
**功能说明**：将当前搜索结果导出为CSV文件。  
**操作步骤**：
1. 用户点击「Excel」按钮。
2. 系统调用 `UD10HdocvariablesApi` 接口获取当前搜索结果。
3. 将数据转换为CSV格式并触发下载。
4. 文件名为“HDoc_Variables_YYYYMMDD.csv”。

## 5. 业务逻辑与校验规则 (Business Logic & Checks)

### 5.1 处理流程

#### 开始：页面加载触发
#### 前置处理：
- 初始化所有字段为空
- 设置Type下拉列表为固定值：“VDA”、“User Defined”

#### 空值校验等 (Frontend Check)：
- 若执行Add/Update/Delete操作时，Variable为空：
  - 设置Message = “Variable为必填项”
  - 终止流程
- 若Add操作时Variable已存在：
  - 设置Message = “Variant already exists. Please enter the correct content”
  - 终止流程
- 若Update/Delete操作时记录不存在：
  - 设置Message = “Variant does not exist. Please enter the correct content”
  - 终止流程

#### 5.1.2 API调用 (Backend Check)：
- 调用 `UD10HdocvariablesApi` 接口执行以下操作：
  - 搜索：GET /api/v1/ud10/hdoc-variables/search
  - 新增：POST /api/v1/ud10/hdoc-variables/add
  - 更新：PUT /api/v1/ud10/hdoc-variables/update
  - 删除：DELETE /api/v1/ud10/hdoc-variables/delete
  - 导出：GET /api/v1/ud10/hdoc-variables/export

#### 5.2 结果处理：
- 成功：显示对应操作成功消息，刷新页面或跳转
- 失败：显示错误消息，保持当前状态

### 5.3 校验详细规格表

| No. | 检查时机 | 检查对象 | 检查条件 | 错误消息 (Message Content) | 动作 |
|-----|---------|---------|---------|--------------------------|------|
| 1 | Add操作 | Variable | 已存在 | “Variant already exists. Please enter the correct content” | 终止流程 |
| 2 | Update操作 | Variable | 不存在 | “Variant does not exist. Please enter the correct content” | 终止流程 |
| 3 | Delete操作 | Variable | 不存在 | “Variant does not exist. Please enter the correct content” | 终止流程 |

## 6. 接口定义 (API Specification)

### UD10HdocvariablesApi
- **功能**：提供HDoc Variables的CRUD操作接口
- **Method**：GET/POST/PUT/DELETE
- **Endpoint**：/api/v1/ud10/hdoc-variables

#### Request [请求格式]

##### GET /search
```json
{
  "variable": "FTLI",
  "type": "User Defined",
  "description": "Front load index"
}

POST /add
{
  "variable": "FTLI",
  "type": "User Defined",
  "description": "Front load index",
  "createdByUser": "admin",
  "date": "2023-09-01"
}

PUT /update
{
  "variable": "FTLI",
  "type": "User Defined",
  "description": "Updated front load index",
  "createdByUser": "admin",
  "date": "2023-09-01"
}

DELETE /delete
{
  "variable": "FTLI"
}

GET /export
{
  "variable": "FTLI",
  "type": "User Defined"
}

Response Success (200)
{
  "success": true,
  "message": "Record added successfully"
}

Response Error (400)
{
  "error": "Validation failed",
  "message": "Variant already exists. Please enter the correct content"
}

Response Error (500)
{
  "error": "Internal Server Error",
  "message": "Failed to process request"
}
