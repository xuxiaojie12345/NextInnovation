## 2. 背景 (Background)

### 核心功能和目标
本模块用于管理用户的文档权限，主要功能包括：
- 输入用户ID查询用户信息和文档权限
- 验证用户ID是否存在于HDOC_FUNCTION_AUTH表中
- 从Saviynt系统获取用户名
- 从HDOC_DOCUMENT_LIST表获取文档列表
- 设置和更新用户的文档权限

### 面向的用户群体
需要管理用户文档权限的系统管理员

### 用户体验考虑
- 清晰的文档权限配置界面
- 明确的错误提示信息
- 支持快速查询和更新权限操作

### 安全性要求
- 用户ID必须存在于HDOC_FUNCTION_AUTH表中才能执行操作
- 防止未授权的文档权限修改
- 支持HTTPS安全传输

## 4. 功能描述 (Functional Description)

### 4.1 页面初始化功能
**功能说明**：页面加载时获取文档列表数据

**操作步骤**：
1. 页面加载时，调用`UD20GetDocumentListApi`的`UD20SelectHdocDocumentList`方法（GET `/api/ud20/UD20SelectHdocDocumentList`）获取文档列表
2. API返回成功后，将文档数据作为选项填充到Document下拉列表中
3. Document下拉列表显示当前用户的已选文档项
4. 页面以空白表单形式呈现，等待用户输入

### 4.2 查询用户信息功能
**功能说明**：用户输入UserID后点击User Info按钮，系统验证用户ID并查询用户信息和文档权限

**操作步骤**：
1. 用户在UserID字段输入用户ID（半角英数字）
2. 用户点击User Info按钮
3. 系统执行前端校验（必填项检查、字符格式检查）
4. 若前端校验通过，调用`UD18HDocUserDocAdministrationApi`的`UD18SelectHdocFunctionAuth`方法（operation=checkAuth）检查用户是否存在
5. 若用户不存在，显示错误消息"We didn't recognize the userid you entered. Please try again."，终止流程
6. 若用户存在，调用`UD18HDocUserDocAdministrationApi`的`UD18SelectHdocUserDoc`方法（operation=select）查询用户信息和文档权限
7. 从响应中获取用户名显示在User标签中
8. 从响应中获取文档权限数据，在Document下拉列表中选中对应的文档项

### 4.3 更新权限功能
**功能说明**：用户修改文档权限配置后点击Update按钮，系统先检查用户是否存在，存在则更新用户文档权限

**操作步骤**：
1. 用户在Document下拉列表中选择或取消选择文档项
2. 用户点击Update按钮
3. 系统执行前端校验（UserID必填检查、字符格式检查）
4. 若前端校验通过，调用`UD18HDocUserDocAdministrationApi`的`UD18SelectHdocFunctionAuth`方法（operation=checkAuth）检查用户是否存在
5. 若用户不存在：显示错误消息"We didn't recognize the userid you entered. Please try again."，终止流程
6. 若用户存在：先调用`UD18HDocUserDocAdministrationApi`的`UD18DeleteHdocUserDoc`方法（operation=delete）删除该用户现有的所有文档权限
7. 再调用`UD18HDocUserDocAdministrationApi`的`UD18CreateHdocUserDoc`方法（operation=create）创建新的文档权限
8. 更新成功后显示成功消息"Document permissions updated successfully."

## 5. 业务逻辑与校验规则 (Business Logic & Checks)

### 5.1 处理流程

#### 5.1.1 页面初始化流程
**开始**：页面加载

**处理步骤**：
- 调用`UD20GetDocumentListApi`的`UD20SelectHdocDocumentList`方法（GET `/api/ud20/UD20SelectHdocDocumentList`）获取文档列表
- 等待API响应
- **成功**：
  - 将所有文档类型作为选项填充到Document下拉列表中
- **失败**：
  - 显示错误消息"Failed to load document list. Please try again."

#### 5.1.2 User Info处理流程
**开始**：用户点击User Info按钮

**前置处理**：
- 获取UserID字段的当前值

**前端校验 (Frontend Check)**：
- 若UserID为空：
  - 设置Error message = "UserID is required."
  - 终止流程，不调用API
  
- 若UserID包含非半角英数字字符：
  - 设置Error message = "UserID must contain only alphanumeric characters."
  - 终止流程，不调用API

**后端校验 (Backend Check)**：
- 调用`UD18HDocUserDocAdministrationApi`的`UD18SelectHdocFunctionAuth`方法（operation=checkAuth），检查用户ID是否存在
- 若用户ID不存在：
  - 设置Error message = "We didn't recognize the userid you entered. Please try again."
  - Error message显示为Error级别
  - 终止流程，不进行后续操作
  
- 若用户ID存在：
  - 继续执行查询操作

**API调用**：
- 调用`UD18HDocUserDocAdministrationApi`的`UD18SelectHdocUserDoc`方法（operation=select）
- 请求参数包含userid
- 等待API响应

**结果处理**：
- **成功（用户ID存在）**：
  - 从响应中获取用户名，显示在User标签中
  - 从响应中获取文档权限列表
  - 在Document下拉列表中选中对应的文档项
  - 清空错误消息区域
  
- **失败（用户ID不存在）**：
  - 设置Error message = "We didn't recognize the userid you entered. Please try again."
  - Error message显示为Error级别
  - 清空User标签
  - 清空Document下拉列表选中值
  
- **服务器错误**：
  - 设置Error message = "System error. Please contact administrator."
  - Error message显示为Error级别
  - 保持当前页面

#### 5.1.3 Update处理流程
**开始**：用户点击Update按钮

**前置处理**：
- 获取UserID字段的当前值
- 获取Document下拉列表的当前选中值

**前端校验 (Frontend Check)**：
- 若UserID为空：
  - 设置Error message = "UserID is required."
  - 终止流程，不调用API
  
- 若UserID包含非半角英数字字符：
  - 设置Error message = "UserID must contain only alphanumeric characters."
  - 终止流程，不调用API

**存在性检查 (Backend Check)**：
- 调用`UD18HDocUserDocAdministrationApi`的`UD18SelectHdocFunctionAuth`方法（operation=checkAuth），检查用户ID是否存在
- 若用户ID不存在：
  - 设置Error message = "We didn't recognize the userid you entered. Please try again."
  - Error message显示为Error级别
  - 终止流程，不执行更新

**API调用 (Backend Check)**：
- 若存在性检查通过，先调用`UD18HDocUserDocAdministrationApi`的`UD18DeleteHdocUserDoc`方法（operation=delete）删除该用户现有的所有文档权限
- 再调用`UD18HDocUserDocAdministrationApi`的`UD18CreateHdocUserDoc`方法（operation=create）创建新的文档权限
- 请求参数包含userid和文档权限列表
- 等待API响应

**结果处理**：
- **成功**：
  - 将文档权限数据更新到HDOC_USER_DOC表
  - 显示成功消息"Document permissions updated successfully."
  - 清空错误消息区域
  
- **失败（用户ID不存在）**：
  - 设置Error message = "We didn't recognize the userid you entered. Please try again."
  - Error message显示为Error级别
  - 保持当前页面
  
- **服务器错误**：
  - 设置Error message = "System error. Please contact administrator."
  - Error message显示为Error级别
  - 保持当前页面

## 6. 接口定义 (API Specification)

### UD20GetDocumentListApi

#### UD20SelectHdocDocumentList - 文档类型列表查询

**功能**：获取文档类型列表

**Method**：GET

**Endpoint**：/api/ud20/UD20SelectHdocDocumentList

**Request**：无请求参数

**Response Success (200)**：
```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "doctype": "string",
      "description": "string"
    }
  ]
}
```

**Response Error (500)**：
```json
{
  "code": 500,
  "message": "Internal server error",
  "data": null
}
```

### UD18HDocUserDocAdministrationApi

统一API名称空间，包含以下方法：**UD18SelectHdocFunctionAuth**（功能权限存在性检查）、**UD18SelectHdocUserDoc**（用户文档权限查询）、**UD18DeleteHdocUserDoc**（用户文档权限删除）、**UD18CreateHdocUserDoc**（用户文档权限创建）。

---

### 6.1 UD18SelectHdocFunctionAuth - 功能权限存在性检查

**功能**：根据userId查询HDOC_FUNCTION_AUTH表，检查用户是否存在

**Method**：POST

**Endpoint**：/api/ud18/UD18HDocUserDocAdministrationApi

**Request**：
```json
{
  "userid": "string (Max 10, Required)",
  "operation": "checkAuth"
}
```

**Response Success (200) - 用户存在**：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "exists": true
  }
}
```

**Response Success (200) - 用户不存在**：
```json
{
  "code": 200,
  "message": "We didn't recognize the userid you entered. Please try again.",
  "data": {
    "exists": false
  }
}
```

**Response Error (500)**：
```json
{
  "code": 500,
  "message": "Internal server error",
  "data": null
}
```

### 6.2 UD18SelectHdocUserDoc - 用户文档权限查询

**功能**：根据userId查询用户信息和文档权限列表

**Method**：POST

**Endpoint**：/api/ud18/UD18HDocUserDocAdministrationApi

**Request**：
```json
{
  "userid": "string (Max 10, Required)",
  "operation": "select"
}
```

**Response Success (200)**：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "username": "string",
    "documentAuth": [
      {
        "doctype": "string"
      }
    ]
  }
}
```

**Response Error (500)**：
```json
{
  "code": 500,
  "message": "Internal server error",
  "data": null
}
```

### 6.3 UD18DeleteHdocUserDoc - 用户文档权限删除

**功能**：根据userId删除该用户的所有文档权限记录

**Method**：POST

**Endpoint**：/api/ud18/UD18HDocUserDocAdministrationApi


**Response Success (200)**：

```json
{
```
