## 2. 背景 (Background)
本模块用于管理HDoc系统的用户文档访问权限，支持查询用户信息并配置其可访问的文档列表。

**核心功能和目标**：
- 用户输入UserID查询用户基本信息（从Saviynt系统获取用户名）
- 验证UserID是否存在于HDOC_FUNCTION_AUTH表中（确保用户具有基本功能权限）
- 展示所有可用文档列表（从HDOC_DOCUMENT_LIST表获取）
- 自动勾选用户已授权的文档（从HDOC_USER_DOC表加载）
- 支持更新用户的文档访问权限配置

**面向的用户群体**：系统管理员、文档权限管理人员

**用户体验方面的考虑**：界面简洁清晰、文档列表易于浏览和选择、操作反馈及时

**安全性或特殊要求**：仅允许授权管理员执行权限配置操作，所有变更需记录日志；必须先验证用户存在于HDOC_FUNCTION_AUTH表中才能进行文档权限配置

## 4. 功能描述 (Functional Description)

### 4.1 初始显示
**功能说明**：加载HDoc User Doc Administration画面，展示UserID输入框和操作按钮,从HDOC_DOCUMENT_LIST表获取所有可用文档列表。

**操作步骤**：
1. 页面加载时初始化"UserID"输入框为空
2. "User"标签显示为空
3. Document多选列表初始为空或不显示任何选项
4. 所有操作按钮处于可用状态

### 4.2 用户信息查询功能（User Info）
**功能说明**：根据用户输入的UserID从Saviynt系统获取用户名，并加载该用户已有的文档权限配置。

**操作步骤**：
1. 用户在"UserID"输入框中输入UserID（如a420064）
2. 点击「User Info」按钮
3. 系统校验UserID是否为空：
   - 若为空：提示"请输入UserID"
   - 若不为空：调用API检查该UserID是否存在于HDOC_FUNCTION_AUTH表中
4. 若HDOC_FUNCTION_AUTH表中未找到该UserID：
   - 设置Message = "We didn't recognize the userid you entered. Please try again."
   - 终止流程
5. 若找到该UserID：
   - 调用AuthenticationApi从Saviynt系统获取用户名
   - 在"User"标签中显示用户名（如Jenna Wang）
   - 从HDOC_USER_DOC表查询该用户已授权的文档列表
   - 在Document多选列表中展示所有文档，并自动勾选已授权的文档

### 4.3 文档权限更新功能（Update）
**功能说明**：保存或更新用户的文档访问权限配置。

**操作步骤**：
1. 用户先通过User Info查询到目标用户
2. 在Document多选列表中勾选/取消勾选需要授权的文档
3. 点击「Update」按钮
4. 系统校验UserID是否存在于HDOC_FUNCTION_AUTH表中：
   - 若不存在：设置Message = "We didn't recognize the userid you entered. Please try again."
   - 若存在：调用API保存文档权限配置到HDOC_USER_DOC表
5. 成功后显示提示："文档权限更新成功"
6. 失败则显示错误消息："更新失败，请联系管理员"

## 5. 业务逻辑与校验规则 (Business Logic & Checks)

### 5.1 处理流程

**开始**：页面加载触发

**前置处理**：
- 初始化所有输入框为空
- Document多选列表初始化为空
- 从HDOC_DOCUMENT_LIST获取所有文档列表

**用户信息查询处理（User Info）**：
- 用户输入UserID并点击按钮
- 校验UserID是否为空
- 调用API检查HDOC_FUNCTION_AUTH表中是否存在该UserID
- 若不存在，报错"We didn't recognize the userid you entered. Please try again."
- 若存在：
  - 调用AuthenticationApi从Saviynt获取用户名
  - 从HDOC_USER_DOC获取该用户已授权的文档
  - 展示文档列表并自动勾选已授权项

**文档权限更新处理（Update）**：
- 用户必须先执行User Info查询到目标用户
- 在Document列表中勾选/取消勾选文档
- 点击Update按钮后调用API保存配置到HDOC_USER_DOC表
- 保存前先验证UserID存在于HDOC_FUNCTION_AUTH表中

**空值校验等 (Frontend Check)**：
- 若执行User Info时UserID为空：
  - 设置Message = "请输入UserID"
  - 终止流程
- 若执行Update操作前未查询到用户：
  - 设置Message = "请先查询用户信息"
  - 终止流程

**API调用 (Backend Check)**：
- 调用 `UD18HDocUserDocAdministrationApi` 接口执行查询和更新操作
- 调用 `AuthenticationApi` 接口从Saviynt获取用户名

### 5.2 结果处理
- **成功**：正常渲染文档权限配置或显示操作成功消息
- **失败**：显示对应错误消息

## 6. 接口定义 (API Specification)

### 6.1 AuthenticationApi
- **功能**：从Saviynt系统获取用户名
- **Method**：GET
- **Endpoint**：/api/auth/saviynt/user

**Request [请求格式]**：
```json
{
  "userId": "a420064"
}
```

**Response Success (200)**：
```json
{
  "success": true,
  "userName": "Jenna Wang"
}
```

### 6.2 UD18HDocUserDocAdministrationApi
- **功能**：提供HDoc用户文档权限管理的查询和更新接口
- **Method**：GET/POST
- **Endpoint**：/api/v1/ud18/hdoc-user-doc-admin
