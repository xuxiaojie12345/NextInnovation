4. 功能描述 (Functional Description)
  4.1 初期表示
    功能说明：画面加载时显示初始表单页面，包含所有输入控件和按钮。从Market Document Settings List返回时，显示检索的结果和条件。
    操作步骤：
      1. 画面加载
      2. 接收Market Document Settings List画面返回的结果和条件
      3. 渲染画面
  
  4.2 Search 功能
    功能说明：传递画面上的检索条件（可以一个多个或者空），跳转到Market Document Settings List画面
    操作步骤：
      1. 用户在表单中输入检索条件
      2. 用户点击Search按钮
      3. 系统获取画面中的检索条件（可以为空）
      4. 传递这些参数并跳转到Market Document Settings List画面 

  4.3 Back 功能
    功能说明：点击Back按钮返回到前一个页面（不携带选择数据）
    操作步骤：
      1. 用户点击Back按钮
      2. 返回到前一个页面

  4.4 Clear 功能
    功能说明：清除输入的检索条件内容
    操作步骤：
      1. 用户点击Clear按钮
      2. 清空表单检索条件

  4.5 Update Mode 功能
    功能说明：更新现有的市场文档信息
    操作步骤：
      1. 输入需要更新的市场文档信息
      2. 点击Update Mode按钮                                                                                                                                                                                                                                                                                                                                     
      3. check验证
      4. 调用API更新对应的HDOC_DOCUMENT_LIST表中的数据
