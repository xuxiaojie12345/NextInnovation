## 2. 背景 (Background)
本模块用于管理HDoc系统的用户权限配置，支持查询用户信息、分配角色权限及Market访问权限。

**核心功能和目标**：
- 用户输入UserID查询用户基本信息（从Saviynt系统获取用户名）
- 展示和配置用户的多种角色权限（Standard User、Rule Admin、Template Admin等）
- 为每个角色分配对应的Market访问权限
- 支持更新和删除用户权限配置
- 提供特殊功能权限开关（Manage Variable List、Show change variants fields等）

**面向的用户群体**：系统管理员、权限管理人员

**用户体验方面的考虑**：界面布局清晰、权限分类明确、操作反馈及时

**安全性或特殊要求**：仅允许授权管理员执行权限配置操作，所有变更需记录日志

## 4. 功能描述 (Functional Description)

### 4.1 初始显示
**功能说明**：加载HDoc User Administration画面，展示UserID输入框和操作按钮。

**操作步骤**：
1. 页面加载时初始化"UserID"输入框为空
2. "User"标签显示为空
3. 所有角色复选框初始未勾选
4. 所有Market下拉列表默认显示'-EU'（如适用）或为空
5. 功能权限复选框初始未勾选
6. 所有操作按钮处于可用状态

### 4.2 用户信息查询功能（User Info）
**功能说明**：根据用户输入的UserID从Saviynt系统获取用户名并展示。

**操作步骤**：
1. 用户在"UserID"输入框中输入UserID（如v0c6900）
2. 点击「User Info」按钮
3. 系统校验UserID是否为空：
   - 若为空：提示"请输入UserID"
   - 若不为空：调用API从Saviynt系统查询用户信息
4. 若Saviynt系统中未找到该UserID：
   - 设置Message = "We didn't recognize the userid you entered. Please try again."
   - 终止流程
5. 若找到用户：
   - 在"User"标签中显示从Saviynt获取的用户名
   - 同时从DOC_MARKET_AUTH和HDOC_FUNCTION_AUTH表加载该用户已有的权限配置
   - 自动勾选已配置的角色复选框
   - 自动填充已配置的Market下拉列表
   - 自动勾选已配置的功能权限复选框

### 4.3 权限更新功能（Update Role）
**功能说明**：保存或更新用户的角色权限和市场访问权限配置。

**操作步骤**：
1. 用户先通过User Info查询到目标用户
2. 根据需要勾选/取消勾选各角色复选框
3. 为每个启用的角色选择对应的Market
4. 勾选/取消勾选功能权限复选框
5. 选择Market Super User（如需要）
6. 点击「Update Role」按钮
7. 系统校验UserID是否存在：
   - 若不存在：设置Message = "We didn't recognize the userid you entered. Please try again."
   - 若存在：调用API保存权限配置到DOC_MARKET_AUTH和HDOC_FUNCTION_AUTH表
8. 成功后显示提示："权限更新成功"
9. 失败则显示错误消息："更新失败，请联系管理员"

### 4.4 权限删除功能（Delete Role）
**功能说明**：删除用户的所有权限配置。

**操作步骤**：
1. 用户先通过User Info查询到目标用户
2. 点击「Delete Role」按钮
3. 系统弹出确认对话框："确定要删除该用户的所有权限吗？"
4. 用户确认后，系统校验UserID是否存在：
   - 若不存在：设置Message = "We didn't recognize the userid you entered. Please try again."
   - 若存在：调用API从DOC_MARKET_AUTH和HDOC_FUNCTION_AUTH表删除该用户的所有权限记录
5. 成功后：
   - 显示提示："权限删除成功"
   - 清空所有角色复选框
   - 清空所有Market下拉列表
   - 清空所有功能权限复选框
6. 失败则显示错误消息："删除失败，请联系管理员"

## 5. 业务逻辑与校验规则 (Business Logic & Checks)

### 5.1 处理流程

**开始**：页面加载触发

**前置处理**：
- 初始化所有输入框和复选框为空/未勾选状态
- 加载MARKET_MASTER表数据到所有Market下拉列表

**用户信息查询处理（User Info）**：
- 用户输入UserID并点击按钮
- 校验UserID是否为空
- 调用API从Saviynt系统查询用户信息
- 若未找到用户，报错"We didn't recognize the userid you entered. Please try again."
- 若找到用户，加载并展示已有权限配置

**权限更新处理（Update Role）**：
- 用户必须先执行User Info查询到目标用户
- 配置各角色、Market和功能权限
- 点击Update Role按钮后调用API保存配置
- 保存到DOC_MARKET_AUTH表（市场权限）和HDOC_FUNCTION_AUTH表（功能权限）
- 根据角色自动应用对应的画面功能权限（参考权限矩阵表）

**权限删除处理（Delete Role）**：
- 用户必须先执行User Info查询到目标用户
- 点击Delete Role按钮后弹出确认对话框
- 用户确认后调用API删除所有权限记录

**空值校验等 (Frontend Check)**：
- 若执行User Info时UserID为空：
  - 设置Message = "请输入UserID"
  - 终止流程
- 若执行Update/Delete操作前未查询到用户：
  - 设置Message = "请先查询用户信息"
  - 终止流程

**API调用 (Backend Check)**：
- 调用 `UD17HDocUserAdministrationApi` 接口执行查询、更新和删除操作

### 5.2 结果处理
- **成功**：正常渲染权限配置或显示操作成功消息
- **失败**：显示对应错误消息
