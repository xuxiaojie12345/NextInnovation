## 2. 背景 (Background)

### 核心功能和目标

### 用户体验考虑

### 安全性要求
- 用户ID必须存在于系统中才能执行操作
- 防止未授权的权限修改
- 支持HTTPS安全传输

## 4. 功能描述 (Functional Description)

### 4.1 页面初始化功能
**功能说明**：页面加载时获取市场列表数据

**操作步骤**：
1. 页面加载时，调用**UD17HDocUserAdministrationApi**的**getMarketList**方法（GET `/api/ud17/markets`）获取市场列表
2. API返回成功后，将市场数据填充到所有Market下拉列表中
3. Standard User对应的Market下拉列表默认选择-EU
4. Adaptation user对应的Market下拉列表默认选择-EU
5. 其他Market下拉列表保持为空或第一个选项

### 4.2 查询用户信息功能
**功能说明**：用户输入UserID后点击User Info按钮，系统查询用户信息和权限

**操作步骤**：
1. 用户在UserID字段输入用户ID
2. 用户点击User Info按钮
3. 系统执行前端校验（必填项检查）
4. 若前端校验通过，调用UD17HDocUserAdministrationApi的UD17Userinfo功能
5. 从Saviynt系统获取用户名并显示在User标签中
6. 从HDOC_FUNCTION_AUTH表获取用户功能权限
7. 根据权限数据勾选对应的复选框
8. 从DOC_MARKET_AUTH表获取用户市场权限
9. 根据市场权限数据设置对应的Market下拉列表
10. 若用户ID不存在，显示错误消息"We didn't recognize the userid you entered. Please try again."

### 4.3 更新权限功能
**功能说明**：用户修改权限配置后点击Update Role按钮，系统先检查用户是否存在，存在则更新用户权限

**操作步骤**：
1. 用户修改各个权限复选框和市场下拉列表的值
2. 用户点击Update Role按钮
3. 系统执行前端校验（UserID必填检查）
4. 若前端校验通过，先调用UD17HDocUserAdministrationApi的UD17Userinfo功能检查UserID是否存在
5. 若UserID不存在：显示错误消息"We didn't recognize the userid you entered. Please try again."，终止流程
6. 若UserID存在：调用UD17HDocUserAdministrationApi的UD17UpdateRole功能更新权限
7. 系统将权限数据更新到HDOC_FUNCTION_AUTH表和DOC_MARKET_AUTH表
8. 更新成功后显示成功消息

### 4.4 删除权限功能
**功能说明**：用户点击Delete Role按钮，系统删除该用户的所有权限

**操作步骤**：
1. 用户点击Delete Role按钮
2. 系统执行前端校验（UserID必填检查）
3. 若前端校验通过，调用UD17HDocUserAdministrationApi的UD17DeleteRole功能
4. 系统从HDOC_FUNCTION_AUTH表中删除该用户的所有功能权限记录
5. 系统从DOC_MARKET_AUTH表中删除该用户的所有市场权限记录
6. 删除成功后显示成功消息
7. 清空页面上的所有权限配置（复选框取消勾选，Market下拉列表重置）

## 5. 业务逻辑与校验规则 (Business Logic & Checks)

### 5.1 处理流程

#### 5.1.1 页面初始化流程
**开始**：页面加载

**处理步骤**：
- 调用**UD17HDocUserAdministrationApi**的**getMarketList**方法（GET `/api/ud17/markets`）获取市场列表
- 等待API响应
- **成功**：
  - 将所有Market下拉列表填充市场数据
  - Standard User对应的Market下拉列表默认选择-EU
  - Adaptation user对应的Market下拉列表默认选择-EU
- **失败**：
  - 显示错误消息"Failed to load market data. Please try again."

#### 5.1.2 User Info处理流程
**开始**：用户点击User Info按钮

**前置处理**：
- 获取UserID字段的当前值

**前端校验 (Frontend Check)**：
- 若UserID为空：
  - 设置Error message = "UserID is required."
  - 终止流程，不调用API

**API调用 (Backend Check)**：
- 调用UD17HDocUserAdministrationApi的UD17Userinfo功能
- 请求参数包含userid
- 等待API响应

**结果处理**：
- **成功（用户ID存在）**：
  - 从响应中获取用户名，显示在User标签中
  - 从响应中获取功能权限列表
  - 根据功能权限勾选对应的复选框（Standard User、Rule Admin、Template Admin、Document Auth Admin、User Admin、Adaptation user、Manage Variable List）
  - 从响应中获取市场权限列表
  - 根据市场权限设置对应的Market下拉列表
  - Market Super User下拉列表设置为对应的值
  
- **失败（用户ID不存在）**：
  - 设置Error message = "We didn't recognize the userid you entered. Please try again."
  - Error message显示为Error级别
  - 清空User标签和所有权限配置
  
- **服务器错误**：
  - 设置Error message = "System error. Please contact administrator."
  - Error message显示为Error级别
  - 保持当前页面

#### 5.1.3 Update Role处理流程
**开始**：用户点击Update Role按钮

**前置处理**：
- 获取UserID字段的当前值
- 获取所有权限复选框的状态
- 获取所有Market下拉列表的选中值
- 获取Market Super User下拉列表的选中值

**前端校验 (Frontend Check)**：
- 若UserID为空：
  - 设置Error message = "UserID is required."
  - 终止流程，不调用API

**存在性检查 (Backend Check)**：
- 先调用UD17HDocUserAdministrationApi的UD17Userinfo功能，检查UserID是否存在
- 若UserID不存在：
  - 设置Error message = "We didn't recognize the userid you entered. Please try again."
  - Error message显示为Error级别
  - 终止流程，不执行更新

**API调用 (Backend Check)**：
- 若存在性检查通过，调用UD17HDocUserAdministrationApi的UD17UpdateRole功能
- 请求参数包含userid、功能权限列表、市场权限列表
- 等待API响应

**结果处理**：
- **成功**：
  - 将功能权限数据更新到HDOC_FUNCTION_AUTH表
  - 将市场权限数据更新到DOC_MARKET_AUTH表
  - 显示成功消息"Role updated successfully."
  - 清空Error message区域
  
- **失败（用户ID不存在）**：
  - 设置Error message = "We didn't recognize the userid you entered. Please try again."
  - Error message显示为Error级别
  - 保持当前页面
  
- **服务器错误**：
  - 设置Error message = "System error. Please contact administrator."
  - Error message显示为Error级别
  - 保持当前页面

#### 5.1.4 Delete Role处理流程
**开始**：用户点击Delete Role按钮

**前置处理**：
- 获取UserID字段的当前值

**前端校验 (Frontend Check)**：
- 若UserID为空：
  - 设置Error message = "UserID is required."
  - 终止流程，不调用API

**API调用 (Backend Check)**：
- 调用UD17HDocUserAdministrationApi的UD17DeleteRole功能
- 请求参数包含userid
- 等待API响应

**结果处理**：
- **成功**：
  - 从HDOC_FUNCTION_AUTH表中删除该用户的所有功能权限记录
  - 从DOC_MARKET_AUTH表中删除该用户的所有市场权限记录
  - 显示成功消息"Role deleted successfully."
  - 清空User标签
  - 取消勾选所有权限复选框
  - 重置所有Market下拉列表（Standard User和Adaptation user对应的Market恢复为-EU，其他恢复为空）
  - 重置Market Super User下拉列表
  
- **失败（用户ID不存在）**：
  - 设置Error message = "We didn't recognize the userid you entered. Please try again."
  - Error message显示为Error级别
  - 保持当前页面
  
- **服务器错误**：
  - 设置Error message = "System error. Please contact administrator."

## 6. 接口定义 (API Specification)

### getMarketList API
**功能**：获取市场列表数据

**Method**：GET

**Endpoint**：/api/ud17/markets

**Request**：无请求参数

**Response Success (200)**：
```json
[
  {
    "market": "string",
    "description": "string"
  }
]

**Response Error (500)**：
```json
{
  "message": "Internal server error"
}
```

### UD17HDocUserAdministrationApi
**功能**：管理用户权限，包括查询用户信息、更新权限、删除权限

**Method**：POST

**Endpoint**：/api/ud17/UD17HDocUserAdministrationApi

**Request - UD17Userinfo操作**：
```json
{
  "userid": "string",
  "operation": "userinfo"
}
```

**Request - UD17UpdateRole操作**：
```json
{
  "userid": "string",
  "operation": "updateRole",
  "functionAuth": [
    {
      "function": "string"
    }
  ],
  "marketAuth": [
    {
      "market": "string",
      "type": "string",
      "bu": "string"
    }
  ]
}
```

**Request - UD17DeleteRole操作**：
```json
{
  "userid": "string",
  "operation": "deleteRole"
}

**Response Success (200) - userinfo操作**：
```json
{
  "success": true,
  "username": "string",
  "functionAuth": [
    {
      "function": "string"
    }
  ],
  "marketAuth": [
    {
      "market": "string",
      "type": "string",
      "bu": "string"
    }
  ]
}

**Response Success (200) - updateRole操作**：
```json
{
  "success": true,
  "message": "Role updated successfully."
}
```

**Response Success (200) - deleteRole操作**：
```json
{
  "success": true,
  "message": "Role deleted successfully."
}
```

**Response Error (404)**：
```json
{
  "success": false,
  "message": "We didn't recognize the userid you entered. Please try again."
}
```

**Response Error (500)**：
```json
{
  "success": false,
  "message": "Internal server error"
}
```
