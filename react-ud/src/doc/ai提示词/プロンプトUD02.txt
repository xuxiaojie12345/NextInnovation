2. 背景 (Background)

核心功能和目标:
本模块提供系统主菜单导航功能，是用户登录后的主要操作界面。
通过左侧菜单树，用户可以访问系统的各个功能模块，包括文档生成、系统管理、用户管理等核心功能。

面向的用户群体:
- 系统注册用户
- 需要访问EDB Engineering Database的工程人员
- 系统管理员
- 文档管理人员

用户体验方面的考虑:
- 清晰的菜单层级结构（一级菜单和二级菜单）
- 直观的图标和文字标识
- 点击菜单项后右侧内容区动态加载对应页面
- 响应式布局，适配不同屏幕尺寸

安全性或特殊要求:
- 根据用户权限动态显示/隐藏菜单项
- 防止未授权访问
- 菜单状态持久化

4. 功能描述 (Functional Description)

4.1 菜单导航
功能说明：用户点击左侧菜单项，右侧内容区显示对应页面

操作步骤：
1. 用户登录后进入Menu页面
2. 左侧显示完整的菜单树结构
3. 用户点击任意菜单项（Link）
4. 右侧内容区加载对应的功能页面
5. 当前选中的菜单项高亮显示


5. 业务逻辑与校验规则 (Business Logic & Checks)

5.1 处理流程

开始：用户登录成功，进入Menu页面

前置处理：
- 从AuthenticationApi获取用户信息
- 从HDOC_FUNCTION_AUTH表获取用户权限
- 根据用户权限过滤菜单项

菜单渲染：
- 遍历菜单配置
- 检查每个菜单项的权限要求
- 仅显示用户有权限访问的菜单项
- 按照一级菜单、二级菜单的层级结构渲染

菜单点击处理：
- 捕获菜单项点击事件
- 更新当前选中菜单状态
- 使用React Router跳转到对应路由
- 右侧内容区加载对应组件

结果处理：
- 成功：右侧显示对应页面内容
- 失败：显示错误提示信息

5.2 校验详细规格表

No. | 检查时机 | 检查对象 | 检查条件 | 错误消息 | 动作
---|---|---|---|---|---
1 | 页面加载 | 用户权限 | 用户未登录或Token失效 | Session expired. Please login again. | 跳转到Login页面
2 | 菜单点击 | 菜单权限 | 用户无该菜单访问权限 | Access denied. You don't have permission to access this feature. | 显示错误提示，不跳转
3 | 路由跳转 | 路由配置 | 路由不存在 | Page not found. | 显示404页面


6. 接口定义 (API Specification)

AuthenticationApi

功能：获取当前登录用户信息

Method：GET

Endpoint：/api/auth/userinfo

Request：
{
  "token": "string"
}

Response Success (200)：
{
  "code": 200,
  "message": "success",
  "data": {
    "userid": "string",
    "username": "string",
    "roles": ["string"]
  }
}

UD02SelectHdocFunctionAuthApi

功能：获取用户功能权限列表

Method：GET

Endpoint：/api/v1/hdoc/functionauth

Request：
{
  "userid": "string"
}

Response Success (200)：
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "userid": "string",
      "function_code": "string",
      "function_name": "string",
      "has_permission": true
    }
  ]
}

---|---|---

网络超时 | 捕获超时异常 | Network timeout. Please try again.
