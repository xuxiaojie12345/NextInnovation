## 2. 背景 (Background)

### 核心功能和目标
本模块用于展示ADCA（Advanced Data Change Authorization）修改内容的详细信息。当用户在前画面执行了数据修改操作后，系统会记录修改信息到HDOC_ADCA_MODIFICATION表中，本画面负责向用户展示这些修改内容，包括文档类型、版本号、存储位置以及未发布版本的数量等关键信息。

### 面向的用户群体
- 具有文档管理权限的系统用户
- 需要查看和确认数据修改内容的业务人员

### 用户体验方面的考虑
- 界面简洁明了，所有信息以只读方式展示
- 提供一键关闭功能，方便用户快速返回前画面
- 重要信息（如未发布版本数量）使用醒目的绿色背景高亮显示

### 安全性或特殊要求
- 所有数据均为只读展示，不允许用户修改
- 需要从HDOC_ADCA_MODIFICATION表读取修改记录
- Chassis serie和Chassis number从前画面传递获取

## 4. 功能描述 (Functional Description)

### 4.1 画面初始化

**功能说明**: 页面加载时自动获取并展示ADCA修改内容的相关信息

**操作步骤**:
1. 页面加载触发初始化事件
2. 从前画面获取Chassis serie和Chassis number参数
   - Chassis serie: 提取'-'符号前的内容
   - Chassis number: 提取'-'符号后的内容
3. 调用后端API `UD06SaveModificationsApi`，传入Chassis serie和Chassis number作为查询条件
4. 从HDOC_ADCA_MODIFICATION表中查询对应的修改记录
5. 将查询结果填充到各Label控件：
   - Doctype: 显示DOCTYPE字段值
   - Version: 显示VERS字段值
   - Storing: 拼接VARIABLE和NEWVAL字段，格式为"VARIABLE: NEWVAL"
   - FOUND UNRELEASED VERSION: 显示未发布版本数量（VERS字段）
   - Message: 固定显示"VERSION IS RELEASED"
6. Message使用绿色背景高亮显示
7. 页面渲染完成，用户可查看修改内容

**结果反馈**: 
- 成功：所有信息正确显示在画面上
- 失败：若未找到对应记录，显示错误提示

### 4.2 关闭画面

**功能说明**: 用户点击Close按钮关闭当前画面，返回前画面

**操作步骤**:
1. 用户点击Close按钮
2. 系统执行画面关闭操作
3. 返回到调用本画面的前一个画面

**结果反馈**: 
- 当前画面被关闭
- 用户回到前画面继续操作

## 6. 接口定义 (API Specification)

### UD06SaveModificationsApi

**功能**: 获取ADCA修改内容信息

**Method**: GET

**Endpoint**: `/api/UD06/saveModifications`

**Request 参数**:
```json
{
  "chassisSerie": "JPCT",
  "chassisNumber": "G28321"
}
```

**参数说明**:
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| chassisSerie | String | Y | Chassis系列号（'-'前部分） |
| chassisNumber | String | Y | Chassis编号（'-'后部分） |

**Response Success (200)**:
```json
{
            "code": 200,
            "msg": "查询成功",
            "data": {
                "modificationList": [
                    {
                        "DOCTYPE": "xxx",
                        "VERS": "xxx",
                        "VARIABLE": "xxx",
                        "NEWVAL": "xxx"
                    }
                ]
            }
        }
```

**响应字段说明**:
| 字段名 | 类型 | 说明 |
|--------|------|------|
| doctype | String | 文档类型，来自HDOC_ADCA_MODIFICATION.DOCTYPE |
| version | String | 版本号，来自HDOC_ADCA_MODIFICATION.VERS |
| storing | String | 存储信息，格式："VARIABLE: NEWVAL" |
| foundUnreleasedVersion | String | 未发布版本数量 |
| message | String | 固定消息："VERSION IS RELEASED" |

**Response Error (400/500)**:
```json
{
  "code": 400,
  "message": "未找到对应的修改记录",
  "data": null
}
```

或

```json
{
  "code": 500,
  "message": "系统错误，请稍后重试",
  "data": null
}
```

## 7. 异常处理 (Exception Handling)

| 异常场景 | 处理方式 | Message显示内容 |
|---------|---------|----------------|
| Chassis serie为空 | 前端校验拦截，不发起API请求 | "Chassis serie不能为空" |
| Chassis number为空 | 前端校验拦截，不发起API请求 | "Chassis number不能为空" |
