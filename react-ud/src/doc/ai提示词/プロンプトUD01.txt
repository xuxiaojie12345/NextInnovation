2. 背景 (Background)
  本模块的核心功能和目标:本模块是系统的入口，负责验证用户身份。用户通过输入 UserID 和 Password，经由前端校验后调用后端 AuthenticationApi 进行认证。
  面向的用户群体:企业内部的工程技术人员或相关专业人员。
  用户体验:采用 Label 形式在页面内显示错误信息，避免频繁弹窗打断操作流。
  安全性:密码字段需掩码显示，所有敏感数据传输需加密。

4. 功能描述 (Functional Description)

    4.1 登录功能
    功能说明：输入UserID和Password，点击Login按钮，迁移到Menu画面。
    操作步骤：
      1. 输入UserID和Password
      2.点击Login按钮
      3. 迁移到Menu画面

5. 业务逻辑与校验规则 (Business Logic & Checks)
   5.1 处理流程
      ①开始：点击Login按钮
      前置处理：输入UserID和Password
      空值校验(Frontend Check)：
       若UserID是空白的场合：
        设置Message ="Username and password are required."
        终止流程
　 ②开始：点击Login按钮
      前置处理：输入UserID和Password
      空值校验(Frontend Check)：
       若Password是空白的场合：
        设置Message ="Username and password are required."
        终止流程
　 ③开始：点击Login按钮
      前置处理：输入UserID和Password
      空值校验(Frontend Check)：
       若输入的UserID或Password不正确的场合：
        设置Message ="We didn't recognize the username or password you entered. Please try again."
        终止流程
      5.1.2 API调用 (Backend Check)：
        调用[AuthenticationApi]
   5.2 结果处理：
       成功："Login successful"
       失败："Login failed"
   5.3 校验详细规格表
   | No | 校验对象| 校验内容 | 错误信息| 错误等级 |
   |----|-------|--------------------------------|--------------------------------------|----------|
   | 1  | UserID   | 用户ID为空，且点击Login按钮时  | Username and password are required. | Warning  |
   | 2  | Password | 密码为空，且点击Login按钮时| Username and password are required. | Warning  |
   | 3  | 用户存在性检查   | 用户ID或密码不正确时| We didn't recognize the username or password you entered. Please try again. | Error |
