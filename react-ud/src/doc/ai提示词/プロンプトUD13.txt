# HDocTemplateCheck 详细设计提示词

## 1. 基本信息
- **模块名称**：HDocTemplateCheckPage
- **文档编号**: DES-HDocTemplateCheckPage-001
- **作成日期**：2026-05-20

## 2. 背景 (Background)

### 核心功能和目标
本模块用于检查HDoc模板文件的格式和内容，主要功能包括：
- 支持选择并上传rtf格式的模板文件
- 读取文件内容，解析$符号之间的变量
- 统计变量数量
- 验证文件格式是否正确
- 提供检查后的模板下载链接
- 仅适用于rtf文件检查

### 面向的用户群体
需要验证认证系统模板文件格式和内容的授权用户，如系统管理员、配置管理人员等

### 用户体验考虑
- 清晰的文件选择界面
- 明确的检查结果反馈
- 便捷的下载功能
- 详细的错误提示信息

### 安全性要求
- 需要用户登录认证后才能访问
- 文件上传需要进行类型验证（仅允许rtf文件）
- 支持HTTPS安全传输协议

## 4. 功能描述 (Functional Description)

### 4.1 页面初始化功能
**功能说明**：页面加载时初始化文件选择区域和消息区域

**操作步骤**：
1. 页面加载时，清空文件选择框
2. 清空错误消息和成功消息区域
3. 隐藏Download checked template链接
4. 页面处于等待用户选择文件的状态

### 4.2 文件检查功能
**功能说明**：用户选择rtf模板文件后点击Check按钮，对文件进行检查

**操作步骤**：
1. 用户点击Template File输入框选择rtf文件
2. 用户点击Check按钮
3. 前端校验：检查是否选择了文件
   - 若未选择文件，显示错误消息"ERROR: Unable to access file!"并终止流程
4. 读取选中的文件内容
5. 解析文件内容，查找$符号之间的内容
6. 提取所有$...$格式的变量
7. 统计变量数量

**后端处理或前端处理**：
- 打开文件并读取内容
- 使用正则表达式或字符串匹配查找$符号对
- 提取$符号之间的内容作为变量
- 计算变量总数

**结果处理**：
- **成功（找到至少一个变量）**：
  - 显示成功消息，包含变量数量和变量列表
  - 显示Download checked template链接
  - 用户可以点击下载检查后的模板文件
  
- **失败（未找到任何变量）**：
  - 显示错误消息"ERROR: The file content is incorrect!"
  - 不显示Download checked template链接
  - 保持当前表单数据不变

### 4.3 下载检查后的模板功能
**功能说明**：用户点击Download checked template链接，下载检查后的模板文件

**操作步骤**：
1. 用户点击Download checked template链接
2. 触发文件下载
3. 浏览器保存检查后的模板文件
4. 文件名建议格式：checked_template_YYYYMMDD.rtf

## 5. 业务逻辑与校验规则 (Business Logic & Checks)

### 5.1 处理流程

#### 5.1.1 页面初始化流程
**开始**：页面加载

**处理步骤**：
- 清空文件选择框
- 清空错误消息和成功消息区域
- 隐藏Download checked template链接
- 页面处于等待状态

#### 5.1.2 文件检查流程
**开始**：用户点击Check按钮

**前置处理**：
- 校验是否选择了文件
- 若未选择，显示错误消息"ERROR: Unable to access file!"并终止流程

**处理步骤**：
- 读取选中的文件内容
- 解析文件内容，查找$符号之间的内容
- 提取所有$...$格式的变量
- 统计变量数量

**结果处理**：
- **成功（变量数量 >= 1）**：
  - 显示成功消息，包含变量数量和变量列表
  - 显示Download checked template链接
  
- **失败（变量数量 = 0）**：
  - 显示错误消息"ERROR: The file content is incorrect!"
  - 不显示Download checked template链接

#### 5.1.3 下载检查后的模板流程
**开始**：用户点击Download checked template链接

**处理步骤**：
- 触发文件下载
- 浏览器保存检查后的模板文件

### 5.2 校验详细规格表

| No. | 检查时机 | 检查对象 | 检查条件 | 错误消息 | 动作 |
|-----|---------|---------|---------|---------|------|
| 1 | 点击Check按钮时 | 文件选择 | 未选择任何文件 | "ERROR: Unable to access file!" | 显示错误消息，终止流程 |
| 2 | 文件内容解析后 | 变量数量 | 文件中没有找到任何$...$格式的变量 | "ERROR: The file content is incorrect!" | 显示错误消息，不显示下载链接 |
| 3 | 文件读取失败 | 文件访问 | 无法读取文件内容 | "ERROR: Unable to access file!" | 显示错误消息，终止流程 |

## 6. 接口定义 (API Specification)

本模块不调用后端API，所有处理在前端完成。

### 6.1 文件读取和处理
**功能**：在前端读取并解析rtf文件内容

**处理方式**：
- 使用FileReader API读取文件内容
- 使用正则表达式匹配$符号之间的内容
- 提取变量并统计数量

### 6.2 文件下载
**功能**：提供检查后的模板文件下载

**处理方式**：
- 创建Blob对象
- 生成下载链接
- 触发浏览器下载

## 7. 异常处理 (Exception Handling)

| 异常场景 | 处理方式 | Message显示内容 |
|---------|---------|----------------|
| 未选择文件点击Check | 显示文件选择提示消息 | "ERROR: Unable to access file!" |
| 文件读取失败 | 捕获读取异常，显示错误消息 | "ERROR: Unable to access file!" |
| 文件中没有变量 | 显示内容错误消息 | "ERROR: The file content is incorrect!" |
| 文件类型不正确 | 可选：显示文件类型提示 | "Please select an RTF file." |
| 未预期的JavaScript错误 | 使用try-catch包裹关键代码，记录错误日志 | "System error. Please contact administrator." |
| 用户未登录 | 检查会话状态，跳转到登录页面 | "Please login first" |
