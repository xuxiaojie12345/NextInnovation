## 1. 背景 (Background)

本模块用于展示ADCA（Advanced Data Change Authorization）修改内容的详细信息。当用户在前画面执行了数据修改操作后，系统会记录修改信息到HDOC_ADCA_MODIFICATION表中，本画面负责向用户展示这些修改内容，包括文档类型、版本号、存储位置以及未发布版本的数量等关键信息。

- **目标**：向用户展示ADCA修改内容的详细信息，提供确认和查看功能。
- **安全性**：所有数据均为只读展示，不允许用户修改；需要从HDOC_ADCA_MODIFICATION表读取修改记录；Chassis serie和Chassis number从前画面传递获取。
- **用户体验**：界面简洁明了，所有信息以只读方式展示；提供一键关闭功能，方便用户快速返回前画面；重要信息（如未发布版本数量）使用醒目的绿色背景高亮显示。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

所有校验逻辑均在页面加载时或用户点击Close按钮时执行。

### 3.1 处理流程

#### 3.1.1 画面初始化流程

1.  **开始**：页面加载事件触发。
2.  **前置处理**：

- 从前画面获取参数：Chassis serie和Chassis number。
- 解析Chassis完整编号，分离出serie部分（'-'前）和number部分（'-'后）。

3.  **空值校验 (Frontend Check)**：

- 若 `Chassis serie` 为空：
  - 设置 `Message` = `Chassis serie不能为空`。
  - **终止**流程。
- 若 `Chassis number` 为空：
  - 设置 `Message` = `Chassis number不能为空`。
  - **终止**流程。

4.  **API 调用 (Backend Check)**：

- 调用 UD06SaveModificationsApi。
- 请求参数：
  ```json
  {
    "chassisSerie": "JPCT",
    "chassisNumber": "G28321"
  }
  ```
- API内部逻辑：
  1.  根据chassisSerie和chassisNumber查询HDOC_ADCA_MODIFICATION表。
  2.  获取最新一条修改记录。
  3.  提取DOCTYPE、VERS、VARIABLE、NEWVAL字段值。
  4.  计算未发布版本数量。

5.  **结果处理**：

- **成功**：
  - 将API返回的数据填充到各Label控件。
  - FOUND UNRELEASED VERSION使用绿色背景高亮显示。
  - Message显示"VERSION IS RELEASED"。
- **失败**：
  - 若未找到记录：显示"未找到对应的修改记录"。
  - 若API调用异常：显示"系统错误，请稍后重试"。

#### 3.1.2 Close按钮操作流程

1.  **开始**：用户点击Close按钮。
2.  **处理逻辑**：

- 无需额外校验。
- 直接执行画面关闭操作。

3.  **结果处理**：

- **成功**：当前画面关闭，返回前画面。
- **失败**：无。

## 4. 接口定义 (API Specification)

### 4.1 UD06SaveModificationsApi

- **功能**：获取ADCA修改内容信息。
- **Method**: `POST`
- **Endpoint**: `/api/XXXXX/saveModifications`

#### Request

```json
{
  "chassisSerie": "JPCT",
  "chassisNumber": "G28321"
}
```

##### 参数说明

| 参数名        | 类型   | 必填 | 说明                       |
| :------------ | :----- | :--- | :------------------------- |
| chassisSerie  | String | Y    | Chassis系列号（'-'前部分） |
| chassisNumber | String | Y    | Chassis编号（'-'后部分）   |

#### Response Success (200)

```json
{
  "code": 200,
  "msg": "查询成功",
  "data": {
    "modificationList": [
      {
        "DOCTYPE": "xxx",
        "VERS": "xxx",
        "VARIABLE": "xxx",
        "NEWVAL": "xxx"
      }
    ]
  }
}
```

##### 响应字段说明

| 字段名                 | 类型   | 说明                                         |
| :--------------------- | :----- | :------------------------------------------- |
| doctype                | String | 文档类型，来自HDOC_ADCA_MODIFICATION.DOCTYPE |
| version                | String | 版本号，来自HDOC_ADCA_MODIFICATION.VERS      |
| storing                | String | 存储信息，格式："VARIABLE: NEWVAL"           |
| foundUnreleasedVersion | String | 未发布版本数量                               |
| message                | String | 固定消息："VERSION IS RELEASED"              |

#### Response Error (400/500)

```json
{
  "code": 400,
  "message": "未找到对应的修改记录",
  "data": null
}
```

或

```json
{
  "code": 500,
  "message": "系统错误，请稍后重试",
  "data": null
}
```

## 5. 异常处理 (Exception Handling)

| 异常场景               | 处理方式                             | Message 显示内容                 |
| :--------------------- | :----------------------------------- | :------------------------------- |
| **Chassis serie为空**  | 前端校验拦截，不发起API请求          | `Chassis serie不能为空`          |
| **Chassis number为空** | 前端校验拦截，不发起API请求          | `Chassis number不能为空`         |
| **未找到修改记录**     | API返回400错误，前端显示错误消息     | `未找到对应的修改记录`           |
| **数据库连接异常**     | API返回500错误，前端显示通用错误消息 | `系统错误，请稍后重试`           |
| **API超时**            | 前端捕获超时异常，显示超时提示       | `请求超时，请检查网络连接后重试` |
| **网络异常**           | 前端捕获网络异常，显示网络错误提示   | `网络连接失败，请检查网络设置`   |

## 6. 实现注意事项 (Implementation Notes)

1.  **状态管理**：
    - 使用 React State 管理 chassisSerie, chassisNumber, doctype, version, storing, foundUnreleasedVersion, message, errorMessage, `isLoading`。
    - Message Label 显示固定文本"VERSION IS RELEASED"。
2.  **安全性**：
    - API 请求必须通过 HTTPS 发送。
    - 所有数据显示为只读，不允许编辑。
3.  **UI 细节**：
    - FOUND UNRELEASED VERSION Label 使用绿色背景高亮显示。
    - Close 按钮在 `isLoading` 期间不需要禁用，因为这是一个只读页面。
    - Message 文字颜色建议使用绿色 (`#52c41a`) 以表示正常状态。
