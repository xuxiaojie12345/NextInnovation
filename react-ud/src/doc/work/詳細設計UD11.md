## 1. 背景 (Background)

本模块用于显示Existing HDoc Variables页面的搜索结果列表，主要功能包括：根据前画面传递的搜索条件显示匹配的变量定义列表；支持选择单条记录并返回前画面；支持将选中记录的Variable作为参数跳转到Homologation Variables页面；支持打印搜索结果；支持导出CSV文件；支持返回前画面并保留搜索条件；显示搜索结果总数。

- **目标**：向需要查看和管理认证系统变量定义的授权用户（如系统管理员、配置管理人员等）提供变量定义列表展示和管理功能。
- **安全性**：需要用户登录认证后才能访问；支持HTTPS安全传输协议。
- **用户体验**：清晰的数据表格展示；便捷的记录选择和操作功能；明确的搜索结果计数显示；支持批量操作和导出功能。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

所有校验逻辑均在页面加载时或用户执行操作时执行。

### 3.1 处理流程

#### 3.1.1 页面初始化流程

1.  **开始**：页面加载。
2.  **处理步骤**：

- 从URL参数或state中获取前画面传递的搜索条件。
- 调用[UD11HdocvariablesApi]获取匹配的变量定义列表。
- 解析响应数据，更新tableData状态。
- 计算记录总数，更新totalCount状态。
- 显示结果列表。

#### 3.1.2 Select操作流程

1.  **开始**：用户点击Select按钮。
2.  **前置处理**：

- 校验是否有选中的记录。
- 若未选择，显示错误消息并终止流程。

3.  **处理步骤**：

- 获取选中行的完整数据。
- 将数据存储到state或sessionStorage中。
- 返回/ExistingHDocVariables页面。
- 传递返回标志。

4.  **结果处理**：

- **成功**：返回前画面并自动填充选中记录的内容。

#### 3.1.3 Back操作流程

1.  **开始**：用户点击Back按钮。
2.  **处理步骤**：

- 保存搜索条件到state或sessionStorage。
- 返回/ExistingHDocVariables页面。
- 传递返回标志。

3.  **结果处理**：

- **成功**：返回前画面并保留搜索条件。

#### 3.1.4 Print操作流程

1.  **开始**：用户点击Print按钮。
2.  **处理步骤**：

- 调用window.print()方法。
- 浏览器打开打印预览。

3.  **结果处理**：

- **成功**：打开打印预览对话框。

#### 3.1.5 Down操作流程

1.  **开始**：用户点击Down按钮。
2.  **前置处理**：

- 校验是否有选中的记录。
- 若未选择，显示警告消息"No key defined for table."并终止流程。

3.  **处理步骤**：

- 获取选中记录的Variable字段值。
- 跳转到/HomologationVariables路由。
- 传递Variable作为URL参数。

4.  **结果处理**：

- **成功**：跳转到Homologation Variables页面并传递Variable参数。

#### 3.1.6 Excel操作流程

1.  **开始**：用户点击Excel按钮。
2.  **处理步骤**：

- 调用导出API或前端生成CSV。
- 触发浏览器文件下载。

3.  **结果处理**：

- **成功**：触发CSV文件下载。

#### 3.1.7 用户链接跳转功能

1.  **开始**：用户在DataTable中点击Created by user列的链接。
2.  **处理**：跳转到EDB User View页面（UD25），携带参数userid（当前行的registerUser值）。
3.  **结果处理**：EDB User View页面加载并显示该用户的详细信息。

## 4. 接口定义 (API Specification)

### 4.1 UD11HdocvariablesApi

- **功能**：根据搜索条件查询变量定义列表。
- **Method**: `POST`
- **Endpoint**: `/api/ud11Hdocvariables/search`

#### Request

```json
{
  "variable": "VAR001",
  "type": "VDA",
  "description": "",
  "Created by user": "xxx",
  "Date": "2023-07-01T00:00:00.000Z"
}
```

##### 请求参数说明

- variable：变量名，字符串类型，可选，最大长度30字符
- type：类型，字符串类型，可选，最大长度20字符
- description：描述，字符串类型，可选，最大长度100字符
- 所有字段均为可选，未提供的字段不参与筛选

#### Response Success (200)

```json
{
  "code": 200,
  "msg": "搜索变量成功",
  "data": [
    {
      "variable": "xxx",
      "type": "xxx",
      "descr": "xxx",
      "registerUser": "xxx",
      "registerDatetime": "xxx"
    }
  ]
}
```

##### 成功响应参数说明

- variable：变量名，字符串类型，对应HDOC_VARIABLES表的VARIABLE字段
- type：类型，字符串类型，对应HDOC_VARIABLES表的TYPE字段
- description：描述，字符串类型，对应HDOC_VARIABLES表的DESCR字段
- userid：用户ID，字符串类型，对应HDOC_VARIABLES表的REGISTER_USER字段
- registerDatetime：注册日期时间，字符串类型，对应HDOC_VARIABLES表的REGISTER_DATETIME字段

#### Response Error (500)

```json
{
  "message": "Internal server error"
}
```

## 5. 异常处理 (Exception Handling)

| 异常场景                   | 处理方式                                 | Message 显示内容                              |
| :------------------------- | :--------------------------------------- | :-------------------------------------------- |
| **网络连接失败**           | 捕获网络异常，显示通用错误消息           | `System error. Please contact administrator.` |
| **API超时**                | 设置超时时间（建议10秒），超时后显示错误 | `System error. Please contact administrator.` |
| **UD11Search返回空列表**   | 显示零结果消息                           | `Number of lines found: 0`                    |
| **UD11Search返回500**      | 显示系统错误消息                         | `System error. Please contact administrator.` |
| **JSON解析失败**           | 捕获解析异常，显示系统错误               | `System error. Please contact administrator.` |
| **未预期的JavaScript错误** | 使用try-catch包裹关键代码，记录错误日志  | `System error. Please contact administrator.` |
| **用户未登录**             | 检查会话状态，跳转到登录页面             | `Please login first`                          |
| **未选择记录点击Select**   | 显示选择提示消息                         | `Please select a record.`                     |
| **未选择记录点击Down**     | 显示警告消息                             | `No key defined for table.`                   |

## 6. 实现注意事项 (Implementation Notes)

1.  **状态管理**：
    - 使用 React State 管理 tableData, totalCount, selectedRecord, errorMessage, `isLoading`。
    - 确保DataTable能够正确显示搜索结果并支持单选功能。
2.  **安全性**：
    - API 请求必须通过 HTTPS 发送。
    - 需要用户登录认证后才能访问。
3.  **UI 细节**：
    - Search, Down, Back, Print, Excel 按钮在 `isLoading` 期间应设为 `disabled`，防止重复提交。
    - Message 文字颜色建议使用红色 (`#ff4d4f`) 以起到警示作用。
    - Count 标签实时显示搜索结果数量。
