## 1. 背景 (Background)

本模块用于管理HDoc系统的用户文档访问权限，支持查询用户信息并配置其可访问的文档列表。

- **目标**：向系统管理员、文档权限管理人员提供用户文档权限管理功能。
- **安全性**：仅允许授权管理员执行权限配置操作，所有变更需记录日志；必须先验证用户存在于HDOC_FUNCTION_AUTH表中才能进行文档权限配置。
- **用户体验**：界面简洁清晰、文档列表易于浏览和选择、操作反馈及时。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

所有校验逻辑均在页面加载时或用户执行操作时执行。

### 3.1 处理流程

#### 3.1.1 页面初始化流程

1.  **开始**：页面加载触发。
2.  **前置处理**：

- 初始化所有输入框为空。
- 调用UD18HDocUserDocAdministrationApi，向后端服务获取文档列表信息(/api/ud18HDocUserDocAdministration/getDocumentList),显示在Document项目上。

3.  **结果处理**：

- **成功**：UserID输入框为空，User标签为空，Document多选列表显示所有的文档列表信息，所有操作按钮处于可用状态。

#### 3.1.2 用户信息查询处理流程（User Info）

1.  **开始**：用户点击User Info按钮。
2.  **前置处理**：
    - 校验UserID是否为空。
    - 若为空：设置Message = "请输入UserID"；终止流程。

3.  **处理步骤**：

- 调用API检查该UserID是否存在于HDOC_FUNCTION_AUTH表中。
- 若HDOC_FUNCTION_AUTH表中未找到该UserID：设置Message = "We didn't recognize the userid you entered. Please try again."；终止流程。
- 若找到该UserID：调用AuthenticationApi获取用户名；在"User"标签中显示用户名（如Jenna Wang）；从HDOC_USER_DOC表查询该用户已授权的文档列表；在Document多选列表中展示所有文档，并自动选中已授权的文档。

4.  **结果处理**：

- **成功**：显示查询到的用户名，在Document多选列表中展示所有文档，并自动选中已授权的文档。
- **失败**：显示错误消息："We didn't recognize the userid you entered. Please try again."。

#### 3.1.3 文档权限更新处理流程（Update）

1.  **开始**：用户点击Update按钮。
2.  **前置处理**：

- 检查是否已查询到用户。
- 若未先执行查询：设置Message = "请先查询用户信息"；终止流程。

3.  **处理步骤**：

- 系统校验UserID是否存在于HDOC_FUNCTION_AUTH表中。
- 若不存在：设置Message = "We didn't recognize the userid you entered. Please try again."。
- 若存在：调用UD18HDocUserDocAdministrationApi(/api/ud18HDocUserDocAdministration/updateUserDocuments)将当前画面已选的文档权限更新到HDOC_USER_DOC表(先删除原来的再登录新选择的)。

4.  **结果处理**：

- **成功**：显示提示："文档权限更新成功"。
- **失败**：显示错误消息："更新失败，请联系管理员"。

## 4. 接口定义 (API Specification)

### 4.1 [UserInfoApi]

- **功能**：验证用户凭证并返回认证结果。
- **Method**: `POST`
- **Endpoint**: `/api/login`

#### Request Body

```json
{
  "userID": "string (Max 10, Alphanumeric)",
  "password": "string (Max 32, Alphanumeric + Symbols)"
}
```

#### Response Success (200 OK)

```json
{
  "code": 200,
  "msg": "登录成功",
  "data": {
    "token": "xxxx",
    "userId": 1,
    "username": "xxx",
    "responsible": "xxx",
    "userPosition": "xxx",
    "eMail": "xxx"
  }
}
```

#### Response Error (401 Unauthorized)

```json
{
  "code": 401,
  "data": null,
  "message": "Invalid credentials"
}
```

### 4.2 [UD18HDocUserDocAdministrationApi]

#### 4.2.1 向后端服务获取文档列表信息

- **功能**：向后端服务获取文档列表信息。
- **Method**: `GET`
- **Endpoint**: `/api/ud18/getdocumentList`

##### Request

无需参数

##### Response Success (200)

```json
{
  "code": 200,
  "msg": "获取文档列表成功",
  "data": [
    {
      "description": "xxx"
    }
  ]
}
```

#### 4.2.3 查询用户文档权限接口

- **功能**：提供HDoc用户文档权限管理的查询接口。
- **Method**: `POST`
- **Endpoint**: `/api/ud18/getuserfunctionsanddocuments`

##### Request

```json
{
  "action": "query",
  "userId": "a420064"
}
```

##### Response Success (200)

```json
{
  "code": 200,
  "msg": "获取用户功能和文档权限成功",
  "data": {
    "functions": [
      {
        "function": "xxx"
      }
    ],
    "documents": [
      {
        "doctype": "xxx"
      }
    ]
  }
}
```

#### 4.2.3 更新文档权限接口

- **功能**：提供HDoc用户文档权限管理的更新接口。
- **Method**: `POST`
- **Endpoint**: `/api/ud18/updateuserdocuments`

##### Request

```json
{
  "action": "update",
  "userId": "a420064",
  "authorizedDocuments": [
    "VIN-PLATE-VIN-Plate",
    "DIM-PLATE-DIM-Plate",
    "SASO-SASO-Plate",
    "COC_EU-COC (EU)"
  ]
}
```

##### Response Success (200)

```json
{
  "code": 200,
  "msg": "更新用户文档权限成功",
  "data": {
    "userid": "xxx",
    "documentTypes": ["xxx"]
  }
}
```

##### Response Error (400)

```json
{
  "error": "Validation failed",
  "message": "We didn't recognize the userid you entered. Please try again."
}
```

##### Response Error (500)

```json
{
  "error": "Internal Server Error",
  "message": "Failed to process request"
}
```

## 5. 异常处理 (Exception Handling)

| 异常场景                               | 处理方式     | Message 显示内容                                                |
| :------------------------------------- | :----------- | :-------------------------------------------------------------- |
| **UserID在HDOC_FUNCTION_AUTH中不存在** | 显示错误消息 | `We didn't recognize the userid you entered. Please try again.` |
| **UserID为空**                         | 终止流程     | `请输入UserID`                                                  |
| **未先查询直接更新**                   | 终止流程     | `请先查询用户信息`                                              |
| **Saviynt系统调用失败**                | 显示通用错误 | `无法获取用户信息，请联系管理员`                                |
| **API调用失败**                        | 显示通用错误 | `更新失败，请联系管理员`                                        |
| **数据库操作异常**                     | 显示通用错误 | `系统内部错误，请联系管理员`                                    |

## 6. 实现注意事项 (Implementation Notes)

1.  **状态管理**：
    - 使用 React State 管理 userId, userName, documents, authorizedDocuments, errorMessage, successMessage, `isLoading`。
    - Document多选列表的状态需要正确绑定到UI组件。
2.  **安全性**：
    - API 请求必须通过 HTTPS 发送。
    - 需要用户登录认证后才能执行权限配置操作。
    - 所有变更需记录日志。
    - 必须先验证用户存在于HDOC_FUNCTION_AUTH表中才能进行文档权限配置。
3.  **UI 细节**：
    - 操作按钮（User Info、Update）在 `isLoading` 期间应设为 `disabled`，防止重复提交。
    - Message 文字颜色建议使用红色 (`#ff4d4f`) 以起到警示作用。
    - 成功消息使用绿色 (`#52c41a`) 显示。
