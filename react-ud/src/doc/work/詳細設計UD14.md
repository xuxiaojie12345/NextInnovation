## 1. 背景 (Background)

本模块用于展示各市场下的模板文件列表，支持按市场筛选并查看模板文件的详细信息及使用状态。

- **目标**：向系统管理员、配置工程师及生产准备人员提供模板文件列表展示和下载功能。
- **安全性**：仅允许授权用户访问，只读操作不涉及数据修改。
- **用户体验**：界面简洁清晰、信息一目了然、操作便捷。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

所有校验逻辑均在页面加载时或用户执行操作时执行。

### 3.1 处理流程

#### 3.1.1 页面初始化流程

1.  **开始**：页面加载触发。
2.  **前置处理**：

- 初始化"Select Market"下拉列表，从MARKET_MASTER表获取所有市场。
- 表格区域初始化为空。

3.  **结果处理**：

- **成功**：市场下拉列表填充完成，表格区域初始为空。
- **失败**：显示错误消息："系统内部错误，请联系管理员"。

#### 3.1.2 市场选择处理流程

1.  **开始**：用户在"Select Market"下拉列表中选择一个市场。
2.  **处理步骤**：

- 调用API获取所选市场文件夹下的所有文件信息。
- 查询HDOC_USER_DEFINED_RULES表，检查每个文件名是否被引用。
- 构建表格数据并渲染。

3.  **结果处理**：

- **成功**：正常渲染表格，显示所有文件信息。
- **失败**：显示"系统内部错误，请联系管理员"。

#### 3.1.3 文件下载处理流程

1.  **开始**：用户点击表格中某行的Filename列的文件名链接。
2.  **处理步骤**：

- 系统将该文件作为附件发送给用户。
- 浏览器触发文件下载，文件名为原始文件名。

3.  **结果处理**：

- **成功**：浏览器触发文件下载。
- **失败**：显示"文件不存在，请联系管理员"。

### 3.2 校验详细规格表

| No. |  检查时机   | 检查对象 |   检查条件   |  错误消息 (Message Content)  |          动作          |

## 4. 接口定义 (API Specification)

### 4.1 UD14SearchresultistApi

#### 4.1.1 获取市场主数据信息

- **功能**：获取完整的市场实体列表。
- **Method**: `GET`
- **Endpoint**: `/api/ud14Searchresultist/getMarkets`

#### Request

无需参数

````

#### Response Success (200)

```json
{
            "code": 200,
            "msg": "获取市场列表成功",
            "data": [
                {
                    "market": "xx"
                }
            ]
        }
````

#### Response Error (400)

```json
{
  "error": "Invalid input",
  "message": "Market parameter is required"
}
```

#### Response Error (500)

```json
{
  "error": "Internal Server Error",
  "message": "Failed to retrieve file list"
}
```

#### 4.1.2 获取市场主数据信息

- **功能**：获取完整的市场实体列表。
- **Method**: `POST`
- **Endpoint**: `/api/ud14Searchresultist/getVariablesByMarket`

#### Request

```json
{
  "Market": "xxx"
}
```

#### Response Success (200)

```json
{
  "code": 200,
  "msg": "根据市场获取变量列表成功",
  "data": [
    {
      "variable": "xxx"
    }
  ]
}
```

## 5. 异常处理 (Exception Handling)

| 异常场景         | 处理方式     | Message 显示内容             |
| :--------------- | :----------- | :--------------------------- |
| **未选择市场**   | 不执行查询   | -                            |
| **市场下无文件** | 表格显示为空 | -                            |
| **API调用失败**  | 显示通用错误 | `系统内部错误，请联系管理员` |
| **文件不存在**   | 下载失败提示 | `文件不存在，请联系管理员`   |

## 6. 实现注意事项 (Implementation Notes)

1.  **状态管理**：
    - 使用 React State 管理 market, files, errorMessage, `isLoading`。
    - 文件列表根据所选市场动态更新。
2.  **安全性**：
    - API 请求必须通过 HTTPS 发送。
    - 需要用户登录认证后才能访问。
3.  **UI 细节**：
    - Select Market 下拉列表在 `isLoading` 期间应设为 `disabled`，防止重复提交。
    - Message 文字颜色建议使用红色 (`#ff4d4f`) 以起到警示作用。
    - Filename 列显示为链接，点击后触发文件下载。
