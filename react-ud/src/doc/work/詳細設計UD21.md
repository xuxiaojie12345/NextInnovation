## 1. 背景 (Background)

本模块用于展示HDoc系统中所有可用市场的列表信息，包括市场代码、市场描述以及是否启用HDoc权重功能。该功能主要用于帮助用户了解系统中配置的所有市场及其权重状态，为后续的市场选择和文档生成提供参考依据。画面为纯展示性质，不提供任何修改操作。

- **目标**：向系统管理员、具有文档管理权限的业务人员及需要查看市场配置信息的授权用户提供市场列表展示功能。
- **安全性**：需要从MARKET_MASTER表读取市场信息；所有数据均为只读展示，不允许用户修改；无需用户输入，页面加载时自动获取并展示数据。
- **用户体验**：以清晰的表格形式展示所有市场信息；按市场代码字母顺序排序，便于快速查找；Weights from Hdoc列使用直观的标识（X或空）显示权重状态；界面简洁，无多余操作按钮，专注于信息展示。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

所有校验逻辑均在页面加载时执行。

### 3.1 处理流程

#### 3.1.1 页面初始化流程

1.  **开始**：页面加载事件触发。
2.  **前置处理**：

- 无。

3.  **API 调用 (Backend Check)**：

- 调用[UD19SearchResultListApi](/api/ud19/getmarketlist)

4.  **结果处理**：

- **成功**：将市场列表填充到DataTable；三列分别为：Market、Description、Weights from Hdoc；Weights from Hdoc列居中对齐。
- **失败**：若无数据：显示"No data found"提示消息；若其他错误：显示具体错误消息。

### 3.2 校验详细规格表

| No. |  检查时机  |    检查对象     |     检查条件     | 错误消息 (Message Content) |            动作             |
| :-: | :--------: | :-------------: | :--------------: | :------------------------: | :-------------------------: |
|  1  | 页面初始化 | MARKET_MASTER表 | 至少存在一条记录 |      `No data found`       | 显示提示消息，DataTable为空 |

## 4. 接口定义 (API Specification)

### 4.1 UD19SearchResultListApi

- **功能**：获取Market列表。
- **Method**: `GET`
- **Endpoint**: `/api/ud19/getmarketlist`

#### Request

无

#### Response Success (200)

```json
{
  "code": 200,
  "msg": "获取市场列表成功",
  "data": [
    {
      "market": "xx",
      "description": "xxx"
    }
  ]
}
```

#### Response Error (500)

```json
{
  "code": 500,
  "message": "获取Market列表失败",
  "data": null
}
```

## 5. 异常处理 (Exception Handling)

| 异常场景                  | 处理方式                             | Message 显示内容                 |
| :------------------------ | :----------------------------------- | :------------------------------- |
| **MARKET_MASTER表无数据** | API返回400错误，前端显示提示消息     | `No data found`                  |
| **数据库连接异常**        | API返回500错误，前端显示通用错误消息 | `系统错误，请稍后重试`           |
| **API超时**               | 前端捕获超时异常，显示超时提示       | `请求超时，请检查网络连接后重试` |
| **网络异常**              | 前端捕获网络异常，显示网络错误提示   | `网络连接失败，请检查网络设置`   |

## 6. 实现注意事项 (Implementation Notes)

1.  **状态管理**：
    - 使用 React State 管理 markets, errorMessage, `isLoading`。
    - 确保DataTable按Market代码字母顺序显示。
2.  **安全性**：
    - API 请求必须通过 HTTPS 发送。
    - 需要用户登录认证后才能访问。
3.  **UI 细节**：
    - Weights from Hdoc 列居中对齐。
    - DataTable 为只读展示，不提供任何编辑功能。
    - Message 文字颜色建议使用红色 (`#ff4d4f`) 以起到警示作用。
