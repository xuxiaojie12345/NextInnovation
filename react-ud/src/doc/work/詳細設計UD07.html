1. 背景 (Background)

本模块用于展示车辆的详细规格信息，基于Chassis编号从多个数据源获取并整合车辆配置数据。

  • 目标：向车辆配置工程师、质量审核人员和生产准备人员提供完整的车辆规格信息。
  • 安全性：仅读取已授权访问的数据，不涉及敏感操作或写入。
  • 用户体验：保证信息清晰、字段排列合理、关键信息突出显示。

3. 业务逻辑与校验规则 (Business Logic & Checks)

所有校验逻辑均在页面加载时执行。

3.1 处理流程

3.1.1 画面初期表示流程

  1. 开始：页面加载触发。
  2. 前置处理：
  • 获取当前Chassis编号。
  • 查询HDOC_REC_DATA_OM获取Model、Build Week，S-Note NO信息。
  • 查询HDOC_REC_DATA_VDA_GENERAL获取VIN、Product Type、Country of Operation。
  • 查询HDOC_REC_DATA_VDA_VARIANTS获取FAMILY_ID和VARIANT_ID（条件：Chassis no + Family ID Like 'DPX%'）。
  • 查询HDOC_REC_DATA_KOLA_VARIANT获取SYMBOL和DESCRIPTION。
  1. 空值校验等 (Frontend Check)：
  • 若Chassis编号为空：
    • 设置Message = "未指定Chassis编号"。
    • 终止流程。
  • 若HDOC_REC_DATA_VDA_VARIANTS中未找到匹配记录：
    • 设置Message = "未找到对应变体信息"。
    • Engine no和SYMBOL_STR字段留空。
  • 若HDOC_REC_DATA_KOLA_VARIANT中未找到对应Symbol：
    • Engine no字段显示"N/A"。
    • SYMBOL_STR字段显示"N/A"。
  1. API 调用 (Backend Check)：
  • 调用 UD07VehicleSpecificationApi 接口获取初始数据。
  • 若返回失败，记录错误日志并显示通用错误消息。
  1. 结果处理：
  • 成功：正常渲染所有标签与tooltip。
  • 失败：显示"系统内部错误，请联系管理员"。

No. 检查时机 检查对象 检查条件 错误消息 (Message Content) 动作

4. 接口定义 (API Specification)

4.1 UD07VehicleSpecificationApi

  • 功能：获取车辆规格信息，包括型号、制造周、VIN、发动机编号、变体信息等。
  • Method: POST
  • Endpoint: /api/XXXXX/vehicleSpecification

Request 

{
  "chassisNo": "JPCT 013945"
}

Response Success (200) 

{
  "code": 200,
  "msg": "查询成功",
  "data": {
    "vehicleInfo": {
      "model": "xxx",
      "builtWeek": "xxx",
      "customerAdap": "xxx",
      "productType": "xxx",
      "vin": "xxx",
      "countryOfOperation": "xxx",
      "familyId": "xxx",
      "variantId": "xxx"
    },
    "variantInfo": {
      // 对应HDOC_REC_DATA_KOLA_VARIANT查询结果
    }
  }
}

Response Error (400) 

{
  "error": "Invalid chassis number",
  "message": "Chassis number is required"
}

Response Error (500) 

{
  "error": "Internal Server Error",
  "message": "Failed to retrieve data from database"
}

5. 异常处理 (Exception Handling)

异常场景 处理方式 Message 显示内容
Chassis编号为空 终止流程 未指定Chassis编号
变体信息未找到 显示提示，字段留空 未找到对应变体信息
Symbol信息未找到 显示"N/A" 无法获取发动机符号信息
API调用失败 显示通用错误 系统内部错误，请联系管理员

6. 实现注意事项 (Implementation Notes)

  1. 状态管理：
    • 使用 React State 管理 chassisNo, model, builtWeek, productType, vin, engineNo, countryOfOperation, symbolStr, description, sNoteNo, errorMessage, isLoading。
    • 所有字段均为只读显示。
  2. 安全性：
    • API 请求必须通过 HTTPS 发送。
    • 仅读取已授权访问的数据。
  3. UI 细节：
    • SYMBOL_STR 字段上方设置tooltip，当用户将鼠标悬停于该字段时，显示对应的DESCRIPTION内容。
    • 所有字段以标签形式静态展示，无交互操作。
