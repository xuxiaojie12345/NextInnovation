## 1. 背景 (Background)

本模块用于说明系统相关信息，提供系统功能导航链接，为用户提供系统使用指导。

- **目标**：提供系统功能的导航入口和帮助信息。
- **面向用户**：系统用户、需要系统帮助信息的工作人员、系统管理员。
- **用户体验**：提供直观的导航链接、清晰的系统功能说明、便捷的页面跳转方式。
- **安全性**：确保页面访问的安全性、防止未授权的系统信息访问。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

### 3.1 处理流程

#### 3.1.1 页面初始化流程

1. **开始**：页面加载。
2. **前置处理**：准备页面元素，显示所有导航链接。
3. **结果处理**：
   - **成功**：显示页面和导航链接。
   - **失败**：显示"HDoc Help页面加载失败，请稍后再试"。

#### 3.1.2 HDoc快速指南跳转流程

1. **开始**：用户点击"HDoc Quick Guide"链接。
2. 系统通过React Router跳转至Download and Print Quick Guides页面（路由：`/DownloadAndPrintQuickGuides`）。
3. **成功**：跳转到目标页面。
4. **失败**：显示"目标页面不可用，请联系管理员"。

#### 3.1.3 文档类型列表跳转流程

1. **开始**：用户点击"List of document types."链接。
2. 系统跳转至Document Types页面（路由：`/DocumentTypes`）。
3. **结果处理**：同HDoc快速指南跳转。

#### 3.1.4 市场信息跳转流程

1. **开始**：用户点击"Markets in HDoc"链接。
2. 系统跳转至Markets in HDoc页面（路由：`/MarketsInHDoc`）。
3. **结果处理**：同HDoc快速指南跳转。

#### 3.1.5 市场文档设置跳转流程

1. **开始**：用户点击"HDoc - Market Document Settings"链接。
2. 系统跳转至HDoc - Market Document Settings页面（路由：`/MarketDocumentSettings`）。
3. **结果处理**：同HDoc快速指南跳转。

## 4. 接口定义 (API Specification)

本模块无API接口定义。页面间跳转通过前端路由（React Router）实现。

## 5. 异常处理 (Exception Handling)

| 异常场景         | 处理方式         | Message 显示内容                    |
| :--------------- | :--------------- | :---------------------------------- |
| **页面加载失败** | 显示系统错误消息 | `HDoc Help页面加载失败，请稍后再试` |
| **链接跳转失败** | 显示错误消息     | `目标页面不可用，请联系管理员`      |
| **路由不存在**   | React Router捕获 | `目标页面不可用，请联系管理员`      |

## 6. 实现注意事项 (Implementation Notes)

1. **导航链接**：所有Link控件通过React Router的`<Link>`或`useNavigate`实现页面跳转。
2. **目标页面路由映射**：
   - HDoc Quick Guide → `/DownloadAndPrintQuickGuides`
   - List of document types → `/DocumentTypes`
   - Markets in HDoc → `/MarketsInHDoc`
   - HDoc - Market Document Setting → `/MarketDocumentSettings`
3. **UI细节**：
   - 链接以蓝色可点击文字显示。
   - 建议使用列表或分组方式清晰排列各导航链接。
   - Other Information区域可通过Checkbox控制显示/隐藏。
4. **无API调用**：本模块不涉及后端API，所有功能为前端页面导航。
