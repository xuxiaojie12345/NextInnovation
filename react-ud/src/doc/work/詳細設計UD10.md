## 1. 背景 (Background)

本模块用于管理HDoc系统中的变量（Variables）配置，支持对变量的查询、新增、修改和删除操作。

- **目标**：向系统管理员、配置工程师及合规审核人员提供HDoc变量的管理功能。
- **安全性**：仅允许授权用户执行增删改操作，所有变更需记录操作人与时间。
- **用户体验**：保证输入字段清晰、操作按钮明确、错误提示及时。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

所有校验逻辑均在页面加载时或用户执行操作时执行。

### 3.1 处理流程

#### 3.1.1 画面初期表示流程

1.  **开始**：页面加载触发。
2.  **前置处理**：

- 初始化所有字段为空。
- 设置Type下拉列表为固定值："VDA"、"User Defined"。

3.  **结果处理**：

- **成功**：所有文本框默认为空，按钮处于可用状态。
- **失败**：显示错误消息："系统内部错误，请联系管理员"。

#### 3.1.2 搜索处理流程

1.  **开始**：用户点击「Search」按钮。
2.  **前置处理**：用户在对应字段中输入或选择条件。
3.  **API 调用 (Backend Check)**：

- 调用 UD10HdocvariablesApi 搜索接口。

4.  **结果处理**：

- **成功**：跳转至"Existing HDoc Variables"搜索结果页面。
- **失败**：显示错误消息："系统内部错误，请联系管理员"。

#### 3.1.3 新增处理流程

1.  **开始**：用户点击「Add」按钮。
2.  **前置处理**：用户填写Variable字段（必填），填写Type、Description等其他字段。
3.  **空值校验 (Frontend Check)**：

- 若Variable为空：
  - 设置Message = "Variable为必填项"。
  - **终止**流程。

4.  **主键冲突校验 (Backend Check)**：

- 调用 UD10HdocvariablesApi 检查Variable是否已存在。
- 若已存在：
  - 设置Message = "Variant already exists. Please enter the correct content"。
  - **终止**流程。

5.  **API 调用 (Backend Check)**：

- 调用 UD10HdocvariablesApi 新增接口执行插入操作。

6.  **结果处理**：

- **成功**：显示提示："记录添加成功"。
- **失败**：显示错误消息："Variant already exists. Please enter the correct content"。

#### 3.1.4 更新处理流程

1.  **开始**：用户点击「Update」按钮。
2.  **前置处理**：用户选择要修改的记录（可通过搜索获取），修改相关字段内容。
3.  **存在性校验 (Backend Check)**：

- 调用 UD10HdocvariablesApi 检查该记录是否存在。
- 若不存在：
  - 设置Message = "Variant does not exists. Please enter the correct content"。
  - **终止**流程。

4.  **API 调用 (Backend Check)**：

- 调用 UD10HdocvariablesApi 更新接口执行更新操作。

5.  **结果处理**：

- **成功**：显示提示："记录更新成功"。
- **失败**：显示错误消息："Variant does not exists. Please enter the correct content"。

#### 3.1.5 删除处理流程

1.  **开始**：用户点击「Delete」按钮。
2.  **前置处理**：用户选择要删除的记录。
3.  **存在性校验 (Backend Check)**：

- 调用 UD10HdocvariablesApi 检查该记录是否存在。
- 若不存在：
  - 设置Message = "Variant does not exists. Please enter the correct content"。
  - **终止**流程。

4.  **API 调用 (Backend Check)**：

- 调用 UD10HdocvariablesApi 删除接口执行删除操作。

5.  **结果处理**：

- **成功**：显示提示："记录删除成功"。
- **失败**：显示错误消息："Variant does not exists. Please enter the correct content"。

#### 3.1.6 导出Excel处理流程

1.  **开始**：用户点击「Excel」按钮。
2.  **API 调用 (Backend Check)**：

- 调用 UD10HdocvariablesApi 导出接口获取当前搜索结果。

3.  **处理逻辑**：

- 将数据转换为CSV格式并触发下载。
- 文件名为"HDoc_Variables_YYYYMMDD.csv"。

4.  **结果处理**：

- **成功**：触发CSV文件下载。

#### 3.1.7 清除处理流程

1.  **开始**：用户点击「Clear」按钮。
2.  **处理逻辑**：

- 所有输入框内容被清空。
- 下拉菜单恢复初始状态。

3.  **结果处理**：

- **成功**：所有字段清空，页面恢复初始状态。

#### 3.1.8 返回处理流程

1.  **开始**：用户点击「Back」按钮。
2.  **处理逻辑**：

- 页面跳转至前画面。

3.  **结果处理**：

- **成功**：返回前画面。

## 4. 接口定义 (API Specification)

### 4.1 UD10HdocvariablesApi

#### 4.1.1 搜索接口 (GET /search)

- **功能**：提供HDoc Variables的CRUD操作接口。
- **Method**: `POST`
- **Endpoint**: `/api/ud10/add`

##### Request

```json
{
  "variable": "FTLI",
  "type": "User Defined",
  "description": "Front load index"
}
```

#### Response Success (200)

```json
{
  "code": 200,
  "msg": "添加变量成功",
  "data": {
    "variable": "xxx"
  }
}
```

#### 4.1.2 新增接口 (POST /add)

- **功能**：提供HDoc Variables的CRUD操作接口。
- **Method**: `PUT`
- **Endpoint**: `/api/ud10/update`

##### Request

```json
{
  "variable": "FTLI",
  "type": "User Defined",
  "description": "Front load index",
  "createdByUser": "admin",
  "date": "2023-09-01"
}
```

#### Response Success (200)

```json
{
  "code": 200,
  "msg": "更新变量成功",
  "data": {
    "variable": "xxx"
  }
}
```

#### 4.1.3 更新接口 (PUT /update)

- **功能**：提供HDoc Variables的CRUD操作接口。
- **Method**: `DELETE`
- **Endpoint**: `/api/ud10/delete`

##### Request

```json
{
  "variable": "FTLI",
  "type": "User Defined",
  "description": "Updated front load index",
  "createdByUser": "admin",
  "date": "2023-09-01"
}
```

#### Response Success (200)

```json
{
  "code": 200,
  "msg": "删除变量成功",
  "data": {
    "variable": "xxx"
  }
}
```

## 5. 异常处理 (Exception Handling)

| 异常场景                        | 处理方式     | Message 显示内容                                             |
| :------------------------------ | :----------- | :----------------------------------------------------------- |
| **主键冲突（Add）**             | 终止流程     | `Variant already exists. Please enter the correct content`   |
| **记录不存在（Update/Delete）** | 终止流程     | `Variant does not  exists. Please enter the correct content` |
| **API调用失败**                 | 显示通用错误 | `系统内部错误，请联系管理员`                                 |

## 6. 实现注意事项 (Implementation Notes)

1.  **状态管理**：
    - 使用 React State 管理 variable, type, description, createdByUser, date, errorMessage, `isLoading`。
    - Type下拉列表选项固定为"VDA"和"User Defined"。
2.  **安全性**：
    - API 请求必须通过 HTTPS 发送。
    - 需要用户登录认证后才能执行增删改操作。
    - 所有变更需记录操作人与时间。
3.  **UI 细节**：
    - 操作按钮（Search、Clear、Add、Update、Delete、Excel）在 `isLoading` 期间应设为 `disabled`，防止重复提交。
    - Message 文字颜色建议使用红色 (`#ff4d4f`) 以起到警示作用。
    - Excel按钮触发CSV文件下载，文件名为"HDoc_Variables_YYYYMMDD.csv"。
