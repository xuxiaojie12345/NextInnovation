## 1. 背景 (Background)

本模块用于显示HDoc系统中可用的文档类型列表，包括文档类型的键值和描述。

- **目标**：向需要了解文档类型的业务人员和系统管理员提供文档类型列表展示功能。
- **安全性**：需验证用户权限，确保只能访问授权的文档类型信息。
- **用户体验**：提供清晰的文档类型列表展示，便于用户识别和选择合适的文档类型。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

所有校验逻辑均在页面加载时执行。

### 3.1 处理流程

#### 3.1.1 页面初始化流程

1.  **开始**：用户进入Document Types画面。
2.  **前置处理**：准备调用API获取HDOC_DOCUMENT_LIST表数据。
3.  **API 调用 (Backend Check)**：

- 调用[UD20MarketDocumentSettingsApi]
- API内部逻辑：
  1.  查询HDOC_DOCUMENT_LIST表，获取所有文档类型记录
  2.  提取DOCTYPE、Description字段
  3.  按DOCTYPE字母顺序排序
  4.  返回文档类型列表

4.  **结果处理**：

- **成功**：正常显示文档类型列表信息。
- **失败**：显示相应错误消息并保持在当前页面。

## 4. 接口定义 (API Specification)

### 4.1 UD20MarketDocumentSettingsApi

- **功能**：获取市场文档设置列表。
- **Method**: `GET`
- **Endpoint**: `/api/ud20/getdocumentlist`

#### Request

无

#### Response Success (200)

```json
{
            "code": 200,
            "msg": "获取文档列表成功",
            "data": [
                {
                    "doctype": "xxx",
                    "description": "xxx"
                    "registerUser": "xxx",
                    "registerDatetime": "xxx"
                }
            ]
        }
```

##### 响应字段说明

| 字段名       | 类型   | 说明                                                                              |
| :----------- | :----- | :-------------------------------------------------------------------------------- |
| documentType | String | 文档类型，来自HDOC_DOCUMENT_LIST.DOCTYPE，最大20字符                              |
| bussinesUnit | String | 业务单元，固定显示'BU'或实际业务单元代码                                          |
| user         | String | 注册用户，来自HDOC_DOCUMENT_LIST.REGISTER_USER，最大16字符，若为空显示'-'         |
| date         | String | 注册日期时间，来自HDOC_DOCUMENT_LIST.REGISTER_DATETIME，格式：YYYY-MM-DD HH:mm:ss |

#### Response Error (400/500)

```json
{
  "code": 400,
  "message": "No data found",
  "data": null
}
```

或

```json
{
  "code": 500,
  "message": "系统错误，请稍后重试",
  "data": null
}
```

## 5. 异常处理 (Exception Handling)

| 异常场景                 | 处理方式                   | Message 显示内容       |
| :----------------------- | :------------------------- | :--------------------- |
| **无法获取文档类型数据** | 显示错误消息，保持当前页面 | `无法获取文档类型信息` |
| **API调用失败**          | 显示错误消息，保持当前页面 | `系统错误，请稍后重试` |

## 6. 实现注意事项 (Implementation Notes)

1.  **状态管理**：
    - 使用 React State 管理 documentTypes, errorMessage, `isLoading`。
    - 确保DataTable按Key（DOCTYPE）字母顺序显示。
2.  **安全性**：
    - API 请求必须通过 HTTPS 发送。
    - 需要用户登录认证后才能访问。
3.  **UI 细节**：
    - DataTable 为只读展示，不提供任何编辑功能。
    - Message 文字颜色建议使用红色 (`#ff4d4f`) 以起到警示作用。
