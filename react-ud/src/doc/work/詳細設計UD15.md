## 1. 背景 (Background)

本模块用于管理VIN Plate的发送数据状态，支持查询、状态更新及模式切换操作。

- **目标**：向系统管理员、生产准备人员及质量审核人员提供VIN Plate状态管理功能。
- **安全性**：仅允许授权用户执行状态更新操作，所有变更需记录日志。
- **用户体验**：操作流程清晰、状态变化明确、错误提示及时。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

所有校验逻辑均在页面加载时或用户执行操作时执行。

### 3.1 处理流程

#### 3.1.1 页面初始化流程

1.  **开始**：页面加载触发。
2.  **前置处理**：

- 初始化所有输入框为空。
- 详细信息展示区域隐藏。

3.  **结果处理**：

- **成功**：Chassis number输入框为空，所有操作按钮处于可用状态，详细信息展示区域隐藏。

#### 3.1.2 查询处理流程（View Info）

1.  **开始**：用户点击View Info按钮。
2.  **前置处理**：

- 校验Chassis number是否为空。
- 若为空：设置Message = "请输入Chassis number"；终止流程。

3.  **处理步骤**：

- 调用API查询HDOC_SEND_DATA_VIN_PLATE表。
- 若未找到记录：报错"Chassis number XXX not found."。
- 若找到记录：解析XML_DOC字段并展示所有信息。

4.  **结果处理**：

- **成功**：显示VIN Plate详细信息。
- **失败**：显示错误消息："Chassis number XXX not found."。

#### 3.1.3 状态更新处理流程（Set Regenerate/Set OK/Change to Basic Info/Change to Advanced Info）

1.  **开始**：用户点击对应状态更新按钮。
2.  **前置处理**：

- 检查是否已查询到Chassis信息。
- 若未先执行查询：设置Message = "请先查询Chassis信息"；终止流程。

3.  **处理步骤**：

- 调用API更新HDOC_SEND_DATA_VIN_PLATE表中的对应字段。

4.  **结果处理**：

- **成功**：刷新页面显示最新状态，显示更新成功消息。
- **失败**：显示错误消息："更新失败，请联系管理员"。

## 5. 异常处理 (Exception Handling)

| 异常场景                 | 处理方式     | Message 显示内容                |
| :----------------------- | :----------- | :------------------------------ |
| **Chassis number未找到** | 显示警告消息 | `Chassis number XXX not found.` |
| **Chassis number为空**   | 终止流程     | `请输入Chassis number`          |
| **未先查询直接更新**     | 终止流程     | `请先查询Chassis信息`           |
| **API调用失败**          | 显示通用错误 | `更新失败，请联系管理员`        |
| **数据库更新异常**       | 显示通用错误 | `系统内部错误，请联系管理员`    |

## 6. 实现注意事项 (Implementation Notes)

1.  **状态管理**：
    - 使用 React State 管理 chassisNumber, plateType, status, errorMessage, defTime, dataReadyTime, sentToFactoryTime, printItems, vpData, loading, `hasQueried`。
    - 详细信息展示区域根据hasQueried状态控制显示/隐藏。
2.  **安全性**：
    - API 请求必须通过 HTTPS 发送。
    - 需要用户登录认证后才能执行状态更新操作。
    - 所有变更需记录日志。
3.  **UI 细节**：
    - 操作按钮（View Info、Set Regenerate、Set OK、Change to Basic Info、Change to Advanced Info）在 `loading` 期间应设为 `disabled`，防止重复提交。
    - Message 文字颜色建议使用红色 (`#ff4d4f`) 以起到警示作用。
    - 成功消息使用绿色 (`#52c41a`) 显示。
