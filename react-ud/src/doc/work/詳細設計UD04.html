1. 背景 (Background)

本模块用于显示和下载车辆认证文档，主要功能包括：

  • 目标：显示指定底盘号的接收信息（OM、VDA、KOLA数据）、S-Note信息和轮胎主数据、ADCA变更状态，支持跳转到修改文档页面，显示VIN Plate参数和模板信息，提供文档下载功能。
  • 安全性：需要用户登录认证后才能访问，敏感数据需要进行权限控制，支持HTTPS安全传输。
  • 用户体验：清晰的信息展示布局，重要的变更信息以红色高亮显示，提供便捷的文档下载链接，实时显示系统时间和版本信息。

3. 业务逻辑与校验规则 (Business Logic & Checks)

所有校验逻辑均在页面加载时或用户点击链接时执行。

3.1 处理流程

3.1.1 页面初始化流程

  1. 开始：页面加载。
  2. 前置处理：从路由参数或上下文获取底盘号。
  3. API 调用 (Backend Check)：
    • 调用 UD04SelectGeneratedocumentApi。
    • 传递参数：chassisNo（底盘号）。
  4. 结果处理：
    • 成功：
      • 解析API返回的数据。
      • 将OM接收数据显示到对应字段（Chassis series、Chassis no、Model、Spec week、S-Note NO）。
      • 将VDA接收数据显示到Market字段。
      • 将KOLA轮胎主数据显示到Load Index字段。
      • 若有S-Note信息，显示固定提示消息"The S-Notes above can affect homologation documents."。
      • 检查ADCA变更状态，决定Modify Doc Link的显示样式。
      • 显示Template信息和Replacing parameters。
      • 启用Generated document下载链接。
      • 显示服务器当前时间和程序版本。
    • 失败（底盘号不存在）：
      • 在Error message area显示"未找到底盘信息"。
      • 其他字段保持为空或显示默认值。
    • 服务器错误：
      • 在Error message area显示"系统错误。请联系管理员。"。
      • 其他字段保持为空或显示默认值。

3.1.2 ADCA变更状态判断流程

  1. 开始：接收到API返回的ADCA变更数据。
  2. 处理步骤：
    • 读取HDOC_ADCA_CHANGE表的ACT字段值。
    • 若ACT为激活状态（值为"Y"）：
      • Modify Doc Link文字颜色设置为红色。
      • 显示提示信息"After def change detected. Document need to be modified."。
      • 启用链接点击事件，点击后跳转到/ModifyDocument路由。
      • 从HDOC_ADCA_MODIFICATION表获取VARIABLE和NEWVAL字段，显示在Replacing parameters区域。
    • 若ACT为非激活状态（值为"N"）：
      • Modify Doc Link不显示或显示为灰色不可点击状态。
      • 不显示提示信息。
      • Replacing parameters区域显示为空。

3.1.3 文档下载流程

  1. 开始：用户点击Generated document链接。
  2. 处理步骤：
    • 触发浏览器下载功能。
    • 请求VPPS VIN PLATE创建批处理生成的.trf文件。
    • 文件路径从API返回数据中获取。
    • 浏览器自动下载文件到本地。
    • 文件名包含底盘号和文档类型信息。

3.1.4 跳转功能流程

  1. Analyze Rules链接：
    • 用户点击Analyze Rules链接。
    • 跳转到分析规则详情页面或弹出对话框显示规则信息。
  2. Modify Doc Link链接：
    • 仅在ADCA变更激活时可点击。
    • 用户点击链接。
    • 跳转到Modify Document页面进行文档修改。
  3. Chassis no链接（如需要）：
    • 用户点击Chassis no链接。
    • 显示该底盘的详细详细信息页面。

4. 接口定义 (API Specification)

4.1 UD04SelectGeneratedocumentApi

  • 功能：根据底盘号查询并返回所有相关的文档信息和数据。
  • Method: POST
  • Endpoint: /api/XXXXX/selectGeneratedocument

Request 

{
  "chassisNo": "028321",
  "chassisSeries":"JPCT"
}

#### Response Success (200)

```json
{
             "code": 200,
             "msg": "查询成功",
             "data": {
                 "ORDERNUMBER": "xxxx",
                 "BUILD": "xxxx",
                 "SPEC": "xxxx",
                 "CUSTOMER_ADAP": "xxxx",
                 "COUNTRY_OF_OPERATION": "xxxx",
                 "LOAD_INDEX": "xxxx",
                 "ACT": "xxxx",
                 "VARIABLE": "xxxx"
             }
         }
```

#### Response Error (404)

```json
{
  "code": 404,
  "msg": "未找到底盘信息",
  "data": null
}
```

#### Response Error (500)

```json
{
  "code": 500,
  "msg": "系统错误。请联系管理员。",
  "data": null
}
```

## 5. 异常处理 (Exception Handling)

| 异常场景                                 | 处理方式                                 | Message 显示内容           |
| :--------------------------------------- | :--------------------------------------- | :------------------------- |
| **网络连接失败**                         | 捕获网络异常                             | `系统错误。请联系管理员。` |
| **API超时**                              | 设置超时时间（建议10秒），超时后显示错误 | `系统错误。请联系管理员。` |
| **UD04SelectGeneratedocumentApi返回404** | 显示底盘号不存在消息                     | `未找到底盘信息`           |
| **UD04SelectGeneratedocumentApi返回500** | 显示系统错误消息                         | `系统错误。请联系管理员。` |
| **JSON解析失败**                         | 捕获解析异常                             | `系统错误。请联系管理员。` |
| **未预期的JavaScript错误**               | 使用try-catch包裹关键代码，记录错误日志  | `系统错误。请联系管理员。` |
| **用户未登录**                           | 检查会话状态                             | `请先登录`                 |
| **文件下载失败**                         | 捕获下载异常                             | `文档文件未找到`           |

## 6. 实现注意事项 (Implementation Notes)

1.  **状态管理**：
    - 使用 React State 管理各个字段的显示数据、errorMessage、`isLoading`。
    - `Error message area` Label 默认隐藏（内容为空时不占位或高度为0）。
2.  **安全性**：
    - API 请求必须通过 HTTPS 发送。
    - 需要用户登录认证后才能访问。
    - 敏感数据需要进行权限控制。
3.  **UI 细节**：
    - Modify Doc Link 在ADCA变更激活时文字颜色建议使用红色 (`#ff4d4f`) 以起到警示作用。
    - Generated document 链接应启用下载功能。
    - Date 字段显示服务器当前时间，格式为"YYYY-MM-DD HH:MM:SS"。
    - HDoc version 字段显示当前程序版本号。
