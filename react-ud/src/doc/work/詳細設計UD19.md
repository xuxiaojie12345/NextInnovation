## 1. 背景 (Background)

本模块用于搜索和展示HDoc系统用户信息。用户可以通过多种条件（Userid、User、Market、权限类型）进行组合搜索，查看用户的详细信息包括Userid、用户名和关联的Market。该功能主要用于用户管理和权限查询，帮助管理员快速定位特定用户及其权限配置。

- **目标**：向系统管理员、具有用户管理权限的业务人员及需要查询用户信息的授权用户提供用户搜索功能。
- **安全性**：需要从Saviynt系统获取用户信息（通过AuthenticationApi）；需要从多个数据库表获取权限信息；支持按权限类型过滤（Rule Admin、Template Admin等）；所有用户数据均为只读展示。
- **用户体验**：提供多种搜索条件组合，支持灵活查询；搜索结果以表格形式清晰展示；Market下拉列表默认显示常用选项（-EU）；实时显示搜索结果数量；支持双向搜索（通过Userid查User，或通过User查Userid）。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

所有校验逻辑均在页面加载时或用户执行操作时执行。

### 3.1 处理流程

#### 3.1.1 页面初始化流程

1.  **开始**：页面加载事件触发。
2.  **前置处理**：

- 无。

3.  **API 调用 (Backend Check)**：

- 调用[UD19SearchResultListApi]
- API内部逻辑：
  1.  查询MARKET_MASTER表，获取所有Market列表。
  2.  按Market代码排序。
  3.  返回Market列表。

4.  **结果处理**：

- **成功**：将Market列表填充到下拉列表；设置默认值为'-EU'。
- **失败**：显示错误消息"获取Market列表失败"。

#### 3.1.2 Userid搜索流程

1.  **开始**：用户点击Search按钮（Userid有值）。
2.  **前置处理**：

- 获取Userid、Market、权限类型参数。
- 去除Userid首尾空格，转换为大写。

3.  **空值校验 (Frontend Check)**：

- 若Userid为空或仅包含空格：
  - 设置Message = "Userid不能为空"。
  - **终止**流程。
- 若Userid包含非半角英数字字符：
  - 设置Message = "Userid只能包含半角英数字"。
  - **终止**流程。
- 若Userid长度超过10字符：
  - 设置Message = "Userid长度不能超过10字符"。
  - **终止**流程。

4.  **API 调用 (Backend Check)**：

- 调用[UD19SearchResultListApi]
- 请求参数：
  ```json
  {
    "userid": "SWE",
    "market": "-EU",
    "permissionType": "NOT_SET"
  }
  ```
- API内部逻辑：
  1.  调用AuthenticationApi从Saviynt系统获取User信息
      - 若Userid不存在于Saviynt系统，返回错误
  2.  从HDOC_FUNCTION_AUTH表查询该Userid的功能权限
  3.  从HDOC_MARKET_AUTH表查询该Userid的Market权限
  4.  根据permissionType过滤：
      - NOT_SET：不过滤
      - RULE：仅保留FUNCTION_TYPE='Rule Admin'的记录
      - TEMPLATE：仅保留FUNCTION_TYPE='Template Admin'的记录
  5.  根据market过滤（若market不为空）：
      - 仅保留包含指定Market的记录
  6.  组装结果列表

5.  **结果处理**：

- **成功**：将结果填充到DataTable；更新COUNT显示记录数；若无结果：显示"未找到匹配的用户"。
- **失败**：若Userid不存在：显示"Userid XXX不存在"；若其他错误：显示具体错误消息。

#### 3.1.3 User搜索流程

1.  **开始**：用户点击Search按钮（User有值）。
2.  **前置处理**：

- 获取User、Market、权限类型参数。
- 去除User首尾空格。

3.  **空值校验 (Frontend Check)**：

- 若User为空或仅包含空格：
  - 设置Message = "User不能为空"。
  - **终止**流程。
- 若User包含非半角英数字字符：
  - 设置Message = "User只能包含半角英数字"。
  - **终止**流程。
- 若User长度超过32字符：
  - 设置Message = "User长度不能超过32字符"。
  - **终止**流程。

4.  **API 调用 (Backend Check)**：

- 调用[UD19SearchResultListApi]
- 请求参数：
  ```json
  {
    "user": "Kurt Bjork",
    "market": "-EU",
    "permissionType": "NOT_SET"
  }
  ```
- API内部逻辑：
  1.  调用AuthenticationApi从Saviynt系统获取Userid
      - 若User不存在于Saviynt系统，返回错误
  2.  根据Userid从HDOC_MARKET_AUTH表查询Market权限
  3.  从HDOC_FUNCTION_AUTH表查询功能权限
  4.  根据permissionType和market过滤（同Userid搜索）
  5.  组装结果列表

5.  **结果处理**：

- **成功**：将结果填充到DataTable；更新COUNT显示记录数。
- **失败**：若User不存在：显示"User XXX不存在"；若其他错误：显示具体错误消息。

#### 3.1.4 Not set搜索流程

1.  **开始**：用户选择Not set并点击Search按钮。
2.  **前置处理**：

- 获取Market参数。

3.  **API 调用 (Backend Check)**：

- 调用[UD19SearchResultListApi]
- 请求参数：
  ```json
  {
    "market": "-EU"
  }
  ```
- API内部逻辑：
  1.  从Saviynt系统获取所有用户列表
  2.  对每个用户：
      - 从HDOC_MARKET_AUTH表查询Market权限
      - 从HDOC_FUNCTION_AUTH表查询功能权限
  3.  根据market过滤（若market不为空）
  4.  组装结果列表

4.  **结果处理**：

- **成功**：将结果填充到DataTable；更新COUNT显示记录数。
- **失败**：显示错误消息。

#### 3.1.5 Rule搜索流程

2.  **前置处理**：

- 获取Market参数。

3.  **API 调用 (Backend Check)**：

- 调用[UD19SearchResultListApi]
- 请求参数：

  2.  获取Userid列表
  3.  对每个Userid：

  4.  根据market过滤
  5.  组装结果列表

4.  **结果处理**：

- **成功**：将结果填充到DataTable；更新COUNT显示记录数；若无结果：显示"未找到Rule Admin权限的用户"。

## 4. 接口定义 (API Specification)

### 4.1 UD19SearchResultListApi

- **功能**：获取Market列表。
- **Method**: `GET`
- **Endpoint**: `/api/ud19/getmarketlist`

#### Request

无

#### Response Success (200)

```json
{
  "code": 200,
  "msg": "获取市场列表成功",
  "data": [
    {
      "market": "xx",
      "description": "xxx"
    }
  ]
}
```

#### Response Error (500)

```json
{
  "code": 500,
  "message": "获取Market列表失败",
  "data": null
}
```

### 4.2 UD19SearchResultListApi

- **功能**：根据Userid或User或选择Not set或选择Rule或Template搜索用户。
- **Method**: `POST`
- **Endpoint**: `/api/ud19/searchhdoc`

#### Request Body

```json
{
  "userid": "SWE",
  "user": "xxx",
  "searchType": "NOT_SET"
}
```

##### 参数说明

| 参数名     | 类型   | 必填 | 说明                            |
| :--------- | :----- | :--- | :------------------------------ |
| userid     | String | Y    | 用户ID，最大10字符              |
| user       | String | N    | 用户名，最大32字符              |
| searchType | String | Y    | 权限类型：NOT_SET/RULE/TEMPLATE |

#### Response Success (200)

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "count": 2,
    "users": [
      {
        "userid": "SWE",
        "user": "Kurt Bjork",
        "market": "-EU,1AD,1CZ"
      },
      {
        "userid": "e2090ru",
        "user": "Ivanova Anna",
        "market": "-EU,1RU"
      }
    ]
  }
}
```

#### Response Error (400/500)

```json
{
  "code": 400,
  "message": "Userid SWE不存在",
  "data": null
}
```

## 6. 实现注意事项 (Implementation Notes)

1.  **状态管理**：
    - 使用 React State 管理 userid, user, market, permissionType, users, count, errorMessage, `isLoading`。
    - 确保RadioBox组的选择状态互斥。
2.  **安全性**：
    - API 请求必须通过 HTTPS 发送。
    - 需要用户登录认证后才能执行搜索操作。
3.  **UI 细节**：
    - Search 按钮在 `isLoading` 期间应设为 `disabled`，防止重复提交。
    - Message 文字颜色建议使用红色 (`#ff4d4f`) 以起到警示作用。
    - 成功消息使用绿色 (`#52c41a`) 显示。
    - COUNT 标签实时显示搜索结果数量。
