## 1. 背景 (Background)

本模块用于显示Homologation Variables页面的搜索结果列表，主要功能包括：根据前画面传递的搜索条件显示匹配的变量规则列表，支持选择单条记录并返回前画面，支持批量删除选中的记录，支持打印搜索结果，支持返回前画面并保留搜索条件，显示搜索结果总数。

- **面向的用户群体**：需要查看和管理认证变量的授权用户，如系统管理员、质量管理人员等
- **用户体验考虑**：清晰的数据表格展示，便捷的记录选择和操作功能，明确的搜索结果计数显示，支持批量删除操作
- **安全性要求**：需要用户登录认证后才能访问，删除操作需要确认或权限控制，支持HTTPS安全传输

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

所有校验逻辑均在用户执行相应操作时同步或异步执行。

### 3.1 处理流程

1. **页面初始化流程**
   - **开始**：页面加载
   - **处理步骤**：
     - 从tate中获取搜索条件
     - 搜索条件包含：Product class、Number、Market、Variable字段
     - 调用UD09Search API（POST方法）
     - 传递参数：搜索条件对象
     - 等待API响应
   - **结果处理**：
     - **成功**：
       - 解析API返回的数据列表
       - 将数据显示到DataTable中
       - 计算记录总数
       - 更新Count字段显示"Number of lines found: XXX"
       - 清空错误消息区域
     - **失败（无匹配数据）**：
       - DataTable显示为空
       - Count字段显示"Number of lines found: 0"
       - 可选择显示提示信息"No records found"
     - **服务器错误**：
       - 在错误消息区域显示"System error. Please contact administrator."
       - DataTable保持为空

2. **选择记录流程**
   - **开始**：用户点击Select按钮
   - **前置处理**：
     - 检查是否有选中的记录
     - 若无选中记录，显示错误消息
   - **处理步骤**：
     - 获取选中记录的完整数据
     - 将数据存储到state或sessionStorage中
     - 使用React Router navigate函数返回/HomologationVariables页面
     - 可选：传递标志位表示是从选择操作返回
   - **前画面处理**：
     - 前画面检测到返回标志
     - 从state或sessionStorage中读取选中的数据
     - 自动填充到对应的输入字段中

3. **返回流程**
   - **开始**：用户点击Back按钮
   - **处理步骤**：
     - 获取当前页面的搜索条件
     - 将搜索条件存储到state或sessionStorage中
     - 使用React Router navigate函数返回/HomologationVariables页面
     - 可选：传递标志位表示是从返回操作回来
   - **前画面处理**：
     - 前画面检测到返回标志
     - 从state或sessionStorage中读取搜索条件
     - 自动填充到对应的输入字段中

4. **打印流程**
   - **开始**：用户点击Print按钮
   - **处理步骤**：
     - 调用window.print()方法
     - 浏览器打开打印预览对话框
     - 用户选择打印机和执行打印
     - 打印内容包括DataTable中的所有数据和Count信息

5. **单条记录删除流程**
   - **开始**：用户点击Delete selected按钮
   - **前置处理**：
     - 检查是否有选中的记录
     - 若无选中记录，显示错误消息"Please select at least one record to delete."
     - 终止流程
   - **处理步骤**：
     - 获取该条选中记录的主键信息（Product class、Number、Market）
     - 构建删除请求参数数组
     - 调用UD09DeleteHdocuserdefinedrules API（POST方法）
     - 传递参数：选中记录的主键列表
     - 等待API响应
   - **结果处理**：
     - **成功**：
       - 成功：显示"Record deleted successfully."，重新调用UD09DeleteHdocuserdefinedrulesApi的UD09Search方法刷新列表数据。
       - 记录不存在：显示"Data does not exist, Please enter the correct content"。
       - 服务器错误：显示"System error. Please contact administrator."。

### 3.2 校验详细规格表

| No. | 检查时机                                 | 检查对象    | 检查条件                   | 错误消息 (Message Content)                   | 动作                                               |
| :-- | :--------------------------------------- | :---------- | :------------------------- | :------------------------------------------- | :------------------------------------------------- |
| 1   | 点击Select按钮时                         | 选中记录    | 未选择任何记录             | Please select a record.                      | 显示错误消息，终止流程                             |
| 2   | 点击Delete selected按钮时                | 选中记录    | 未选择任何记录             | Please select at least one record to delete. | 显示错误消息，终止流程                             |
| 3   | UD08Search API调用后                     | 搜索结果    | API返回空列表              | 无错误消息                                   | Count显示"Number of lines found: 0"，DataTable为空 |
| 4   | UD08Search API调用后                     | 网络/服务器 | API返回500或其他错误状态码 | System error. Please contact administrator.  | 显示错误消息，DataTable为空                        |
| 5   | UD09DeleteHdocuserdefinedrules API调用后 | 删除操作    | 部分记录删除失败           | X records deleted, Y records failed.         | 显示消息，刷新列表                                 |
| 6   | UD09DeleteHdocuserdefinedrules API调用后 | 删除操作    | 全部记录删除失败           | Failed to delete records. Please try again.  | 显示错误消息，保持列表不变                         |

## 4. 接口定义 (API Specification)

### 4.1 UD09DeleteHdocuserdefinedrulesApi

- **功能**：根据搜索条件查询用户自定义规则列表
- **Method**: POST
- **Endpoint**: /api/ud09/search

#### Request Body

```json
{
  "productClass": "string",
  "number": "string",
  "market": "string",
  "variable": "string"
}
```

#### Response Success (200 OK)

```json
{
  "code": 200,
  "msg": "搜索用户定义规则成功",
  "data": [
    {
      "pc": "xx",
      "num": 1,
      "market": "xxx",
      "val": "xxx",
      "vs": "xxx",
      "vs2": "xxx",
      "addDate": "xxx",
      "deleteDate": "xxx",
      "registerUser": "xxx",
      "registerDatetime": "xxx"
    }
  ]
}
```

#### Response Error (500 Internal Server Error)

```json
{
  "message": "Internal server error"
}
```

### 4.2 UD09DeleteHdocuserdefinedrules

- **功能**：批量删除用户自定义规则记录
- **Method**: DELETE
- **Endpoint**: /api/ud09/deleteselected

#### Request Body

```json
[
  {
    "productClass": "PC01",
    "number": "1234567890",
    "market": "DE"
  },
  {
    "productClass": "PC02",
    "number": "0987654321",
    "market": "FR"
  }
]
```

#### Response Success (200 OK)

```json
{
  "code": 200,
  "msg": "删除用户定义规则成功",
  "data": {
    "pc": "xx",
    "num": 1,
    "market": "xxx"
  }
}
```

#### Response Error (500 Internal Server Error)

```json
{
  "success": false,
  "message": "Internal server error"
}
```

## 5. 异常处理 (Exception Handling)

| 异常场景                                  | 处理方式                                 | Message 显示内容                             |
| :---------------------------------------- | :--------------------------------------- | :------------------------------------------- |
| **网络连接失败**                          | 捕获网络异常，显示通用错误消息           | System error. Please contact administrator.  |
| **API超时**                               | 设置超时时间（建议10秒），超时后显示错误 | System error. Please contact administrator.  |
| **UD08Search返回空列表**                  | 显示零结果消息                           | Number of lines found: 0                     |
| **UD08Search返回500**                     | 显示系统错误消息                         | System error. Please contact administrator.  |
| **UD09DeleteHdocuserdefinedrules返回500** | 显示系统错误消息                         | System error. Please contact administrator.  |
| **JSON解析失败**                          | 捕获解析异常，显示系统错误               | System error. Please contact administrator.  |
| **未预期的JavaScript错误**                | 使用try-catch包裹关键代码，记录错误日志  | System error. Please contact administrator.  |
| **用户未登录**                            | 检查会话状态，跳转到登录页面             | Please login first                           |
| **未选择记录点击Select**                  | 显示选择提示消息                         | Please select a record.                      |
| **未选择记录点击Delete selected**         | 显示选择提示消息                         | Please select at least one record to delete. |

## 6. 实现注意事项 (Implementation Notes)

1. **状态管理**：
   - 使用 React State 管理输入值、错误信息及加载状态
   - `Message` Label 默认隐藏（内容为空时不占位或高度为0）
   - 管理选中记录的状态以及DataTable的数据状态
2. **安全性**：
   - 严禁在前端日志中打印敏感数据
   - API 请求必须通过 HTTPS 发送
   - 删除操作需要适当的确认机制
3. **UI 细节**：
   - [Select]、[Back]、[Print]、[Delete selected] 按钮在适当情况下应设为 `disabled`，防止重复提交
   - `Message` 文字颜色建议使用红色 (`#ff4d4f`) 以起到警示作用
   - DataTable 应支持复选框选择功能
   - 用户链接应使用不同的样式以表明其可点击性
   - Count 标签应始终显示当前结果数量
   - 删除操作应弹出确认对话框，确保用户意图
