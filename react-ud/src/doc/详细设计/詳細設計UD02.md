## 1. 背景 (Background)

本模块提供系统主菜单导航功能，是用户登录后的主要操作界面。通过左侧菜单树，用户可以访问系统的各个功能模块，包括文档生成、系统管理、用户管理等核心功能。

- **目标**：提供清晰的菜单层级结构导航，根据用户权限动态显示/隐藏菜单项。
- **面向用户**：系统注册用户、EDB Engineering Database的工程人员、系统管理员、文档管理人员。
- **用户体验**：清晰的菜单层级结构（一级菜单和二级菜单）、直观的图标和文字标识、点击菜单项后右侧内容区动态加载对应页面、响应式布局适配不同屏幕尺寸。
- **安全性**：根据用户权限动态显示/隐藏菜单项、防止未授权访问、菜单状态持久化。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

### 3.1 处理流程

1. **开始**：用户登录成功，进入Menu页面。
2. **前置处理**：
   - 从Session获取用户信息
3. **菜单渲染**：
   - 遍历菜单配置
   - 检查每个菜单项的权限要求
   - 按照一级菜单、二级菜单的层级结构渲染
4. **菜单点击处理**：
   - 捕获菜单项点击事件
   - 更新当前选中菜单状态
   - 使用React Router跳转到对应路由
   - 右侧内容区加载对应组件
5. **结果处理**：
   - **成功**：右侧显示对应页面内容
   - **失败**：显示错误提示信息

## 5. 异常处理 (Exception Handling)

| 异常场景 | 处理方式 | Message 显示内容 |
| :--- | :--- | :--- |
| **用户未登录或Token失效** | 前端拦截，跳转登录页 | `Session expired. Please login again.` |

| **网络超时** | 捕获超时异常 | `Network timeout. Please try again.` |

## 6. 实现注意事项 (Implementation Notes)

1. **状态管理**：
   - 使用React State管理菜单展开/折叠状态、当前选中的菜单项
   - 使用React Router进行页面路由跳转
2. **权限控制**：
   - 登录成功后立即获取用户权限列表
   - 菜单渲染时根据权限列表过滤不可访问的菜单项
3. **UI细节**：
   - 当前选中的菜单项应高亮显示
   - 所有子菜单默认全部展开，用户不可折叠（移除折叠按钮）
   - 菜单宽度固定为 340px，菜单项文字不截断、不显示省略号
   - 右侧内容区使用React Router的Outlet或嵌套路由实现动态加载
