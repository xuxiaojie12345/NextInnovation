## 1. 背景 (Background)

本模块用于展示HDoc系统的市场文档设置列表，用户可以查看文档类型、业务单元、注册用户和注册日期等信息。用户可以选择某条记录并返回前画面，将选中的文档信息自动填充到前画面的相应字段中。

- **目标**：提供文档选择的列表展示与选择返回功能。
- **面向用户**：具有文档管理权限的系统用户、需要选择文档模板的业务人员、需要查看文档注册信息的授权用户。
- **用户体验**：以表格形式清晰展示所有文档信息、提供RadioBox单选机制确保用户只能选择一个记录、支持打印功能、User列提供链接快速查看用户详细信息。
- **安全性**：需要从HDOC_DOCUMENT_LIST表读取文档信息、所有数据均为只读展示（除选择操作外）。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

### 3.1 处理流程

#### 3.1.1 页面初始化流程

1. **开始**：页面加载。
2. 调用`UD20GetDocumentListApi`的`UD20SelectHdocDocumentList`方法，从HDOC_DOCUMENT_LIST表获取所有文档列表。
3. 将数据填充到DataTable中，为每行记录添加RadioBox控件（单选模式）。
4. Bussines unit列固定显示'BU'。
5. 初始化时所有RadioBox均为未选中状态。

#### 3.1.2 Select操作流程

1. **开始**：用户点击Select按钮。
2. **前端校验**：检查是否有记录被选中，若未选中则显示"No data found"（Error级别）并**终止**。
3. 获取选中记录的Document type、Bussines unit、User、Date信息。
4. 将选中的数据存储到状态管理或URL参数中。
5. 关闭当前画面，返回前画面，前画面自动将Document type等信息填充到相应字段。

#### 3.1.3 Back操作流程

1. **开始**：用户点击Back按钮。
2. 无需校验，直接执行画面关闭操作，返回到前画面。
3. 前画面保持原有状态，不更新任何字段。

#### 3.1.4 Print操作流程

1. **开始**：用户点击Print按钮。
2. 调用浏览器打印功能（`window.print()`），生成打印预览。
3. 打印内容包括页面标题、DataTable所有数据、打印时间戳。

#### 3.1.5 User链接点击流程

1. **开始**：用户点击User列的链接。
2. 获取该行的User值（REGISTER_USER）。
3. 打开新窗口或标签页，跳转到EDB用户查看画面，将User值作为参数传递。

### 3.2 校验详细规格表

| No. | 检查时机 | 检查对象 | 检查条件 | 错误消息 (Message Content) | 动作 |
| :-: | :---: | :---: | :--- | :--- | :---: |
| 1 | 点击Select按钮时 | RadioBox选择状态 | 必须有且仅有一个记录被选中 | `No data found` | 终止流程，显示Error级别错误消息 |
| 2 | 页面初始化 | HDOC_DOCUMENT_LIST表 | 至少存在一条记录 | `No data found` | 显示错误消息，DataTable为空 |
| 3 | User链接点击 | User值 | User必须在Saviynt系统中存在 | `用户不存在` | 显示错误提示，不打开新窗口 |

## 4. 接口定义 (API Specification)

### UD20GetDocumentListApi

统一API名称空间，包含以下方法：**UD20SelectHdocDocumentList**（文档列表查询）。

---

### 4.1 UD20SelectHdocDocumentList - 文档列表查询

**功能**：获取市场文档设置列表数据

- **Method**：`POST`
- **Endpoint**：`/api/ud20/UD20GetDocumentListApi`

#### Request

```json
{
  "operation": "SELECT_HDOC_DOCUMENT_LIST"
}
```

#### Response Success (200)

```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "documentType": "COC_EUB1",
      "bussinesUnit": "VBC",
      "user": "-",
      "date": "2026-05-20 10:30:00"
    },
    {
      "documentType": "COC_EU",
      "bussinesUnit": "VTC",
      "user": "ADMIN01",
      "date": "2026-05-19 15:45:00"
    }
  ]
}
```

#### Response Error (500)

```json
{
  "code": 500,
  "message": "Internal server error",
  "data": null
}
```

## 5. 异常处理 (Exception Handling)

| 异常场景 | 处理方式 | Message 显示内容 |
| :--- | :--- | :--- |
| **未选择记录就点击Select** | 前端校验拦截，不发起后续操作 | `No data found`（Error级别） |
| **HDOC_DOCUMENT_LIST表无数据** | API返回400错误，前端显示错误消息 | `No data found` |
| **数据库连接异常** | API返回500错误，前端显示通用错误消息 | `系统错误，请稍后重试` |
| **API超时** | 前端捕获超时异常，显示超时提示 | `请求超时，请检查网络连接后重试` |
| **网络异常** | 前端捕获网络异常，显示网络错误提示 | `网络连接失败，请检查网络设置` |
| **打印功能不可用** | 前端捕获打印异常，显示提示消息 | `打印功能不可用` |

## 6. 实现注意事项 (Implementation Notes)

1. **布局**：
   - 页面以表格形式展示所有文档信息，包含Document type、Bussines unit、User、Date四列。
   - 每行第一列为RadioBox单选按钮，用于选择记录。
2. **数据展示**：
   - Bussines unit列固定显示'BU'。
   - User列渲染为蓝色可点击链接，点击后打开EDB用户查看画面。
3. **排序**：按REGISTER_DATETIME降序排序（最新注册的排在前面）。
4. **Select操作**：必须选择一条记录后才能点击Select按钮，否则显示错误消息。
5. **User链接**：点击后通过新窗口或标签页打开EDB用户查看画面，传递User值作为参数。
