## 1. 背景 (Background)

本模块用于检查HDoc模板文件的格式和内容，主要功能包括支持选择并上传rtf格式的模板文件、读取文件内容并解析`$`符号之间的变量、统计变量数量、验证文件格式是否正确、提供检查后的模板下载链接。

- **目标**：提供模板文件中变量的解析与检查功能。
- **面向用户**：需要验证认证系统模板文件格式和内容的授权用户，如系统管理员、配置管理人员等。
- **用户体验**：清晰的文件选择界面、明确的检查结果反馈、便捷的下载功能、详细的错误提示信息。
- **安全性**：需要用户登录认证后才能访问、文件上传需要进行类型验证（仅允许rtf文件）、支持HTTPS安全传输协议。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

### 3.1 处理流程

#### 3.1.1 页面初始化流程

1. **开始**：页面加载。
2. 清空文件选择框、清空错误消息和成功消息区域、隐藏Download checked template链接。
3. 页面处于等待用户选择文件的状态。

#### 3.1.2 文件检查流程

1. **开始**：用户点击Check按钮。
2. **前置处理**：校验是否选择了文件，若未选择则显示"ERROR: Unable to access file!"并**终止**。
3. 读取选中的文件内容。
4. 使用正则表达式或字符串匹配查找`$`符号对，提取所有`$...$`格式的变量，统计变量数量。
5. **结果处理**：
   - **成功（变量数量 >= 1）**：显示成功消息（包含变量数量和变量列表），显示Download checked template链接。
   - **失败（变量数量 = 0）**：显示错误消息"ERROR: The file content is incorrect!"，不显示下载链接。

#### 3.1.3 下载检查后的模板流程

1. **开始**：用户点击Download checked template链接。
2. 触发文件下载，浏览器保存检查后的模板文件。
3. 文件名建议格式：checked_template_YYYYMMDD.rtf。

### 3.2 校验详细规格表

| No. | 检查时机 | 检查对象 | 检查条件 | 错误消息 (Message Content) | 动作 |
| :-: | :---: | :---: | :--- | :--- | :---: |
| 1 | 点击Check按钮时 | 文件选择 | 未选择任何文件 | `ERROR: Unable to access file!` | 显示错误消息，终止流程 |
| 2 | 文件内容解析后 | 变量数量 | 文件中没有找到任何$...$格式的变量 | `ERROR: The file content is incorrect!` | 显示错误消息，不显示下载链接 |
| 3 | 文件读取失败 | 文件访问 | 无法读取文件内容 | `ERROR: Unable to access file!` | 显示错误消息，终止流程 |

## 4. 接口定义 (API Specification)

本模块不调用后端API，所有处理在前端完成。

### 4.1 文件读取和处理

- **功能**：在前端读取并解析rtf文件内容
- **处理方式**：
  - 使用`FileReader` API读取文件内容
  - 使用正则表达式匹配`$`符号之间的内容
  - 提取变量并统计数量

### 4.2 文件下载

- **功能**：提供检查后的模板文件下载
- **处理方式**：
  - 创建`Blob`对象
  - 生成下载链接
  - 触发浏览器下载

## 5. 异常处理 (Exception Handling)

| 异常场景 | 处理方式 | Message 显示内容 |
| :--- | :--- | :--- |
| **未选择文件点击Check** | 显示文件选择提示消息 | `ERROR: Unable to access file!` |
| **文件读取失败** | 捕获读取异常，显示错误消息 | `ERROR: Unable to access file!` |
| **文件中没有变量** | 显示内容错误消息 | `ERROR: The file content is incorrect!` |
| **文件类型不正确** | 可选：显示文件类型提示 | `Please select an RTF file.` |
| **用户未登录** | 检查会话状态，跳转到登录页面 | `Please login first` |

## 6. 实现注意事项 (Implementation Notes)

1. **全前端处理**：本模块不调用后端API，所有处理在前端完成。
2. **文件读取**：使用HTML5的FileReader API读取文件内容。
3. **变量解析**：使用正则表达式`/\$([^$]+)\$/g`匹配`$`符号之间的内容。
4. **UI细节**：
   - 页面标题显示为"EDB Engineering Database - HDoc Template Check"。
   - 成功时显示变量数量和变量列表。
   - 成功时显示Download checked template链接。
   - 失败时显示相应的错误消息。
5. **下载功能**：下载的文件可以是原始文件或添加了检查信息的文件。
6. **仅适用于rtf文件检查**：文件选择后可以选择重新选择其他文件。
