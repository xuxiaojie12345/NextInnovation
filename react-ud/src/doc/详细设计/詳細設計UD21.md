## 1. 背景 (Background)

本模块用于展示HDoc系统中所有可用市场的列表信息，包括市场代码、市场描述以及是否启用HDoc权重功能。该功能主要用于帮助用户了解系统中配置的所有市场及其权重状态，为后续的市场选择和文档生成提供参考依据。画面为纯展示性质，不提供任何修改操作。

- **目标**：提供市场中所有可用市场的信息展示。
- **面向用户**：系统管理员、具有文档管理权限的业务人员、需要查看市场配置信息的授权用户。
- **用户体验**：以清晰的表格形式展示所有市场信息、按市场代码字母顺序排序便于快速查找、Weights from Hdoc列使用直观的标识（X或空）显示权重状态、界面简洁无多余操作按钮。
- **安全性**：需要从MARKET_MASTER表读取市场信息、所有数据均为只读展示不允许用户修改、无需用户输入页面加载时自动获取并展示数据。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

### 3.1 处理流程

#### 3.1.1 页面初始化流程

1. **开始**：页面加载。
2. 调用`UD19SearchResultListApi`的`UD19SelectMarketMaster`方法（operation=GET_MARKET_LIST），从MARKET_MASTER表获取所有市场列表。
3. **API内部逻辑**：
   - 查询MARKET_MASTER表，获取所有市场记录。
   - 提取Market、Description字段。
   - 根据业务逻辑确定Weights from Hdoc字段的值：
     - 若该市场启用了HDoc权重功能，显示"X"
     - 若该市场启用了带特殊条件的HDoc权重功能，显示"X(*)"
     - 若该市场未启用HDoc权重功能，显示为空
   - 按Market代码字母顺序升序排序。
   
4. **结果处理**：
   - **成功**：将市场列表填充到DataTable，三列为Market、Description、Weights from Hdoc。
   - **失败（无数据）**：显示"No data found"提示消息。

## 4. 接口定义 (API Specification)

### 4.1 UD19SearchResultListApi - UD19SelectMarketMaster

**功能**：获取市场列表（复用UD19的市场列表查询接口）

- **Method**：`POST`
- **Endpoint**：`/api/ud19/UD19SearchResultListApi`

#### Request

```json
{
  "operation": "GET_MARKET_LIST"
}
```

#### Response Success (200)

```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "market": "AUT",
      "description": "Austria"
    },
    {
      "market": "BEL",
      "description": "Belgium"
    },
    {
      "market": "FIN",
      "description": "Finland"
    },
    {
      "market": "DEU",
      "description": "Germany"
    }
  ]
}
```

#### Response Error (500)

```json
{
  "code": 500,
  "message": "Internal server error",
  "data": null
}
```

## 5. 异常处理 (Exception Handling)

| 异常场景 | 处理方式 | Message 显示内容 |
| :--- | :--- | :--- |
| **MARKET_MASTER表无数据** | API返回空数据，前端显示提示消息 | `No data found` |
| **数据库连接异常** | API返回500错误，前端显示通用错误消息 | `系统错误，请稍后重试` |
| **API超时** | 前端捕获超时异常，显示超时提示 | `请求超时，请检查网络连接后重试` |
| **网络异常** | 前端捕获网络异常，显示网络错误提示 | `网络连接失败，请检查网络设置` |

## 6. 实现注意事项 (Implementation Notes)

1. **纯展示页面**：本页面为纯展示性质，不提供任何修改操作或用户输入。
2. **数据排序**：按Market代码字母顺序升序排序。
3. **权重标识**：
   - "X"：表示该市场启用了HDoc权重功能。
   - "X(*)"：表示该市场启用了带特殊条件的HDoc权重功能。
   - 空字符串：表示该市场未启用HDoc权重功能。
4. **对齐方式**：Weights from Hdoc列居中对齐，Market和Description列左对齐。
5. **自动加载**：页面加载时自动获取并展示数据，无需用户手动触发。
