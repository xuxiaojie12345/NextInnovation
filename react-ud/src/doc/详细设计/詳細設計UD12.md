## 1. 背景 (Background)

本模块用于管理HDoc模板文件的上传和删除操作，主要功能包括支持选择并上传模板文件到指定市场文件夹、支持从指定市场文件夹删除模板文件、提供模板检查链接跳转到HDoc Template Check页面、市场下拉列表动态加载可用市场选项、模板下拉列表根据所选市场动态加载该市场下的模板文件。

- **目标**：提供模板文件的上传和删除管理功能。
- **面向用户**：需要管理认证系统模板文件的授权用户，如系统管理员、配置管理人员等。
- **用户体验**：清晰的文件上传界面、明确的操作反馈消息、删除操作前的确认提示、便捷的模板检查跳转功能。
- **安全性**：需要用户登录认证后才能访问、文件上传需要进行类型和大小验证（**最大10MB**）、支持HTTPS安全传输协议。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

### 3.1 处理流程

#### 3.1.1 页面初始化流程

1. **开始**：页面加载。
2. 调用 **UD12SelectMarket**（GET `/api/ud12/selectmarket`）获取可用市场列表，将返回的市场列表填充到两个Market下拉列表中。
3. Templates下拉列表初始化为空列表且设置为禁用状态（disabled），用户选择Market后才加载数据并启用。
4. 清空错误消息和成功消息区域。

#### 3.1.2 文件上传流程

1. **开始**：用户点击Upload file按钮。
2. **前置处理**：校验是否选择了文件，若未选择则显示"NO FILE UPLOADED"并**终止**。
3. **文件大小校验**：检查文件大小是否超过10MB（10 × 1024 × 1024 bytes），若超过则显示"File size exceeds the 10MB limit."并**终止**。
3. 获取选中的文件和市场代码，构建FormData对象（file: 文件对象, market: 市场代码）。
4. 调用 **UD12UploadFlie**（POST `/api/ud12/upload`，Content-Type: `multipart/form-data`）。
5. **结果处理**：
   - **成功**：显示成功消息"TEMPLATE XXX WAS SUCESSFULLY UPLOADED TO MARKET JPN"（XXX为文件名，JPN为市场代码）。
   - **失败**：显示错误消息。

#### 3.1.3 模板删除流程

1. **开始**：用户点击Delete按钮。
2. **前置处理**：校验是否选择了市场和模板，若未选择则显示"Please select market and template."并**终止**。
3. 显示确认对话框"Do you really want to delete template?"，若用户取消则**终止**。
4. 调用 **UD12DeleteFlie**（POST `/api/ud12/delete`，请求体：`{ "market": "JPN", "fileName": "template1.rtf" }`）。
5. **结果处理**：
   - **成功**：显示成功消息"TEMPLATE XXX WAS SUCESSFULLY DELETE FROM MARKET JPN"，刷新Templates下拉列表。
   - **失败**：显示错误消息。

#### 3.1.4 市场选择联动流程

1. **开始**：用户在Delete区域的Market下拉列表中选择市场。
2. 调用 **UD12SelectMarket**（GET `/api/ud12/selectmarket?marketCode={marketCode}`）获取该市场文件夹下的模板文件列表。
3. 将文件列表填充到Templates下拉列表中，若无文件则显示"No templates available"。

#### 3.1.5 模板检查链接跳转

1. 用户点击"Check Template (Only for rtf files)"链接。
2. 使用React Router navigate跳转到/HDocTemplateCheck路由。

## 4. 接口定义 (API Specification)

### UD12UploadDeletetemplatApi

统一API名称空间，包含以下三个API：**UD12SelectMarket**、**UD12UploadFlie**、**UD12DeleteFlie**。

---

### 4.1 UD12SelectMarket - 市场列表及模板文件查询

**功能**：获取可用市场列表，或根据市场代码获取该市场文件夹下的模板文件列表。

#### 场景1：获取市场列表（页面初始化时调用）

- **Method**：`GET`
- **Endpoint**：`/api/ud12/selectmarket`

##### Request

无

##### Response Success (200 OK)

```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "marketCode": "JPN",
      "marketName": "Japan"
    }
  ]
}
```

#### 场景2：获取模板文件列表（选择Market后联动加载）

- **Method**：`GET`
- **Endpoint**：`/api/ud12/selectmarket/{marketCode}`

##### Request

| 参数名 | 位置 | 类型 | 必填 | 说明 |
| :--- | :---: | :---: | :---: | :--- |
| marketCode | Path | String | Y | 市场代码，如"JPN" |

##### Response Success (200 OK)

```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "fileName": "template1.rtf",
      "filePath": "/templates/JPN/template1.rtf"
    }
  ]
}
```

---

### 4.2 UD12UploadFlie - 文件上传

**功能**：上传模板文件到指定市场文件夹。

- **Method**：`POST`
- **Endpoint**：`/api/ud12/upload`
- **Content-Type**: `multipart/form-data`

##### Request

```json
{
  "file": "File (模板文件对象, Required)",
  "market": "String (市场代码, Required)"
}
```

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "fileName": "template1.rtf",
    "market": "JPN"
  }
}
```

##### Response Error (400)

```json
{
  "code": 400,
  "message": "Invalid file type or size (Max 10MB)",
  "data": null
}
```

---

### 4.3 UD12DeleteFlie - 文件删除

**功能**：从指定市场文件夹删除模板文件。

- **Method**：`POST`
- **Endpoint**：`/api/ud12/delete`

##### Request

```json
{
  "market": "JPN",
  "fileName": "template1.rtf"
}
```

| 参数名 | 类型 | 必填 | 说明 |
| :--- | :---: | :---: | :--- |
| market | String | Y | 市场代码 |
| fileName | String | Y | 要删除的文件名 |

##### Response Success (200 OK)

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "fileName": "template1.rtf",
    "market": "JPN"
  }
}
```

## 5. 异常处理 (Exception Handling)

| 异常场景 | 处理方式 | Message 显示内容 |
| :--- | :--- | :--- |
| **网络连接失败** | 捕获网络异常，显示通用错误消息 | `System error. Please contact administrator.` |
| **API超时** | 设置超时时间（建议10秒），超时后显示错误 | `System error. Please contact administrator.` |
| **文件上传API返回400** | 显示文件验证错误消息 | `Invalid file type or size (Max 10MB)` |
| **文件大小超过10MB** | 前端校验拦截 | `File size exceeds the 10MB limit.` |
| **文件删除API返回404** | 显示文件不存在错误消息 | `File not found` |
| **未选择文件点击Upload** | 显示文件选择提示消息 | `NO FILE UPLOADED` |
| **未选择市场或模板点击Delete** | 显示选择提示消息 | `Please select market and template.` |
| **删除确认用户取消** | 终止流程，不执行删除 | - |

## 6. 实现注意事项 (Implementation Notes)

1. **布局**：
   - 页面分为两个区域：HDoc Template Upload区域和HDoc Template Delete区域。
   - Upload区域包含：Template File输入框、Market下拉列表、Upload file按钮。
   - Delete区域包含：Market下拉列表、Templates下拉列表、Delete按钮。
   - 底部有链接"Check Template (Only for rtf files)"。
2. **Market下拉列表**：
   - Upload区域：从后端获取可用市场列表。
   - Delete区域：从MARKET_MASTER表的MARKET字段获取。
3. **Templates下拉列表**：根据所选市场动态加载该市场文件夹下的文件名。
4. **成功消息格式**：
   - 上传："TEMPLATE XXX WAS SUCESSFULLY UPLOADED TO MARKET JPN"
   - 删除："TEMPLATE XXX WAS SUCESSFULLY DELETE FROM MARKET JPN"
5. **删除确认**：删除操作前必须显示确认对话框"Do you really want to delete template?"。
6. **文件上传**：需要验证文件类型和大小（前端限制最大10MB，后端也需校验）。
