## 1. 背景 (Background)

本模块用于展示各市场下的模板文件列表，支持按市场筛选并查看模板文件的详细信息及使用状态。

- **目标**：用户可选择特定市场（Market），显示所选市场文件夹下的所有模板文件，展示文件名、使用状态、最后修改时间、文件大小等信息，点击文件名链接可下载对应模板文件。Used列显示该模板是否在HDOC_USER_DEFINED_RULES表中被引用。
- **面向用户**：系统管理员、配置工程师及生产准备人员。
- **用户体验**：界面简洁清晰、信息一目了然、操作便捷。
- **安全性**：仅允许授权用户访问，只读操作不涉及数据修改。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

### 3.1 处理流程

#### 3.1.1 页面初始化流程

1. **开始**：页面加载。
2. 调用 **UD14SearchresultistApi** 的 **UD14SelectMarketmaster** 方法（GET `/api/ud14/UD14SelectMarketmaster`，无参数）获取市场列表，将返回的市场列表填充到"Select Market"下拉列表中。
3. 表格区域初始为空，不显示任何文件信息。
4. "Select Market"下拉列表默认值为空。

> **调用API**：UD14SearchresultistApi.UD14SelectMarketmaster（GET `/api/ud14/UD14SelectMarketmaster`）
> - **参数**：无
> - **响应**：`{ "code": 200, "message": "success", "data": { "markets": ["AUT", "JPN", ...], "totalCount": 2 } }`

#### 3.1.2 市场选择与文件列表加载流程

1. **开始**：用户在"Select Market"下拉列表中选择一个市场。
2. 调用 **UD14SearchresultistApi** 的 **UD14SelectHdocuserdefinedrules** 方法（GET `/api/ud14/UD14SelectHdocuserdefinedrules?market={marketCode}`）获取所选市场文件夹下的所有文件信息。该方法查询HDOC_USER_DEFINED_RULES表，检查每个文件名是否被引用。
3. 将结果以表格形式展示，包含Filename（带下载链接）、Used、Last Mod,、Size四列。
4. 若所选市场下无文件，表格显示为空但保留表头。

> **调用API**：UD14SearchresultistApi.UD14SelectHdocuserdefinedrules（GET `/api/ud14/UD14SelectHdocuserdefinedrules?market={marketCode}`）
> - **参数**：`market`（Query，String，必填，市场代码）
> - **说明**：查询HDOC_USER_DEFINED_RULES表，检查模板文件是否被引用
> - **响应**：`{ "code": 200, "message": "success", "data": { "files": [...], "totalCount": 2 } }`

#### 3.1.3 文件下载流程

1. **开始**：用户点击表格中某行的Filename列的文件名链接。
2. 系统将该文件作为附件发送给用户，浏览器触发文件下载。

### 3.2 校验详细规格表

| No. | 检查时机 | 检查对象 | 检查条件 | 错误消息 (Message Content) | 动作 |
| :-: | :---: | :---: | :--- | :--- | :---: |
| 1 | 市场选择后 | 文件列表 | 市场下无文件 | - | 表格显示为空，保留表头 |
| 2 | API调用失败 | 数据获取 | 接口异常 | `系统内部错误，请联系管理员` | 显示错误消息 |
| 3 | 文件下载时 | 文件存在性 | 文件不存在 | `文件不存在，请联系管理员` | 显示错误提示 |

## 4. 接口定义 (API Specification)

### UD14SearchresultistApi

统一API名称空间，包含以下方法：**UD14SelectMarketmaster**（市场列表查询）、**UD14SelectHdocuserdefinedrules**（模板文件列表及使用状态查询）。

---

### 4.1 UD14SelectMarketmaster - 市场列表查询

**功能**：获取所有可用市场列表，用于填充"Select Market"下拉列表。

- **Method**：`GET`
- **Endpoint**：`/api/ud14/UD14SelectMarketmaster`

#### Request

无

#### Response Success (200 OK)

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "markets": [
      { "market": "AUT" },
      { "market": "JPN" }
    ],
    "totalCount": 2
  }
}
```

#### Response Error (500)

```json
{
  "code": 500,
  "message": "Failed to retrieve market list",
  "data": null
}
```

---

### 4.2 UD14SelectHdocuserdefinedrules - 模板文件列表及使用状态查询

**功能**：获取指定市场下的模板文件列表及使用状态信息。查询HDOC_USER_DEFINED_RULES表，检查每个模板文件是否被引用。

- **Method**：`GET`
- **Endpoint**：`/api/ud14/UD14SelectHdocuserdefinedrules?market={marketCode}`

#### Request

| 参数名 | 位置 | 类型 | 必填 | 说明 |
| :--- | :---: | :---: | :---: | :--- |
| market | Query | String | Y | 市场代码，如"AUT"、"JPN" |

#### Response Success (200 OK)

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "files": [
      {
        "filename": ".m003432.txt",
        "used": "",
        "lastModified": "2022-01-10 18:29",
        "size": "317 Kb",
        "downloadUrl": "/download/templates/AUT/.m003432.txt"
      },
      {
        "filename": ".m003432.txt.170629.backup",
        "used": "TEMPLATE-VIN-PLATE",
        "lastModified": "2017-06-29 16:50",
        "size": "377 Kb",
        "downloadUrl": "/download/templates/AUT/.m003432.txt.170629.backup"
      }
    ],
    "totalCount": 2
  }
}
```

#### Response Error (400)

```json
{
  "code": 400,
  "message": "Market parameter is required",
  "data": null
}
```

#### Response Error (500)

```json
{
  "code": 500,
  "message": "Failed to retrieve file list",
  "data": null
}
```

## 5. 异常处理 (Exception Handling)

| 异常场景 | 处理方式 | Message 显示内容 |
| :--- | :--- | :--- |
| **未选择市场** | 不执行查询 | - |
| **市场下无文件** | 表格显示为空 | - |
| **API调用失败** | 显示通用错误 | `系统内部错误，请联系管理员` |
| **文件不存在** | 下载失败提示 | `文件不存在，请联系管理员` |
| **网络超时** | 捕获超时异常 | `系统内部错误，请联系管理员` |

## 6. 实现注意事项 (Implementation Notes)

1. **状态管理**：
   - 使用React State管理Select Market下拉列表的选中值和DataTable数据。
   - 市场切换时自动触发文件列表加载。
2. **数据展示**：
   - Filename列渲染为可点击的链接（`<a>`标签），点击后触发文件下载。
   - Used列显示模板文件是否被引用的变量名。
   - Last Mod,列显示文件最后修改时间，格式为YYYY-MM-DD HH:mm:ss。
   - Size列显示文件大小，单位Kb。
3. **排序**：文件列表默认按文件名排序展示。
4. **只读操作**：本页面仅为数据展示和文件下载，不提供任何修改功能。
