1. 背景 (Background)

本模块用于显示和下载车辆认证文档，主要功能包括显示指定底盘号的接收信息（OM、VDA、KOLA数据）、S-Note信息和轮胎主数据、ADCA变更状态（支持跳转到修改文档页面）、VIN Plate参数和模板信息、文档下载功能，以及系统时间和程序版本信息。

  • 目标：提供底盘认证文档的完整信息展示与下载功能。
  • 面向用户：需要查看和下载车辆认证文档的授权用户，如质量管理人员、文档管理员等。
  • 用户体验：清晰的信息展示布局、重要的变更信息以红色高亮显示、提供便捷的文档下载链接、实时显示系统时间和版本信息。
  • 安全性：需要用户登录认证后才能访问、敏感数据需要进行权限控制、支持HTTPS安全传输。

3. 业务逻辑与校验规则 (Business Logic & Checks)

3.1 处理流程

3.1.1 页面初始化流程

  1. 开始：页面加载。
  2. 从路由参数或上下文中获取当前底盘号。
  3. 调用UD04SelectGeneratedocumentApi（POST方法）获取底盘相关信息。
  4. 结果处理：

    • 成功：解析API返回的数据，按以下步骤处理各字段：

      Chassis no显示处理：

      • 从API返回数据中获取serie（底盘系列号）和chassisNo（底盘号）
      • 合并显示格式：serie chassisNo（serie加粗显示，chassisNo带下划线显示）
      • 点击Chassis no时，跳转到Vehicle Specification页面（UD07），携带参数chassisNo（serie + 半角空格 + chassisNo）

      OM接收数据显示：

      • 将Ordernumber字段显示到对应Label
      • 将Build week字段显示到对应Label
      • 将Spec week字段显示到对应Label
      • 将S-Note NO字段显示到对应Label

      VDA接收数据显示：

      • 将Market（COUNTRY_OF_OPERATION）字段显示到对应Label

      KOLA轮胎主数据显示：

      • 将Load Index字段显示到对应Label

      S-Note信息判断：

      • 若有S-Note信息，显示固定提示消息"The S-Notes above can affect homologation documents."

      ADCA变更状态判断（API返回的ADCA变更数据中读取HDOC_ADCA_CHANGE表的ACT字段值）：

      • 若ACT为激活状态（如"ACTIVE"或"Y"）：
        • Modify Doc Link文字颜色设置为红色
        • 显示提示信息"After def change detected. Document need to be modified."
        • 启用链接点击事件，点击后跳转到/ModifyDocument路由
        • 从HDOC_ADCA_MODIFICATION表获取VARIABLE字段，按"AD Change. Modifying:"+VARIABLE格式显示在Replacing parameters区域（不取NEWVAL）
      • 若ACT为非激活状态（如"INACTIVE"或"N"）：
        • Modify Doc Link不显示或显示为灰色不可点击状态
        • 不显示提示信息
        • Replacing parameters区域显示为空

      Using template固定显示"VIN_PLATE_TEMPLATE_V1"。Generated document静态显示。显示服务器当前时间和程序版本。

    • 失败（底盘号不存在）：在Error message area显示"Chassis not found"，其他字段保持为空。

    • 服务器错误：在Error message area显示"System error. Please contact administrator."，其他字段保持为空。

3.1.2 Generated document显示

  1. 开始：页面加载。
  2. Generated document为Link类型显示，不实装点击功能。
  3. 固定显示"Generated document"文字。

3.1.3 Chassis no Link 押下時処理

  1. 开始：用户点击Chassis no Link。
  2. 获取数据：从当前页面状态中获取serie（底盘系列号）和chassisNo（底盘号）。
  3. 页面跳转：
    • 跳转到Vehicle Specification页面（UD07），路由为 /vehicle-specification。
    • 传递参数：{ chassisNo: "ABC12 1234567890" }（serie + 半角空格 + chassisNo 的拼接值）。
  4. 结果反馈：
    • 成功：UD07页面加载并显示该底盘号的车辆规格详细信息。
    • 失败：不进行特殊处理，由UD07页面自身处理API调用异常。

4. 接口定义 (API Specification)

4.1 UD04SelectGeneratedocumentApi

  • 功能：根据底盘号查询并返回所有相关的文档信息和数据
  • Method：POST
  • Endpoint：/api/ud04/selectgenerateddocument

Request 

{
  "chassisSeries": "string",
  "chassisNo": "string",
  "documentType": "string"
}

Response Success (200 OK) 

{
  "code": 200,
  "message": "success",
  "data": {
    "chassisNo": "1234567890",
    "serie": "ABC12",
    "ordernumber": "GOLF",
    "buildWeek": "2022W45",
    "specWeek": "2022W45",
    "market": "DE",
    "masterMarket": "-EU",
    "sNoteNo": "S-NOTE-001",
    "sNoteMessage": "The S-Notes above can affect homologation documents.",
    "loadIndex": "91",
    "analyzeRules": "View Rules",
    "modifyDocLink": "ACTIVE",
    "replacingParameters": "AD Change. Modifying:PARAM1; AD Change. Modifying:PARAM2",
    "date": "2022-12-02 05:11:45",
    "hdocVersion": "v1.0.0"
  }
}

Response Error (404) 

{
  "code": 404,
  "message": "Chassis not found",
  "data": null

  "message": "Internal server error",

6. 实现注意事项 (Implementation Notes)

  1. 状态管理：
    • 使用React State管理所有从API返回的显示数据。
    • Error message区域默认隐藏，仅在发生错误时显示。
  2. ADCA变更状态显示：
    • Modify Doc Link在ADCA变更激活时显示为红色（#ff4d4f）以起到警示作用。
    • 点击Modify Doc Link时，通过路由state传递chassisNo、serie和market参数跳转到/ModifyDocument页面。
  3. Generated document：
    • 点击Generated document时检查文件是否存在，若不存在显示错误消息"Document file not found"。
    • 当前为占位实现，文件下载功能尚未实装。
  4. 系统信息：
    • Date字段显示从服务器获取的时间，而非客户端时间。
    • 程序版本号从API返回数据中获取。
