1. 背景 (Background)

本模块用于显示Homologation Variables页面的搜索结果列表，主要功能包括根据前画面传递的搜索条件显示匹配的变量规则列表、支持选择单条记录并返回前画面、支持批量删除选中的记录、支持打印搜索结果、支持返回前画面并保留搜索条件、显示搜索结果总数。

  • 目标：提供认证变量搜索结果的展示与操作功能。
  • 面向用户：需要查看和管理认证变量的授权用户，如系统管理员、质量管理人员等。
  • 用户体验：清晰的数据表格展示、便捷的记录选择和操作功能、明确的搜索结果计数显示、支持批量删除操作。
  • 安全性：需要用户登录认证后才能访问、删除操作需要确认或权限控制、支持HTTPS安全传输。

3. 业务逻辑与校验规则 (Business Logic & Checks)

3.1 处理流程

3.1.1 页面初始化流程

  1. 开始：页面加载。
  2. 从URL参数或state中获取前画面传递的搜索条件（包含字段值和对应的运算符）。
  3. 调用UD09DeleteHdocuserdefinedrulesApi的UD09Search方法（POST /api/ud09/search），传递搜索条件（含运算符）作为请求参数。
  4. 结果处理：
    • 成功：将数据显示到DataTable中，计算并显示搜索结果总数到Count字段。
    • 失败（无匹配数据）：DataTable显示为空，Count显示"Number of lines found: 0"。
    • 服务器错误：显示"System error. Please contact administrator."。

3.1.2 选择记录流程

  1. 开始：用户点击Select按钮。
  2. 前置处理：检查是否有选中的记录，若无则显示错误消息。
  3. 获取选中记录的完整数据，存储到state或sessionStorage中。
  4. 使用React Router导航回/HomologationVariables页面。
  5. 前画面从state或sessionStorage中读取选中的数据并自动填充到对应的输入字段。
  6. 字段映射：
    • DataTable的updateUser → 前画面"Created by user"字段（对应UPDATE_USER）
    • DataTable的updateDatetime → 前画面"Date"字段（对应UPDATE_DATETIME）

3.1.3 返回流程

  1. 开始：用户点击Back按钮。
  2. 获取当前页面的搜索条件，存储到state或sessionStorage中。
  3. 使用React Router导航回/HomologationVariables页面。
  4. 前画面从state或sessionStorage中读取搜索条件并自动填充到对应的输入字段。

3.1.4 删除流程

  1. 开始：用户选择一条记录后点击Delete selected按钮。
  2. 前置处理：检查是否有选中的记录，若无则显示错误消息"Please select at least one record to delete."，终止流程。
  3. 获取选中记录的主键信息（Product class、Number、Market）。
  4. 调用UD09DeleteHdocuserdefinedrulesApi的UD09DeleteSelected方法（POST /api/ud09/deletehdocuserdefinedrules），传递选中记录的主键。
  5. 结果处理：
    • 成功：显示"Record deleted successfully."，重新调用UD09DeleteHdocuserdefinedrulesApi的UD09Search方法刷新列表数据。
    • 记录不存在：显示"Data does not exist, Please enter the correct content"。
    • 服务器错误：显示"System error. Please contact administrator."。

3.1.5 打印流程

  1. 开始：用户点击Print按钮。
  2. 调用window.print()方法。
  3. 浏览器打开打印预览对话框。
  4. 打印内容包括DataTable中的所有数据和Count信息。

3.1.6 用户链接跳转功能

  1. 开始：用户在DataTable中点击Created by user列的链接。
  2. 处理：跳转到EDB User View页面（UD25），携带参数userid（当前行的UPDATE_USER值）。
  3. 结果处理：EDB User View页面加载并显示该用户的详细信息。

6. 实现注意事项 (Implementation Notes)

  1. 状态管理：
    • 使用React State管理DataTable中的数据、选中记录列表、Count值。
    • 选中记录使用数组存储，支持多选。
  2. 数据交互：
    • 从HomologationVariables页面跳转时，通过URL参数或React Router的state传递搜索条件。
    • Select操作将选中记录数据存储到state或sessionStorage，返回后前画面自动填充。
    • Back操作将当前搜索条件存储到state或sessionStorage，返回后前画面自动恢复。
  3. UI细节：
    • Created by user列显示为蓝色可点击链接，点击后跳转到EDB User View页面。
    • 数据表格默认按Product Class、Market、Number升序排序。
    • 表格支持行多选（通过复选框实现）。
    • Count字段显示格式固定为"Number of lines found: XXX"。
  4. 打印功能：
    • 调用window.print()实现打印功能。
    • 建议添加打印样式表，确保打印输出格式清晰。
