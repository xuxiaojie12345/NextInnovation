## 1. 背景 (Background)

本模块用于显示Existing HDoc Variables页面的搜索结果列表，主要功能包括根据前画面传递的搜索条件显示匹配的变量定义列表、支持选择单条记录并返回前画面、支持将选中记录的Variable作为参数跳转到Homologation Variables页面、支持打印搜索结果、支持导出CSV文件、支持返回前画面并保留搜索条件、显示搜索结果总数。

- **目标**：提供变量定义搜索结果的展示与操作功能。
- **面向用户**：需要查看和管理认证系统变量定义的授权用户，如系统管理员、配置管理人员等。
- **用户体验**：清晰的数据表格展示、便捷的记录选择和操作功能、明确的搜索结果计数显示、支持批量操作和导出功能。
- **安全性**：需要用户登录认证后才能访问、支持HTTPS安全传输协议。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

### 3.1 处理流程

#### 3.1.1 页面初始化流程

1. **开始**：页面加载。
2. 从URL参数或state中获取前画面传递的搜索条件（variable、type、description）。
3. 调用`UD11HdocvariablesApi`的`UD11Search`方法（POST `/api/ud11/search`）获取匹配的变量定义列表。
4. **结果处理**：
   - **成功**：将数据显示到DataTable中，计算记录总数，更新Count显示"Number of lines found: XXX"。
   - **失败（空列表）**：Count显示"Number of lines found: 0"，DataTable为空。
   - **服务器错误**：显示"System error. Please contact administrator."。

#### 3.1.2 Select操作流程

1. **开始**：用户点击Select按钮。
2. 校验是否有选中的记录，若未选择则显示"Please select a record."并**终止**。
3. 获取选中记录的完整数据，存储到state或sessionStorage中。
4. 返回到/ExistingHDocVariables页面，前画面自动填充选中数据到对应输入字段。

#### 3.1.3 Back操作流程

1. **开始**：用户点击Back按钮。
2. 保存当前搜索条件到state或sessionStorage。
3. 返回到/ExistingHDocVariables页面，前画面自动恢复搜索条件。

#### 3.1.4 Down按钮

Down按钮仅实装样式，不实装机能。

#### 3.1.5 Print操作流程

1. **开始**：用户点击Print按钮。
2. 调用`window.print()`方法，浏览器打开打印预览对话框。

#### 3.1.6 Excel操作流程（导出CSV）

1. **开始**：用户点击Excel按钮。
2. 调用导出API或前端生成CSV文件。
3. 浏览器触发文件下载，文件名格式：HDOC_Variables_YYYYMMDD.csv。

#### 3.1.7 用户链接跳转功能

1. **开始**：用户在DataTable中点击Created by user列的链接。
2. **处理**：跳转到EDB User View页面（UD25），携带参数userid（当前行的registerUser值）。
3. **结果处理**：EDB User View页面加载并显示该用户的详细信息。

## 4. 接口定义 (API Specification)

### 4.1 UD11HdocvariablesApi

`UD11HdocvariablesApi`包含以下方法：

#### 方法①. UD11Search

- **功能**：根据搜索条件查询变量定义列表
- **Method**：`POST`
- **Endpoint**：`/api/ud11/search`

#### Request

```json
{
  "variable": "string (Optional)",
  "type": "string (Optional)",
  "description": "string (Optional)",
  "userid": "string (Optional)",
  "registerDatetime": "string (Optional)",
  "variableOp": "string (Optional, Values: =/!=)",
  "typeOp": "string (Optional, Values: =/!=)",
  "descriptionOp": "string (Optional, Values: =/!=)",
  "useridOp": "string (Optional, Values: =/!=)",
  "registerDatetimeOp": "string (Optional, Values: =/GT/LT)"
}
```

#### Response Success (200 OK)

```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "variable": "VAR001",
      "type": "VDA",
      "description": "Test variable description",
      "userid": "admin",
      "registerDatetime": "2022-12-02T05:11:45"
    }
  ]
}
```

#### Response Error (500)

```json
{
  "code": 500,
  "message": "Internal server error",
  "data": null
}
```

## 5. 异常处理 (Exception Handling)

| 异常场景 | 处理方式 | Message 显示内容 |
| :--- | :--- | :--- |
| **网络连接失败** | 捕获网络异常，显示通用错误消息 | `System error. Please contact administrator.` |
| **API超时** | 设置超时时间（建议10秒），超时后显示错误 | `System error. Please contact administrator.` |
| **UD11Search返回空列表** | 显示零结果消息 | `Number of lines found: 0` |
| **未选择记录点击Select** | 显示选择提示消息 | `Please select a record.` |
| **Down按钮** | 仅实装样式，不实装机能 | - |
| **用户未登录** | 检查会话状态，跳转到登录页面 | `Please login first` |

## 6. 实现注意事项 (Implementation Notes)

1. **状态管理**：
   - 使用React State管理DataTable数据、选中行索引、Count值。
   - 选中记录使用单行选中模式。
2. **数据交互**：
   - 从ExistingHDocVariables页面跳转时，通过URL参数或React Router的state传递搜索条件。
   - Select和Back操作返回前画面时，通过state或sessionStorage传递数据。
3. **UI细节**：
   - 页面标题显示为"EDB Engineering Database - Existing HDoc Variables Result List"。
   - Created by user列显示为蓝色可点击链接。
   - 点击Created by user链接跳转到/EDBUserView/:username路由。
   - Down按钮仅实装样式，不实装机能。
   - CSV导出功能可使用前端库（如papaparse）实现。
