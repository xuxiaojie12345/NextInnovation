1. 背景 (Background)

本模块用于显示从Modify Document页面传递过来的修改内容，供用户确认。用户查看修改信息后，可以点击Close按钮关闭当前页面。

  • 目标：提供修改内容的确认展示页面。
  • 面向用户：车辆认证相关人员、需要确认文档变量修改内容的业务人员。
  • 用户体验：清晰展示修改前后的对比信息、简洁的确认界面、快速关闭功能。
  • 安全性：需要用户登录认证、从前一页面传递底盘信息和修改数据。

3. 业务逻辑与校验规则 (Business Logic & Checks)

3.1 处理流程

3.1.1 页面初始化流程

  1. 开始：用户从Modify Document页面跳转到Save Modifications页面。
  2. 前置处理：从React Router的location state中获取ModifyDocument页面传递的参数 { chassisNo, serie }。
  3. API调用：调用UD06SaveModificationsApi，传递参数{serie, chno}，查询HDOC_ADCA_MODIFICATION表获取修改信息。
  4. 结果处理：
    • 成功：填充页面字段，显示修改内容。其中Chassis serie和Chassis number直接使用ModifyDocument页面传递的参数值进行显示。
    • 失败：显示错误消息。

3.1.2 Close按钮点击处理

  1. 开始：用户点击Close按钮。
  2. 系统关闭当前Save Modifications页面。
  3. 返回到前一页面（Modify Document页面）或关闭弹窗/对话框。
  4. 不执行任何保存操作，仅作为信息确认页面。

3.2 校验详细规格表

4. 接口定义 (API Specification)

4.1 UD06SaveModificationsApi

  • 功能：获取ADCA修改信息，包括文档类型、版本号、存储信息等。从HDOC_ADCA_MODIFICATION表查询指定底盘的修改记录。
  • Method：POST
  • Endpoint：/api/ud06/savemodifications/query

Request 

{
  "serie": "string (底盘系列号)",
  "chno": "string (底盘编号)"
}

Response Success (200 OK) 

{
  "code": 200,
  "message": "success",
  "data": {
    "chassisSerie": "string",
    "chassisNumber": "string",
    "doctype": "string",
    "version": "string",
    "storing": {
      "variable": "string",
      "newval": "string"
    },
    "foundUnreleasedVersion": "string"
  }
}

Response Error (404) 

{
  "code": 404,
  "message": "未找到该底盘的修改记录",
  "data": null
}
Response Error (500) 
{
  "code": 500,
  "message": "查询失败，请稍后重试",
  "data": null
}

5. SQL定义 (SQL Statements)

5.1 查询语句 (UD06SelectHdocAdcaModification) 

SELECT DOCTYPE, VERS, VARIABLE, NEWVAL
FROM HDOC_ADCA_MODIFICATION
WHERE SERIE = {serie} AND CHNO = {chno}

6. 异常处理 (Exception Handling)

异常场景 处理方式 Message 显示内容

未找到修改记录 显示提示信息 未找到该底盘的修改记录

7. 实现注意事项 (Implementation Notes)

  1. 状态管理：
    • 使用React State管理所有从API返回的显示数据。
    • 页面为只读展示页面，所有数据不可编辑。
  2. 数据传递：
    • 从Modify Document页面跳转时，通过路由参数或localStorage传递底盘信息（SERIE和CHNO）。
  3. UI细节：
    • Close按钮点击后导航回前一页面。
    • Message区域固定显示"VERSION IS RELEASED"。
    • FOUND UNRELEASED VERSION区域根据API返回数据显示是否存在未发布的版本信息。
