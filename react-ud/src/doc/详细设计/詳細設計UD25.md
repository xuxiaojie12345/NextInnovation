## 1. 背景 (Background)

本模块用于显示当前登录用户的详细信息，主要功能包括从Saviynt系统获取并显示用户信息、展示用户ID、负责人、职位和邮箱等信息、提供清空输入内容和返回前页面的功能。

- **目标**：提供当前登录用户详细信息的展示。
- **面向用户**：需要查看自己账户信息的系统用户。
- **用户体验**：清晰的信息展示界面、简洁的操作按钮、支持快速返回前页面。
- **安全性**：仅显示当前登录用户的信息、所有字段为只读不可编辑、支持HTTPS安全传输。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

### 3.1 处理流程

#### 3.1.1 页面初始化流程

1. **开始**：页面加载。
2. 调用`AuthenticationApi`获取当前登录用户的信息。
3. **结果处理**：
   - **成功**：从响应中提取userid、responsible、userPosition、email字段，分别显示到对应文本框中。
   - **失败**：显示"Failed to load user information. Please try again."，所有字段保持为空。

#### 3.1.2 Clear处理流程

1. **开始**：用户点击Clear按钮。
2. 清空Userid、Responsible、User Position、E-mail四个字段的值。
3. 不调用任何API，仅前端清空显示。

#### 3.1.3 Back处理流程

1. **开始**：用户点击Back按钮。
2. **画面关闭**：关闭当前画面（EDB用户查看画面），返回到调用本画面的前画面。
3. **数据保持**：前画面保持原有状态，不更新任何字段。

### 3.2 校验详细规格表

本页面无校验规则，所有字段均为只读显示，无用户输入验证需求。

## 4. 接口定义 (API Specification)

### 4.1 UD25AuthenticationApi

- **功能**：根据Userid从HDOC_USER_INFOR表获取用户详细信息
- **Method**：`GET`
- **Endpoint**：`/api/authentication/userinfo`

#### Request

| 参数名 | 类型 | 必须 | 说明 |
| :--- | :--- | :---: | :--- |
| userId | String | 是 | 用户ID，由前画面（如UD09）的Created by user链接传递 |

#### Response Success (200)

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "userid": "string",
    "responsible": "string",
    "userPosition": "string",
    "email": "string"
  }
}
```

#### Response Error (400)

```json
{
  "code": 400,
  "message": "User ID is required.",
  "data": null
}
```

#### Response Error (404)

```json
{
  "code": 404,
  "message": "User not found.",
  "data": null
}
```

#### Response Error (500)

```json
{
  "code": 500,
  "message": "Internal server error",
  "data": null
}
```

## 5. 异常处理 (Exception Handling)

| 异常场景 | 处理方式 | Message 显示内容 |
| :--- | :--- | :--- |
| **网络连接失败** | 捕获网络异常，显示通用错误消息 | `System error. Please contact administrator.` |
| **API超时** | 设置超时时间（建议10秒），超时后显示错误 | `System error. Please contact administrator.` |
| **API返回500** | 显示系统错误消息 | `System error. Please contact administrator.` |
| **用户信息获取失败** | 显示加载用户信息失败消息 | `Failed to load user information. Please try again.` |
| **JSON解析失败** | 捕获解析异常，显示系统错误 | `System error. Please contact administrator.` |

## 6. 实现注意事项 (Implementation Notes)

1. **只读展示**：所有TextField控件在此页面中为只读状态，不允许用户编辑。
2. **自动加载**：页面加载时自动获取用户信息，无需用户手动触发。
3. **数据来源**：从Saviynt系统通过UD25AuthenticationApi（GET /api/authentication/userinfo?userId=xxx）获取用户信息（Userid、Responsible、User Position、E-mail）。
4. **Clear按钮**：仅清空前端显示，不影响后端数据。
5. **Back按钮**：返回前一个页面，建议使用浏览器历史记录。
6. **Loading状态**：建议在API调用期间显示加载提示。
7. **页面标题**：显示为"EDB Engineering Database - EDB User View"。
