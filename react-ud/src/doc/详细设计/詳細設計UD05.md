## 1. 背景 (Background)

本模块用于显示并修改文档变量值，支持查看模板文件和底盘详细信息。用户可以在当前页面修改变量值，然后跳转到确认页面查看修改内容。

- **目标**：提供认证文档变量值的修改功能。
- **面向用户**：车辆认证相关人员、需要修改认证文档变量的业务人员。
- **用户体验**：提供清晰的变量对照界面、显示当前值和修改值的对比、提供模板文件下载功能。
- **安全性**：需要用户登录认证、从上一页传递底盘信息、所有输入字段需进行长度校验。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

### 3.1 处理流程

#### 3.1.1 页面初始化流程

1. **开始**：用户访问ModifyDocument页面。
2. **前置处理**：从路由参数或localStorage获取SERIE（底盘系列号）和CHNO（底盘编号）。
3. **API调用**：调用`UD05ModifyDocumentApi`，传递参数`{serie, chno}`。
4. **结果处理**：
   - **成功**：填充DataTable，显示变量列表（Variable、Description、Current value、Modified value）。同时显示chassis no、Market和Template文件链接。
   - **失败**：显示错误消息。
5. 若某变量在HDOC_ADCA_MODIFICATION表中不存在记录，则Current value和Modified value均为空。

#### 3.1.2 下载模板文件（未实装）

1. **开始**：用户点击Template文件链接。
2. **处理**：当前版本未实装文件下载功能，点击后显示提示消息"模板文件下载功能未实装"。

#### 3.1.3 查看底盘详细信息

1. **开始**：用户点击chassis no链接。
2. **处理**：跳转到Vehicle Specification页面（UD07），携带参数chassisNo（SERIE + CHNO拼接）。
3. **结果处理**：Vehicle Specification页面加载并显示底盘详细信息。

#### 3.1.4 保存修改流程

1. **开始**：用户点击Save按钮。
2. **前置处理**：遍历DataTable，收集所有Modified value字段的值。
3. **空值校验 (Frontend Check)**：
   - 若所有Modified value字段均为空或未修改：设置Message = "NO UNRELEASED VERSION EXISTS!"，**终止**流程。
   - 若任一Modified value字段长度超过500字符：设置Message = "修改后的值长度不能超过500字符"，**终止**流程。
4. **结果处理**：
   - **校验通过**：先调用`UD05UpdateHdocAdcaModification`（POST `/api/ud05/modifydocument/update`）保存所有修改值，成功后通过 React Router 的 location state 传递 `{ chassisNo, serie }` 跳转到"Save Modifications"页面。
   - **校验失败**：在当前页面显示错误消息。

### 3.2 校验详细规格表

| No. | 检查时机 | 检查对象 | 检查条件 | 错误消息 (Message Content) | 动作 |
| :-: | :---: | :---: | :--- | :--- | :---: |
| 1 | 页面加载时 | SERIE/CHNO参数 | 参数必须存在 | 缺少必要的底盘信息 | 返回上一页或显示错误 |

| 3 | 点击Save按钮时 | Modified value | 任一字段长度超过500字符 | `修改后的值长度不能超过500字符` | 显示错误消息，阻止跳转 |
| 4 | API调用后 | 查询结果 | 未找到该底盘的修改记录 | 未找到该底盘的修改记录 | 显示提示信息或返回上一页 |

## 4. 接口定义 (API Specification)

### 4.1 UD05ModifyDocumentApi

UD05ModifyDocumentApi包含两个请求方法：查询和更新。

#### 请求方法①. UD05SelectVariableModification（查询）

- **功能**：获取待修改变量列表，包括变量名、描述、当前值等信息。通过关联查询HDOC_ADCA_MODIFICATION（左连接）HDOC_VARIABLES表获取变量数据。
- **Method**：`POST`
- **Endpoint**：`/api/ud05/modifydocument/query`

#### 请求方法②. UD05UpdateHdocAdcaModification（更新）

- **功能**：更新HDOC_ADCA_MODIFICATION表的NEWVAL字段，同时更新UPDATE_USER（当前登录用户ID）、UPDATE_DATETIME（当前时间）、UPDATE_PROCESS（'UD05'）。
- **Method**：`POST`
- **Endpoint**：`/api/ud05/modifydocument/update`

#### 请求方法①. UD05SelectVariableModification（查询）

**Endpoint**：`POST /api/ud05/modifydocument/query`

##### Request

```json
{
  "serie": "string (底盘系列号)",
  "chno": "string (底盘编号)"
}
```

##### Response Success (200 OK)

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "chassisNo": "string",
    "market": "string",
    "templateFile": "string",
    "variables": [
      {
        "variable": "string",
        "description": "string",
        "currentValue": "string",
        "modifiedValue": "string"
      }
    ]
  }
}
```

##### Response Error (404)

```json
{
  "code": 404,
  "message": "未找到该底盘的修改记录",
  "data": null
}
```

#### 请求方法②. UD05UpdateHdocAdcaModification（更新）

**Endpoint**：`POST /api/ud05/modifydocument/update`

##### Request

```json
{
  "serie": "string (底盘系列号)",
  "chno": "string (底盘编号)",
  "variable": "string (变量名)",
  "modifiedValue": "string (修改后的值)",
  "updateUser": "string (当前登录用户ID)"
}
```

##### Response Success (200 OK)

```json
{
  "code": 200,
  "message": "success",
  "data": "更新成功"
}
```

##### Response Error (404)

```json
{
  "code": 404,
  "message": "未找到对应的修改记录",
  "data": null
}
```

##### Response Error (500)

```json
{
  "code": 500,
  "message": "Internal server error",
  "data": null
}
```

## 5. 异常处理 (Exception Handling)

| 异常场景 | 处理方式 | Message 显示内容 |
| :--- | :--- | :--- |
| **API网络错误** | 捕获异常，显示友好提示 | `网络连接失败，请稍后重试` |
| **API超时** | 设置超时时间，超时后提示 | `请求超时，请检查网络连接` |
| **数据库异常** | 记录日志，返回通用错误 | `系统异常，请联系管理员` |
| **参数缺失** | 检查URL参数或localStorage | `缺少必要的底盘信息` |
| **模板文件下载未实装** | 点击后显示提示消息 | `模板文件下载功能未实装` |

## 6. 实现注意事项 (Implementation Notes)

1. **状态管理**：
   - 使用React State管理DataTable中的变量列表数据。
   - Modified value列使用受控组件，实时监听输入变化。
2. **数据传递**：
   - 从GenerateDocument页面跳转时，通过路由参数或localStorage传递底盘信息（SERIE和CHNO）。
   - 点击Save按钮后，将修改数据保存到localStorage或作为路由参数传递给Save Modifications页面。
3. **UI细节**：
   - Save按钮在数据校验或API调用期间应设为`disabled`，防止重复提交。
   - Error message区域显示错误消息时使用红色文字（`#ff4d4f`）。
   - Template文件链接显示为可点击的蓝色文字，当前下载功能未实装，点击后显示提示消息"模板文件下载功能未实装"。
4. **输入限制**：
   - Modified value输入框限制最大输入长度为500字符。
   - 建议在输入框上显示剩余可输入字符数。
