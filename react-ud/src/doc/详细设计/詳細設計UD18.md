## 1. 背景 (Background)

本模块用于管理用户的文档权限，主要功能包括输入用户ID查询用户信息和文档权限、验证用户ID是否存在于HDOC_FUNCTION_AUTH表中、从Saviynt系统获取用户名、从HDOC_DOCUMENT_LIST表获取文档列表、设置和更新用户的文档权限。

- **目标**：提供用户文档权限的查询和更新管理功能。
- **面向用户**：需要管理用户文档权限的系统管理员。
- **用户体验**：清晰的文档权限配置界面、明确的错误提示信息、支持快速查询和更新权限操作。
- **安全性**：用户ID必须存在于HDOC_FUNCTION_AUTH表中才能执行操作、防止未授权的文档权限修改、支持HTTPS安全传输。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

### 3.1 处理流程

#### 3.1.1 页面初始化流程

1. **开始**：页面加载。
2. 调用`UD20GetDocumentListApi`的`UD20SelectHdocDocumentList`方法（GET `/api/ud20/UD20SelectHdocDocumentList`）获取文档列表。
3. 将所有文档类型以文本形式展示在Document文本框中。

#### 3.1.2 User Info处理流程

1. **开始**：用户点击User Info按钮。
2. **前端校验**：
   - 若UserID为空：显示"UserID is required."，**终止**。
   - 若UserID包含非半角英数字字符：显示"UserID must contain only alphanumeric characters."，**终止**。
3. **存在性检查**：调用`UD18HDocUserDocAdministrationApi`的`UD18SelectHdocFunctionAuth`方法（operation=checkAuth），检查用户是否存在于HDOC_FUNCTION_AUTH表中。若不存在，显示"We didn't recognize the userid you entered. Please try again."，**终止**。
4. 调用`UD18HDocUserDocAdministrationApi`的`UD18SelectHdocUserDoc`方法（operation=select）查询用户信息和文档权限。
5. **结果处理**：
   - **成功**：从响应中获取用户名显示在User标签中；从响应中获取文档权限，将对应的文档描述显示在Document文本框中。
   - **失败**：显示对应错误消息。

#### 3.1.3 Update处理流程

1. **开始**：用户点击Update按钮。
2. **前端校验**：
   - 若UserID为空：显示"UserID is required."，**终止**。
   - 若UserID包含非半角英数字字符：显示"UserID must contain only alphanumeric characters."，**终止**。
3. **存在性检查（前置处理）**：调用`UD18HDocUserDocAdministrationApi`的`UD18SelectHdocFunctionAuth`方法（operation=checkAuth）检查该用户是否存在于HDOC_FUNCTION_AUTH表中。
   - 若用户不存在：显示"We didn't recognize the userid you entered. Please try again."，**终止**流程，不执行后续更新。
   - 若用户存在：继续执行更新。
4. **删除旧权限**：调用`UD18HDocUserDocAdministrationApi`的`UD18DeleteHdocUserDoc`方法（operation=delete）删除该用户现有的所有文档权限记录。
5. **创建新权限**：调用`UD18HDocUserDocAdministrationApi`的`UD18CreateHdocUserDoc`方法（operation=create）创建新的文档权限记录。
6. **结果处理**：
   - **成功**：显示"Document permissions updated successfully."。
   - **失败**：显示对应错误消息。

| 3 | 点击Update按钮时 | UserID | 值为空字符串或未填写 | `UserID is required.` | 显示错误消息，终止流程 |
| 4 | 点击Update按钮时 | UserID | 包含非半角英数字字符 | `UserID must contain only alphanumeric characters.` | 显示错误消息，终止流程 |

## 4. 接口定义 (API Specification)

### 4.1 UD20SelectHdocDocumentList - 文档类型列表查询

**功能**：获取文档类型列表

- **Method**：`GET`
- **Endpoint**：`/api/ud20/UD20SelectHdocDocumentList`

#### Request

无

#### Response Success (200 OK)

```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "doctype": "string",
      "description": "string"
    }
  ]
}
```

#### Response Error (500)

```json
{
  "code": 500,
  "message": "Internal server error",
  "data": null
}
```

---

### 4.2 UD18HDocUserDocAdministrationApi

统一API名称空间，包含以下方法：**UD18SelectHdocFunctionAuth**（功能权限存在性检查）、**UD18SelectHdocUserDoc**（用户文档权限查询）、**UD18DeleteHdocUserDoc**（用户文档权限删除）、**UD18CreateHdocUserDoc**（用户文档权限创建）。

---

### 4.3 UD18SelectHdocFunctionAuth - 功能权限存在性检查

**功能**：根据userId查询HDOC_FUNCTION_AUTH表，检查用户是否存在

- **Method**：`POST`
- **Endpoint**：`/api/ud18/UD18HDocUserDocAdministrationApi`

#### Request

```json
{
  "userid": "string (Max 10, Required)",
  "operation": "checkAuth"
}
```

#### Response Success (200) - 用户存在

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "exists": true
  }
}
```

#### Response Success (200) - 用户不存在

```json
{
  "code": 200,
  "message": "We didn't recognize the userid you entered. Please try again.",
  "data": {
    "exists": false
  }
}
```

#### Response Error (500)

```json
{
  "code": 500,
  "message": "Internal server error",
  "data": null
}
```

---

### 4.4 UD18SelectHdocUserDoc - 用户文档权限查询

## 5. 异常处理 (Exception Handling)

| 异常场景 | 处理方式 | Message 显示内容 |
| :--- | :--- | :--- |
| **网络连接失败** | 捕获网络异常，显示通用错误消息 | `System error. Please contact administrator.` |
| **API超时** | 设置超时时间（建议10秒），超时后显示错误 | `System error. Please contact administrator.` |
| **getDocumentList API失败** | 显示加载文档列表失败消息 | `Failed to load document list. Please try again.` |
| **API返回404** | 显示用户ID不存在消息 | `We didn't recognize the userid you entered. Please try again.` |
| **UserID为空或格式错误** | 前端校验拦截 | `UserID is required.` 或 `UserID must contain only alphanumeric characters.` |

## 6. 实现注意事项 (Implementation Notes)

1. **状态管理**：
   - 使用React State管理UserID输入值、User标签显示值、Document文本框的值。
   - User标签初始为空，查询成功后显示从HDOC_USER_INFOR表获取的用户名。
2. **数据来源**：
   - HDOC_USER_INFOR表：获取用户名。
   - HDOC_DOCUMENT_LIST表：获取文档类型列表。
   - HDOC_FUNCTION_AUTH表：验证用户ID是否存在。
   - HDOC_USER_DOC表：存储和查询用户文档权限。
3. **UserID输入限制**：只能输入半角英数字（a-z, A-Z, 0-9）。
4. **权限验证**：所有操作都需要先验证用户ID是否存在于HDOC_FUNCTION_AUTH表中。
5. **Document字段**：以文本框形式展示，显示文档描述信息。
