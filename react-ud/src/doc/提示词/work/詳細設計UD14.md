## 1. 背景 (Background)

本模块提供可用Template列表展示功能，用户可以选择Market，显示该Market文件夹中存储的所有Template文件信息，包括文件名、是否被使用、最后修改时间、文件大小等。支持点击文件名下载对应的Template文件。

- **目标**：允许Template Admin权限用户和其他需要查看和下载Homologation文档模板的用户管理模板文件。
- **核心功能**：Market选择、模板文件列表展示、文件下载、使用状态显示。
- **用户体验**：清晰的Market选择、完整的文件信息展示、直观的文件下载操作、显示文件使用情况（Used列）。
- **安全性**：文件下载权限控制、防止路径遍历攻击。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

所有校验逻辑均在用户选择Market或点击下载链接时同步或异步执行。

### 3.1 处理流程

#### 3.1.1 页面初始化流程

1. **开始**：页面加载。
2. **API调用**：
   - 呼出时点：画面加载时
   - 呼出方法：POST请求
   - 参数：无
   - 调用UD14SelectMarketmaster（Endpoint: `/api/v1/hdoc/ud14/selectMarketmaster`）获取Market列表。
3. **处理**：
   - 显示所有Market供用户选择。
   - 默认不选择Market 显示为 [-]。
   - 如果之前已选择Market，显示该Market文件夹中的所有Template文件。
4. **结果处理**：
   - **成功**：在DataTable中显示Filename、Used、Last Mod、Size等信息。
   - **失败**：显示错误消息"System error. Please contact administrator."。

#### 3.1.2 选择Market流程

1. **开始**：用户在[SelectMartet]下拉列表中选择Market。
2. **前置处理**：获取选中的Market值。
3. **API 调用**：
   - 呼出时点：用户选择Market后
   - 呼出方法：POST请求
   - 参数：画面のMarket
   - 调用 `UD14SelectHdocuserdefinedrules`（Endpoint: `/api/v1/hdoc/ud14/selectHdocUserDefinedRules`）接口。
4. **处理**：
   - 对于每个文件，检查是否在HDOC_USER_DEFINED_RULES中注册。
   - 如果已注册，Used列显示对应的VARIABLE。
   - 从文件系统获取文件的Last Mod和Size。
5. **结果处理**：
   - **成功**：刷新DataTable，显示选中Market的Template文件。
   - **失败**：显示错误消息"Market folder not found."。

#### 3.1.3 下载Template文件流程

1. **开始**：用户点击DataTable中的文件名链接。
2. **API 调用**：
   - 呼出时点：用户点击文件名链接后
   - 呼出方法：GET请求
   - 参数：画面のMarket、画面のFilename
   - 调用 `UD14downfile`（Endpoint: `/api/v1/hdoc/template/download`）接口。
3. **处理**：
   - 系统根据Market和Filename定位文件。
   - 读取文件内容。
4. **结果处理**：
   - **成功**：触发浏览器下载。
   - **失败**：显示错误消息"File not found."。

## 4. 接口定义 (API Specification)

### 4.1 UD14SelectMarketmaster - 获取Market列表

- **功能**：获取Market列表。
- **Method**: `POST`
- **Endpoint**: `/api/v1/hdoc/ud14/selectMarketmaster`

#### Response Success (200 OK)

```json
{
   "code": 200,
   "message": "查询成功",
   "data": {
      "marketList": ["xxx", "xxx"]
   }
}
```

### 4.2 UD14SelectHdocuserdefinedrules - 获取Template文件列表及使用信息

- **功能**：获取Template文件列表及使用信息。
- **Method**: `POST`
- **Endpoint**: `/api/v1/hdoc/ud14/selectHdocUserDefinedRules`

#### Request Body

```json
{
  "market": "string"
}
```

#### Response Success (200 OK)

```json
{
    "code": 200,
    "message": "查询成功",
    "data": {
      "variableList": ["xxx", "xxx"]
    }
}
```

### 4.3 UD14downfile - 下载Template文件

- **功能**：下载Template文件。
- **Method**: `GET`
- **Endpoint**: `/api/v1/hdoc/template/download`

#### Request Query Parameters

```json
{
  "market": "string",
  "filename": "string"
}
```

#### Response

文件流

## 5. 异常处理 (Exception Handling)

| 异常场景 | 处理方式 | Message 显示内容 |
| :------- | :------- | :--------------- |
| **文件不存在** | API返回404错误 | `File not found.` |
| **Market文件夹不存在** | API返回错误 | `Market folder not found.` |
| **API调用失败** | 捕获异常，返回500错误 | `System error. Please contact administrator.` |
| **网络超时** | 捕获超时异常 | `Network timeout. Please try again.` |

## 6. 实现注意事项 (Implementation Notes)

1. **状态管理**：
   - 使用 React State 管理 `selectMarket`, `templateList`, `message`, `isLoading`。
   - `Message` Label 默认隐藏（内容为空时不占位或高度为0）。

2. **安全性**：
   - 严禁在前端日志中打印敏感数据。
   - API 请求必须通过 HTTPS 发送。
   - 文件下载时需进行路径校验，防止路径遍历攻击。

3. **UI 细节**：
   - 所有操作按钮在 `isLoading` 期间应设为 `disabled`，防止重复提交。
   - `Message` 文字颜色建议使用红色 (`#ff4d4f`) 以起到警示作用。
   - DataTable中的文件名列应实现为可点击的链接。

4. **数据表**：
   - 主要数据表：`MARKET_MASTER`, `HDOC_USER_DEFINED_RULES`
   - 字段包括：MARKET, VARIABLE 等
