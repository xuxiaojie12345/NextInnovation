## 1. 背景 (Background)

本模块是系统的主菜单导航界面，负责提供用户登录后的主要操作入口。通过左侧菜单树，用户可以访问系统的各个功能模块，包括文档生成、系统管理、用户管理等核心功能。

- **目标**：提供清晰的导航结构，确保用户能够快速找到并访问所需功能。
- **安全性**：根据用户权限动态显示/隐藏菜单项，防止未授权访问。
- **用户体验**：采用清晰的菜单层级结构和直观的图标文字标识，支持响应式布局适配不同屏幕尺寸。

### 2.2 画面布局说明

**整体布局:**

**左侧菜单区:**
包含以下一级菜单和二级菜单结构：

  - Generate Doc

- **一级菜单：Admin**
  - Update user defined variables (rules)
  - Existing HDoc variables
  - Upload/Delete template
  - List available templates
  - VPPS Vin plate
  - AD/CA Change

  - HDoc User Administration
  - HDoc User Doc Administration

- **一级菜单：Documentation**

**右侧内容区:**
- 初始状态为空白
- 点击左侧菜单项后，动态加载对应的页面内容

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

所有菜单逻辑均在用户登录成功后同步或异步执行。

### 3.1 处理流程

1. **开始**：用户登录成功，进入Menu页面。
2. **前置处理**：
   - 从前画面获取用户信息
3. **菜单渲染**：
   - 遍历菜单配置
   - 显示需要访问的菜单项
   - 按照一级菜单、二级菜单的层级结构渲染
4. **菜单点击处理**：
   - 捕获菜单项点击事件
   - 更新当前选中菜单状态
   - 使用React Router跳转到对应路由
   - 右侧内容区加载对应组件
      注：Generate Doc：跳转到 03_Generate Homologation Document 画面
          Update user defined variables (rules)：跳转到 08_Homologation Variables 画面
          Existing HDoc variables：跳转到 10_Existing HDoc Variables 画面
          Upload/Delete template：跳转到 12_Upload&Delete template 画面
          List available templates：跳转到 14_List availableTemplates 画面
          VPPS Vin plate：跳转到 15_Vin Plate 画面
          AD/CA Change：跳转到 16_AD Change 画面
          HDoc User Administration：跳转到 17_HDoc User Admin 画面
          HDoc User Doc Administration：跳转到 18_HDoc User Doc Administration 画面
          Search User：跳转到  19_Search User 画面
          User Guide：跳转到 24_HDoc Help 画面
5. **结果处理**：
   - **成功**：右侧显示对应页面内容
   - **失败**：显示错误提示信息

### 3.2 校验详细规格表

| No. | 检查时机 | 检查对象 | 检查条件 | 错误消息 | 动作 |
| :-: | :----------: | :---------------: | :------------------------------------: | :---------------------------------------------------------------------------: | :----------------------------------: |
| 1 | 页面加载 | 用户权限 | 用户未登录或Token失效 | `Session expired. Please login again.` | 跳转到Login页面 |
| 2 | 菜单点击 | 菜单权限 | 用户无该菜单访问权限 | `Access denied. You don't have permission to access this feature.` | 显示错误提示，不跳转 |
| 3 | 路由跳转 | 路由配置 | 路由不存在 | `Page not found.` | 显示404页面 |

## 5. 异常处理 (Exception Handling)

| 异常场景 | 处理方式 | Message 显示内容 |
| :----------------------- | :----------------- | :--------------------------------------------- |
| **用户未登录或Token失效** | 前端拦截，跳转登录页 | `Session expired. Please login again.` |
| **用户无菜单访问权限** | 前端权限校验拦截 | `Access denied. You don't have permission to access this feature.` |
| **路由配置错误** | React Router捕获 | `Page not found.` |
| **API调用失败** | 捕获异常，显示错误提示 | `System error. Please contact administrator.` |
| **网络超时** | 捕获超时异常 | `Network timeout. Please try again.` |

## 6. 实现注意事项 (Implementation Notes)

1. **状态管理**：
   - 使用 React State 管理 `selectedMenu`, `userPermissions`, `isLoading`。
   - 菜单状态应持久化存储（如localStorage）以保持用户体验一致性。
2. **安全性**：
   - 所有菜单权限必须在前端和后端双重验证。
   - Token 应定期刷新，防止会话劫持。
3. **UI 细节**：
   - 当前选中的菜单项应高亮显示。
   - 菜单应支持折叠/展开功能以节省空间。
   - 支持响应式布局，在小屏幕上可切换为汉堡菜单。
4. **性能优化**：
   - 菜单数据应缓存，避免重复API调用。
   - 右侧内容区使用懒加载，提高初始加载速度。
