## 1. 背景 (Background)

本模块用于显示HDoc系统中可用的市场信息列表，为用户提供清晰的市场数据展示界面。

- **目标**：提供完整的市场信息列表，包括市场代码和描述，便于用户了解系统支持的所有市场。
- **安全性**：需验证用户权限，确保只能访问授权的市场数据，保护敏感商业信息。
- **用户体验**：提供清晰的市场列表展示，便于用户查看市场及描述信息，界面简洁直观。

面向的用户群体:
- 需要查看和了解市场信息的业务人员
- HDoc系统管理员
- 具有市场数据查看权限的用户

用户体验方面的考虑:
- 市场列表按字母顺序或逻辑顺序排列，便于查找
- 信息展示区域布局合理，字段对齐清晰
- 加载过程显示进度指示器，提升用户体验
- 错误信息清晰明确，便于用户理解问题所在

安全性或特殊要求:
- 需要验证当前用户是否有查看市场数据的权限
- 敏感市场信息需按照公司安全策略进行适当处理
- 所有数据传输必须通过HTTPS加密

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

所有校验逻辑均在用户进入画面时自动执行。

### 3.1 处理流程

#### Markets in HDoc画面加载流程

1. **开始**：用户进入Markets in HDoc画面。
2. **前置处理**：准备调用API获取MARKET_MASTER表数据。
3. **API调用**：
   - 呼出时点：画面加载时
   - 呼出方法：POST请求
   - 参数：无
   - 调用`：UUD19SelectMarketMaster` 获取MARKET_MASTER表数据。
4. **结果处理**：
   - **成功**：正常显示市场列表信息（Market、Description、Weights from Hdoc）。
   - **失败**：显示相应错误消息并保持在当前页面。

### 3.2 校验详细规格表

| No. | 检查时机 | 检查对象 | 检查条件 | 错误消息 (Message Content) | 动作 |
| :-: | :----------: | :---------------: | :------------------------------------: | :---------------------------------------------------------------------------: | :----------------------------------: |
| 1 | 进入画面时 | 市场数据获取 | 无法获取市场数据 | `无法获取市场信息` | 显示错误消息，保持当前页面 |

| 3 | API调用时 | 系统状态 | 系统异常 | `系统暂时不可用，请稍后重试` | 显示错误消息 |

## 4. 接口定义 (API Specification)

### 4.1 UD19SelectMarketMaster

- **功能**：获取Market列表
- **所属Api**：UD19SearchResultListApi
- **Method**: `POST`
- **Endpoint**: `/api/v1/hdoc/ud19/selectMarketMaster`

#### Request Body

```json
{}
```

#### Response Success (200 OK)

```json
{
    "code": 200,
    "message": "查询成功",
    "data": {
        "marketList": [
            {
                "market": "MARKET-A",
                "description": "A市场说明文本"
            },
            {
                "market": "MARKET-B",
                "description": "B市场说明文本"
            }
      ]
    }
}
```

#### Response Error (400 Bad Request)

```json
{
  "code": 400,
  "data": null,
  "message": "Invalid request parameters"
}
```

## 5. 异常处理 (Exception Handling)

| 异常场景 | 处理方式 | Message显示内容 |
| :----------------------- | :----------------- | :--------------------------------------------- |
| **无法获取市场数据** | 显示错误消息，保持当前页面 | `无法获取市场信息` |
| **API调用失败** | 显示错误消息，保持当前页面 | `系统错误，请稍后重试` |
| **用户无查看权限** | 拒绝访问，返回错误信息 | `您没有权限查看市场信息` |
| **网络断开/超时** | 捕获 Network Error | `网络连接失败，请稍后重试` |
| **服务器内部错误** | 捕获 Server Error | `系统错误，请联系管理员` |

## 6. 实现注意事项 (Implementation Notes)

1. **状态管理**：
   - 使用 React State 管理市场数据列表、Message等状态。
   - Message Label 默认隐藏（内容为空时不占位或高度为0）。
   - 加载状态使用`isLoading`标志控制。
2. **安全性**：
   - 在页面加载时验证用户权限，确保只有授权用户能访问。
   - API 请求必须通过 HTTPS 发送。
   - 敏感市场信息应按照公司安全策略进行适当处理。
3. **UI 细节**：
   - 所有TextField控件设置为只读状态（readOnly=true）。
   - 市场列表建议使用表格形式展示，便于阅读和对比。
   - 加载过程中显示Loading指示器，提升用户体验。
   - Message 文字颜色建议使用红色 (`#ff4d4f`) 以起到警示作用。
4. **数据源**：
   - 市场信息来源于MARKET_MASTER表。
   - 确保数据字段映射正确：Market、Description。
   - Weights from Hdoc字段可能需要从其他相关表或配置文件中获取。
5. **性能优化**：
   - 考虑市场数据量较大时的分页或虚拟滚动实现。
   - 数据缓存策略：市场数据相对静态，可考虑客户端缓存减少API调用。
