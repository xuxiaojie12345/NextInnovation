## 1. 背景 (Background)

本模块提供Vin Plate信息管理功能，用户输入Chassis number后，可以查看VIN Plate的详细信息，包括状态、类型、错误消息、发送数据状态等。支持多种操作：View Info、Set Regenerate、Set OK、Change to Basic Info、Change to Advanced Info，用于更新Chassis的状态和类型。

- **目标**：允许系统工程人员和需要管理VIN Plate数据的用户查看和管理VIN Plate信息。
- **核心功能**：Chassis信息查看、状态更新、类型更改、XML数据解析展示。
- **用户体验**：清晰的Chassis信息展示、直观的操作按钮、明确的状态和错误消息显示、XML数据解析展示（Print Items和VP Data）。
- **安全性**：Chassis number格式校验、状态更新权限控制、XML数据安全解析。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

所有校验逻辑均在用户点击操作按钮时同步或异步执行。

### 3.1 处理流程

#### 3.1.1 点击 [View Info] 按钮

1. **开始**：用户点击 [View Info] 按钮。
2. **前置处理**：获取Chassis number输入值，去除首尾空格。
3. **空值校验 (Frontend Check)**：
   - 若 `Chassis number` 为空：
     - 设置 `Message` = `Chassis number is required.`
     - **终止**流程，不调用 API。
4. **API 调用**：
   - 呼出时点：用户点击View Info按钮后
   - 呼出方法：POST请求
   - 参数：画面のChassis number
   - 调用 `UD15ViewInfo`（Endpoint: `/api/v1/hdoc/ud15/viewInfo`）接口。
5. **处理**：
   - 检索结果为0件时：显示错误消息"Chassis number XXX not found."。
   - 从HDOC_SEND_DATA_VIN_PLATE表查询该Chassis的记录。
   - 解析XML_DOC字段：
     - 提取PrintItemName项目值，显示在Print items列。
     - 提取各Variant名称和Value，显示在VP Data列。
6. **结果处理**：
   - **成功**：显示Plate type、Status、Error Message、Def.、Data ready、Sent to CAB factory等信息。
   - **失败**：显示错误消息"Chassis number XXX not found."。

#### 3.1.2 点击 [Set Regenerate] 按钮

1. **开始**：用户点击 [Set Regenerate] 按钮。
2. **前置处理**：获取Chassis number输入值，去除首尾空格。
3. **空值校验 (Frontend Check)**：

## 5. 异常处理 (Exception Handling)

| 异常场景 | 处理方式 | Message 显示内容 |
| :------- | :------- | :--------------- |
| **Chassis number为空** | 前端校验拦截 | `Chassis number is required.` |
| **Chassis记录不存在** | API返回404错误 | `Chassis number XXX not found.` |
| **XML解析失败** | 捕获异常 | `XML parsing failed.` |
| **API调用失败** | 捕获异常，返回500错误 | `System error. Please contact administrator.` |
| **网络超时** | 捕获超时异常 | `Network timeout. Please try again.` |

## 6. 实现注意事项 (Implementation Notes)

1. **状态管理**：
   - 使用 React State 管理 `chassisNumber`, `vinPlateInfo`, `message`, `isLoading`。
   - `Message` Label 默认隐藏（内容为空时不占位或高度为0）。

2. **安全性**：
   - 严禁在前端日志中打印敏感数据。
   - API 请求必须通过 HTTPS 发送。
   - 对Chassis number进行格式校验。

3. **UI 细节**：
   - 所有操作按钮在 `isLoading` 期间应设为 `disabled`，防止重复提交。
   - `Message` 文字颜色建议使用红色 (`#ff4d4f`) 以起到警示作用。
   - XML数据解析结果显示时需格式化，提高可读性。

4. **数据表**：
   - 主要数据表：`HDOC_SEND_DATA_VIN_PLATE`
   - 字段包括：CHNR, TYPE, STATUS, MSG, REGISTER_DATETIME, DOC_READY, DOC_SENT, XML_DOC 等
