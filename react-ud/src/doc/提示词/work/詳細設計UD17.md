## 1. 背景 (Background)

本模块提供HDoc用户权限管理功能，管理员可以输入UserID，从Saviynt系统获取用户信息，并设置该用户的各种权限角色，包括Standard User、Rule Admin、Template Admin、Document Auth Admin、User Admin、Adaptation user、Manage Variable List、Market Super User等。支持更新和删除用户权限。

- **目标**：为User Admin权限用户提供完整的用户权限管理界面，确保权限分配的准确性和安全性。
- **安全性**：用户ID存在性校验、权限变更审计日志、防止未授权权限修改。
- **用户体验**：清晰的UserID输入和用户信息显示、直观的权限角色复选框、Market下拉列表联动显示、明确的更新和删除操作反馈。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

所有校验逻辑均在用户执行相应操作时同步或异步执行。

### 3.1 处理流程

#### 页面初期化

1. **开始**：页面加载。
2. **API调用**：
   - 呼出时点：画面加载时
   - 呼出方法：POST请求
   - 参数：无
   - 调用 `UD19SelectMarketMaster` 获取Market列表。
3. **处理**：
   - 将所有权限复选框设为未选中状态。
   - 将Standard User和Adaptation user对应的Market下拉列表默认设为`-EU`。
   - 将其余Market下拉列表设为空。
   - UserID输入框和User标签设为空。
4. **结果处理**：
   - **成功**：各Market下拉列表加载所有Market选项，画面处于初始状态。
   - **失败**：显示错误消息"System error. Please contact administrator."。

#### 点击 [User Info] 按钮
1. **开始**：用户点击 [User Info] 按钮。
2. **前置处理**：获取 UserID，执行 `trim()` 去除首尾空白。
3. **空值校验 (Frontend Check)**：
   - 若 `UserID` 为空：
     - 显示错误消息 `Userid is required.`
     - **终止**流程，不调用 API。
4. **API 调用**：
   - 呼出时点：用户点击User Info按钮后
   - 呼出方法：POST请求
   - 参数：画面のUserID
   - 调用 `UD17Userinfo`
   - 检索结果为0件时：显示错误消息 `We didn't recognize the userid you entered. Please try again.`
                    **终止**流程，不调用 API。

5. **结果处理**：
   - **查询成功**：显示用户信息，自动勾选已有权限复选框，显示对应的Market选择。
   - **查询失败**：显示错误消息 `We didn't recognize the userid you entered. Please try again.`

#### 点击 [Update Role] 按钮
1. **开始**：用户点击 [Update Role] 按钮。
2. **前置处理**：获取 UserID 和所有权限复选框状态及Market选择值。
3. **API 调用**：
   - 呼出时点：用户点击Update Role按钮后
   - 呼出方法：POST请求
   - 参数：画面のUserID
   - 调用 `UD17Userinfo` 
   - 检索结果为0件时：显示错误消息 `We didn't recognize the userid you entered. Please try again.`
                     **终止**流程，不调用 API。
   - 呼出方法：POST请求
   - 参数：画面のUserID、画面の权限列表
   - 调用 `UD17UpdateRole`
4. **结果处理**：
   - **更新成功**：显示成功消息 `权限更新成功`。
   - **更新失败**：显示相应错误消息。

#### 点击 [Delete Role] 按钮
1. **开始**：用户点击 [Delete Role] 按钮。
2. **前置处理**：获取 UserID。
3. **API 调用**：
   - 呼出时点：用户点击Delete Role按钮后
   - 呼出方法：POST请求
   - 参数：画面のUserID
   - 调用 `UD17DeleteRole`
4. **结果处理**：
   - **删除成功**：显示成功消息 `用户权限已全部删除`，清空所有权限复选框。
   - **删除失败**：显示相应错误消息。

## 4. 接口定义 (API Specification)

### 4.1 UD17Userinfo

- **功能**：查询用户权限信息（支持多条数据）。
- **Method**: `POST`
- **Endpoint**: `/api/v1/hdoc/user/info`

#### Request Body

```json
{
  "userid": "string"
}
```

#### Response Success (200 OK)

```json
{
  "code": 200,
  "message": "查询成功",
  "data": {
    "userId": "xxx",
    "username": "xxx",
    "authList": [
      {
        "function": "功能权限1",
        "market": "市场权限1"
      },
      {
        "function": "功能权限2",
        "market": "市场权限2"
      },
      {
        "function": "功能权限3",
        "market": "市场权限3"
      }
    ]
  }
}
```

### 4.2 UD17UpdateRole

- **功能**：更新用户角色权限。
- **Method**: `POST`
- **Endpoint**: `/api/v1/hdoc/user/update/role`

#### Request Body

```json
{
  "userid": "string",
  "authList": [
    {
      "function": "功能权限1",
      "market": "市场权限1"
    },
    {
      "function": "功能权限2",
      "market": "市场权限2"
    }
  ]
}
```

#### Response Success (200 OK)

```json
{
  "code": 200,
  "message": "权限更新成功",
  "data": {
    "userId": "xxx",
    "updateCount": 3,
    "authList": [
      {
        "function": "功能权限1",
        "market": "市场权限1"
      }
    ]
  }
}
```

### 4.3 UD17DeleteRole

- **功能**：删除用户角色权限。
- **Method**: `POST`
- **Endpoint**: `/api/v1/hdoc/user/delete/role`

#### Request Body

```json
{
  "userid": "string"
}
```

#### Response Success (200 OK)

```json
{
  "code": 200,
  "message": "用户权限已全部删除",
  "data": {
    "userId": "xxx"
  }
}
```

## 5. 异常处理 (Exception Handling)

| 异常场景 | 处理方式 | Message 显示内容 |
| :----------------------- | :----------------- | :--------------------------------------------- |
| **UserID为空或格式错误** | 前端校验拦截 | `We didn't recognize the userid you entered. Please try again.` |
| **用户不存在于权限表** | API返回404错误 | `We didn't recognize the userid you entered. Please try again.` |
| **API调用失败** | 捕获异常，返回500错误 | `System error. Please contact administrator.` |
| **网络超时** | 捕获超时异常 | `Network timeout. Please try again.` |

## 6. 实现注意事项 (Implementation Notes)

1. **状态管理**：
   - 使用 React State 管理 `userId`, `userInfo`, `authList`, `selectedPermissions`, `isLoading`, `errorMessage`。
   - 权限复选框状态需要与Market下拉列表联动。
2. **安全性**：
   - 仅User Admin权限用户可访问此页面。
   - 所有API调用必须通过HTTPS发送。
   - 权限变更需记录审计日志。
3. **UI 细节**：
   - 按钮在 `isLoading` 期间应设为 `disabled`，防止重复提交。
   - 错误消息文字颜色建议使用红色 (`#ff4d4f`) 以起到警示作用。
   - Market下拉列表应根据权限复选框的选择动态显示/隐藏。
4. **数据源**：
   - 用户信息：Saviynt系统（通过AuthenticationApi）
   - Market列表：MARKET_MASTER.MARKET
   - 用户权限：HDOC_FUNCTION_AUTH、HDOC_MARKET_AUTH表
5. **操作流程**：
   - 更新操作采用事务处理，确保权限数据的一致性。
   - 所有API调用都需要进行错误处理和用户反馈。
