## 1. 背景 (Background)

本模块为 HDoc 系统用户提供快速导航与帮助入口，汇总常用文档类型、市场说明、模板与其他参考资料，便于用户查阅与跳转。

- **目标**：提供对常见操作与页面（如 Generate Document、Market Document Setting、List of document types 等）的快速链接，提升用户操作效率。
- **用户体验**：界面简洁明了，链接项以清晰的文字呈现并在左侧统一对齐，点击可直接跳转到目标页面。保持与系统整体导航风格一致。
- **安全性**：本画面暂不考虑权限控制，所有链接均可见。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

所有处理逻辑在页面初始化或用户点击链接时触发。

### 3.1 处理流程

1. **开始**：页面加载（初期表示）。
2. **空值校验**：无。
3. **初期表示**：
   - 页面显示所有Link项和Checkbox控件。
4. **用户点击Link**：
   - **开始**：用户点击任意Link项。
   - 前端根据Link对应的路由进行画面跳转：
     - **HDoc Quick Guide** → 跳转到「Download and Print Quick Guides」画面
     - **List of document types.** → 跳转到「Document Types」画面
     - **Markets in Hdoc** → 跳转到「Markets in HDoc」画面
     - **HDoc - Market Document Setting** → 跳转到「Market Document Settings」画面
     - **Describation** → 只是link链接 不跳转具体画面
5. **结果处理**：
   - **成功**：页面正常显示，点击链接可正常跳转。
   - **失败**：无（纯静态页面，不涉及API调用）。

## 6. 实现注意事项 (Implementation Notes)

1. **状态管理**：无（静态页面，无需状态管理）。
2. **UI 细节**：
   - 链接项采用左对齐排列，与系统整体导航风格保持一致。
   - 链接文本颜色使用蓝色 (`#002182`)，hover 时颜色加深并显示下划线。
   - 点击链接时使用 `navigate()` 实现 SPA 跳转，避免页面刷新。
