## 1. 背景 (Background)

本模块提供 HDoc Template 校验功能。用户上传 Template 文件后，系统打开文件并读取内容，获取 `$` 之间的变量内容，统计变量个数，校验文件内容的正确性。校验结果可以下载。

- **目标**：为 Template Admin 权限用户提供模板校验功能，确保模板文件格式正确且包含必要的变量定义。
- **安全性**：文件访问权限控制、文件内容解析安全、防止恶意文件上传。
- **用户体验**：直观的文件上传界面、清晰的校验结果显示、支持下载校验结果、明确的错误提示。

## 6. 实现注意事项 (Implementation Notes)

1. **状态管理**：
   - 使用 React State 管理 `selectedFile`, `message`, `isLoading`, `downloadUrl`, `checkResult`。
   - `Message` Label 默认隐藏（内容为空时不占位或高度为0）。
   - `Download checked template` 链接在校验成功前隐藏，校验成功后显示。
2. **安全性**：
   - 严禁在前端日志中打印文件内容或敏感路径信息。
   - API 请求必须通过 HTTPS 发送。
   - 后端需验证文件扩展名是否为 `.rtf`。
   - 防止恶意文件上传：限制文件大小（如最大 10MB），校验文件头信息。
3. **UI 细节**：
   - [Check] 按钮在 `isLoading` 期间应设为 `disabled`，防止重复提交。
   - `Message` 文字颜色建议使用红色 (`#ff4d4f`) 以起到警示作用，成功消息可使用绿色 (`#52c41a`)。
   - `Download checked template` 链接使用蓝色 (`#1890ff`) 并添加下划线，符合超链接视觉规范。
4. **文件解析逻辑**：
   - 后端需实现正则表达式解析，提取所有 `$变量名$` 格式的内容。
   - 变量名应符合命名规范（如：仅包含字母、数字、下划线）。
   - 校验结果文件应包含：变量总数、变量列表、每个变量的位置信息等。
5. **下载功能**：
   - 点击下载链接时，使用 `window.location.href` 或创建隐藏的 `<a>` 标签触发下载。
   - 下载文件名建议格式：`template_check_result_YYYYMMDD_HHmmss.csv`。
   - 下载完成后，可选择是否清除 `downloadUrl` 状态。
6. **错误处理**：
   - 对于文件解析失败，应提供详细的错误信息，帮助用户定位问题。
   - 建议在 UI 上显示变量个数，让用户了解校验结果的详细信息。
