## 1. 背景 (Background)

本模块提供修改保存确认功能，显示已保存的修改内容，包括Chassis信息、Doctype、Version以及修改的Variable和NewVal列表。用户确认后点击Close按钮关闭页面。

- **目标**：清晰展示已保存的修改内容，提供明确的版本状态提示，确保用户能够确认修改操作已完成。
- **安全性**：数据只读显示，防止未授权访问。
- **用户体验**：采用简洁的信息展示布局，提供明确的关闭操作。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

所有校验逻辑均在用户点击 **[Save]** 按钮时同步或异步执行。

### 3.1 处理流程

#### 画面初期表示
1. **开始**：从前页面接收SERIE和CHNO参数。
2. **前置处理**：
   - 解析Chassis serie（'-'前的内容）和Chassis number（'-'后的内容）
3. **API调用**：
   - 呼出时点：画面加载时
   - 呼出方法：POST请求
   - 参数：画面のSERIE、画面のCHNO
   - 调用UD06SaveModificationsApi的UD06SelectHdocAdcaModification（Endpoint: `/api/v1/hdoc/adcamodification`）
4. **数据获取**：
   - 从HDOC_ADCA_MODIFICATION表获取DOCTYPE、VERS、VARIABLE、NEWVAL
   - 根据SERIE和CHNO查询
5. **结果显示**：
   - 显示Chassis serie和Chassis number
   - 显示Doctype和Version
   - 显示Storing（VARIABLE和NEWVAL列表）
   - 如果找到未发布版本，显示"FOUND UNRELEASED VERSION"
   - 显示Message：'VERSION IS RELEASED'
6. **结果处理**：
   - **成功**：显示所有信息
   - **失败**：显示错误消息

#### Close操作
1. **开始**：用户点击[Close]按钮。
2. **处理**：关闭当前页面。

## 4. 接口定义 (API Specification)

### 4.1 UD06SelectHdocAdcaModification

- **功能**：查询HDOC_ADCA_MODIFICATION表中的修改记录。
- **所属 API**：UD06SaveModificationsApi
- **Method**: `POST`
- **Endpoint**: `/api/v1/hdoc/adcamodification`

#### Request Body

```json
{
  "serie": "string",
  "chno": "string"
}
```

#### Response Success (200 OK)

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "doctype": "string",
    "version": "string",
    "modifications": [
      {
        "variable": "string",
        "newVal": "string"
      }
    ],
    "hasUnreleasedVersion": boolean
  }
}
```

#### Response Error (500 Internal Server Error)

```json
{
  "code": 500,
  "message": "Failed to query record.",
  "data": null
}
```

| 异常场景 | 处理方式 | Message 显示内容 |

## 6. 实现注意事项 (Implementation Notes)

1. **状态管理**：
   - 使用 React State 管理 `chassisInfo`, `modificationData`, `message`, `isLoading`。
   - `Message` Label 默认隐藏（内容为空时不占位）。
2. **安全性**：
   - 所有API请求必须通过 HTTPS 发送。
   - 对输入参数进行SQL注入防护。
   - 验证用户是否有修改权限。
3. **UI 细节**：
   - Close 按钮在 `isLoading` 期间应设为 `disabled`，防止重复提交。
   - `Message` 文字颜色建议使用红色 (`#ff4d4f`) 以起到警示作用。
4. **数据表**：
   - 主要数据表：`HDOC_ADCA_MODIFICATION`
   - 字段包括：VARIABLE, VAL, COMMENTS, REGISTER_DATETIME, UPDATE_DATETIME等
