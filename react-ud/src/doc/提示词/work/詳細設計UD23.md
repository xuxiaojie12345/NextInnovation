## 1. 背景 (Background)

本模块提供Quick Guides文件下载功能，同时展示Quick Guides的打印方法和折叠方法说明。用户可以通过链接下载Quick Guides文件，并通过复选框查看打印和折叠的操作说明。

- **目标**：提供Quick Guides文件的便捷下载入口，同时清晰展示打印和折叠的操作步骤。
- **用户体验**：采用清晰的链接和复选框布局，点击链接可预览或下载文件，勾选复选框查看对应操作说明，界面简洁直观。
- **安全性**：无需后端API调用，所有内容为静态展示，不涉及用户数据交互。

## 6. 实现注意事项 (Implementation Notes)

1. **状态管理**：
   - 使用 React State 管理 `isPrintChecked`、`isFoldChecked` 两个复选框状态。
   - 复选框状态变化时，控制对应说明区域的显示和隐藏。
2. **UI 细节**：
   - 链接使用下划线样式，点击后触发跳转或下载。
   - 复选框与说明内容关联，勾选后显示对应的操作说明区域。
   - 操作说明区域使用条件渲染（如 `{isPrintChecked && <PrintInstructions />}`）。
   - Back按钮点击后使用 `navigate()` 实现 SPA 跳转到HDoc Help画面。
3. **布局**：
   - 参考图片：`react-ud\src\doc\image\Download and Print Quick Guides.png`
   - 上部为Quick Guides卡片展示区，下部为Volvo 3P Quick Guides链接列表。
   - 复选框和说明区域位于页面下方。
