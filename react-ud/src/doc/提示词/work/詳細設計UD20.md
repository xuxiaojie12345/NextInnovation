## 1. 背景 (Background)

本模块提供市场文档设置的查询和管理功能。画面流转顺序为：24_HDoc Help画面 → 点击链接 → HDoc - Market Document Setting検索画面 → 点击Search → HDoc - Market Document Setting検索結果画面。支持按文档类型、业务单元、用户、日期等条件检索文档列表，支持选择记录并回填至查询画面，支持查看注册用户详细信息。

- **目标**：提供清晰的文档查询界面，便于用户管理和查找市场文档设置。
- **安全性**：需要验证用户是否有查看权限，仅显示用户有权限查看的文档信息。
- **用户体验**：查询条件与查询结果分离，界面清晰；选择记录后自动回填至查询画面，减少重复操作；提供Clear按钮快速清空查询条件。

面向的用户群体:
- HDoc系统管理员
- 具有文档管理权限的用户

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

所有校验逻辑均在用户执行相应操作时同步或异步执行。

### 3.1 处理流程

#### 检索画面的[Search] 按钮压下（检索画面 → 检索結果画面）

1. **开始**：用户在检索画面点击 [Search] 按钮。
2. **前置处理**：收集Document type、Business unit、User、Date等查询参数。
3. **API调用**：
   - 呼出时点：用户点击Search按钮后
   - 呼出方法：POST请求
   - 参数：画面のDocument type、画面のUser、画面のDate
   - 调用 `UD20SelectHdocDocumentList`获取文档列表。
4. **结果处理**：
   - **成功**：跳转至检索結果画面，显示查询结果列表。
   - **失败（无权限）**：Message = `您没有权限执行此操作`。
   - **失败（结果为空）**：显示`没有找到符合条件的文档`。
   - **系统异常**：Message = `系统暂时不可用，请稍后重试`。

#### 检索画面点击 [Clear] 按钮

1. **开始**：用户在检索画面点击 [Clear] 按钮。
2. **处理**：将Document type、User、Date等字段重置为空值。

#### 检索画面点击 [Back] 按钮

1. **开始**：用户在检索画面点击 [Back] 按钮。
2. **处理**：返回前画面（24_HDoc Help）。

#### 检索画面点击 [Update Mode] 按钮

1. **开始**：用户在检索画面点击 [Update Mode] 按钮。
2. **前置处理**：获取Document type、User、Date等输入参数。
3. **API调用**：
   - 呼出时点：用户点击Update Mode按钮后
   - 呼出方法：POST请求
   - 参数：画面のDocument type、画面のUser、画面のDate
   - 调用 `UD20-1UpdateHdocDocumentList` 
5. **结果处理**：
   - **成功**：显示成功消息。
   - **失败**：显示相应的错误消息。


#### 检索結果画面的[Select] 按钮压下 记录选择流程（检索結果画面 → 检索画面）

1. **开始**：用户在检索結果画面点击 [Select] 按钮。
2. **前置处理**：获取用户选中的记录数据。
3. **空值校验 (Frontend Check)**：
   - 若未选择任何记录：
     - 设置 Message = `No data found`
     - **终止**流程，不执行跳转。
4. **结果处理**：
   - **成功**：将选中记录数据传递至检索画面，自动回填各字段。
   - **失败**：显示相应的错误消息。

#### 检索結果画面点击 [Back] 按钮

1. **开始**：用户在检索結果画面点击 [Back] 按钮。
2. **处理**：返回检索画面。

#### 检索結果画面点击 [Print] 按钮

1. **开始**：用户在检索結果画面点击 [Print] 按钮。
2. **处理**：调用浏览器打印功能，打印当前查询结果页面。

### 3.2 校验详细规格表

| No. | 检查时机 | 检查对象 | 检查条件 | 错误消息 (Message Content) | 动作 |
| :-: | :----------: | :---------------: | :------------------------------------: | :---------------------------------------------------------------------------: | :----------------------------------: |
| 1 | 点击Select按钮时 | 记录选择状态 | 未选择任何记录 | `No data found` | 显示错误消息，阻止跳转操作 |
| 2 | 页面加载时 | 用户权限 | 当前用户无查看权限 | `您没有权限执行此操作` | 阻止访问，重定向到主页 |
| 3 | API调用时 | 系统状态 | 系统异常 | `系统暂时不可用，请稍后重试` | 显示错误消息 |

## 4. 接口定义 (API Specification)

### 4.1 UD20SelectHdocDocumentList

- **功能**：获取市场文档设置列表信息。
- **所属Api**：UD20GetDocumentListApi 
- **Method**: `POST`
- **Endpoint**: `/api/v1/hdoc/ud20/getDocumentList`

#### Request

```json
{
  "doctype": "string (MaxLength 20, 可选)",
  "registerUser": "string (MaxLength 16, 可选)",
  "registerDatetime": "datetime (可选)"
}
```

#### Response Success (200 OK)

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "documents": [
      {
        "doctype": "string",
        "description": "string",
        "businessUnit": "BU",
        "registerUser": "string",
        "registerDatetime": "datetime"
      }
    ]
  }
}
```

#### Response Error (400 Bad Request)

```json
{
  "code": 400,
  "message": "error message",
  "data": null
}
```

#### Response Error (500 Internal Server Error)

```json
{
  "code": 500,
  "message": "系统暂时不可用，请稍后重试",
  "data": null
}
```

### 4.2 UD20-1UpdateHdocDocumentList

- **功能**：更新市场文档设置信息。
- **所属**：UD20MarketDocumentSettingsApi
- **Method**: `POST`
- **Endpoint**: `/api/v1/hdoc/ud20/updateDocumentList`

#### Request Body

```json
{
  "doctype": "string (MaxLength 20)",
  "registerUser": "string (MaxLength 16)",
  "registerDatetime": "datetime"
}
```

#### Response Success (200 OK)

```json
{
  "code": 200,
  "message": "更新成功",
  "data": null
}
```

#### Response Error (400 Bad Request)

```json
{
  "code": 400,
  "message": "error message",
  "data": null
}
```

#### Response Error (500 Internal Server Error)

```json
{
  "code": 500,
  "message": "系统暂时不可用，请稍后重试",
  "data": null
}
```

## 5. 异常处理 (Exception Handling)

| 异常场景 | 处理方式 | Message显示内容 |
| :----------------------- | :----------------- | :--------------------------------------------- |
| **API连接失败** | 记录错误日志，返回错误信息 | `系统暂时不可用，请稍后重试` |
| **用户无查看权限** | 拒绝操作，返回错误信息 | `您没有权限执行此操作` |
| **查询结果为空** | 显示相应提示信息 | `没有找到符合条件的文档` |
| **未选择记录点击Select** | 进行前端校验，阻止操作 | `No data found` |
| **Update Mode更新失败** | API返回错误 | `系统暂时不可用，请稍后重试` |
| **网络超时** | 捕获超时异常 | `网络连接失败，请稍后重试` |
| **服务器内部错误** | 捕获Server Error | `系统错误，请联系管理员` |

## 6. 实现注意事项 (Implementation Notes)

1. **状态管理**：
   - 使用 React State 管理查询条件、查询结果、选中记录、Message等状态。
   - Message Label 默认隐藏（内容为空时不占位或高度为0）。
2. **安全性**：
   - 在页面加载时验证用户权限，确保只有授权用户能访问。
   - API 请求必须通过 HTTPS 发送。
3. **UI 细节**：
   - Business unit 下拉列表固定包含 BU 选项。
   - User 字段在检索結果画面应显示为链接，点击可跳转至 EDB User View。
   - Select 按钮在未选择记录时应设为 disabled，防止无效操作。
   - Message 文字颜色建议使用红色 (`#ff4d4f`) 以起到警示作用。
4. **数据源**：
   - HDOC_DOCUMENT_LIST 表包含字段：DOCTYPE, REGISTER_USER, REGISTER_DATETIME 等。
   - MARKET_MASTER.MARKET 获取 Market 列表（如适用）。
