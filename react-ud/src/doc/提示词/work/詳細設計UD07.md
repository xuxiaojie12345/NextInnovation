## 1. 背景 (Background)

本模块提供车辆规格信息的查看功能，是Homologation（认证）流程中的重要环节。通过Vehicle Specification页面，用户可以查看特定车辆的完整规格信息，包括车型、生产周次、产品类型、VIN、发动机号、适用国家等关键数据。

- **目标**：清晰展示车辆规格信息，确保数据的准确性和一致性，支持从前画面传递Chassis no参数。
- **安全性**：需要校验车辆数据的存在性，确保数据显示的数据一致性。
- **用户体验**：采用清晰的标签式布局，易于阅读，重要信息突出显示，鼠标悬停时显示详细描述信息（SYMBOL的tooltip），支持响应式布局适配不同屏幕尺寸。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

所有逻辑均在页面加载时同步或异步执行。

### 3.1 处理流程

#### 画面初期表示
1. **开始**：从前页面获取Chassis no (CHNR)参数。
2. **前置处理**：
   - 校验Chassis no是否为空
   - 如果为空，显示错误提示
3. **API调用**：
   - 呼出时点：画面加载时
   - 呼出方法：POST请求
   - 参数：画面のserie、画面のchno
   - 调用UD07VehicleSpecificationApi（Endpoint: `/api/v1/hdoc/vehiclespecification`）
4. **数据展示**：
   - 将UD07VehicleSpecificationApi返回的数据填充到画面项目中
5. **结果处理**：
   - **成功**：页面正常显示所有车辆规格信息
   - **失败**：显示错误提示信息

### 3.2 校验详细规格表

| No. | 检查时机 | 检查对象 | 检查条件 | 错误消息 | 动作 |
| :-: | :----------: | :---------------: | :------------------------------------: | :---------------------------------------------------------------------------: | :----------------------------------: |
| 1 | 页面加载 | Chassis no | Chassis no为空 | `Chassis no is required. Please return to the previous page.` | 显示错误提示 |
| 2 | API调用失败 | 任意API | 接口调用超时或失败 | `System error. Please contact administrator.` | 显示错误提示，提供重试按钮 |
| 3 | 网络异常 | 网络请求 | 网络连接失败 | `Network timeout. Please try again.` | 显示错误提示，提供重试按钮 |

## 4. 接口定义 (API Specification)

### 4.1 UD07VehicleSpecificationApi

- **功能**：获取车辆符号和描述信息（SYMBOL_STR、DESCRIPTION、Engine no）。
- **Method**: `POST`
- **Endpoint**: `/api/v1/hdoc/vehiclespecification`

#### Request Body

```json
{
  "serie": "string",
  "chno": "string"
}
```

#### Response Success (200 OK)

## 6. 实现注意事项 (Implementation Notes)

1. **状态管理**：
   - 使用 React State 管理 `vehicleSpecData`, `symbolData`, `errorMessage`, `isLoading`。
   - 所有数据显示为只读，不提供编辑功能。
2. **安全性**：
   - 页面访问必须验证用户登录状态。
   - 所有API请求必须通过 HTTPS 发送。
   - Chassis no参数必须进行有效性校验。
3. **UI 细节**：
   - SYMBOL_STR项目应绑定鼠标悬停事件，显示DESCRIPTION tooltip。
   - 标签式布局应保持良好的可读性，标签和值之间应有适当的间距。
   - Error message区域默认隐藏（内容为空时不占位）。
4. **性能优化**：
   - 两个API应并行调用，减少总加载时间。
   - 数据应缓存，避免重复API调用。
