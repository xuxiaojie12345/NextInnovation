## 1. 背景 (Background)

本模块提供Homologation Variables查询结果展示功能，以DataTable形式显示查询结果，支持选择记录、返回、打印和删除选中记录等操作。

- **目标**：清晰展示查询结果，支持记录选择和批量操作，显示查询结果数量，支持打印和导出。
- **安全性**：数据只读显示（除删除操作外），防止未授权删除，Created by user列支持跳转到EDB User View。
- **用户体验**：采用清晰的查询结果表格展示，支持记录选择和批量操作，显示查询结果数量。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

所有校验逻辑均在各操作按钮点击时同步或异步执行。

### 3.1 处理流程

#### 初期表示
1. **开始**：从Homologation Variables查询页面跳转过来。
2. **前置处理**：
   - 接收从HomologationVariables页面传递的查询条件
3. **API调用**：
   - 呼出时点：结果画面加载时
   - 呼出方法：POST请求
   - 参数：从HomologationVariables页面传递的查询条件
   - 调用 `UD09Search` 检索数据
4. **数据显示**：
   - 在DataTable中显示所有查询结果
   - 显示查询结果数量（Number of lines found: XXX）
5. **结果处理**：
   - **成功**：正常显示查询结果
   - **失败**：显示错误消息

#### Select按钮点击
1. **开始**：用户点击[Select]按钮。
2. **记录选择校验**：
   - 检查是否选择了记录
   - 若未选择，显示警告消息 `Please select a record first.`，**终止**流程
3. **画面迁移**：
   - 携带选中记录数据返回前页面（HomologationVariables）
4. **回显处理**：
   - 前页面自动显示所选记录的Product class、Number、Market、Variable、Value等各字段内容

#### Back按钮点击
1. **开始**：用户点击[Back]按钮。
2. **画面迁移**：
   - 返回前页面（HomologationVariables）
   - 携带查询条件
3. **回显处理**：
   - 前页面自动显示查询条件（Product class、Number、Market等）

#### Print按钮点击
1. **开始**：用户点击[Print]按钮。
2. **处理**：
   - 调用浏览器打印功能
   - 打印当前页面内容

#### Delete Selected按钮点击
1. **开始**：用户点击[Delete selected]按钮。
2. **记录选择校验**：
   - 检查是否选择了记录
   - 若未选择，显示警告消息 `Please select records to delete.`，**终止**流程
3. **API调用**：
   - 呼出时点：用户点击Delete selected按钮后
   - 呼出方法：POST请求
   - 调用 `UD09DeleteSelected` 删除选中的记录
4. **结果处理**：
   - **成功**：刷新列表，显示成功消息
   - **失败**：显示错误消息

#### Created by user链接点击
1. **开始**：用户点击Created by user列的链接。
2. **处理**：
   - 获取该记录的UPDATE_USER
   - 跳转到EDB User View页面
   - 传递userid作为参数

### 3.2 校验详细规格表

| :-: | :----------: | :---------------: | :------------------------------------: | :---------------------------------------------------------------------------: | :----------------------------------: |

## 4. 接口定义 (API Specification)

### 4.1 UD09Search

- **功能**：根据查询条件检索Homologation Variables记录列表。
- **所属 API**：UD09DeleteHdocuserdefinedrulesApi
- **Method**: `POST`
- **Endpoint**: `/api/v1/hdoc/ud09/search`

#### Request Body

```json
{
  "pc": "string",
  "num": "string",
  "market": "string",
  "variable": "string",
  "val": "string",
  "vs": "string",
  "vs2": "string",
  "comments": "string",
  "addDate": "string",
  "deleteDate": "string",
  "updateUser": "string",
  "updateDatetime": "string"
}
```

#### Response Success (200 OK)

```json
{
  "code": 200,
  "message": "查询成功",
  "data": {
    "ruleList": [
      {
        "pc": "string",
        "num": "string",
        "market": "string",
        "variable": "string",
        "val": "string",
        "vs": "string",
        "vs2": "string",
        "comments": "string",
        "addDate": "string",
        "deleteDate": "string",
        "updateUser": "string",
        "updateDatetime": "string"
      }
    ]
  }
}
```

### 4.2 UD09DeleteSelected

- **功能**：删除选中的Homologation Variables记录。
- **所属 API**：UD09DeleteHdocuserdefinedrulesApi
- **Method**: `POST`
- **Endpoint**: `/api/v1/hdoc/ud09/deleteSelected`

#### Request Body

```json
{
  "records": [
    {
      "pc": "string",
      "num": "string",
      "market": "string"
    }
  ]
}
```

#### Response Success (200 OK)

```json
{
  "code": 200,
  "message": "Records deleted successfully.",
  "data": null
}
```

## 6. 实现注意事项 (Implementation Notes)

1. **状态管理**：
   - 使用 React State 管理 `searchResults`, `selectedRecords`, `errorMessage`, `isLoading`。
   - 选中记录应支持多选。
2. **安全性**：
   - 删除操作必须进行权限验证。
   - API请求必须包含用户身份验证token。
   - 用户必须具有Rule Admin权限才能执行删除操作。
3. **UI 细节**：
   - DataTable应支持行选择（checkbox或radio）。
   - Created by user列应显示为可点击链接样式。
   - Count区域应醒目显示查询结果数量。
   - Delete selected按钮在未选择记录时应禁用。
4. **性能优化**：
   - 大量数据时应支持分页或虚拟滚动。
   - 删除操作后应局部刷新列表，避免重新加载全部数据。
