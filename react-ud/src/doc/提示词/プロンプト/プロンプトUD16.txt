2. 背景 (Background)

核心功能和目标：
本模块提供AD Change管理功能，用户可以对Serie-Chnr进行添加、删除和校验操作。支持在HDOC_ADCA_CHANGE表中管理AD/CA变更记录，包括Serie-Chnr和Desc字段。

面向的用户群体：
- 系统工程人员
- 需要管理AD/CA变更的用户

用户体验方面的考虑：
- 清晰的Serie-Chnr输入
- 直观的CRUD操作按钮
- 明确的存在性校验提示

安全性或特殊要求：
- Serie-Chnr存在性校验
- 防止SQL注入

4. 功能描述 (Functional Description)

4.1 添加Serie-Chnr
功能说明： 输入Serie-Chnr和Desc，点击ADD按钮添加记录

操作步骤：
1. 用户输入Serie-Chnr（最多15字符）
2. 输入Desc（最多4000字符）
3. 点击ADD按钮
4. 调用UD16InsertHdocAdcaChange方法
5. 前端校验：检查Serie-Chnr是否存在于HDOC_ADCA_CHANGE表中
6. 如果已存在，显示警告消息"AFTER DEF CHANGE IS NOT ACTIVATED"
7. 如果不存在，插入记录到HDOC_ADCA_CHANGE表
8. 显示成功或失败消息

4.2 删除Serie-Chnr
功能说明： 输入Serie-Chnr，点击DELETE按钮删除记录

操作步骤：
1. 用户输入Serie-Chnr
2. 点击DELETE按钮
3. 调用UD16UpdateHdocAdcaChange方法（标记删除或实际删除）
4. 从HDOC_ADCA_CHANGE表删除或更新记录
5. 显示成功或失败消息

4.3 校验Serie-Chnr
功能说明： 输入Serie-Chnr，点击CHECK按钮进行校验

操作步骤：
1. 用户输入Serie-Chnr
2. 点击CHECK按钮
3. 调用UD16SelectHdocAdcaChange方法
4. 检查Serie-Chnr是否存在于HDOC_ADCA_CHANGE表中
5. 如果存在且未激活，显示警告消息"AFTER DEF CHANGE IS NOT ACTIVATED"
6. 如果不存在，显示提示信息
7. 如果存在且已激活，显示成功消息

5. 业务逻辑与校验规则 (Business Logic & Checks)

5.1 处理流程

开始：用户执行操作（添加/删除/校验）

前置处理：
- 获取Serie-Chnr和Desc输入值
- 去除首尾空格

添加操作：
- 调用UD16SelectHdocAdcaChange检查Serie-Chnr是否存在
- 如果已存在：显示警告消息"AFTER DEF CHANGE IS NOT ACTIVATED"
- 如果不存在：调用UD16InsertHdocAdcaChange插入记录
- 设置REGISTER_DATETIME等字段
- 显示成功消息

删除操作：
- 调用UD16UpdateHdocAdcaChange删除或更新记录
- 显示成功消息

校验操作：
- 调用UD16SelectHdocAdcaChange查询记录
- 如果记录不存在：显示提示信息
- 如果记录存在但未激活：显示警告消息"AFTER DEF CHANGE IS NOT ACTIVATED"
- 如果记录存在且已激活：显示成功消息

结果处理：
- 成功：显示成功消息
- 失败：显示错误消息

6. 接口定义 (API Specification)

功能： 查询HDOC_ADCA_CHANGE记录数量

Method： POST

Endpoint： `/api/v1/hdoc/adca/select`

Request Body：
```json
{
  "serie": "string",
  "chnr": "string"
}
```
