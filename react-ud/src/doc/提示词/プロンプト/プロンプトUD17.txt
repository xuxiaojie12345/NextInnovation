2. 背景 (Background)

核心功能和目标：
本模块提供HDoc用户权限管理功能，管理员可以输入UserID，从Saviynt系统获取用户信息，并设置该用户的各种权限角色，
包括Standard User、Rule Admin、Template Admin、Document Auth Admin、User Admin、Adaptation user、
Manage Variable List、Market Super User等。支持更新和删除用户权限。

面向的用户群体：
- User Admin权限用户
- 系统管理员
- 需要管理用户权限的管理员

用户体验方面的考虑：
- 清晰的UserID输入和用户信息显示
- 直观的权限角色复选框
- Market下拉列表联动显示
- 明确的更新和删除操作反馈

安全性或特殊要求：
- 用户ID存在性校验
- 权限变更审计日志
- 防止未授权权限修改

4. 功能描述 (Functional Description)

4.1 页面初期化
功能说明： 页面加载时初始化各控件状态

操作步骤：
1. 页面加载时，获取Market列表（调用UD19SelectMarketMaster）
2. UserID输入框清空
3. User标签清空
4. 所有权限复选框设为未选中状态
5. Standard User和Adaptation user对应的Market下拉列表默认显示'-EU'
6. 其余Market下拉列表设为空

4.2 点击User Info按钮
功能说明： 输入UserID，点击User Info按钮获取用户信息和权限

操作步骤：
1. 用户输入UserID（必填，最多10字符）
2. 点击User Info按钮
3. 调用UD17Userinfo方法
   检索结果为0件时：显示错误消息 `We didn't recognize the userid you entered. Please try again.`
                   终止流程
4. 从Saviynt系统获取User名
5. 从HDOC_FUNCTION_AUTH表获取该用户的权限
6. 自动勾选该用户已有的权限复选框
7. 显示对应的Market选择

4.3 点击Update Role按钮
功能说明： 修改权限后，点击Update Role按钮更新用户权限

操作步骤：
1. 用户修改权限复选框的选中状态
2. 选择对应的Market
3. 点击Update Role按钮
4. 调用UD17Userinfo方法
   检索结果为0件时：显示错误消息 `We didn't recognize the userid you entered. Please try again.`
                   终止流程
5. 调用UD17UpdateRole方法, 更新HDOC_FUNCTION_AUTH和MARKET_MASTER表中的权限记录
8. 显示成功或失败消息

4.4 点击Delete Role按钮
功能说明： 点击Delete Role按钮删除该用户的所有权限

操作步骤：
1. 用户点击Delete Role按钮
2. 调用UD17DeleteRole方法
3. 调用UD17Userinfo方法
   检索结果为0件时：显示错误消息 `We didn't recognize the userid you entered. Please try again.`
                   终止流程
4. 如果存在，从HDOC_FUNCTION_AUTH和MARKET_MASTER表删除该用户的所有权限记录
5. 显示成功或失败消息
6. 清空所有权限复选框

5. 业务逻辑与校验规则 (Business Logic & Checks)

5.1 处理流程

开始： 用户执行操作（获取信息/更新/删除）

前置处理： 
- 获取UserID输入值
- 去除首尾空格

User Info操作：
- 调用UD17Userinfo方法
- 从Saviynt系统获取User名
- 从HDOC_FUNCTION_AUTH和MARKET_MASTER表查询该用户的权限
- 如果用户ID不存在，显示错误消息"We didn't recognize the userid you entered. Please try again."
- 如果用户ID存在，自动勾选已有权限，显示Market选择

Update Role操作：
- 获取所有权限复选框的状态
- 获取所有Market选择的值
- 调用UD17UpdateRole方法
- 调用UD17Userinfo方法
   检索结果为0件时：显示错误消息 `We didn't recognize the userid you entered. Please try again.`
                   终止流程
- 更新HDOC_FUNCTION_AUTH和MARKET_MASTER表
- 显示成功消息

Delete Role操作：
- 调用UD17DeleteRole方法
- 从HDOC_FUNCTION_AUTH和MARKET_MASTER表删除该用户的所有权限记录
- 清空所有权限复选框
- 显示成功消息

结果处理：
- 成功：显示成功消息
- 失败：显示错误消息

 UD17HDocUserAdministrationApi

### 4.1 UD17Userinfo

- **功能**：查询用户权限信息（支持多条数据）。
- **Method**: `POST`
- **Endpoint**: `/api/v1/hdoc/user/info`

#### Request Body

```json
{
  "userid": "string"
}
```

#### Response Success (200 OK)

```json
{
  "code": 200,
  "message": "查询成功",
  "data": {
    "userId": "xxx",
    "username": "xxx",
    "authList": [
      {
        "function": "功能权限1",
        "market": "市场权限1"
      },
      {
        "function": "功能权限2",
        "market": "市场权限2"
      },
      {
        "function": "功能权限3",
        "market": "市场权限3"
      }
    ]
  }
}
```

#### Response Error (404 Not Found)

```json
{
  "code": 404,
  "message": "We didn't recognize the userid you entered. Please try again.",
  "data": null
}
```

#### Response Error (500 Internal Server Error)

```json
{
  "code": 500,
  "message": "System error. Please contact administrator.",
  "data": null
}
```
