2. 背景 (Background)

核心功能和目标：
本模块提供修改保存确认功能，显示已保存的修改内容，包括Chassis信息、Doctype、Version以及修改的Variable和NewVal列表。
用户确认后点击Close按钮关闭页面。

面向的用户群体：
- 系统工程人员
- 需要确认Homologation文档修改内容的用户

用户体验方面的考虑：
- 清晰展示已保存的修改内容
- 明确的版本状态提示
- 简洁的关闭操作

安全性或特殊要求：
- 数据只读显示
- 防止未授权访问

4. 功能描述 (Functional Description)

4.1 页面初始化
功能说明： 页面加载时显示已保存的修改内容

操作步骤：
1. 从前页面接收SERIE和CHNO参数
2. 解析Chassis serie（'-'前的内容）和Chassis number（'-'后的内容）
3. 调用UD06SelectHdocAdcaModification获取修改内容

4.2 关闭页面
功能说明： 点击Close按钮关闭当前页面

操作步骤：
1. 用户点击Close按钮

5. 业务逻辑与校验规则 (Business Logic & Checks)

5.1 处理流程

开始： 从前页面接收SERIE和CHNO参数

前置处理： 
- 解析Chassis serie和Chassis number
- 调用UD06SelectHdocAdcaModification

数据获取：
- 从HDOC_ADCA_MODIFICATION表获取DOCTYPE、VERS、VARIABLE、NEWVAL
- 根据SERIE和CHNO查询

结果显示：

6. 接口定义 (API Specification)

### 6.1 UD06SelectHdocAdcaModification

- **功能**：查询HDOC_ADCA_MODIFICATION表中的修改记录。
- **所属 API**：UD06SaveModificationsApi
- **Method**: `POST`
- **Endpoint**: `/api/v1/hdoc/adcamodification`

#### Request Body

```json
{
  "serie": "string",
  "chno": "string"
}
```

#### Response Success (200 OK)

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "doctype": "string",
    "version": "string",
    "modifications": [
      {
        "variable": "string",
        "newVal": "string"
      }
    ],
    "hasUnreleasedVersion": boolean
  }
}
```

#### Response Error (500 Internal Server Error)

```json
{
  "code": 500,
  "message": "Failed to query record.",
  "data": null
}
```
