2. 背景 (Background)

核心功能和目标：
本模块提供Existing HDoc Variables查询结果展示功能，
以DataTable形式显示HDOC_VARIABLES表的查询结果，
支持选择记录、返回、打印、Excel导出和Down操作（跳转到Homologation Variables页面并过滤Variant）。

面向的用户群体：
- 系统管理员
- Manage Variable List权限用户
- 需要查看和管理Homologation变量定义的用户

用户体验方面的考虑：
- 清晰的查询结果表格展示
- 支持记录选择和操作
- 显示查询结果数量
- 支持打印和Excel导出
- Down操作可快速定位到相关Variant

安全性或特殊要求：
- 数据只读显示（除删除操作外）
- Created by user列支持跳转到EDB User View
- Down操作需要选择记录

5. 业务逻辑与校验规则 (Business Logic & Checks)

5.1 处理流程

初期表示：
- 前画面（ExistingHdocVariables）携带检索条件跳转过来
- 前端获取前画面传递的检索条件（Variable, Type, Description, Created by user, Date）
- 调用 UD11Search 执行查询
- 成功：在DataTable中显示查询结果，显示结果数量（Number of lines found: XXX）
- 失败：显示错误消息

Select操作：
- 检查是否选择了记录
- 如果没有选择显示错误信息”No key defined for table.“ 终止流程
- 如果已选择，携带选中记录数据返回前页面，自动显示所选记录的内容

Back操作：
- 携带查询条件返回前页面，之前的查询条件在前画面正常显示

Print操作：
- 调用浏览器打印功能
- 打印当前页面内容

Down操作：
- 暂定不实装具体功能

Excel导出：
- 触发浏览器下载， 导出对应的csv文件 (ExistingHDocVariablesResultList_yyyymmdd.csv)
- 显示消息"CSV文件导出成功"。

Created by user链接点击：
- 获取该记录的REGISTER_USER
- 跳转到EDB User View页面
- 传递userid作为参数

结果处理：
- 成功：执行相应操作
- 失败：显示错误消息

6. 接口定义 (API Specification)

### 6.1 UD11Search

- **功能**：查询HDOC_VARIABLES。
- **所属 API**：UD11HdocvariablesApi
- **Method**: `POST`
- **Endpoint**: `/api/v1/hdoc/variables/search`

#### Request Body

```json
{
   "variable": "string",
   "type": "string",
   "descr": "string",
   "registerUser": "string",
   "registerDatetime": "string"
}
```

#### Response Success (200 OK)

```json
{
   "code": 200,
   "message": "查询成功",
   "data": {
      "list": [
               {
                  "variable": "xxx",
                  "type": "xxx",
                  "description": "xxx",
                  "registerUser": "xxx",
                  "registerDatetime": "xxx"
               }
            ]
          }
}
```

#### Response Error (400 Bad Request)

```json
{
  "code": 400,
  "message": "No data found",
  "data": null
}
```
