2. 背景 (Background)

核心功能和目标：
本模块提供HDoc Template的上传和删除功能。用户可以上传Template文件到指定Market文件夹，也可以从指定Market文件夹删除Template文件。同时提供链接跳转到HDoc Template Check页面进行模板校验。

面向的用户群体：
- Template Admin权限用户
- 需要管理Homologation文档模板的用户

用户体验方面的考虑：
- 直观的文件上传界面
- 清晰的Market和Template选择
- 明确的操作反馈消息
- 提供模板校验链接

安全性或特殊要求：
- 文件上传大小限制
- 文件格式校验（rtf文件）
- 防止路径遍历攻击
- 删除操作二次确认

 4. 功能描述 (Functional Description)

 4.1 页面初期化
功能说明： 页面加载时初始化Market下拉列表

操作步骤：
1. 页面加载时，调用UD12SelectMarket方法获取Market列表
2. Upload区域的Market下拉列表加载所有Market选项
3. Delete区域的Market下拉列表加载所有Market选项
4. Delete区域的Templates下拉列表动态加载Market文件夹中的文件名。

 4.2 上传Template文件
功能说明： 指定Template文件，点击Upload按钮上传到指定文件夹

操作步骤：
1. 用户点击Template File选择文件
2. 选择Market下拉列表
3. 点击Upload file按钮
4. 前端校验：检查是否选择了文件和Market文件夹
5. 如果未选择文件，显示错误消息"NO FILE UPLOADED"
   如果未选择Market文件夹，显示错误消息"NO Market UPLOADED"
6. 如果选择了文件和 Market文件夹，调用 UD12UploadFlie 将文件上传到指定Market文件夹
7. 显示成功消息"TEMPLATE XXX WAS SUCESSFULLY UPLOADED TO MARKET JPN"

 4.3 删除Template文件
功能说明： 选择Market和Template，点击Delete按钮从指定文件夹删除

操作步骤：
1. 用户选择Market下拉列表
2. 系统自动加载该Market下的Templates列表
3. 用户选择要删除的Template
4. 点击Delete按钮
5. 如果未选择文件，显示错误消息"NO FILE UPLOADED"
   如果未选择Market文件夹，显示错误消息"NO Market UPLOADED"
6. 显示确认对话框"Do you really want to delete template?"
7. 用户确认后，调用 UD12DeleteFlie 从指定文件夹删除Template文件
8. 显示成功消息"TEMPLATE XXX WAS SUCESSFULLY DELETE FROM MARKET JPN"

 4.4 跳转到HDoc Template Check
功能说明： 点击链接跳转到HDoc Template Check页面

操作步骤：
1. 用户点击链接 'Check Template (Only for rtf files)'
2. 跳转到「HDoc Template Check」页面

 6. 接口定义 (API Specification)

 UD12UploadDeletetemplatApi

 1. UD12SelectMarket

功能： 获取Market列表（初期化时加载）
Method： POST
Endpoint： `/api/v1/hdoc/template/selectMarket`

Request：
```json
{}
```

Response Success (200)：
```json
{
  "code": 200,
  "message": "查询成功",
  "data": {
    "marketList": ["MARKET001", "MARKET002"]
  }
}
```

Response Error (500)：
```json
{
  "code": 500,
  "message": "System error. Please contact administrator.",
  "data": null
}
```

 2. UD12UploadFlie

功能： 上传Template文件
Method： POST
Endpoint： `/api/v1/hdoc/template/upload`

Request： Multipart Form Data
```
file: [binary]
market: "string"
```

Response Success (200)：
```json
{
  "code": 200,
  "message": "TEMPLATE XXX WAS SUCESSFULLY UPLOADED TO MARKET JPN",
  "data": null
}
```

Response Error (400)：
```json
{
  "code": 400,
  "message": "NO FILE UPLOADED",
  "data": null
}
```

 3. UD12DeleteFlie

功能： 删除Template文件
Method： POST
Endpoint： `/api/v1/hdoc/template/delete`

Request：
```json
{
  "market": "string",
  "template": "string"
}
```

Response Success (200)：
```json
{
  "code": 200,
  "message": "TEMPLATE XXX WAS SUCESSFULLY DELETE FROM MARKET JPN",
  "data": null
}
```

 7. 异常处理 (Exception Handling)

 异常场景 | 处理方式 | Message显示内容 
---------|---------|----------------
 未选择文件就点击Upload | 前端校验拦截 | NO FILE UPLOADED 
 文件上传失败 | API返回错误 | File upload failed. Please try again. 
 删除确认取消 | 用户取消操作 | 不执行删除 
 文件删除失败 | API返回错误 | File deletion failed. Please try again. 
 API调用失败 | 捕获异常，返回500错误 | System error. Please contact administrator.
