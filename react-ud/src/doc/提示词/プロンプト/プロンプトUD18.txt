 2. 背景 (Background)

 核心功能和目标：
本模块提供HDoc用户文档权限管理功能，管理员可以输入UserID，从Saviynt系统获取用户信息，并设置该用户对各个文档的访问权限。支持查询、更新用户的文档权限。

 面向的用户群体：
- User Admin权限用户
- 系统管理员
- 需要管理用户文档权限的管理员

 用户体验方面的考虑：
- 清晰的UserID输入和用户信息显示
- 直观的文档权限选择
- 明确的存在性校验提示
- 自动选择用户已有权限

 安全性或特殊要求：
- 用户ID存在性校验
- 文档权限变更审计日志
- 防止未授权权限修改

 4. 功能描述 (Functional Description)

 4.1 页面初始化
功能说明： 页面加载时获取文档列表

操作步骤：
1. 页面加载时，调用UD20SelectHdocDocumentList方法, 从HDOC_DOCUMENT_LIST表获取所有可用文档列表
2. 显示Document下拉列表

 4.2 获取用户信息
**功能说明：** 输入UserID，点击User Info按钮获取用户信息和文档权限

操作步骤：
1. 用户输入UserID（必填，最多10字符，半角英数字）
2. 点击User Info按钮
3. 前端校验：检查UserID是否存在于HDOC_FUNCTION_AUTH表中
4. 如果不存在，显示错误消息"We didn't recognize the userid you entered. Please try again."
5. 如果存在，调用AuthenticationApi获取User名
6. 调用UD18SelectHdocUserDoc方法从HDOC_USER_DOC表获取该用户的文档权限
7. 自动勾选该用户已有的文档权限
8. 显示用户信息和已有权限

 4.3 更新用户文档权限
**功能说明：** 修改文档权限后，点击Update按钮更新用户文档权限

操作步骤：
1. 用户修改文档权限的选择状态
2. 点击Update按钮
3. 前端校验：检查UserID是否存在于HDOC_FUNCTION_AUTH表中
4. 如果不存在，显示错误消息"We didn't recognize the userid you entered. Please try again."
5. 如果存在，调用UD18DeleteHdocUserDoc删除该用户的所有文档权限
6. 调用UD18CreateHdocUserDoc插入新的文档权限记录
7. 显示成功或失败消息

 5. 业务逻辑与校验规则 (Business Logic & Checks)

 5.1 处理流程

开始： 用户执行操作（获取信息/更新）

前置处理： 
- 获取UserID输入值
- 去除首尾空格
- 校验UserID格式（半角英数字，最多10字符）

页面初始化：
- 调用UD20SelectHdocDocumentList获取文档列表
- 从HDOC_DOCUMENT_LIST表获取所有DESCRIPTION
- 显示Document选择控件

User Info操作：
- 调用UD18SelectHdocFunctionAuth检查UserID是否存在于HDOC_FUNCTION_AUTH表中
- 如果不存在：显示错误消息"We didn't recognize the userid you entered. Please try again."
- 如果存在：
  - 调用AuthenticationApi 获取User名
  - 调用UD18SelectHdocUserDoc从HDOC_USER_DOC表获取该用户的文档权限
  - 自动勾选已有权限

Update操作：
- 获取所有文档权限的选择状态
- 调用UD18SelectHdocFunctionAuth检查UserID是否存在于HDOC_FUNCTION_AUTH表中
- 如果不存在：显示错误消息"We didn't recognize the userid you entered. Please try again."
- 如果存在：
  - 调用UD18DeleteHdocUserDoc删除该用户的所有文档权限
  - 调用UD18CreateHdocUserDoc插入新的文档权限记录
  - 显示成功消息

结果处理：
- 成功：显示成功消息
- 失败：显示错误消息

 5.2 校验详细规格表

No. | 检查时机 | 检查对象 | 检查条件 | 错误消息 | 动作

Method：POST

Endpoint：/api/auth/login

Request：

  "userid": "string",
  "password": "string"
}

Response Success (200)：

  "code": 200,
  "message": "登录成功",

}
