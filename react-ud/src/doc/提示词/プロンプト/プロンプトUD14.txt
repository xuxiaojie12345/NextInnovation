 2. 背景 (Background)

 核心功能和目标：
本模块提供可用Template列表展示功能，用户可以选择Market，显示该Market文件夹中存储的所有Template文件信息，包括文件名、是否被使用、最后修改时间、文件大小等。支持点击文件名下载对应的Template文件。

 面向的用户群体：
- Template Admin权限用户
- 需要查看和下载Homologation文档模板的用户

 用户体验方面的考虑：
- 清晰的Market选择
- 完整的文件信息展示
- 直观的文件下载操作
- 显示文件使用情况（Used列）

 安全性或特殊要求：
- 文件下载权限控制
- 防止路径遍历攻击

 4. 功能描述 (Functional Description)

 4.1 页面初始化
功能说明： 页面加载时显示存储的文件列表

操作步骤：
1. 页面加载时，调用API获取所有Market列表
2. 默认不选择Market或选择第一个Market
3. 如果选择了Market，显示该Market文件夹中的所有Template文件
4. 在DataTable中显示Filename、Used、Last Mod、Size等信息

 4.2 选择Market
功能说明： 选择Market，显示该Market文件夹中的文件

操作步骤：
1. 用户在SelectMartet下拉列表中选择Market
2. 系统自动调用API获取该Market文件夹中的文件列表
3. 刷新DataTable，显示选中Market的Template文件

 4.3 下载Template文件
功能说明： 点击文件名的链接下载该文件

操作步骤：
1. 用户点击DataTable中的文件名链接
2. 系统根据文件名和Market定位文件
3. 浏览器启动文件下载

 5. 业务逻辑与校验规则 (Business Logic & Checks)

 5.1 处理流程

开始： 页面加载或用户选择Market

页面初始化：
- 调用UD14SelectMarketmaster获取Market列表
- 显示所有Market供用户选择

选择Market：
- 用户选择Market
- 调用API获取该Market文件夹中的文件列表
- 对于每个文件，检查是否在HDOC_USER_DEFINED_RULES中注册
- 如果已注册，Used列显示对应的VARIABLE
- 从文件系统获取文件的Last Mod和Size
- 在DataTable中显示所有信息

下载文件：
- 用户点击文件名链接
- 系统根据Market和Filename定位文件
- 读取文件内容
- 触发浏览器下载

结果处理：
- 成功：显示文件列表或下载文件
- 失败：显示错误消息

 6. 接口定义 (API Specification)

 UD14SearchresultistApi

 1. UD14SelectMarketmaster

功能： 获取Market列表

Method： POST

Endpoint： `/api/v1/hdoc/ud14/selectMarketmaster`

Response Success (200)：
```json
{
   "code": 200,
   "message": "查询成功",
   "data": {
      "marketList": ["xxx", "xxx"]
   }
}
```

 2. UD14SelectHdocuserdefinedrules

功能： 获取Template文件列表及使用信息

Method： POST

Endpoint： `/api/v1/hdoc/ud14/selectHdocUserDefinedRules`

Request Body：
```json
{
  "market": "string"
}
```

Response Success (200)：
```json
{
    "code": 200,
    "message": "查询成功",
    "data": {
      "variableList": ["xxx", "xxx"]
    }
}
```

 3. UD14downfile

功能： 下载Template文件

Method： GET

Endpoint： `/api/v1/hdoc/template/download`

Request：
```json
{
  "market": "string",
  "filename": "string"
}
```

Response： 文件流
