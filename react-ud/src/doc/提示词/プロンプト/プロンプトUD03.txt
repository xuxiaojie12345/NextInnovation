2. 背景 (Background)

核心功能和目标:
本模块提供车辆认证文档生成功能。
用户通过输入底盘系列号(Chassis series)、底盘编号(Chassis no)和选择文档类型(Document type),系统验证车辆信息后跳转到文档生成页面。

面向的用户群体:
- 车辆认证工程师
- 文档管理人员
- 质量管理部门人员

用户体验方面的考虑:
- 简洁直观的表单输入
- 实时校验和错误提示
- 默认显示上次输入的条件
- 提供帮助文档链接

安全性或特殊要求:
- 需要用户登录认证
- 输入参数需要进行格式校验
- 防止SQL注入攻击

4. 功能描述 (Functional Description)

4.1 页面初始化
功能说明：页面加载时初始化表单数据

操作步骤：
1. 页面加载时,调用API获取文档类型列表
2. 将文档类型列表填充到下拉框中
3. 如果存在上次输入的条件,自动填充到对应字段
4. 如果API调用失败,显示错误消息

4.2 提交表单
功能说明：用户输入完成后点击Submit按钮提交表单

操作步骤：
1. 用户输入Chassis series(必填,最多5个半角英文字母)
2. 用户输入Chassis no(必填,最多10个半角数字)
3. 用户从下拉列表选择Document type(必填)
4. 用户点击Submit按钮
5. 系统进行前端校验
6. 校验通过后,调用API验证车辆是否存在
7. 车辆存在:跳转到Generate Document页面,传递SERIE、CHNR、DOCTYPE参数
8. 车辆不存在:显示错误消息"Chassis no is not exists"

4.3 重置表单
功能说明：清空所有输入字段,恢复初始状态

操作步骤：
1. 用户点击Reset按钮
2. 清空Chassis series输入框
3. 清空Chassis no输入框
4. 重置Document type下拉框为空
5. 清除错误消息

4.4 查看帮助
功能说明：打开帮助文档页面

操作步骤：
1. 用户点击Help按钮
2. 跳转到HDoc Help页面


5. 业务逻辑与校验规则 (Business Logic & Checks)

5.1 处理流程

开始：用户点击Submit按钮

前置处理：
- 获取表单输入值
- 去除首尾空格

前端校验 (Frontend Check)：
- 若Chassis series为空：
  - 设置Message = "Chassis series is required."
  - 终止流程
- 若Chassis series长度超过5或包含非英文字母：
  - 设置Message = "Chassis series must be 5 alphabetic characters."
  - 终止流程
- 若Chassis no为空：
  - 设置Message = "Chassis no is required."
  - 终止流程
- 若Chassis no长度超过10或包含非数字：
  - 设置Message = "Chassis no must be up to 10 digits."
  - 终止流程
- 若Document type未选择：
  - 设置Message = "Document type is required."
  - 终止流程

API调用 (Backend Check)：
1. 调用UD03SelectHdocdocumentlistApi获取文档类型列表
2. 调用GenerateDocumentApi API验证车辆是否存在
   -  `{ serie, chnr, doctype }`

结果处理：
- 成功(车辆存在)：跳转到Generate Document页面,传递参数{ SERIE, CHNR, DOCTYPE }
- 失败(车辆不存在)：Message = "Chassis no is not exists"
- 系统异常：Message = "System error. Please contact administrator."

6. 接口定义 (API Specification)

API 1: UD03SelectHdocdocumentlistApi

功能：从HDOC_DOCUMENT_LIST表获取所有可用的文档类型列表

Method：GET

Endpoint：/api/v1/hdoc/document-types

Request：
{
  // 无需请求参数
}

Response Success (200)：
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "doctype": "VIN_PLATE",
      "description": "VIN Plate Document"
    },
    {
      "doctype": "COC",
      "description": "Certificate of Conformity"
    }
  ]
}

Response Error (500)：
{
  "code": 500,
  "message": "System error. Please contact administrator.",
  "data": null
}

SQL查询：
SELECT DOCTYPE, DESCRIPTION 
FROM HDOC_DOCUMENT_LIST 
ORDER BY DOCTYPE;

---

API 2: GenerateDocumentApi

功能：验证底盘信息是否存在，返回文档生成所需数据。

Method：POST

Endpoint：/api/v1/hdoc/generatedocument

Request：
{
  "serie": "ABCDE",
  "chnr": "1234567890",
  "doctype": "VIN_PLATE"
}

Response Success (200)：
{
  "code": 200,
  "message": "success",
  "data": {
    "ordernumber": "19146492",
    "buildWeek": "2020186",
    "specWeek": "202018",
    "market": "AUS",
    "sNoteNo": "SN12345",
    "loadIndex": "152",
    "modifyDocLink": false,
    "replacingParameters": { "variable": "VPGVW 2" }
  }
}

Response Error (500)：
{
  "code": 500,
  "message": "System error. Please contact administrator.",
  "data": null
}

SQL查询：
SELECT DOCTYPE, DESCRIPTION 
FROM HDOC_DOCUMENT_LIST 
ORDER BY DOCTYPE;
