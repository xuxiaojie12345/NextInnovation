2. 背景 (Background)

核心功能和目标:
本模块提供Homologation Document生成功能，
显示车辆相关信息、S-Note信息、轮胎信息等，并提供文档下载和修改功能。
用户可以从前页面传入Chassis信息，查看生成的文档状态和相关信息。

面向的用户群体:
- 系统工程人员
- 文档管理人员
- 需要生成和查看Homologation文档的用户

用户体验方面的考虑:
- 清晰展示车辆关键信息
- 直观的文档下载链接
- 明确的错误提示信息
- S-Note信息的醒目提示

安全性或特殊要求:
- 数据只读显示
- 防止未授权访问
- 文件下载权限控制

4. 功能描述 (Functional Description)

4.1 页面初始化
功能说明：页面加载时显示车辆和文档信息

操作步骤：
1. 从前页面接收Chassis series和Chassis no参数
2. 调用UD04SelectGeneratedocumentApi获取相关数据
3. 显示Ordernumber、Build week、Spec week等信息
4. 如果有S-Note信息，显示警告消息
5. 如果AD-Change激活，显示Modify Doc Link

4.2 文档下载
功能说明：点击Generated document链接下载VIN Plate文件

操作步骤：
  Generated document下载链接 正常显示 但是 不实装下载功能

4.3 跳转到Modify Document
功能说明：点击Modify链接（After def change detected. Document need to be modified.） 跳转到文档修改页面

操作步骤：
1. 用户点击'Modify Doc Link'
2. 跳转到「Modify Document」页面
3. 传递Chassis信息作为参数

4.4 查看Chassis详细信息
功能说明：点击Chassis no查看详细信息

操作步骤：
1. 用户点击'Chassis no'
2. 跳转到Vehicle Specification页面


5. 业务逻辑与校验规则 (Business Logic & Checks)

5.1 处理流程

开始：从前页面接收Chassis series和Chassis no参数

前置处理：
- 验证参数有效性
- 调用UD04SelectGeneratedocumentApi

数据获取：
- 从HDOC_REC_DATA_OM表获取Ordernumber、Build week、Spec week、CUSTOMER_ADAP
- 从HDOC_REC_DATA_VDA_GENERAL表获取COUNTRY_OF_OPERATION
- 从HDOC_REC_DATA_KOLA_TIRE_MASTER表获取LOAD_INDEX
- 从HDOC_ADCA_CHANGE表获取ACT状态
- 从HDOC_ADCA_MODIFICATION表获取VARIABLE和NEWVAL

结果显示：
- 设置Master Market为固定值'-EU'
- 设置HDoc version为固定值'4.2.1'
- 如果有S-Note信息，显示S-Note Message
- 如果AD-Change激活，显示Modify Doc Link
- 显示Generated document下载链接

结果处理：
- 成功：显示所有信息
- 失败：在Error message area显示错误消息

5.2 校验详细规格表

No. | 检查时机 | 检查对象 | 检查条件 | 错误消息 | 动作
---|---|---|---|---|---
1 | 页面加载 | Chassis参数 | Chassis series或Chassis no为空 | Invalid chassis information. | 显示错误消息
2 | API调用 | 数据查询 | 车辆信息不存在 | Vehicle data not found. | 显示错误消息
3 | 文件下载 | 文件存在性 | VIN Plate文件不存在 | Generated document not available. | 显示错误消息


6. 接口定义 (API Specification)

UD04SelectGeneratedocumentApi

功能：获取Generate Document页面所需的所有数据

Method：POST

Endpoint：/api/v1/hdoc/generatedocument

Request：
{
  "serie": "string",
  "chnr": "string"
}

Response Success (200)：
{
  "code": 200,
  "message": "success",
  "data": {
    "ordernumber": "string",
    "buildWeek": "string",
    "specWeek": "string",
    "market": "string",
    "sNoteNo": "string",
    "loadIndex": "string",
    "modifyDocLink": boolean,
    "replacingParameters": 
      {
        "variable": "string"
      }
  }
}

Response Error (404)：
{
  "code": 404,
  "message": "Vehicle data not found.",
  "data": null
}


7. 异常处理 (Exception Handling)

异常场景 | 处理方式 | Message显示内容
---|---|---
Chassis参数无效 | 前端校验拦截 | Invalid chassis information.
车辆信息不存在 | API返回404错误 | Vehicle data not found.
VIN Plate文件不存在 | 前端检查文件URL | Generated document not available.
API调用失败 | 捕获异常，返回500错误 | System error. Please contact administrator.
网络超时 | 捕获超时异常 | Network timeout. Please try again.
