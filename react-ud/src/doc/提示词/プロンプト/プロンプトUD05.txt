 2. 背景 (Background)

核心功能和目标：
本模块提供Homologation Document修改功能，用户可以查看Template中的Variable列表，修改对应的值，并保存修改内容。
支持从HDOC_ADCA_MODIFICATION 和 HDOC_REC_DATA_KOLA_VARIANT表获取当前值。

面向的用户群体：
- 系统工程人员
- 文档管理人员
- 需要修改Homologation文档参数的用户

用户体验方面的考虑：
- 清晰的Variable列表展示
- 直观的当前值和修改值对比
- 明确的保存操作反馈
- Template文件下载功能

安全性或特殊要求：
- 输入数据校验
- 防止SQL注入
- 修改记录追踪

4. 功能描述 (Functional Description)

4.1 页面初始化
功能说明： 页面加载时显示可修改的Variable列表

操作步骤：
1. 从前页面接收Chassis no和Market参数
2. 调用UD05ModifyDocumentApi的 UD05SelectVariableModification 获取Variable列表
3. 显示Variable、Description、Current value
4. Modified value初始为空或已有修改值

4.2 修改Variable值
功能说明： 用户在Modified value列输入修改后的值

操作步骤：
1. 用户在Modified value输入框中输入新值
2. 前端进行基本校验（长度不超过500）
3. 可以修改多个Variable的值

4.3 保存修改
功能说明： 点击Save按钮保存所有修改

操作步骤：
1. 用户点击Save按钮
2. 前端校验：检查是否有任何项目被输入
3. 如果没有输入，显示错误消息"NO UNRELEASED VERSION EXISTS!"
4. 如果有输入，调用UD05ModifyDocumentApi的 UD05UpdateHdocAdcaModification保存
5. 跳转到「Save Modifications」页面，显示修改内容

4.4 Template文件下载
功能说明： 点击Template文件链接下载文件

操作步骤：
1. 只显示不实装具体功能

4.5 查看Chassis详细信息
功能说明： 点击Chassis no查看详细信息

操作步骤：
1. 用户点击'Chassis no'链接
2. 显示该Chassis的详细信息

5. 业务逻辑与校验规则 (Business Logic & Checks)

5.1 处理流程

开始： 从前页面接收Chassis no和Market参数

前置处理：
- 验证参数有效性
- 调用UD05ModifyDocumentApi 的 UD05SelectVariableModification获取Variable列表

数据显示：
- 遍历Variable列表
- 对于每个Variable，从HDOC_ADCA_MODIFICATION获取NEWVAL（如果存在）
- 如果不存在，从HDOC_REC_DATA_KOLA_VARIANT获取SYMBOL作为Current value
- Modified value初始为空或已有修改值

用户修改：
- 用户在Modified value列输入新值
- 前端实时校验输入长度（最大500字符）

保存操作：
- 用户点击Save按钮
- 检查是否有任何Modified value被修改
- 如果没有修改：显示错误消息"NO UNRELEASED VERSION EXISTS!"
- 如果有修改：调用UD05ModifyDocumentApi 的 UD05UpdateHdocAdcaModification批量更新
- 跳转到「Save Modifications」页面

结果处理：
- 成功：跳转页面，显示修改内容
- 失败：显示错误消息

5.2 校验详细规格表

 No. | 检查时机 | 检查对象 | 检查条件 | 错误消息 | 动作 
-----|---------|---------|---------|---------|------
 1 | Save按钮点击 | Modified value | 没有任何项目被修改 | NO UNRELEASED VERSION EXISTS! | 显示错误消息，不提交

6. 接口定义 (API Specification)

### 6.1 UD05SelectVariableModification

- **功能**：获取Modify Document页面所需的变量列表数据。
- **所属 API**：UD05ModifyDocumentApi
- **Method**: `POST`
- **Endpoint**: `/api/v1/hdoc/modifydocument/select`

#### Request Body

```json
{
  "serie": "string",
  "chnr": "string"
}
```

#### Response Success (200 OK)

```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "variable": "VIN",
      "val": "12345678901234567"
    },
    {
      "variable": "ENGINE_NO",
      "val": "ENG123456"
    }
  ]
}
```

#### Response Error (404 Not Found)

```json
{
  "code": 404,
  "message": "Vehicle data not found.",
  "data": null
}
```

### 6.2 UD05UpdateHdocAdcaModification

- **功能**：更新Modify Document的变量值。
- **所属 API**：UD05ModifyDocumentApi
- **Method**: `POST`
- **Endpoint**: `/api/v1/hdoc/modifydocument/update`

#### Request Body

```json
{
  "serie": "string",
  "chnr": "string",
  "modifications": [
    {
      "variable": "VIN",
      "val": "NEW_VIN_VALUE"
    }
  ]
}
```

#### Response Success (200 OK)

```json
{
  "code": 200,
  "message": "Modifications saved successfully.",
  "data": null
}
```

#### Response Error (400 Bad Request)

```json
{
  "code": 400,
  "message": "Value is required.",
  "data": null
}
```
