 2. 背景 (Background)

 核心功能和目标：
本模块提供Homologation Variables查询结果展示功能，以DataTable形式显示查询结果，支持选择记录、返回、打印和删除选中记录等操作。

 面向的用户群体：
- 系统管理员
- Rule Admin权限用户
- 需要查看Homologation变量查询结果的用户

 用户体验方面的考虑：
- 清晰的查询结果表格展示
- 支持记录选择和批量操作
- 显示查询结果数量
- 支持打印和导出

 安全性或特殊要求：
- 数据只读显示（除删除操作外）
- 防止未授权删除
- Created by user列支持跳转到EDB User View

 4. 功能描述 (Functional Description)

 4.1 选择记录
 功能说明：  检查记录，点击Select按钮返回前页面

 操作步骤： 
1. 用户在DataTable中选择一条记录
2. 点击Select按钮
3. 跳转到之前的「Homologation Variables」页面
4. 自动显示所选记录的内容

 4.2 返回操作
 功能说明：  点击Back按钮返回前页面

 操作步骤： 
1. 用户点击Back按钮
2. 跳转到之前的「Homologation Variables」页面
3. 自动显示查询条件

 4.3 打印操作
 功能说明：  点击Print按钮打印查询结果

 操作步骤： 
1. 用户点击Print按钮
2. 浏览器启动打印功能
3. 打印查询结果页面

 4.4 删除选中记录
 功能说明：  点击Delete Selected按钮删除选中的记录

 操作步骤： 
1. 用户在DataTable中选择要删除的记录
2. 点击Delete Selected按钮
3. 调用UD09DeleteHdocuserdefinedrulesApi删除记录
4. 刷新查询结果列表

 4.5 查看用户信息
 功能说明：  点击Created by user列的链接查看用户信息

 操作步骤： 
1. 用户点击记录的'Created by user'列的链接
2. 跳转到「EDB User View」页面
3. 显示该用户的详细信息

 5. 业务逻辑与校验规则 (Business Logic & Checks)

 5.1 处理流程

 开始：  从查询页面跳转过来，显示查询结果

 前置处理：  
- 接收查询条件 调用UD09DeleteHdocuserdefinedrulesApi的 UD09Search 
- 根据从前画面传过来的检索条件 进行检索

 数据显示： 
- 在DataTable中显示所有查询结果
- 显示查询结果数量（Number of lines found: XXX）

 Select操作： 
- 检查是否选择了记录
- 如果未选择，显示警告消息
- 如果已选择，携带选中记录数据返回前页面

 Back操作： 
- 返回前页面
- 携带查询条件

 Print操作： 
- 调用浏览器打印功能
- 打印当前页面内容

 Delete Selected操作： 
- 检查是否选择了记录
- 如果未选择，显示警告消息
- 如果已选择，调用API删除选中的记录
- 刷新列表

 Created by user链接点击： 
- 获取该记录的REGISTER_USER
- 跳转到EDB User View页面
- 传递userid作为参数

 结果处理： 
- 成功：执行相应操作
- 失败：显示错误消息

 6. 接口定义 (API Specification)

### 6.1 UD09Search

- **功能**：根据查询条件检索Homologation Variables记录列表。
- **所属 API**：UD09DeleteHdocuserdefinedrulesApi
- **Method**: `POST`
- **Endpoint**: `/api/v1/hdoc/ud09/search`

#### Request Body

```json
{
  "pc": "string",
  "num": "string",
  "market": "string",
  "variable": "string",
  "val": "string",
  "vs": "string",
  "vs2": "string",
  "comments": "string",
  "addDate": "string",
  "deleteDate": "string",
  "updateUser": "string",
  "updateDatetime": "string"
}
```

#### Response Success (200 OK)

```json
{
  "code": 200,
  "message": "查询成功",
  "data": {
    "ruleList": [
      {
        "pc": "string",
        "num": "string",
        "market": "string",
        "variable": "string",
        "val": "string",
        "vs": "string",
        "vs2": "string",
        "comments": "string",
        "addDate": "string",
        "deleteDate": "string",
        "updateUser": "string",
        "updateDatetime": "string"
      }
    ]
  }
}
```

### 6.2 UD09DeleteSelected

- **功能**：删除选中的Homologation Variables记录。
- **所属 API**：UD09DeleteHdocuserdefinedrulesApi
- **Method**: `POST`
- **Endpoint**: `/api/v1/hdoc/ud09/deleteSelected`

#### Request Body

```json
{
  "records": [
    {
      "pc": "string",
      "num": "string",
      "market": "string"
    }
  ]
}
```

#### Response Success (200 OK)

```json
{
  "code": 200,
  "message": "Records deleted successfully.",
  "data": null
}
```
