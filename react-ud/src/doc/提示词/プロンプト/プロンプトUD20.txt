## 2. 背景 (Background)
 本模块的核心功能和目标：
 - 提供市场文档设置的查询功能，支持按文档类型、业务单元、用户、日期等条件检索文档列表
 - 提供查询结果展示功能，支持选择记录并回填至查询画面
 - 支持查看注册用户详细信息，可跳转至EDB User View画面

 画面流转顺序：
 - **24_HDoc Help画面** → 点击链接 → **HDoc - Market Document Setting検索画面** → 点击Search → **HDoc - Market Document Setting検索結果画面**

 面向的用户群体：
 - HDoc系统管理员
 - 具有文档管理权限的用户

 用户体验方面的考虑：
 - 查询条件与查询结果分离，界面清晰
 - 选择记录后自动回填至查询画面，减少重复操作
 - 提供Clear按钮快速清空查询条件

 安全性或特殊要求（如有）：
 - 需要验证用户是否有查看权限

## 4. 功能描述 (Functional Description)

### 4.1 进入查询画面功能
    功能说明：从24_HDoc Help画面点击链接，进入Market Document Setting检索画面
    操作步骤：
      1. 用户在24_HDoc Help画面点击Market Document Settings链接
      2. 系统跳转至HDoc - Market Document Setting検索画面
      3. 画面各字段显示为初始空值（Business unit下拉列表固定包含BU选项）

### 4.2 执行查询功能
    功能说明：根据查询条件检索文档列表并显示结果
    操作步骤：
      1. 用户在检索画面输入查询条件（Document type、User、Date等）
      2. 点击"Search"按钮
      3. 系统调用UD20GetDocumentListApi / UD20SelectHdocDocumentList获取数据
      4. 跳转至HDoc - Market Document Setting検索結果画面，显示查询结果列表

### 4.3 清空查询条件功能
    功能说明：清空检索画面所有输入条件
    操作步骤：
      1. 用户在检索画面点击"Clear"按钮
      2. 画面所有输入字段（Document type、User、Date等）清空为初始状态

### 4.4 记录选择与回填功能
    功能说明：在检索結果画面选择记录后，返回检索画面并自动回填
    操作步骤：
      1. 用户在检索結果画面选择一条记录
      2. 点击"Select"按钮
      3. 系统跳转回HDoc - Market Document Setting検索画面
      4. 选中的Document type、Business unit、User、Date自动填充至对应字段

### 4.5 用户信息查看功能
    功能说明：点击检索結果画面User链接，查看用户详细信息
    操作步骤：
      1. 用户在检索結果画面点击User字段中的链接
      2. 系统跳转至EDB User View画面
      3. 显示该用户的详细信息

### 4.6 打印功能
    功能说明：打印当前检索结果
    操作步骤：
      1. 用户在检索結果画面点击"Print"按钮
      2. 系统调用打印功能，输出当前查询结果

### 4.8 Update Mode功能
    功能说明：更新市场文档设置信息
    操作步骤：
      1. 用户在检索画面输入Document type、User、Date等更新条件
      2. 点击"Update Mode"按钮
      3. 系统调用UD20MarketDocumentSettingsApi的UD20-1UpdateHdocDocumentList方法
      4. 更新HDOC_DOCUMENT_LIST表中对应的记录

### 4.9 返回功能
    功能说明：各画面的返回操作
    操作步骤：
      1. 检索結果画面点击"Back"按钮 → 返回检索画面（回填数据）
      2. 检索画面点击"Back"按钮 → 返回24_HDoc Help画面

## 5. 业务逻辑与校验规则 (Business Logic & Checks)

### 5.1 处理流程

#### 5.1.1 查询流程（检索画面 → 检索結果画面）

    开始：点击检索画面"Search"按钮
    前置处理：收集Document type、Business unit、User、Date等查询参数
    空值校验等 (Frontend Check)：
     若无任何查询条件：
      允许查询（查询全部数据）
    API调用 (Backend Check)：
     调用UD20GetDocumentListApi / UD20SelectHdocDocumentList获取文档列表
    结果处理：
     成功：跳转至检索結果画面，显示查询结果列表
     失败：显示相应的错误消息

#### 5.1.2 记录选择流程（检索結果画面 → 检索画面）

    开始：点击检索結果画面"Select"按钮
    前置处理：获取用户选中的记录数据
    空值校验等 (Frontend Check)：
     若未选择任何记录：
      设置Message = "No data found"
      终止流程
    结果处理：
     成功：将选中记录数据传递至检索画面，自动回填各字段
     失败：显示相应的错误消息

#### 5.1.3 清空流程

    开始：点击检索画面"Clear"按钮
    处理：将Document type、User、Date等字段重置为空值

#### 5.1.4 Update Mode流程

    开始：点击检索画面"Update Mode"按钮
    前置处理：获取Document type、User、Date等输入参数
    API调用 (Backend Check)：
     调用UD20MarketDocumentSettingsApi的UD20-1UpdateHdocDocumentList方法
     更新HDOC_DOCUMENT_LIST表
    结果处理：
     成功：显示成功消息
     失败：显示相应的错误消息

### 5.2 校验详细规格表
| No. | 检查时机 | 检查对象 | 检查条件 | 错误消息 (Message Content) | 动作 |
|-----|---------|---------|---------|--------------------------|------|
| 1 | 点击Select按钮时 | 记录选择状态 | 未选择任何记录 | No data found | 显示错误消息，阻止跳转操作 |
| 2 | 页面加载时 | 用户权限 | 当前用户无查看权限 | 您没有权限执行此操作 | 阻止访问，重定向到主页 |

## 6. 接口定义 (API Specification)

### 6.1 UD20SelectHdocDocumentList

- **功能**：获取市场文档设置列表信息。
- **所属Api**：UD20GetDocumentListApi
- **Method**: `POST`
- **Endpoint**: `/api/v1/hdoc/ud20/getDocumentList`

#### Request

```json
{
  "doctype": "string (MaxLength 20, 可选)",
  "registerUser": "string (MaxLength 16, 可选)",
  "registerDatetime": "datetime (可选)"
}
```

#### Response Success (200 OK)

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "documents": [
      {
        "doctype": "string",
        "description": "string",
        "businessUnit": "BU",
        "registerUser": "string",
        "registerDatetime": "datetime"
      }
    ]
  }
}
```

#### Response Error (400 Bad Request)

```json
{
  "code": 400,
  "message": "error message",
  "data": null
}
```

#### Response Error (500 Internal Server Error)

```json
{
  "code": 500,
  "message": "系统暂时不可用，请稍后重试",
  "data": null
}
```

### 6.2 UD20-1UpdateHdocDocumentList

- **功能**：更新市场文档设置信息。
- **所属**：UD20MarketDocumentSettingsApi
- **Method**: `POST`
- **Endpoint**: `/api/v1/hdoc/ud20/updateDocumentList`

#### Request Body

```json
{
  "doctype": "string (MaxLength 20)",
  "registerUser": "string (MaxLength 16)",
  "registerDatetime": "datetime"
}
```

#### Response Success (200 OK)

```json
{
  "code": 200,
  "message": "更新成功",
  "data": null
}
```

#### Response Error (400 Bad Request)

```json
{
  "code": 400,
  "message": "error message",
  "data": null
}
```

#### Response Error (500 Internal Server Error)

```json
{
  "code": 500,
  "message": "系统暂时不可用，请稍后重试",
  "data": null
}
```


## 7. 异常处理 (Exception Handling)

| 异常场景 | 处理方式 | Message显示内容 |
|---------|---------|----------------|
| API连接失败 | 记录错误日志，返回错误信息 | 系统暂时不可用，请稍后重试 |
| 用户无查看权限 | 拒绝操作，返回错误信息 | 您没有权限执行此操作 |
| 查询结果为空 | 显示相应提示信息 | 没有找到符合条件的文档 |
| 未选择记录点击Select | 进行前端校验，阻止操作 | No data found |
| Update Mode更新失败 | API返回错误 | 系统暂时不可用，请稍后重试 |
