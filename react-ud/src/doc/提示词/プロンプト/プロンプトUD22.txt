6. 接口定义 (API Specification)

### 6.1 UD20SelectHdocDocumentList

- **功能**：获取市场文档设置列表信息。
- **所属Api**：UD20GetDocumentListApi
- **Method**: `POST`
- **Endpoint**: `/api/v1/hdoc/ud20/getDocumentList`

#### Request

```json
{
  "doctype": "string (MaxLength 20, 可选)",
  "registerUser": "string (MaxLength 16, 可选)",
  "registerDatetime": "datetime (可选)"
}
```

#### Response Success (200 OK)

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "documents": [
      {
        "doctype": "string",
        "description": "string",
        "businessUnit": "BU",
        "registerUser": "string",
        "registerDatetime": "datetime"
      }
    ]
  }
}
```

#### Response Error (400 Bad Request)

```json
{
  "code": 400,
  "message": "error message",
  "data": null
}
```

#### Response Error (500 Internal Server Error)

```json
{
  "code": 500,
  "message": "系统暂时不可用，请稍后重试",
  "data": null
}
```
