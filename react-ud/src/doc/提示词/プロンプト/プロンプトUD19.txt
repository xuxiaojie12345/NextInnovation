2. 背景 (Background)

核心功能和目标:
本模块提供用户查询功能，支持通过多种条件查询HDoc系统中的用户信息。用户可以通过输入UserID、User、Market等条件进行精确或模糊查询，并可根据不同权限类型(Rule Admin、Template Admin)筛选用户，最终显示用户的基本信息及权限情况。

面向的用户群体:
- HDoc系统管理员
- 具有用户管理权限的操作员

用户体验方面的考虑:
- 提供多种查询方式，提高查询效率
- 清晰的结果展示界面，便于识别用户信息
- 支持灵活的权限筛选功能

安全性或特殊要求:
- 需要验证用户是否有查询权限，确保只有授权用户可以使用此功能
- API请求必须通过HTTPS发送
- 支持半角英数字输入校验

4. 功能描述 (Functional Description)

4.1 用户查询
功能说明：根据输入的查询条件，从数据库中检索匹配的用户信息

操作步骤：
1. 用户在界面上输入一个或多个查询条件（Userid、User、Market）
2. 用户可以选择一个筛选条件（Not set、Rule、Template）
3. 点击"Search"按钮提交查询请求
4. 系统调用UD19SearchResultListApi进行查询
5. 查询成功：在DataTable中显示符合条件的用户列表，更新COUNT标签显示记录总数
6. 查询失败：显示相应的错误消息

4.2 权限筛选
功能说明：根据选择的权限类型筛选用户

操作步骤：
1. 用户选择"Not set"单选框，查询所有用户
2. 用户选择"Rule"单选框，查询具有Rule Admin权限的用户
3. 用户选择"Template"单选框，查询具有Template Admin权限的用户
4. 单选按钮组实现互斥选择逻辑
5. 点击"Search"按钮执行筛选查询


5. 业务逻辑与校验规则 (Business Logic & Checks)

5.1 处理流程

5.1.1 页面初始化

开始：页面加载

前置处理：
- 无

API调用：
- 调用UD19SelectMarketMaster获取Market列表

结果处理：

- 失败：显示错误消息"System error. Please contact administrator."

开始：用户点击Search按钮

前置处理：
- 准备查询参数，包括Userid、User、Market以及权限筛选选项


API调用 (Backend Check)：
- 调用UD19SearchHdoc获取用户信息
- Request: { userid: string, user: string, check: string, market: string }

结果处理：
- 成功：在DataTable中显示查询到的用户列表，更新COUNT标签显示记录总数
- 失败（无权限）：Message = "您没有权限执行此操作"
- 失败（结果为空）：Message = "没有找到匹配的用户"
- 系统异常：Message = "系统错误，请联系管理员"

Endpoint：/api/v1/hdoc/ud19/selectMarketMaster

Request Body：
```json
{}
```

Response Success (200 OK)：

```json
    "message": "查询成功",
    "data": {
        "marketList": [

                "market": "MARKET-A",
                "description": "A市场说明文本"
              },
              {
                "market": "MARKET-B",
                "description": "B市场说明文本"
              }
            ]
    }
}
```

Response Error (400 Bad Request)：
```json
{
  "code": 400,
  "data": null,
  "message": "Invalid request parameters"
}
```

6.2 UD19SearchHdoc

功能：获取用户信息

Method：POST

Endpoint：/api/v1/hdoc/ud19/searchHdoc

Request Body：
```json
{
  "userid": "string (Max 10, Alphanumeric)",
  "user": "string",
  "check": "string",
  "market": "string"
}
```

Response Success (200 OK)：
```json
{
    "code": 200,
    "message": "查询成功",
    "data": {
        "hdocList": [
            {
                "userid": "U001",
                "username": "测试用户01",
                "market": "MARKET01"
            },
            {
                "userid": "U002",
                "username": "测试用户02",
                "market": "MARKET02"
            }
        ]
    }
}
```

#### Response Error (400 Bad Request)

```json
{
  "code": 400,
  "data": null,
  "message": "Invalid request parameters"
}
```
