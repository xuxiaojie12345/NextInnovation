2. 背景 (Background)

核心功能和目标:
本模块提供车辆规格信息的查看功能，是Homologation（认证）流程中的重要环节。
通过Vehicle Specification页面，用户可以查看特定车辆的完整规格信息，包括车型、生产周次、产品类型、VIN、发动机号、适用国家等关键数据。

面向的用户群体:
- 系统注册用户
- 需要进行车辆认证的工程人员
- 文档管理人员

用户体验方面的考虑:
- 清晰的标签式布局，易于阅读
- 重要信息突出显示
- 鼠标悬停时显示详细描述信息（SYMBOL的tooltip）
- 响应式布局，适配不同屏幕尺寸

安全性或特殊要求:
- 需要校验车辆数据的存在性
- 确保数据显示的数据一致性
- 支持从前画面传递Chassis no参数

6. 接口定义 (API Specification)

### 6.1 UD07VehicleSpecificationApi

- **功能**：获取车辆规格信息（Model、Built week、Product type、VIN、Country of Operation、S-Note NO、SYMBOL_STR、DESCRIPTION等）。
- **Method**: `POST`
- **Endpoint**: `/api/v1/hdoc/vehiclespecification`

#### Request Body

```json
{
  "serie": "string",
  "chno": "string"
}
```

#### Response Success (200 OK)

```json
{
  "code": 200,
  "message": "查询成功",
  "data": {
    "model": "xxxx",
    "build": "xxxx",
    "productType": "xxxx",
    "vin": "xxxx",
    "symbolStr": "xxxx",
    "countryOfOperation": "xxxx",
    "customerAdap": "xxxx",
    "familyId": "xxx",
    "variantId": "xxx",
    "kolaList": [
      {
        "symbol": "xxx",
        "description": "xxx"
      }
    ]
  }
}
```
