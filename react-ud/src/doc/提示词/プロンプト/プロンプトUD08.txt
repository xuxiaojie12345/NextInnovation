 2. 背景 (Background)

 核心功能和目标：
本模块提供Homologation Variables的管理功能，包括查询、添加、更新和删除用户自定义规则。
用户可以按Product class、Number、Market等条件查询，并对HDOC_USER_DEFINED_RULES表进行操作。

 面向的用户群体：
- 系统管理员
- Rule Admin权限用户
- 需要管理Homologation变量的工程人员

 用户体验方面的考虑：
- 清晰的查询条件输入
- 直观的CRUD操作按钮
- 明确的校验错误提示
- Variant格式自动处理（TEMPLATE-XXX）

 安全性或特殊要求：
- 主键冲突校验
- Variant存在性校验
- 防止SQL注入

 4. 功能描述 (Functional Description)

 4.1 查询操作
功能说明： 输入查询条件，点击Search按钮查询记录

操作步骤：
1. 用户输入Product class、Number、Market等查询条件
2. 点击Search按钮
3. 调用D08HomologationVariablesApi的查询方法
4. 跳转到「Homologation Variables」查询结果页面
5. 显示符合条件的记录列表

 4.2 清除操作
功能说明： 点击Clear按钮清除已输入的内容

操作步骤：
1. 用户点击Clear按钮
2. 清空所有输入框和下拉列表
3. 恢复初始状态

 4.3 添加操作
功能说明： 输入新内容，点击Add按钮添加记录

操作步骤：
1. 用户输入Product class、Number、Market（必填）
2. 输入Variable、Value、Variant string等可选字段
3. 点击Add按钮
4. 前端校验：检查必填项、主键重复、Variant存在性
5. 调用UD08SelectDefinedRules检查主键是否重复
6. 调用UD08SelectHdocvariables检查Variable是否存在
7. 调用UD08Add插入记录到HDOC_USER_DEFINED_RULES表
8. 显示成功或失败消息

 4.4 更新操作
功能说明： 输入变更内容，点击Update按钮更新记录

操作步骤：
1. 用户修改现有记录的内容
2. 点击Update按钮
3. 前端校验：检查记录存在性、主键重复、Variant存在性
4. 调用UD08SelectDefinedRules校验记录是否存在
5. 从 Homologation Variables Result List 画面跳转过来时 需要检查主键是否被更改
6. 调用UD08SelectHdocvariables检查Variable是否存在
7. 调用UD08Update更新HDOC_USER_DEFINED_RULES表
8. 显示成功或失败消息

 4.5 删除操作
功能说明： 输入删除内容，点击Delete按钮删除记录

操作步骤：
1. 用户选择要删除的记录
2. 点击Delete按钮
3. 前端校验：检查记录存在性
4. 调用UD08SelectDefinedRules校验记录是否存在
5. 调用UD08Delete从HDOC_USER_DEFINED_RULES表删除
6. 显示成功或失败消息

 5. 业务逻辑与校验规则 (Business Logic & Checks)

 5.1 处理流程

开始： 用户执行操作（查询/添加/更新/删除）

前置处理： 
- 获取输入参数
- 去除首尾空格

查询操作：
- 将Product class、Number、Market等条件传递到下一个页面

添加操作：
- 校验Product class、Number、Market必填
- 调用UD08SelectDefinedRules检查主键（Product、Number、Market）是否重复
- 如果Variable是'TEMPLATE-XXX'格式，删除'TEMPLATE-'前缀
- 调用UD08SelectHdocvariables检查Variable是否存在于HDOC_VARIABLES表中
- 调用UD08Add插入记录
- 设置ADD_DATE、UPDATE_USER、UPDATE_DATETIME

更新操作：
- 调用UD08SelectDefinedRules校验记录是否存在（按Product、Number、Market）
- 从 Homologation Variables Result List 画面跳转过来时 需要检查主键是否被更改
- 调用UD08SelectHdocvariables检查Variable是否存在于HDOC_VARIABLES表中
- 调用UD08Update更新记录
- 更新UPDATE_USER、UPDATE_DATETIME

删除操作：
- 调用UD08SelectDefinedRules校验记录是否存在（按Product、Number、Market）
- 调用UD08Delete删除记录
- 设置DELETE_DATE

结果处理：
- 成功：显示成功消息
- 失败：显示错误消息
