 2. 背景 (Background)

 核心功能和目标：
本模块提供Vin Plate信息管理功能，用户输入Chassis number后，可以查看VIN Plate的详细信息，包括状态、类型、错误消息、发送数据状态等。
支持多种操作：View Info、Set Regenerate、Set OK、Change to Basic Info、Change to Advanced Info，用于更新Chassis的状态和类型。

 面向的用户群体：
- 系统工程人员
- 需要管理VIN Plate数据的用户

 用户体验方面的考虑：
- 清晰的Chassis信息展示
- 直观的操作按钮
- 明确的状态和错误消息显示
- XML数据解析展示（Print Items和VP Data）

 安全性或特殊要求：
- Chassis number格式校验
- 状态更新权限控制
- XML数据安全解析

 4. 功能描述 (Functional Description)

 4.1 查看VIN Plate信息
功能说明： 输入Chassis number，点击View Info按钮查看VIN Plate详细信息

操作步骤：
1. 用户输入Chassis number（最多15字符）
2. 点击View Info按钮
3. 调用UD15ViewInfo方法
4. 检索结果为0件时，显示错误消息"Chassis number XXX not found."。
4. 从HDOC_SEND_DATA_VIN_PLATE表获取该Chassis的信息
5. 显示Plate type、Status、Error Message、Def.、Data ready、Sent to CAB factory等信息
6. 解析XML_DOC，提取PrintItemName并显示在Print items列
7. 解析XML_DOC，提取各Variant名称和Value并显示在VP Data列

 4.2 设置为再生状态
功能说明： 输入Chassis number，点击Set Regenerate按钮将状态更新为'0'（新增）

操作步骤：
1. 用户输入Chassis number
2. 点击Set Regenerate按钮
3. 调用UD15SetRegenerate方法
4. 将该Chassis的STATUS更新为'0'（新增）
5. 刷新页面显示最新状态

 4.3 设置为OK状态
功能说明： 输入Chassis number，点击Set OK按钮将状态更新为'1'（xml doc已创建）

操作步骤：
1. 用户输入Chassis number
2. 点击Set OK按钮
3. 调用UD15SetOK方法
4. 将该Chassis的STATUS更新为'1'（xml doc已创建）
5. 刷新页面显示最新状态

 4.4 更改为Basic Info
功能说明： 输入Chassis number，点击Change to Basic Info按钮将状态更新为'0'，TYPE更新为'1'（basic）

操作步骤：
1. 用户输入Chassis number
2. 点击Change to Basic Info按钮
3. 调用UD15ChangetoBasicInfo方法
4. 将该Chassis的STATUS更新为'0'（新增），TYPE更新为'1'（basic）
5. 刷新页面显示最新状态

 4.5 更改为Advanced Info
功能说明： 输入Chassis number，点击Change to Advanced Info按钮将状态更新为'0'，TYPE更新为'2'（ADVANCED (with weights)）

操作步骤：
1. 用户输入Chassis number
2. 点击Change to Advanced Info按钮
3. 调用UD15ChangetoAdvancedInfo方法
4. 将该Chassis的STATUS更新为'0'（新增），TYPE更新为'2'（ADVANCED (with weights)）
5. 刷新页面显示最新状态

 5. 业务逻辑与校验规则 (Business Logic & Checks)

 5.1 处理流程

开始： 用户输入Chassis number并执行操作

前置处理： 
- 获取Chassis number输入值
- 去除首尾空格
- 校验Chassis number格式（最多15字符）

View Info操作：
- 调用UD15ViewInfo方法
- 从HDOC_SEND_DATA_VIN_PLATE表查询该Chassis的记录
- 如果记录不存在，显示错误消息
- 如果记录存在，显示所有字段信息
- 解析XML_DOC字段：
  - 提取PrintItemName项目值，显示在Print items列
  - 提取各Variant名称和Value，显示在VP Data列

Set Regenerate操作：
- 调用UD15SetRegenerate方法
- 更新HDOC_SEND_DATA_VIN_PLATE表，设置STATUS='0'
- 刷新页面显示最新状态

Set OK操作：
- 调用UD15SetOK方法
- 更新HDOC_SEND_DATA_VIN_PLATE表，设置STATUS='1'
- 刷新页面显示最新状态

Change to Basic Info操作：
- 调用UD15ChangetoBasicInfo方法
- 更新HDOC_SEND_DATA_VIN_PLATE表，设置STATUS='0'，TYPE='1'
- 刷新页面显示最新状态

Change to Advanced Info操作：
- 调用UD15ChangetoAdvancedInfo方法
- 更新HDOC_SEND_DATA_VIN_PLATE表，设置STATUS='0'，TYPE='2'
- 刷新页面显示最新状态

结果处理：
- 成功：显示更新后的信息
- 失败：显示错误消息
