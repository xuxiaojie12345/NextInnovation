2. 背景 (Background)

核心功能和目标:
本模块提供用户登录认证功能，是系统的入口页面。用户通过输入用户名和密码进行身份验证，认证成功后跳转到主菜单页面。

面向的用户群体:
- 系统注册用户
- 需要访问EDB Engineering Database的工程人员

用户体验方面的考虑:
- 简洁直观的登录界面
- 清晰的错误提示信息
- 响应式布局，适配不同屏幕尺寸
- 提供备选登录链接以应对账户锁定情况

安全性或特殊要求:
- 密码输入需要隐藏显示
- 支持半角英数字和符号
- 账户锁定机制
- 防止SQL注入和XSS攻击

4. 功能描述 (Functional Description)

4.1 用户登录
功能说明：用户输入用户名和密码进行身份验证

操作步骤：
1. 用户在UserID输入框中输入用户ID（必填，最多10个半角英数字）
2. 用户在Password输入框中输入密码（必填，最多32个半角英数字+符号）
3. 用户点击Login按钮
4. 系统调用AuthenticationApi进行认证
5. 认证成功：跳转到Menu页面
6. 认证失败：在Password下方显示错误消息

4.2 输入校验
功能说明：对输入内容进行前端校验

操作步骤：
1. 用户点击Login按钮时触发校验
2. 若UserID为空：显示错误消息【Username and password are required.】
3. 若Password为空：显示错误消息【Username and password are required.】
4. 若UserID或Password格式不正确：显示相应错误消息


5. 业务逻辑与校验规则 (Business Logic & Checks)

5.1 处理流程

开始：用户点击Login按钮

前置处理：
- 获取UserID和Password输入值
- 去除首尾空格

空值校验 (Frontend Check)：
- 若UserID为空或Password为空：
  - 设置Message = "Username and password are required."
  - 终止流程

API调用 (Backend Check)：
- 调用AuthenticationApi
- Request: { userid: string, password: string }

结果处理：
- 成功：跳转到Menu页面
- 失败（用户名或密码错误）：Message = "We didn't recognize the username or password you entered. Please try again."
- 失败（账户锁定）：Message = "Your account is locked. Please contact your system administrator."
- 系统异常：Message = "System error. Please contact administrator."

5.2 校验详细规格表

No. | 检查时机 | 检查对象 | 检查条件 | 错误消息 (Message Content) | 动作
---|---|---|---|---|---
1 | Login按钮点击 | UserID | 不能为空 | Username and password are required. | 显示错误消息，终止提交
2 | Login按钮点击 | Password | 不能为空 | Username and password are required. | 显示错误消息，终止提交
3 | API返回 | 认证结果 | 用户名或密码不正确 | We didn't recognize the username or password you entered. Please try again. | 显示错误消息
4 | API返回 | 认证结果 | 账户已锁定 | Your account is locked. Please contact your system administrator. | 显示错误消息
5 | API调用 | 系统状态 | 系统异常 | System error. Please contact administrator. | 显示错误消息


6. 接口定义 (API Specification)

AuthenticationApi

功能：用户身份认证

Method：POST

Endpoint：/api/auth/login

Request：
{
  "userid": "string",
  "password": "string"
}

Response Success (200)：
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "userid": "string",
    "username": "string",
    "token": "string"
  }
}

Response Error (401)：
{
  "code": 401,
  "message": "We didn't recognize the username or password you entered. Please try again.",
  "data": null
}

Response Error (403)：
{
  "code": 403,
  "message": "Your account is locked. Please contact your system administrator.",
  "data": null
}

Response Error (500)：
{
  "code": 500,
  "message": "System error. Please contact administrator.",
  "data": null
}

---|---|---
