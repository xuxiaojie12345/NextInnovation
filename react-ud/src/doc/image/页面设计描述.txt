================================================================================
页面设计描述文档 - 用于还原页面样式代码
================================================================================

【通用风格说明】
- 整个系统使用 Ant Design 暗色侧边栏菜单 + 白色内容区的布局风格
- 所有页面卡片均采用 白色背景、圆角（6px）、轻微阴影（0 2px 8px rgba(0,0,0,0.08)）
- 页面标题居中，标题下方有分割线
- 支持信息区域：浅灰背景（#fafafa）、灰边框（#e8e8e8）、小号文字
- 错误消息区域：浅红背景（#fff2f0）、红色边框（#ffccc7）、红色文字（#ff4d4f）
- 响应式：小屏幕下按钮纵向排列，内边距缩小

布局：
- 白色大卡片居中（max-width: 780px）

  5. Template & Parameters - 显示 Using template、Replacing parameters
  6. Generated Document - 文档下载链接
  7. System Information - 显示 Date（服务器时间）、HDoc version（程序版本）
- 标签固定宽度（min-width: 110px），值在右侧
- 行与行之间有浅灰分隔线（border-bottom）
