画面名: HDoc User Administration
作成日: 2022-11-29
作成者: UD 劉

概要处理:
1. 初始显示
   1. HDoc用户管理画面
   设置用户权限。
   (1) 输入Userid后，按下「用户信息」按钮，从Saviynt获取对应用户的用户名。
       从用户功能权限表获取对应用户的权限。
   (2) 按下「更新角色」按钮，更新用户权限。
   (3) 按下「删除角色」按钮，删除对应用户的所有权限。
