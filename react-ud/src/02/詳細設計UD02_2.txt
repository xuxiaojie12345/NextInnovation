 2. 背景 (Background)

本模块是 VOLVO 公司内部工程数据库系统的主导航界面。用户在成功登录并经过权限校验后进入此页面。

   核心功能和目标：
       提供清晰的功能导航，将系统功能划分为“Generate Document”、“User Administration”、“Archive”和“Documentation”四大模块。
       根据登录用户的权限动态渲染菜单项，隐藏无权访问的功能。
       作为系统操作的入口，点击菜单项触发相应的业务功能或页面跳转。
   面向的用户群体：
       已登录的 VOLVO 内部员工、工程师、管理员及支持人员。
   用户体验方面的考虑：
       界面布局简洁，靠左对齐，符合阅读习惯。
       顶部蓝色底板配合白色 Logo，强化品牌识别度。
       使用 `»` 符号明确标识可点击的操作链接，视觉引导性强。
       模块化分组展示，便于用户快速定位所需功能。
   安全性或特殊要求：
       权限控制：严格执行基于角色的访问控制（RBAC）。若用户尝试访问无权限页面，或在加载菜单时发现无权查看某些模块，需进行隐藏或拦截。
       未授权提示：若用户通过直接 URL 访问无权限页面，需显示警告信息：“YOU (XXXXXXXX) ARE NOT AUTHORIZED TO ACCESS THIS PAGE”。

 4. 功能描述 (Functional Description)

 4.1 菜单渲染与权限过滤
功能说明：页面加载时，根据当前登录用户的权限列表，动态生成左侧菜单树。无权访问的模块或菜单项不渲染。

操作步骤：
1.  用户从登录页跳转至本页面。
2.  系统读取 Session/Token 中的用户权限数据。
3.  遍历预定义的菜单结构。
4.  结果反馈：
       若用户拥有某模块下至少一个功能的权限，则显示该模块标题及有权限的子菜单项。
       若用户对某模块无任何权限，则该模块标题及子项完全隐藏。
       若用户没有任何菜单权限，显示空白或默认提示。

 4.2 功能导航跳转
功能说明：用户点击具体的菜单操作项（如 `Generate Doc`），系统执行相应的业务逻辑或页面跳转。

操作步骤：
1.  用户点击带有 `»` 符号的操作链接。
2.  系统再次校验用户对该特定功能的实时权限（可选，增强安全性）。
3.  调用对应的后台服务接口或路由跳转。
4.  结果反馈：
       成功：进入对应的功能子页面或执行后台任务（如弹出下载框）。
       失败：若权限校验失败，显示警告消息 “YOU (UserID) ARE NOT AUTHORIZED TO ACCESS THIS PAGE”。

 5. 业务逻辑与校验规则 (Business Logic & Checks)

 5.1 处理流程

开始：页面加载（OnMount）或用户点击菜单项。

前置处理：
   获取当前用户对象 `CurrentUser` 及其权限列表 `Permissions`。

5.1.1 权限校验 (Frontend/Backend Check)：
   场景 A：页面加载时渲染菜单
       遍历菜单配置树。
       若 `CurrentPermission` 不包含该菜单项 ID：
           动作：不渲染该 DOM 元素（隐藏）。
   场景 B：点击菜单项时
       若 `CurrentPermission` 不包含该操作 ID：
           设置 `MsgUnauthorized` = "YOU (" + UserID + ") ARE NOT AUTHORIZED TO ACCESS THIS PAGE"
           类型：Warning
           终止跳转流程

5.1.2 API调用 (Backend Action)：
   根据点击的菜单项，调用相应的业务 API（如 `/api/generate/doc`, `/api/user/search` 等）。

5.2 结果处理：
   成功：执行具体业务逻辑（跳转、弹窗、下载等）。
   失败：显示通用错误提示或权限拒绝提示。

 5.3 校验详细规格表

| No. | 检查时机 | 检查对象 | 检查条件 | 错误消息 (Message Content) | 动作 |
|-----|---------|---------|---------|--------------------------|------|
| 1   | 页面加载 | 用户权限 | 用户是否拥有任何菜单权限 | - | 若无权限，显示空白或重定向至登出页 |
| 2   | 点击菜单项 | 特定功能权限 | 用户是否拥有该具体操作权限 | YOU (XXXXXXXX) ARE NOT AUTHORIZED TO ACCESS THIS PAGE | 显示 Warning 消息，不执行跳转 |
| 3   | API 响应 | 会话有效性 | Token 是否过期 | Session expired. Please login again. | 重定向至登录页 |

 6. 接口定义 (API Specification)

由于菜单点击涉及多个不同的业务功能，此处定义通用的权限验证接口及各模块的典型调用示例。

 6.1 获取用户菜单权限 (GetUserMenuPermissions)
通常在登录成功后调用，或在此页面初始化时调用

功能：获取当前用户有权访问的菜单项 ID 列表。
Method：GET
Endpoint：`/api/user/permissions`

Request
```json
{
  "token": "eyJhbGciOi..." // Header中携带
}
```

Response Success (200 OK)
```json
{
  "code": 200,
  "data": {
    "userId": "A451340",
    "allowedMenuItems": [
      "generate_doc",
      "generate_batch",
      "search_user",
      "user_guide"
      // ... 其他有权访问的项
    ]
  }
}
```

 6.2 典型业务调用示例 (以 Generate Doc 为例)

功能：生成文档
Method：POST
Endpoint：`/api/generate/doc`

Request
```json
{
  "docType": "HDoc",
  "params": { ... }
}
```

Response Success (200 OK)
```json
{
  "code": 200,
  "data": {
    "downloadUrl": "/downloads/doc_123.pdf"
  }
}
```

Response Error (403 Forbidden)
```json
{
  "code": 403,
  "message": "YOU (A451340) ARE NOT AUTHORIZED TO ACCESS THIS PAGE"
}
```

 7. 异常处理 (Exception Handling)

| 异常场景 | 处理方式 | Message显示内容 |
|---------|---------|----------------|
| 无权限访问特定功能 | 前端拦截或后端返回 403，显示警告 | YOU (XXXXXXXX) ARE NOT AUTHORIZED TO ACCESS THIS PAGE |
| 会话过期 (401) | 捕获全局 Auth 错误，重定向 | Session expired. Please login again. |
| 网络错误 | 显示通用错误提示 | Network error. Please check your connection. |
| 服务器内部错误 (500) | 显示通用错误提示 | System error. Please contact support. |
