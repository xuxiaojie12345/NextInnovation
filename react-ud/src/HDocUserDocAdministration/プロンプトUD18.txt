画面ID: HDoc User Doc Administration
画面名称: HDoc User Doc Administration
创建日期: 2022-11-29
创建者: UD 刘

概要处理:
1. 初始显示
   １. HDoc User Doc Administration画面
   设置用户的文档权限。
   (1) 输入Userid，点击“User Info”按钮，检查该Userid是否存在于用户功能权限表中。
       仅当存在时，才能执行权限的检索和设置操作。
   (2) 点击“User Info”按钮后，从Saviynt获取用户名，并自动选择该用户拥有的权限。
   (3) 选择权限后，点击“Update”按钮，首先检查该Userid是否存在于用户功能权限表中。
       仅当存在时，才能为该用户设置用户权限。
