## 1. 背景 (Background)

本模块的核心功能是展示基于上一页查询条件所获取的 `HDOC_VARIABLES` 表中认证参数（Homologation Variables）的数据列表。该页面作为查询流程的输出界面，支持用户对检索结果进行选择、打印、导出等操作，并提供跳转至用户详情页的功能。

- **目标**：清晰展示检索结果，提供高效的数据操作能力（选择、下载、导出），并确保操作的安全性。
- **安全性**：
  - 创建人链接仅限于已登录用户访问，且权限控制由后端统一管理。
  - 导出文件不包含敏感信息。
  - 所有通信使用 HTTPS 加密。
- **用户体验**：
  - 支持多行勾选，提升批量操作效率。
  - 提供清晰的数据字段展示（如 Variable、Type、Description）。
  - 创建人列可点击跳转，增强信息追溯能力。
  - 所有按钮具备明确语义，避免误操作。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

所有操作逻辑均在用户点击相应按钮时执行。

### 3.1 处理流程

1.  **开始**：页面加载或用户点击操作按钮。
2.  **前置处理**：
    - 页面加载时，从 URL 或 State 获取查询条件，调用 API 获取数据列表。
    - 操作前，验证当前会话有效性。
3.  **空值/状态校验 (Frontend Check)**：
    - 若点击 **Select** 或 **Down**：
      - 检查是否有至少一行被勾选。
      - 若无选中项，设置 `ErrorMessage` = `请至少选择一条记录`，**终止**流程。
4.  **API 调用 (Backend Check)**：
    - **Search**: 调用 `GET /api/HDOC_VARIABLES/search` 获取列表数据。
    - **Export**: 调用 `GET /api/HDOC_VARIABLES/export` 获取 CSV 流。
5.  **结果处理**：
    - **Select**: 将选中数据通过 State 或 Callback 回传至父页面/上一级页面，并执行返回操作。提示：“已成功选择 X 条记录”。
    - **Down**: 提取选中记录的 `Variable` 和 `Type`，跳转至 `/homologation-variables?variable=XXX&type=YYY`。
    - **Back**: 直接执行路由返回，不保存当前页状态。
    - **Print**: 调用浏览器 `window.print()`，并通过 CSS `@media print` 隐藏按钮和非必要元素。
    - **Excel**: 触发文件下载，文件名格式：`HDoc_Variables_YYYYMMDD.csv`。
    - **User Link**: 跳转至 `/user/profile/{userId}`。

## 4. 接口定义 (API Specification)

### 4.1 HDOC_VARIABLES Search (查询列表)

- **功能**：获取符合查询条件的认证参数列表。
- **Method**: `GET`
- **Endpoint**: `/api/HDOC_VARIABLES/search`

#### Request Parameters (Query)

```text
?variable=CDB_CADDRESS_LINE1&type=CDB
```

#### Response Success (200 OK)

```json
{
  "data": [
    {
      "Variable": "CDB_CADDRESS_LINE1",
      "Type": "CDB",
      "Description": "CDB customer address line 1",
      "Created_by_user": "mg",
      "Date": "2006-03-21"
    }
  ],
  "totalCount": 3619
}
```

#### Response Error (400 Bad Request)

```json
{
  "error": "Invalid parameters",
  "message": "查询参数格式错误"
}
```

### 4.2 HDOC_VARIABLES Export (导出)

- **功能**：导出当前查询结果为 CSV 文件。
- **Method**: `GET`
- **Endpoint**: `/api/HDOC_VARIABLES/export`

#### Request Parameters (Query)

```text
?variable=CDB_CADDRESS_LINE1&type=CDB
```

#### Response Success (200 OK)

- Content-Type: `text/csv`
- Content-Disposition: `attachment; filename="HDoc_Variables_YYYYMMDD.csv"`
- Body: [CSV File Stream]

#### Response Error (400 Bad Request)

```json
{
  "error": "Invalid export request",
  "message": "无法生成导出文件"
}
```

| 异常场景           | 处理方式           | Message 显示内容               |

| **网络断开/超时**  | 捕获 Network Error | `网络连接失败，请检查网络设置` |

| **未选择记录操作** | 前端校验拦截       | `No key defined for table.`    |
| **用户不存在**     | 跳转/提示          | `用户信息不存在`               |

## 6. 实现注意事项 (Implementation Notes)

1.  **状态管理**：
    - 使用 React State 管理 `dataSource` (列表数据), `selectedRowKeys` (选中项的主键集合), `loading`, `errorMessage`。
    - 使用 `useLocation` 或 `useSearchParams` 获取上一页传来的查询条件。
2.  **UI 细节**：
    - **表格选择**：使用 Ant Design Table 的 `rowSelection` 属性实现多选。
    - **打印样式**：编写专门的 CSS `@media print` 规则，隐藏 `.no-print` 类（包含按钮、导航栏等），确保打印输出整洁。
    - **用户链接**：`Created by user` 列渲染为 `<Link to={`/user/profile/${record.Created_by_user}`}>{record.Created_by_user}</Link>`。
    - **计数显示**：`Count` Label 动态更新为 `Number of lines found: ${dataSource.length}`。
3.  **交互反馈**：
    - 操作成功后，使用 `message.success` 提示用户。
    - `Select` 和 `Down` 按钮在未选中任何行时应设为 `disabled` 或在点击时给出明确提示。
4.  **安全性**：
    - API 请求必须通过 HTTPS 发送。
    - 对 URL 参数进行编码，防止注入攻击。
