## 1. 背景 (Background)

本模块的核心功能是展示基于上一页查询条件所获取的 `HDOC_VARIABLES` 表中认证参数（Homologation Variables）的数据列表。该页面作为查询流程的输出界面，支持用户对检索结果进行选择、打印、导出等操作，并提供跳转至用户详情页的功能。

- **目标**：清晰展示检索结果，提供高效的数据操作能力（选择、打印、导出），确保数据可追溯性。
- **面向的用户群体**：
  - 系统管理员
  - 产品工程师
  - 认证管理人员
- **用户体验**：
  - 支持多行勾选，提升批量操作效率
  - 提供清晰的数据字段展示（Variable、Type、Description）
  - 创建人列可点击跳转，增强信息追溯能力
  - 所有按钮具备明确语义，避免误操作
- **安全性**：
  - 删除操作需确认，防止误删
  - 创建人链接仅限于已登录用户访问
  - 导出文件不包含敏感信息
  - 所有通信使用 HTTPS 加密

## 3. 功能描述 (Functional Description)

### 3.1 数据展示功能

功能说明：根据上一页的查询条件，从数据库中加载并展示对应的 HDOC_VARIABLES 数据。

操作步骤：

1. 用户在前一页面输入查询条件并提交
2. 系统调用 `GET /api/ud11hdocvariablesapi/ud11search` 接口获取匹配数据
3. 将数据渲染为表格形式，每行包含 Variable、Type、Description 等字段
4. 显示总记录数（Count）于页面底部

### 3.2 选择并返回功能

功能说明：用户勾选一条或多条数据后，点击「Select」按钮，将所选数据回传至上一级页面。

操作步骤：

1. 用户勾选一个或多个数据条目
2. 点击「Select」按钮
3. 系统收集所有选中项的主键信息
4. 跳转至上一级认证参数页面，并自动填充选中数据的信息
5. 页面提示：「已成功选择 X 条记录」

### 3.3 返回功能

功能说明：点击「Back」按钮返回上一级页面，并恢复原始查询条件。

操作步骤：

1. 用户点击「Back」按钮
2. 系统不保存当前筛选状态
3. 跳转至认证参数查询页面
4. 查询条件自动还原为进入本页面前的状态

### 3.4 打印功能

功能说明：将当前检索结果以打印格式输出。

操作步骤：

1. 用户点击「Print」按钮
2. 系统触发浏览器打印对话框
3. 打印内容包括表头、所有可见列
4. 不包含系统按钮和操作栏

### 3.5 下载功能

功能说明：选中数据条目后点击「Down」按钮，携带该条目的参数跳转至认证参数页面。

操作步骤：

1. 用户勾选一条或多条数据条目
2. 点击「Down」按钮
3. 系统提取选中记录的 Variable 和 Type 字段
4. 跳转至目标页面并传递参数

### 3.6 导出 Excel 功能

功能说明：将当前查询结果导出为 CSV 格式文件。

操作步骤：

1. 用户点击「Excel」按钮
2. 系统调用导出接口获取数据
3. 生成 CSV 文件并触发下载
4. 文件命名格式：`HDoc_Variables_YYYYMMDD.csv`

### 3.7 创建人跳转功能

功能说明：点击「Created by user」列中的用户名链接，跳转至用户信息查看页面。

操作步骤：

1. 用户点击某条记录的「Created by user」字段
2. 系统发起请求至用户信息查看页面
3. 展示该用户的详细信息
4. 支持返回原页面

## 4. 业务逻辑与校验规则 (Business Logic & Checks)

所有校验逻辑均在用户点击 Select / Down / Back / Print / Excel / Created by user 链接时执行。

### 4.1 处理流程

1. **开始**：用户点击操作按钮或链接。
2. **前置处理**：
   - 页面加载时，从 URL 或 State 获取查询条件，调用 API 获取数据列表
   - 操作前，验证当前会话有效性
3. **空值/状态校验 (Frontend Check)**：
   - 若点击 **Select** 或 **Down**：
     - 检查是否有至少一行被勾选
     - 若无选中项，设置 `ErrorMessage` = `请至少选择一条记录`，**终止**流程
4. **API 调用 (Backend Check)**：
   - **页面加载**: 调用 `GET /api/ud11hdocvariablesapi/ud11search` 获取列表数据
   - **Create User Link**: 无需额外 API 调用，直接路由跳转至用户详情页
5. **按钮按下处理**：
   - **Select**: 将选中数据通过 State 回传至上一级页面，并执行返回操作（参照3.2 功能描述）
   - **Back**: 直接执行路由返回，不保存当前页状态（参照3.3 功能描述）
   - **Print**: 调用浏览器 `window.print()`，通过 CSS `@media print` 隐藏按钮和非必要元素（参照3.4 功能描述）
   - **Down**: 携带选中记录的参数跳转至目标页面（参照3.5 功能描述）
   - **Excel**: 调用导出接口下载 CSV 文件（参照3.6 功能描述）

### 4.2 校验详细规格表

| No. |     检查时机      |    检查对象    |            检查条件             | 错误消息 (Message Content) |       动作        |
| :-: | :---------------: | :------------: | :-----------------------------: | :------------------------: | :---------------: |
|  1  | Click Select/Down | Selected Rows  |      `SelectedCount == 0`       |    `请至少选择一条记录`    | 显示 ErrorMessage |
|  2  | Click Created by  | User Existence | `UserExists == false` (Backend) |      `用户信息不存在`      |   跳转至错误页    |

## 5. 接口定义 (API Specification)

### 5.1 获取检索结果列表

- **功能**：根据条件查询认证参数列表。
- **Method**: `GET`
- **Endpoint**: `/api/ud11hdocvariablesapi/ud11search`

#### Request

```json
{
  "variable": "CDB_CADDRESS_LINE1",
  "type": "CDB"
}
```

#### Response Success (200 OK)

```json
{
  "code": 200,
  "msg": "查询成功",
  "data": {
    "variables": [
      {
        "variable": "CDB_CADDRESS_LINE1",
        "type": "CDB",
        "description": "CDB customer address line 1",
        "createdByUser": "mg",
        "date": "2006-03-21"
      }
    ],
    "count": 3619
  }
}
```

#### Response Error (400 Bad Request)

```json
{
  "error": "Invalid parameters",
  "message": "查询参数格式错误"
}
```

### 5.2 导出 CSV

- **功能**：导出当前查询结果为 CSV 文件。
- **Method**: `GET`
- **Endpoint**: `/api/hdoc_variables/export`

#### Request Parameters (Query)

```text
?variable=CDB&type=CDB
```

#### Response Success (200 OK)

- Content-Type: `text/csv`
- Content-Disposition: `attachment; filename="HDoc_Variables_YYYYMMDD.csv"`
- Body: [CSV File Stream]

## 6. 异常处理 (Exception Handling)

| 异常场景               | 处理方式           | Message 显示内容                 |
| :--------------------- | :----------------- | :------------------------------- |
| **网络断开/超时**      | 捕获 Network Error | 「网络连接失败，请检查网络设置」 |
| **数据库异常**         | 回滚事务，记录日志 | 「系统繁忙，请稍后再试」         |
| **未选择记录点击按钮** | 返回错误响应       | 「请至少选择一条记录」           |
| **用户不存在**         | 跳转至错误页或提示 | 「用户信息不存在」               |

## 7. 实现注意事项 (Implementation Notes)

1. **状态管理**：
   - 使用 React State 管理 `dataSource`（列表数据）、`selectedRowKeys`（选中项）、`loading`、`errorMessage`。
   - 使用 `useLocation` 或 `useSearchParams` 获取上一页传来的查询条件。

2. **表格选择**：
   - 使用单选框（Radio）实现单选，或多选框（Checkbox）实现多选，按业务需求决定。
   - 选中行高亮显示。

3. **打印样式**：
   - 编写 CSS `@media print` 规则，隐藏按钮和操作栏，确保打印输出整洁。

4. **用户链接**：
   - `Created by user` 列渲染为可点击链接，跳转至 `/UD25?userid=xxx`。

5. **导出交互**：
   - 点击 Excel 按钮后显示 loading 状态，直到文件下载开始或失败。

6. **按钮交互**：
   - Back 按钮使用 `navigate(-1)` 实现返回上一页。
   - Select 按钮将选中数据通过 `location.state` 回传至上一级页面。
