## 1. 背景 (Background)

本模块用于在用户提交文档修改后，展示系统处理结果及当前版本状态。主要功能包括显示车辆基本信息、当前操作的版本信息，并提供关键的状态提示（如“VERSION IS RELEASED”）。

- **目标**：清晰反馈修改操作的结果，告知用户当前版本状态（已发布或存在未发布版本），并提供关闭页面的入口。
- **安全性**：页面均为只读输出项，不允许直接编辑；所有信息均来自数据库读取，防止篡改。
- **用户体验**：
  - 界面简洁明了，突出关键信息。
  - 使用绿色高亮显示重要状态消息（如已发布）。
  - 操作路径清晰，仅需点击“Close”即可返回。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

### 3.1 处理流程

1.  **开始**：用户从 Modify Document 页面成功保存后跳转至本页面。
2.  **前置处理**：
    - 获取 URL 参数或 State 中的 `ChassisSerie` 和 `ChassisNumber`。
    - 调用 API 获取最新的修改状态信息。
3.  **数据加载校验 (Frontend/Backend Check)**：
    - 若 API 返回数据为空或失败：
      - 设置 `Message` = `无法加载修改状态，请重试`
      - **终止**正常渲染，显示错误状态。
    - 若 API 返回成功：
      - 渲染 `Chassis serie`, `Chassis number`, `Doctype`, `Version`, `Storing` 等字段。
      - 根据 `FOUND UNRELEASED VERSION` 的值更新 `Message` 显示内容。
        - 若值为 1 (或 true)：显示 `VERSION IS RELEASED` (绿色)。
        - 若值为 0 (或 false)：显示 `NO UNRELEASED VERSION EXISTS!` (可选黄色或默认色)。
4.  **关闭操作**：
    - 用户点击 [Close] 按钮。
    - 执行页面关闭逻辑（如 `window.close()` 或路由返回上一级）。

## 4. 接口定义 (API Specification)

### 4.1 UD06SelectHdocAdcaModification

- **功能**：获取文档修改后的状态信息，用于渲染 Save Modifications 页面。
- **Method**: `GET`
- **Endpoint**: `/api/UD06SaveModificationsApi/UD06SelectHdocAdcaModification`

#### Request Parameters

- `ChassisSerie`: String (Query Param, e.g., "JPCT")
- `ChassisNumber`: String (Query Param, e.g., "028321")

#### Response Success (200 OK)

```json
{
  "doctype": "DIM-PLATE",
  "version": "1",
  "storing": "SEAT_NO 4",
  "foundUnreleasedVersion": 1,
  "message": "VERSION IS RELEASED"
}
```

#### Response Error (400 Bad Request / 404 Not Found)

```json
{
  "msg": "无法加载修改状态，请重试"
}
```

2.  **UI 细节**：
    - `Message` Label 应根据后端返回的 `message` 字段动态设置样式。若包含 "RELEASED"，应用绿色样式类。

3.  **安全性**：
    - API 请求必须通过 HTTPS 发送。
    - 确保所有显示的数据仅用于展示，不包含可执行脚本。
