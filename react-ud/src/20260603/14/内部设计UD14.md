## 1. 背景 (Background)

本模块的核心功能是展示指定市场文件夹下的所有模板文件列表，支持用户查看文件名、大小、修改时间等信息，并可直接下载文件。

- **目标**：提供清晰的文件清单视图，标识哪些模板正在被系统规则使用（Used），并提供便捷的下载入口。
- **用户体验**：
  - 提供清晰的表格布局，便于浏览
  - 支持市场选择，实现数据分类展示
  - 文件名可点击下载，提升操作效率
  - "Used"列直观展示模板的使用状态

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

### 3.1 处理流程

1. **开始**：用户进入页面或改变"Select Market"选项。
2. **空值校验 (Frontend Check)**：
   - 若未选择市场：不加载数据，提示选择市场。
3. **API 调用**：
   - 调用 `POST /api/UD14SearchresultistApi/UD14SelectMarketmaster` 获取文件列表。
4. **结果处理**：
   - **成功**：渲染表格，显示 Filename, Used, Last Mod., Size。
   - **失败**：显示错误消息。

### 3.2 校验详细规格表

| No. |      检查时机      |     检查对象     |        检查条件         | 错误消息 (Message Content) |            动作             |
| :-: | :----------------: | :--------------: | :---------------------: | :------------------------: | :-------------------------: |
|  1  | Change Market/Load | Market Selection | `Value == null` OR `""` |        `请选择市场`        | 显示 ErrorMessage，清空表格 |
|  2  |    API Response    | Market Validity  |     `Status != 200`     |     `无法加载文件列表`     |      显示 ErrorMessage      |

## 4. 接口定义 (API Specification)

### 4.1 获取模板文件列表

- **功能**：获取指定市场的模板文件列表及使用状态
- **Method**: `POST`
- **Endpoint**: `/api/UD14SearchresultistApi/UD14SelectMarketmaster`

#### Request Body

```json
{
  "market": "AUT"
}
```

#### Response Success (200)

```json
{
  "code": 200,
  "msg": "查询成功",
  "data": [
    {
      "filename": ".m003432.txt",
      "used": true,
      "lastModified": "2022-01-10 18:29",
      "size": "317 Kb"
    },
    {
      "filename": ".m003432.txt.170629.backup",
      "used": false,
      "lastModified": "2017-06-29 16:50",
      "size": "377 Kb"
    }
  ]
}
```

### 4.2 下载模板文件

- **功能**：下载指定市场的指定模板文件
- **Method**: `GET`
- **Endpoint**: `/api/UD14SearchresultistApi/UD14DownloadFile`

#### Request Parameters (Query)

```
?market=AUT&filename=.m003432.txt
```

#### Response Success

- Content-Type: `application/octet-stream`
- Content-Disposition: `attachment; filename=".m003432.txt"`
- Body: File Stream

## 5. 异常处理 (Exception Handling)

| 异常场景          | 处理方式           | Message 显示内容               |
| :---------------- | :----------------- | :----------------------------- |
| **网络断开/超时** | 捕获 Network Error | `无法加载文件列表，请稍后重试` |
| **市场不存在**    | 捕获 API 错误      | `市场不存在`                   |
| **文件无法访问**  | 捕获 API 错误      | `无法访问文件`                 |

## 6. 实现注意事项 (Implementation Notes)

1. **状态管理**：
   - 使用 React State 管理 `selectedMarket`, `fileList`, `isLoading`, `errorMessage`。
   - 当 `selectedMarket` 变化时，触发 `useEffect` 重新获取数据。
2. **UI 细节**：
   - Market 下拉框与表格在同一卡片内。
   - Used 列：`true` 显示绿色 "✓"，`false` 显示 "-"。
   - 点击 Filename 触发文件下载。
   - 空状态时表格显示 "暂无数据"。
3. **安全性**：
   - 后端在处理 filename 参数时，必须校验文件是否确实位于该 market 对应的目录下。
