## 1. 背景 (Background)

本模块的核心功能是展示指定市场文件夹下的所有模板文件列表，支持用户查看文件名、大小、修改时间等信息，并可直接下载文件。该页面用于管理与检索存储在服务器上的模板文件，确保用户能够快速定位并获取所需资源。

- **目标**：提供清晰的文件清单视图，标识哪些模板正在被系统规则使用（Used），并提供便捷的下载入口。
- **安全性**：
  - 仅允许授权用户访问此页面。
  - 下载链接需验证权限，且不直接暴露服务器物理路径，防止目录遍历攻击。
  - 所有通信使用 HTTPS 加密。
- **用户体验**：
  - 提供清晰的表格布局，便于浏览。
  - 支持市场选择，实现数据分类展示。
  - 文件名可点击下载，提升操作效率。
  - “Used”列直观展示模板的使用状态。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

### 3.1 处理流程

1.  **开始**：用户进入页面或改变“Select Market”选项。
2.  **前置处理**：
    - 若页面初始化，默认不加载数据或加载默认市场（依产品定义，Prompt 指出“未选择市场且提交”才报错，暗示可能是手动触发查询或Change事件触发）。此处假设选择市场后自动触发查询，或有一个隐含的“Search”动作。根据 Prompt 5.1.1，若未选择市场则阻止加载。
3.  **空值校验 (Frontend Check)**：
    - 若 `Select Market` 为空：设置 `ErrorMessage` = `请选择市场`，**终止**API调用。
4.  **API 调用 (Backend Check)**：
    - 调用 `GET /api/templates/list?market={market}` 获取文件列表及元数据（含 Used 状态）。
    - _(注：Prompt 中提到了两个接口 `/templates/list` 和 `/rules/used`。为了性能优化，建议后端合并为一个接口返回完整数据；若必须分开，前端需并行调用并合并数据。以下设计基于合并后的理想接口，或前端分别调用后组装)_。
5.  **结果处理**：
    - **成功**：渲染表格，显示 Filename, Used, Last Mod., Size。
    - **失败**：显示错误消息（如“市场不存在”、“无法加载文件列表”）。

## 4. 接口定义 (API Specification)

### 4.1 Get Template List (获取模板列表)

_注：建议将此接口设计为包含“Used”状态，以减少前端请求次数。_

- **功能**：获取指定市场的模板文件列表及其使用状态。
- **Method**: `GET`
- **Endpoint**: `/api/templates/list`

#### Request Parameters (Query)

```text
?market=AUT
```

#### Response Success (200 OK)

```json
{
  "data": [
    {
      "filename": ".m003432.txt",
      "used": true,
      "lastModified": "2022-01-10 18:29",
      "size": "317 Kb",
      "downloadUrl": "/api/templates/download/.m003432.txt?market=AUT"
    },
    {
      "filename": ".m003432.txt.170629.backup",
      "used": false,
      "lastModified": "2017-06-29 16:50",
      "size": "377 Kb",
      "downloadUrl": "/api/templates/download/.m003432.txt.170629.backup?market=AUT"
    }
  ]
}
```

#### Response Error (404 Not Found)

```json
{
  "error": "Not Found",
  "message": "Market not found"
}
```

### 4.2 Download Template (下载文件 - 辅助接口)

- **功能**：下载指定市场的指定模板文件。
- **Method**: `GET`
- **Endpoint**: `/api/templates/download/{filename}`

#### Request Parameters (Query)

```text
?market=AUT
```

#### Response Success (200 OK)

- Content-Type: `application/octet-stream`
- Content-Disposition: `attachment; filename="{filename}"`
- Body: [File Stream]

#### Response Error (403 Forbidden)

```json
{
  "error": "Forbidden",
  "message": "您没有权限下载此文件"
}
```

## 6. 实现注意事项 (Implementation Notes)

1.  **状态管理**：
    - 使用 React State 管理 `selectedMarket`, `fileList`, `loading`, `errorMessage`。
    - 当 `selectedMarket` 变化时，触发 `useEffect` 重新获取数据。
2.  **UI 细节**：
    - **表格排序**：默认按文件名升序排列。
    - **Used 列展示**：若 `used === true`，可显示绿色对勾图标或文本“Yes”；若 `false`，显示“-”或留空。
    - **下载交互**：点击 Filename 时，直接使用 `window.location.href = record.downloadUrl` 或创建隐藏的 `<a>` 标签点击触发下载，避免跳转页面。
    - **空状态**：若某市场下无文件，表格显示“暂无数据”。
3.  **安全性**：
    - **路径遍历防护**：后端在处理 `filename` 参数时，必须校验文件是否确实位于该 `market` 对应的目录下，严禁直接使用用户传入的路径拼接文件地址。
    - API 请求必须通过 HTTPS 发送。
4.  **性能优化**：
    - 若文件列表较大，考虑前端分页或虚拟滚动。
    - “Used”状态的判断若涉及复杂数据库查询，建议后端缓存该状态或定期更新标记文件。
