2. 背景 (Background)
  本模块的核心功能是提供对 HDoc 系统用户的权限配置与管理。用户可通过输入 User ID，从 Saviynt 系统获取用户基本信息，并查询其在 HDoc 中的现有权限，支持更新或删除角色配置。

  面向的用户群体：
  - 系统管理员
  - IT 运维人员
  - 安全管理人员

  用户体验方面的考虑：
  - 界面简洁，突出核心操作区域
  - 支持快速输入与权限查看
  - 所有操作均有明确反馈提示
  - 权限项以复选框形式展示，便于选择

  安全性或特殊要求：
  - 仅允许授权用户访问此页面
  - 所有权限变更需确认
  - 数据更新由后端统一控制，防止并发冲突
  - 所有通信使用 HTTPS 加密
  - 用户信息从 Saviynt 获取，确保一致性

4. 功能描述 (Functional Description)

    4.1 用户信息获取功能
    功能说明：输入用户 ID 后点击“USER INFO”按钮，从 Saviynt 系统获取用户姓名，并查询其在 HDoc 中的已有权限。
    操作步骤：
      1. 用户在 UserID 字段中输入用户 ID（如 v0c6900）
      2. 点击“USER INFO”按钮
      3. 系统调用后台接口获取用户姓名
      4. 同时查询 DOC_MARKET_AUTH 和 HDOC_FUNCTION_AUTH 表获取权限数据
      5. 成功后显示用户姓名，并勾选已有的权限项
      6. 若用户不存在，则显示错误消息：“We didn't recognize the userid you entered. Please try again.”

    4.2 更新角色功能
    功能说明：用户选择权限后点击“Update Role”按钮，将权限配置写入数据库。
    操作步骤：
      1. 用户勾选需要的权限项
      2. 点击“Update Role”按钮
      3. 系统校验输入合法性
      4. 若通过，则调用接口更新权限表
      5. 成功后提示：“权限更新成功”

    4.3 删除角色功能
    功能说明：点击“Delete Role”按钮，清空该用户下所有权限数据。
    操作步骤：
      1. 用户点击“Delete Role”按钮
      2. 弹出确认对话框：“确定要删除该用户的所有权限吗？”
      3. 用户确认后，系统调用接口执行删除
      4. 成功后提示：“权限已清除”，并重置所有复选框

5. 业务逻辑与校验规则 (Business Logic & Checks)

   5.1 处理流程

      开始：用户点击 USER INFO / Update Role / Delete Role 按钮
      前置处理：获取 userID 参数

      5.1.1 空值校验等 (Frontend Check)：
       若点击 USER INFO 且 userID 为空：
        设置Message = “请输入用户 ID”
        终止流程

      5.1.2 API调用 (Backend Check)：
        调用 `GET /api/UD17HDocUserAdministration​​Api/UD17Userinfo` 获取用户信息
        调用 `PUT /api/UD17HDocUserAdministration​​Api/UD17UpdateRole` 更新权限
        调用 `DELETE /api/UD17HDocUserAdministration​​Api/UD17DeleteRole` 删除权限

   5.2 结果处理：
       成功：显示提示消息“操作成功”
       失败：显示错误消息“操作失败，请稍后重试”

   5.3 校验详细规格表

   | No. | 检查时机 | 检查对象 | 检查条件 | 错误消息 (Message Content) | 动作 |
   |-----|---------|---------|---------|--------------------------|------|
   | 1   | 点击 USER INFO | UserID | 为空 | “请输入用户 ID” | 阻止提交 |
   | 2   | 查询用户信息 | UserID | 不存在 | “We didn't recognize the userid you entered. Please try again.” | 显示错误 |
   | 3   | 更新权限 | 用户权限 | 无变更 | “未发现权限变更” | 提示用户 |
