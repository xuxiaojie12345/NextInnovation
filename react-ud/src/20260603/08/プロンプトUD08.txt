 2. 背景 (Background)

 核心功能与目标  
本模块用于管理系统中的认证参数（Homologation Variables），支持对用户定义规则的查询、新增、修改和删除操作。主要功能包括：
- 提供灵活的查询条件输入界面
- 支持数据的增删改查（CRUD）操作
- 确保数据完整性，防止重复或无效记录
- 所有操作均记录创建/更新时间及用户信息

 面向用户群体  
- 系统管理员  
- 车辆合规工程师  
- 数据维护人员  

 用户体验考虑  
- 查询条件清晰排列，关键字段带星号标识必填项
- 操作按钮集中放置于顶部，便于快速访问
- 输入框长度合理，避免内容截断
- 支持实时校验，减少提交错误

 安全性要求  
- `Product class`、`Number`、`Market` 组合为主键，禁止重复
- `Variable` 必须存在于 `HDOC_VARIABLES` 表中
- 所有写入操作需验证权限（由后端控制）
- 自动记录 `Created by user` 和 `Date` 字段，不可手动编辑

 4. 功能描述 (Functional Description)

 4.1 查询认证参数

功能说明：  
根据输入的查询条件，检索符合条件的认证参数记录。

操作步骤：
1. 用户在“Product class”、“Number”、“Market”等字段中输入查询条件。
2. 点击“Search”按钮。
3. 系统执行前端校验，确保必填项不为空。
4. 调用后端 API 进行查询。
5. 成功后跳转至“认证参数查询结果页”，展示匹配记录列表。

 4.2 清空输入内容

功能说明：  
清除所有已输入的查询条件，恢复初始状态。

操作步骤：
1. 用户点击“Clear”按钮。
2. 系统清空所有文本框和下拉选择项。
3. 所有字段重置为默认值（空）。

 4.3 新增认证参数

功能说明：  
录入新的认证参数，并保存至数据库。

操作步骤：
1. 用户填写“Product class”、“Number”、“Market”等必填字段。
2. 填写可选字段如 `Variable`、`Value`、`Comments` 等。
3. 点击“Add”按钮。
4. 系统执行校验：
   - 检查主键是否重复
   - 检查 `Variable` 是否有效
5. 若通过，调用 `POST /api/UD08HomologationVariablesApi/UD08Add` 接口。
6. 成功后提示“添加成功”，并刷新页面或跳转至列表页。

 4.4 编辑并更新认证参数

功能说明：  
修改现有认证参数记录。

操作步骤：
1. 用户在查询结果中选择一条记录，进入编辑模式。
2. 修改任意字段（如 `Value`、`Comments`）。
3. 点击“Update”按钮。
4. 系统校验数据有效性。
5. 调用 `POST /api/UD08HomologationVariablesApi/UD08Update` 接口。
6. 成功后提示“更新成功”。

 4.5 删除认证参数

功能说明：  
删除指定的认证参数记录。

操作步骤：
1. 用户在查询结果中选择一条记录。
2. 点击“Delete”按钮。
3. 系统弹出确认对话框：“确定要删除该记录吗？”
4. 用户确认后，调用 `DELETE /api/UD08HomologationVariablesApi/UD08Delete` 接口。
5. 成功后提示“删除成功”。

5. 业务逻辑与校验规则 (Business Logic & Checks)

   5.1 处理流程

      开始：用户点击 Search / Add / Update / Delete 按钮
      前置处理：验证会话有效性，检查权限

      5.1.1 空值校验等 (Frontend Check)：
       若点击 Add 或 Update 且 Product class、Number、Market 任一为空：
        设置Message = “Product class, Number, Market 是必填项”
        终止流程

       若点击 Delete 但未选中任何记录：
        设置Message = “请选择要删除的记录”
        终止流程

      5.1.2 API调用 (Backend Check)：
                调用 `GET /UD08HomologationVariablesApi/UD08SelectProductclassmaster` 获取查询结果
                调用 `GET /UD08HomologationVariablesApi/UD08SelectMarketmaster` 获取查询结果
                调用 `GET /UD08HomologationVariablesApi/UD08SelectHdocvariables` 获取查询结果
        调用 `POST /UD08HomologationVariablesApi/UD08Add` 添加新记录
        调用 `POST /UD08HomologationVariablesApi/UD08Update` 更新记录
        调用 `DELETE /UD08HomologationVariablesApi/UD08Delete` 删除记录

   5.2 结果处理：
       成功：显示提示消息“操作成功”
       失败：显示错误消息“操作失败，请稍后重试”

   5.3 校验详细规格表

   | No. | 检查时机 | 检查对象 | 检查条件 | 错误消息 (Message Content) | 动作 |
   |-----|---------|---------|---------|--------------------------|------|
   | 1   | Add 操作前 | Product class | 为空 | “Product class 是必填项” | 阻止提交 |
   | 2   | Add 操作前 | Number | 为空 | “Number 是必填项” | 阻止提交 |
   | 3   | Add 操作前 | Market | 为空 | “Market 是必填项” | 阻止提交 |
   | 4   | Add 操作时 | Variant | 不存在于 HDOC_VARIABLES | “Variant does not exist, Please enter the correct content” | 返回错误 |
   | 5   | Update 操作时 | Record | 不存在 | “Data does not exist, Please enter the correct content” | 返回错误 |
   | 6   | Delete 操作时 | Record | 不存在 | “Data does not exist, Please enter the correct content” | 返回错误 |
