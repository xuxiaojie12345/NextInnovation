2. 背景 (Background)
  本模块的核心功能是配置用户对各类认证文档的操作权限。用户可通过输入 User ID，从 Saviynt 系统获取用户名，并查询其在 HDoc 中可分配的文档权限列表。系统支持勾选多个文档类型并提交更新，确保权限配置准确且安全。

  面向的用户群体：
  - 系统管理员
  - IT 运维人员
  - 安全管理人员

  用户体验方面的考虑：
  - 界面简洁，突出核心操作区域
  - 支持快速输入与权限查看
  - 所有操作均有明确反馈提示
  - 权限项以复选框形式展示，便于选择

  安全性或特殊要求：
  - 仅允许授权用户访问此页面
  - 所有权限变更需确认
  - 数据更新由后端统一控制，防止并发冲突
  - 所有通信使用 HTTPS 加密
  - 用户信息从 Saviynt 获取，确保一致性

4. 功能描述 (Functional Description)

    4.1 初期表示
    功能说明：画面初期表示的时候，画面信息全部表示。
    操作步骤：
      1. 画面初期表示的时候
      2. 调用接口“GET /api/UD18HDocUserDocAdministrationApi/UD20SelectHdocDocumentList”，取得HDOC_DOCUMENT_LIST表信息。
      3. 取得信息全部展示在画面上。

    4.2 用户信息获取功能
    功能说明：输入用户 ID 后点击“User Info”按钮，校验该用户是否存在于用户功能权限表，并同步从 Saviynt 获取用户名。
    操作步骤：
      1. 用户在 UserID 字段中输入用户 ID（如 a420064）
      2. 点击“User Info”按钮
      3. 系统先校验该 UserID 是否存在于 HDOC_FUNCTION_AUTH 表
      4. 若存在，则调用 Saviynt 接口（AuthenticationApi）获取用户姓名
      5. 查询 HDOC_DOCUMENT_LIST 表获取所有可分配文档
      6. 成功后显示用户姓名，并将文档列表渲染为可勾选的文本区域
      7. 若用户不存在，则显示错误消息：“We didn't recognize the userid you entered. Please try again.”

    4.3 权限更新功能
    功能说明：用户选择文档权限后点击“Update”按钮，将权限配置写入数据库。
    操作步骤：
      1. 用户在 Document 区域中勾选需要的文档类型
      2. 点击“Update”按钮
      3. 系统再次校验 UserID 是否存在于 HDOC_FUNCTION_AUTH 表
      4. 若通过，则调用接口（/api/UD18HDocUserDocAdministrationApi/UD18SelectHdocUserDoc，UD18DeleteHdocUserDoc，UD18CreateHdocUserDoc，UD18SelectHdocFunctionAuth）更新 HDOC_USER_DOC 表
      5. 成功后提示：“权限更新成功”

5. 业务逻辑与校验规则 (Business Logic & Checks)

   5.1 处理流程

      开始：用户点击 User Info / Update 按钮
      前置处理：获取 userID 参数

      5.1.1 空值校验等 (Frontend Check)：
       若点击 User Info 且 userID 为空：
        设置Message = “请输入用户 ID”
        终止流程

      5.1.2 API调用 (Backend Check)：
        调用 `GET /api/UD18HDocUserDocAdministrationApi/UD20SelectHdocDocumentList` 初期表示
        调用 `GET /api/AuthenticationApi/Login` 「User Info」按钮按下
        调用 `PUT /api/UD18HDocUserDocAdministrationApi/UD18SelectHdocUserDoc` 更新权限
        调用 `PUT /api/UD18HDocUserDocAdministrationApi/UD18DeleteHdocUserDoc` 更新权限
        调用 `PUT /api/UD18HDocUserDocAdministrationApi/UD18CreateHdocUserDoc` 更新权限
        调用 `PUT /api/UD18HDocUserDocAdministrationApi/UD18SelectHdocFunctionAuth` 更新权限

   5.2 结果处理：
       成功：显示提示消息“操作成功”
       失败：显示错误消息“操作失败，请稍后重试”

   5.3 校验详细规格表

   | No. | 检查时机 | 检查对象 | 检查条件 | 错误消息 (Message Content) | 动作 |
   |-----|---------|---------|---------|--------------------------|------|
   | 1   | 点击 User Info | UserID | 为空 | “请输入用户 ID” | 阻止提交 |
   | 2   | 查询用户信息 | UserID | 不存在于 HDOC_FUNCTION_AUTH | “We didn't recognize the userid you entered. Please try again.” | 显示错误 |
   | 3   | 点击 Update | UserID | 不存在于 HDOC_FUNCTION_AUTH | “We didn't recognize the userid you entered. Please try again.” | 显示错误 |

7. 异常处理 (Exception Handling)

|---------|---------|----------------|
| 网络超时 | 重试一次，若仍失败则提示 | “网络连接失败，请检查网络设置” |
| 用户不存在 | 返回错误响应 | “We didn't recognize the userid you entered. Please try again.” |
