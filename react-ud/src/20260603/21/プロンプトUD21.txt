2. 背景 (Background)
  本模块的核心功能是展示 HDoc 系统中所有市场的基础信息列表，包括市场代码、描述以及是否支持重量数据（Weights from Hdoc）。该页面用于提供市场配置的概览，支持用户快速查阅各市场的属性。

  面向的用户群体：
  - 系统管理员
  - 生产工程师
  - 认证管理人员

  用户体验方面的考虑：
  - 表格布局清晰，便于浏览
  - 支持排序与筛选（如按市场代码）
  - 所有字段均来自数据库，确保一致性
  - 不提供编辑功能，仅为只读展示

  安全性或特殊要求：
  - 仅允许授权用户访问此页面
  - 所有通信使用 HTTPS 加密
  - 不暴露敏感信息
  - 数据来源为 `MARKET_MASTER` 表，确保准确性

4. 功能描述 (Functional Description)

    4.1 市场列表展示功能
    功能说明：从 `MARKET_MASTER` 表中加载并展示所有市场的基础信息。
    操作步骤：
      1. 用户进入 HDoc 系统市场列表页面
      2. 系统调用 `GET /api/market/list` 接口获取所有市场数据
      3. 将 Market、Description、Weights from Hdoc 字段渲染为表格
      4. 显示在页面中央区域

6. 接口定义 (API Specification)

   GET /api/market/list
     功能：获取所有市场列表
     Method：GET
     Endpoint：/api/market/list

     Request [请求格式]
     无参数

     Response Success (200)
     [
       {
         "market": "AUT",
         "description": "Austria",
         "weightsFromHdoc": true
       },
       {
         "market": "BEL",
         "description": "Belgium",
         "weightsFromHdoc": true
       },
       {
         "market": "CHE",
         "description": "Switzerland",
         "weightsFromHdoc": true
       }
     ]

     Response Error (500)
     {
       "error": "Internal Server Error",
       "message": "Failed to load market list"
     }
