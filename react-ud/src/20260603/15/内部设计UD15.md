## 1. 背景 (Background)

本模块的核心功能是提供对车辆铭牌（VIN Plate）数据的查询与状态管理。用户可通过输入底盘编号（Chassis number）来查看对应车辆的铭牌详情，并执行重新生成、确认完成、切换版本等操作，支持生产流程中的状态控制。

- **目标**：实现 VIN Plate 生命周期的关键节点控制（重置、完成、类型切换），并提供快速查询入口。
- **用户体验**：
  - 界面简洁，突出核心操作按钮。
  - 支持快速输入与状态变更。
  - 所有操作均有明确的成功/失败反馈提示。
  - 操作逻辑清晰，避免误操作（如空值拦截）。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

所有校验逻辑均在用户点击任意操作按钮时执行。

### 3.1 处理流程

1. **开始**：用户点击任意按钮。
2. **前置处理**：获取 `Chassis number` 输入值。
3. **空值校验 (Frontend Check)**：
   - 若 `Chassis number` 为空：设置 `ErrorMessage` = `Please enter a chassis number.`，**终止**流程。
4. **点击View Info按钮**：
   - VIN　Plate的详细情报显示。
5. **点击Set Regenerate按钮**：
   - 该条数据的Chassisの状态更新为 0。
6. **点击Set OK按钮**：
   - 该条数据的Chassisの状态更新成1。
7. **点击Change to Basic Info按钮**：
   - 该条数据的Chassisの状态更新成0，TYPE更新为1。
8. **点击Change to Advanced Info按钮**：
   - 该条数据的Chassisの状态更新成0，TYPE更新为2。
9. **API 调用**：
   - **View Info**: `GET /api/UD15SelecthdocsenddatavinplateApi/UD15ViewInfo?chassisNumber=XXX`
   - **Set Regenerate**: `POST /api/UD15SelecthdocsenddatavinplateApi/UD15SetRegenerate`
   - **Set OK**: `POST /api/UD15SelecthdocsenddatavinplateApi/UD15SetOK`
   - **Change to Basic Info**: `POST /api/UD15SelecthdocsenddatavinplateApi/UD15ChangetoBasicInfo`
   - **Change to Advanced Info**: `POST /api/UD15SelecthdocsenddatavinplateApi/UD15ChangetoAdvancedInfo`
10. **结果处理**：
    - **View Info 成功**：跳转页面显示详情（当前页切换至详情视图或弹窗）。
    - **View Info 失败 (404)**：显示 `Chassis number XXX not found.`。
    - **Update 成功**：显示成功消息，清空输入框。
    - **Update 失败**：显示后端返回的错误消息。

### 3.2 校验详细规格表

| No. |   检查时机   |     检查对象      |                检查条件                |    错误消息 (Message Content)    |            动作             |
| :-: | :----------: | :---------------: | :------------------------------------: | :------------------------------: | :-------------------------: |
|  1  |  Click Any   |  Chassis Number   | `Value == null` OR `Trim(Value) == ""` | `Please enter a chassis number.` | 显示 ErrorMessage，焦点停留 |
|  2  | API Response | Chassis Existence |            `Status == 404`             | `Chassis number XXX not found.`  |      显示 ErrorMessage      |

## 4. 接口定义 (API Specification)

### 4.1 View Info

- **功能**：获取指定底盘的车辆铭牌信息。
- **Method**: `GET`
- **Endpoint**: `/api/UD15SelecthdocsenddatavinplateApi/UD15ViewInfo`

#### Request Parameters (Query)

```
?chassisNumber=JPCT%20013945
```

#### Response Success (200)

```json
{
  "chassisNumber": "JPCT 013945",
  "plateType": 1,
  "status": 0,
  "registerDateTime": "2022-01-10 18:29",
  "docReady": true,
  "sentToCABFactory": false,
  "printItems": ["AXLE_CONF", "WB_MM"],
  "vpData": {
    "variantName": "E2-OMEGA",
    "value": "1234"
  }
}
```

#### Response Error (404)

```json
{
  "error": "Not Found",
  "message": "Chassis number JPCT 013945 not found."
}
```

## 5. 异常处理 (Exception Handling)

| 异常场景           | 处理方式           | Message 显示内容                 |
| :----------------- | :----------------- | :------------------------------- |
| **底盘编号为空**   | 前端校验           | `Please enter a chassis number.` |
| **底盘编号不存在** | API 返回 404       | `Chassis number XXX not found.`  |
| **网络断开/超时**  | 捕获 Network Error | `网络连接失败，请检查网络设置`   |

## 6. 实现注意事项 (Implementation Notes)

1. **状态管理**：
   - 使用 React State 管理 `chassisInput`, `errorMessage`, `successMessage`, `isLoading`, `vinPlateInfo`。
   - `isLoading` 用于在 API 请求期间禁用所有按钮。
2. **交互细节**：
   - **View Info**：成功响应后，在当前页显示铭牌详情信息（Chassis number, Plate type, Status 等标签）。
   - **Update 操作**：成功响应后显示成功消息，并可清空输入框。
   - **Error Display**：每次新操作开始时清空之前的错误/成功消息。
3. **UI 布局**：
   - 输入框与按钮组放置于页面上方。
   - 详情信息区域在 View Info 成功后显示。
