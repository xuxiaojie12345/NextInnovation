2. 背景 (Background)
  本模块的核心功能是展示系统中所有可用的文档类型（Document Types）列表，包括其键值（Key）和描述（Description）。该页面用于提供文档类型的参考信息，支持用户在生成或配置文档时选择正确的类型。

  面向的用户群体：
  - 系统管理员
  - 生产工程师
  - 认证管理人员

  用户体验方面的考虑：
  - 表格布局清晰，便于浏览
  - 支持排序与筛选（如按 Key）
  - 所有字段均来自数据库，确保一致性
  - 不提供编辑功能，仅为只读展示

  安全性或特殊要求：
  - 仅允许授权用户访问此页面
  - 所有通信使用 HTTPS 加密
  - 不暴露敏感信息
  - 数据来源为 `HDOC_DOCUMENT_LIST` 表，确保准确性

4. 功能描述 (Functional Description)

    4.1 文档类型列表展示功能
    功能说明：从 `HDOC_DOCUMENT_LIST` 表中加载并展示所有文档类型的键值与描述。
    操作步骤：
      1. 用户进入 Document Types 页面
      2. 系统调用 `GET /api/document/types` 接口获取所有文档类型数据
      3. 将 Key 和 Description 字段渲染为表格
      4. 显示在页面中央区域

5. 业务逻辑与校验规则 (Business Logic & Checks)

   5.1 处理流程

      开始：用户访问此页面

      5.1.1 空值校验等 (Frontend Check)：
       无前端校验，直接加载数据

      5.1.2 API调用 (Backend Check)：
        调用 `GET /api/document/types` 获取文档类型列表

   5.2 结果处理：
       成功：正常渲染表格
       失败：显示错误消息：“无法加载文档类型列表，请稍后重试”

6. 接口定义 (API Specification)

   GET /api/document/types
     功能：获取所有文档类型列表
     Method：GET
     Endpoint：/api/document/types

     Request [请求格式]
     无参数

     Response Success (200)
     [
       {
         "key": "VIN-PLATE",
         "description": "VIN Plate (weight calculation performed)"
       },
       {
         "key": "VIN-PL2",
         "description": "VIN Plate (NO weight calculation performed). Only fetch data from VDA, use this option for re-production of VIN plate."
       },
       {
         "key": "DIM-PLATE",
         "description": "Dimension Plate (weight calculation performed)"
       }
     ]

     Response Error (500)
     {
       "error": "Internal Server Error",
       "message": "Failed to load document types"
     }
