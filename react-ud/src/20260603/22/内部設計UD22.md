## 1. 背景 (Background)

本模块的核心功能是展示系统中所有可用的文档类型（Document Types）列表，包括其键值（Key）和描述（Description）。该页面用于提供文档类型的参考信息，支持用户在生成或配置文档时选择正确的类型。

- **目标**：以只读表格形式呈现文档类型主数据，便于用户快速浏览和检索文档类型信息。
- **面向的用户群体**：
  - 系统管理员
  - 生产工程师
  - 认证管理人员
- **用户体验**：
  - 表格布局清晰，便于浏览
  - 支持排序与筛选（如按 Key）
  - 所有字段均来自数据库，确保一致性
  - 不提供编辑功能，仅为只读展示
- **安全性**：
  - 仅允许授权用户访问此页面
  - 所有通信使用 HTTPS 加密
  - 不暴露敏感信息
  - 数据来源为 `HDOC_DOCUMENT_LIST` 表，确保准确性

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

所有逻辑均在页面加载时自动执行。

### 3.1 处理流程

1.  **开始**：初期表示。
2.  **前置处理**：无。
3.  **空值校验 (Frontend Check)**：
    - 无前端校验，直接加载数据。
4.  **API 调用 (Backend Check)**：
    - 调用 `GET /api/document/types` 获取文档类型列表。
5.  **结果处理**：
    - **成功**：正常渲染表格，显示 Key、Description 字段。
    - **失败**：显示错误消息：「无法加载文档类型列表，请稍后重试」。

### 3.2 校验详细规格表

| No. |  检查时机  |      检查对象      |    检查条件    |      错误消息 (Message Content)      |     动作     |
| :-: | :--------: | :----------------: | :------------: | :----------------------------------: | :----------: |
|  1  | 页面加载时 | HDOC_DOCUMENT_LIST | 数据库连接失败 | 「无法加载文档类型列表，请稍后重试」 | 显示错误信息 |

## 4. 接口定义 (API Specification)

### 4.1 获取文档类型列表接口

- **功能**：获取所有文档类型列表。
- **Method**: `GET`
- **Endpoint**: `/api/document/types`

#### Request

无参数。

#### Response Success (200 OK)

```json
[
  {
    "key": "VIN-PLATE",
    "description": "VIN Plate (weight calculation performed)"
  },
  {
    "key": "VIN-PL2",
    "description": "VIN Plate (NO weight calculation performed). Only fetch data from VDA, use this option for re-production of VIN plate."
  },
  {
    "key": "DIM-PLATE",
    "description": "Dimension Plate (weight calculation performed)"
  }
]
```

#### Response Error (500 Internal Server Error)

```json
{
  "error": "Internal Server Error",
  "message": "Failed to load document types"
}
```

## 5. 异常处理 (Exception Handling)

| 异常场景                 | 处理方式                 | Message 显示内容                     |
| :----------------------- | :----------------------- | :----------------------------------- |
| **网络超时**             | 重试一次，若仍失败则提示 | 「网络连接失败，请检查网络设置」     |
| **数据库异常**           | 回滚事务，记录日志       | 「系统繁忙，请稍后再试」             |
| **服务器内部错误 (500)** | 捕获 Server Error        | 「无法加载文档类型列表，请稍后重试」 |

## 6. 实现注意事项 (Implementation Notes)

1.  **状态管理**：
    - 使用 React State 管理 `documentTypes`（文档类型列表数据）、`isLoading`（加载状态）、`errorMessage`（错误消息）。
    - 页面初始化时自动触发数据加载。
2.  **加载状态**：
    - 数据加载期间应显示 Loading 指示器（如 Spin 或 Skeleton），提升用户体验。
3.  **错误处理**：
    - API 调用失败时，页面中央显示错误消息，并提供重试按钮或提示用户刷新页面。
4.  **UI 细节**：
    - 表格建议支持按 Key 列排序，便于用户快速查找特定文档类型。
    - Description 列内容可能较长，建议设置合适的列宽或支持文本折行显示。
5.  **性能**：
    - 若文档类型数据量较大，建议后端支持分页查询，前端表格配合分页控件。
