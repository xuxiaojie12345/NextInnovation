## 1. 背景 (Background)

本模块是 HDoc 系统的帮助导航主页，提供了通往各个帮助子模块的入口。主要功能包括跳转到快速指南下载页、文档类型列表页、市场信息页以及市场文档设置页。该画面旨在帮助用户快速定位所需的信息和支持资源。

- **目标**：以清晰的链接列表形式提供帮助文档导航入口，减少用户寻找帮助信息的时间。
- **面向的用户群体**：
  - 所有 HDoc 系统用户
  - 需要寻求帮助、了解系统功能或配置市场相关文档的用户
- **用户体验**：
  - 简洁导航：采用清晰的链接列表布局，减少用户寻找帮助信息的时间。
  - 一致性：保持与系统整体风格一致的 UI 设计，提供熟悉的交互体验。
  - 响应式：确保在不同设备上链接易于点击和阅读。
- **安全性**：
  - 访问控制：确保只有登录用户才能访问帮助文档，防止未授权访问内部资料。

## 3. 功能描述 (Functional Description)

### 3.1 帮助导航功能

功能说明：提供 HDoc 系统各帮助子模块的导航入口，用户通过点击链接跳转到对应页面。

操作步骤：

1. 用户进入 User Guide 帮助导航主页
2. 页面展示所有可用的帮助模块链接列表
3. 用户根据需要点击对应的链接
4. 系统通过前端路由跳转至目标页面

### 3.2 各导航入口说明

| 链接名称                       | 目标页面                        | 功能概要                 |
| ------------------------------ | ------------------------------- | ------------------------ |
| HDoc Quick Guide               | Download and Print Quick Guides | 快速入门指南的预览和下载 |
| List of document types.        | Document Types                  | 文档类型列表查看         |
| Markets in Hdoc                | Markets in Hdoc                 | 市场基础信息列表查看     |
| HDoc - Market Document Setting | Market Document Settings List   | 市场文档设置列表查看     |

## 4. 业务逻辑与校验规则 (Business Logic & Checks)

### 4.1 处理流程

#### 4.1.1 页面加载流程

开始：用户访问 User Guide 帮助导航主页

前置处理：验证用户登录状态

空值校验等 (Frontend Check)：

- 若用户未登录或 Token 失效：
  - 重定向至登录页
  - 终止流程

API调用 (Backend Check)：

- 无 API 调用，页面为静态导航页面

#### 4.1.2 链接跳转流程

开始：用户点击某个导航链接

前置处理：检测用户会话状态

空值校验等 (Frontend Check)：

- 若会话已过期：
  - 重定向至登录页
  - 终止流程

API调用 (Backend Check)：

- 无 API 调用，通过前端路由进行页面跳转

#### 4.1.3 结果处理

- 成功：页面跳转至目标帮助子页面
- 失败：显示错误消息「页面跳转失败，请稍后重试」

### 4.2 校验详细规格表

| No. | 检查时机   | 检查对象 | 检查条件           | 错误消息 (Message Content)           | 动作                 |
| --- | ---------- | -------- | ------------------ | ------------------------------------ | -------------------- |
| 1   | 页面加载时 | 用户会话 | Token 失效或未登录 | 「会话已过期，请重新登录」           | 重定向至登录页       |
| 2   | 点击链接时 | 路由跳转 | 路由跳转失败       | 「页面跳转失败，请稍后重试」         | 重定向至首页或错误页 |
| 3   | 页面加载时 | 网络连接 | 网络中断           | 「网络连接异常，请检查您的网络设置」 | 提示用户检查网络     |

## 5. 接口定义 (API Specification)

无。本页面为静态导航页面，不涉及后端 API 调用。

## 6. 异常处理 (Exception Handling)

| 异常场景         | 处理方式                               | Message 显示内容                     |
| ---------------- | -------------------------------------- | ------------------------------------ |
| **路由跳转失败** | 捕获前端路由错误，重定向至首页或错误页 | 「页面跳转失败，请稍后重试」         |
| **会话过期**     | 检测到 Token 失效，重定向至登录页      | 「会话已过期，请重新登录」           |
| **网络中断**     | 检测网络连接状态，提示用户检查网络     | 「网络连接异常，请检查您的网络设置」 |

## 7. 实现注意事项 (Implementation Notes)

1. **状态管理**：
   - 使用 React State 管理页面状态。
   - 页面为纯静态导航页，无需复杂状态管理。

2. **路由实现**：
   - 链接跳转建议使用前端路由（如 React Router）的 `Link` 或 `useNavigate` 实现。
   - 目标页面路径应在路由配置中预先定义。

3. **权限控制**：
   - 页面初始化时检测用户登录状态及 Token 有效性。
   - 未登录用户应被重定向至登录页面。

4. **UI 细节**：
   - 链接列表建议使用统一的列表样式（如 `<ul>` / `<li>`），保持视觉一致性。
   - 链接文字支持悬停（hover）高亮效果，提升交互反馈。
   - 页面布局应适配不同屏幕尺寸，确保链接在移动端也易于点击。

5. **可维护性**：
   - 导航链接列表建议通过配置文件驱动，便于后续增删改。
   - 链接的目标页面路径应集中管理，避免硬编码。
