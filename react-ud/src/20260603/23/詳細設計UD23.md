## 1. 背景 (Background)

本模块的核心功能是提供一系列快速入门指南（Quick Guides）的预览和下载功能。用户可以在页面上直接查看指南的缩略图，并点击链接下载对应的 PDF 或图片文件。此外，页面还区分了内网版本（Intranet version）和外部可用版本，并列出了当前不可用（非活性）的指南链接，以便用户了解系统支持的范围。

- **目标**：为用户提供直观的快速入门指南预览与下载入口，帮助用户快速上手 HDoc 系统各模块操作。
- **面向的用户群体**：
  - HDoc 系统的所有用户
  - 新用户或需要查阅特定模块操作手册的业务人员
  - 技术支持人员
- **用户体验**：
  - 可视化预览：通过展示图片（picture1-picture8），用户可以直观地识别所需的指南。
  - 清晰的分类：将可用的指南与不可用的指南分开显示，避免用户点击无效链接产生困惑。
  - 便捷的导航：提供「Back」链接，方便用户返回上一级帮助菜单。
  - 提示信息：在页面底部添加 Note，说明字体移除等技术细节，保持信息透明。
- **安全性**：
  - 文件访问权限：确保只有经过认证的用户才能下载内部指南文件。
  - 链接有效性：定期检查非活性链接的状态，若未来可用需及时更新前端状态。

## 3. 功能描述 (Functional Description)

### 3.1 快速入门指南预览功能

功能说明：在页面上展示各快速入门指南的缩略图（picture1-picture8），帮助用户直观识别所需指南。

操作步骤：

1. 用户进入 Download and Print Quick Guides 页面
2. 系统加载各指南的缩略图图片
3. 图片按顺序展示在页面中
4. 用户可浏览所有指南缩略图

### 3.2 指南文件下载功能

功能说明：用户点击活性链接下载对应的快速入门指南文件（PDF 或图片）。

操作步骤：

1. 用户点击某个活性指南链接（如「WIS Quick Guide」）
2. 系统触发对应图片文件（picture1）的下载
3. 浏览器开始下载文件
4. 下载完成后用户可在本地查看指南文件

### 3.3 返回导航功能

功能说明：用户点击「Back」链接返回上一级帮助菜单页面。

操作步骤：

1. 用户点击「Back」链接
2. 系统跳转至 HDoc Help 页面
3. 不保存当前页面状态

## 4. 业务逻辑与校验规则 (Business Logic & Checks)

### 4.1 处理流程

#### 4.1.1 页面加载流程

开始：用户访问 Download and Print Quick Guides 页面

前置处理：加载页面布局，准备显示所有指南缩略图和链接

空值校验等 (Frontend Check)：

- 无前端校验，直接加载页面内容

API调用 (Backend Check)：

- 无 API 调用，页面为静态内容展示

#### 4.1.2 文件下载流程

开始：用户点击活性指南链接

前置处理：检测链接状态

空值校验等 (Frontend Check)：

- 若链接状态为「非活性」：
  - 不执行任何操作
  - 终止流程

API调用 (Backend Check)：

- 无 API 调用，直接触发文件下载

#### 4.1.3 结果处理

- 成功：文件成功下载到本地
- 失败：显示错误消息「下载失败，请检查网络连接后重试」

### 4.2 校验详细规格表

| No. | 检查时机   | 检查对象   | 检查条件          | 错误消息 (Message Content)         | 动作                     |
| --- | ---------- | ---------- | ----------------- | ---------------------------------- | ------------------------ |
| 1   | 页面加载时 | 图片资源   | 图片加载失败      | 「图片加载失败」                   | 显示默认占位图或破碎图标 |
| 2   | 点击下载时 | 文件资源   | 文件下载失败      | 「下载失败，请检查网络连接后重试」 | 提示用户重试             |
| 3   | 点击链接时 | 用户权限   | 用户无访问权限    | 「您没有权限访问此资源」           | 禁用链接或提示           |
| 4   | 点击链接时 | 服务器资源 | 资源不存在（404） | 「请求的资源不存在」               | 返回 404 错误处理        |

## 5. 接口定义 (API Specification)

无。本页面为静态内容展示，不涉及后端 API 调用。

## 6. 异常处理 (Exception Handling)

| 异常场景             | 处理方式                               | Message 显示内容                   |
| -------------------- | -------------------------------------- | ---------------------------------- |
| **图片加载失败**     | 显示默认占位图或破碎图标               | 「图片加载失败」                   |
| **文件下载失败**     | 捕获网络错误，提示用户重试             | 「下载失败，请检查网络连接后重试」 |
| **链接访问受限**     | 检测用户权限，若无权限则禁用链接或提示 | 「您没有权限访问此资源」           |
| **服务器资源不存在** | 返回 404 错误处理                      | 「请求的资源不存在」               |

## 7. 实现注意事项 (Implementation Notes)

1. **状态管理**：
   - 使用 React State 管理各组件的显示状态。
   - 页面为纯静态展示，无需复杂状态管理。

2. **图片加载**：
   - 图片加载失败时，显示默认占位图，避免页面布局错乱。
   - 建议对图片进行懒加载（Lazy Loading），优化页面性能。

3. **链接控制**：
   - 非活性链接应显示为灰色或不可点击样式，视觉上区别于活性链接。
   - 活性链接点击后触发文件下载，可使用 `<a>` 标签的 `download` 属性实现。

4. **UI 细节**：
   - 每行建议使用「缩略图 + 下载链接 + 版本标识」的布局，保持整齐对齐。
   - 内网版本（Intranet version）使用 version 标签标注。
   - 页面底部的 Note 使用较小字号或斜体，作为辅助信息展示。

5. **可维护性**：
   - 指南列表建议通过配置文件或数据源驱动，便于后续增删改。
   - 链接的活性/非活性状态可通过配置字段控制，无需修改代码。
