## 1. 背景 (Background)

本模块是 VOLVO 公司内部工程数据库系统的主导航界面。用户在成功登录后进入此页面。

- **目标**：提供清晰的功能导航，将系统功能划分为"Generate"、"Admin"、"User Administration"和"Documentation"四大模块。渲染菜单项。作为系统操作的入口，点击菜单项触发相应的业务功能或页面跳转。
- **面向用户**：已登录的 VOLVO 内部员工、工程师、管理员及支持人员。
- **用户体验**：
  - 界面布局简洁，靠左对齐，顶部logo是蓝色背景，下面菜单树是浅灰色背景，纵向：整体大小大约占据屏幕的30%，靠左表示，符合阅读习惯。
  - 顶部蓝色底板配合白色 Logo，强化品牌识别度。
  - 使用 `»` 符号明确标识可点击的操作链接，视觉引导性强。
  - 模块化分组展示，便于用户快速定位所需功能。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

### 3.1 处理流程

#### 流程1: 菜单渲染

1. **开始**：用户从登录页跳转至本页面（Page OnMount）。
2. **前置处理**：无。
3. **菜单渲染逻辑**：
   - 遍历预定义的菜单结构。
   - 显示模块标题（Generate、Admin、User Administration、Documentation）及子菜单项。
4. **结果反馈**：显示模块标题及子菜单项。

#### 流程2: 功能导航跳转

1. **开始**：用户点击带有 `»` 符号的操作链接。
2. **前置处理**：无。
3. **执行跳转**：调用对应的后台服务接口或路由跳转。
4. **结果处理**：
   - **成功**：进入对应的功能子页面或执行后台任务（如弹出下载框）。
   - **失败**：显示错误信息。

## 4. 接口定义 (API Specification)

本模块无直接业务数据接口调用，主要为前端路由导航与菜单渲染。

## 5. 异常处理 (Exception Handling)

| 异常场景                 | 处理方式                           | Message 显示内容                               |
| :----------------------- | :--------------------------------- | :--------------------------------------------- |
| **会话过期 (401)**       | 捕获全局 Auth 错误，重定向至登录页 | `Session expired. Please login again.`         |
| **网络断开/超时**        | 捕获 Network Error                 | `Network error. Please check your connection.` |
| **服务器内部错误 (500)** | 捕获 Server Error                  | `System error. Please contact support.`        |

## 6. 实现注意事项 (Implementation Notes)

1. **状态管理**：
   - 使用 React State 管理 `user`（用户信息）、`isLoading`（加载状态）。
   - 从 `localStorage` 中读取 `user_info` 和 `auth_token` 进行会话校验。
2. **会话校验**：
   - 页面加载时（OnMount）检查 Token 是否存在及是否过期。
   - 若 Token 无效（401），重定向至登录页，显示 `Session expired. Please login again.`。
3. **UI 细节**：
   - 顶部 Header 使用蓝色背景底板，白色字体显示 "VOLVO" Logo。
   - 菜单区域使用浅灰色背景，靠左对齐。
   - 整体大小大约占据屏幕的 30%，纵向靠左表示。
   - `»` 符号建议使用 CSS pseudo-element (`::before`) 实现，便于统一样式管理。
   - 菜单项 hover 效果应明显，提升交互反馈。
4. **路由配置**：
   - 菜单项的点击事件通过 `useNavigate` 实现路由跳转，路径根据各子模块的 Route 配置映射。
5. **性能优化**：
   - 菜单结构相对静态，可考虑使用 `React.memo` 避免不必要的重渲染。
