## 1. 背景 (Background)

本模块是 VOLVO 公司内部工程数据库系统（EDB）的主导航界面。用户在成功登录后进入此页面。

- **目标**：提供清晰的功能导航，将系统功能划分为“Generate Document”、“User Administration”、“Archive”和“Documentation”四大模块，渲染菜单项。
- **安全性**：-。
- **用户体验**：
  - 界面布局简洁，靠左对齐，符合阅读习惯。
  - 顶部蓝色底板配合白色 Logo，强化品牌识别度。
  - 使用 `»` 符号明确标识可点击的操作链接，视觉引导性强。
  - 模块化分组展示，便于用户快速定位所需功能。

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

### 3.1 处理流程

1.  **开始**：用户从登录页跳转至本页面（OnMount）。
2.  **前置处理**：
    - 获取本地存储或上下文中的当前用户对象 `CurrentUser` 及其权限列表 `Permissions`。
    - 若 `CurrentUser` 不存在或 Token 过期，重定向至登录页。
3.  **菜单渲染逻辑**：
    - 遍历预定义的菜单结构树。
    - 则渲染该菜单项；否则跳过。
4.  **交互处理**：
    - 用户点击具体的菜单操作项（如 `Generate Doc`）。
    - 系统执行路由跳转或调用后台服务。

### 3.2 校验详细规格表

| No. |  检查时机  |     检查对象     |                检查条件                |       错误消息 (Message Content)       |             动作              |
| :-: | :--------: | :--------------: | :------------------------------------: | :------------------------------------: | :---------------------------: |
|  1  | Page Mount |   User Session   | `Token == null` OR `IsExpired == true` | `Session expired. Please login again.` |        重定向至登录页         |
|  2  | Click Link | Permission Check |      `CurrentRole` 不包含所需权限      |   无（前端已隐藏）或 `Access Denied`   | 阻止跳转，可选显示 Toast 提示 |

## 4. 接口定义 (API Specification)

本模块主要为前端路由导航，不直接调用业务数据接口。

## 5. 异常处理 (Exception Handling)

| 异常场景                 | 处理方式                   | Message 显示内容                               |
| :----------------------- | :------------------------- | :--------------------------------------------- |
| **会话过期 (401)**       | 捕获全局 Auth 错误，重定向 | `Session expired. Please login again.`         |
| **网络断开/超时**        | 捕获 Network Error         | `Network error. Please check your connection.` |
| **服务器内部错误 (500)** | 捕获 Server Error          | `System error. Please contact support.`        |

## 6. 实现注意事项 (Implementation Notes)

1.  **路由配置**：
    - 建议将菜单结构与 React Router 的路由配置映射起来，便于维护。
    - 例如：`Link_GenDoc` 对应路径 `/generate/doc`。
2.  **UI 细节**：
    - 顶部 Header 固定高度，背景色建议使用 Volvo 品牌蓝（如 `#003057` 或设计稿指定色值）。
    - 菜单项 hover 效果应明显，提升交互反馈。
    - `»` 符号建议使用 CSS pseudo-element (`::before`) 实现，以便统一样式管理。
3.  **性能优化**：
    - 菜单结构相对静态，可考虑使用 `React.memo` 避免不必要的重渲染。
