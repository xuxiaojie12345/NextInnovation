## 1. 背景 (Background)

本模块的核心功能是对上传的模板文件进行内容校验，确保其符合系统规范。所有校验逻辑在**前端**完成，无需后端 API 支持。

主要校验逻辑包括：

- 使用 `FileReader` 读取文件内容
- 使用正则表达式提取 `$` 符号之间的变量文本（如 `$AXLE_CONF$`）
- 统计变量数量并验证是否存在有效变量
- 校验通过后，提供处理后的文件下载

面向的用户群体：

- 系统管理员
- 生产工程师
- 认证管理人员

用户体验方面的考虑：

- 界面简洁，仅包含必要控件
- 支持文件选择与校验结果下载
- 错误信息明确，便于问题定位
- 所有操作均有即时反馈提示

## 3. 业务逻辑与校验规则 (Business Logic & Checks)

所有校验逻辑均在用户点击 **[Check]** 按钮时执行，全部为前端处理。

### 3.1 处理流程

1. **开始**：用户点击 [Check] 按钮。
2. **前置处理**：获取上传的文件对象。
3. **空值/格式校验 (Frontend Check)**：
   - 若未选择文件：设置 `ErrorMessage` = `ERROR: Unable to access file!`，**终止**流程。
4. **前端文件读取与校验**：
   - 使用 `FileReader` 读取文件内容为文本。
   - 若文件无法读取（FileReader 触发 error 事件）：设置 `ErrorMessage` = `ERROR: Unable to access file!`，**终止**流程。
   - 使用正则表达式 `/\$([^$]+)\$/g` 提取所有 `$...$` 格式的变量。
   - 若未找到任何有效变量：设置 `ErrorMessage` = `ERROR: The file content is incorrect!`，**终止**流程。
5. **结果处理**：
   - **成功**：
     - 隐藏 `ErrorMessage`。
     - 显示 `SuccessMessage` = `校验完成`。
   - **失败**：
     - 隐藏 `SuccessMessage` 和 `Download Link`。
     - 显示 `ErrorMessage` 为对应的错误信息。

## 4. 接口定义 (API Specification)

无（全部逻辑在前端完成，无需后端 API）

## 5. 异常处理 (Exception Handling)

| 异常场景                 | 处理方式        | Message 显示内容                        |
| :----------------------- | :-------------- | :-------------------------------------- |
| **未选择文件**           | 前端校验        | `ERROR: Unable to access file!`         |
| **文件无法读取**         | 前端 FileReader | `ERROR: Unable to access file!`         |
| **文件内容无效(无变量)** | 前端正则校验    | `ERROR: The file content is incorrect!` |

## 6. 实现注意事项 (Implementation Notes)

1. **状态管理**：
   - 使用 React State 管理 `selectedFile`, `errorMessage`, `successMessage`, `checkedContent`, `variableCount`, `isLoading`。
   - `checkedContent` 为读取到的文件内容（校验通过时保留）。
2. **文件处理**：
   - 使用 `FileReader.readAsText()` 读取文件内容。
3. **UI 细节**：
   - **Loading 状态**：点击 Check 后，按钮应显示 Loading 并禁用，防止重复提交。
   - **消息展示**：`ErrorMessage` 使用红色 (`#d32f2f`)，`SuccessMessage` 使用绿色 (`#389e0d`)。
   - **下载链接**：使用 `Blob` 创建对象 URL，通过 `<a href={objectUrl} download="checked_template.rtf">` 触发下载。
4. **安全性**：
   - 下载文件使用 Blob URL，不会暴露服务器路径。
