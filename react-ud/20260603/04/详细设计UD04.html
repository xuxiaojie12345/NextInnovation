1. 背景 (Background)

本模块是 VPPS 批处理程序生成车辆铭牌（VIN Plate）后的结果展示页面。用于确认生成结果，展示底盘数据、S-Notes、轮胎主数据、变更状态及最终生成的文档链接，并支持后续操作（如下载、修改、查看详情）。

  • 目标：清晰展示生成结果，提供关键信息的快速访问入口，并通过颜色区分异常状态（如 AD-Change）。
  • 安全性：错误信息不暴露系统内部结构，所有通信需通过 HTTPS 加密。
  • 用户体验：
    • 关键信息（Chassis no, Error message）突出显示。
    • 支持点击链接跳转至详情页或下载文件。
    • 变更状态以红色高亮显示，提示用户注意。
    • 提供清晰的系统时间与版本信息。

3. 业务逻辑与校验规则 (Business Logic & Checks)

3.1 处理流程

3.1.1 初期处理

  1. 开始：初期表示场合，接收前画面的参数。
  2. 前置处理：
    • 获取 URL 参数或 State 中的 chassisNo, ordernumber, market。
    • 执行非空校验。
  3. 空值校验 (Frontend Check)：
    • 若 chassisNo 为空：
      • 设置 ErrorMessage = 无法加载数据，请检查输入
      • 终止流程，不调用 API。
  4. API 调用 (Backend Check)：
    • 若校验通过，调用 GET /api/ud04selectgeneratedocumentapi/selectgeneratedocument。
  5. 结果处理：
    • 成功 (200)：
      • 渲染所有字段。
      • 若 sNotes 存在，显示 S-Note 列表及红色警告消息。
      • 若 adChangeEnabled 为 true，将 Modify Doc Link 标红并激活。
      • 绑定 Generated document 下载链接。
    • 失败 (404/500)：
      • 设置 ErrorMessage = 数据加载失败，请稍后重试 或具体错误消息（如 Chassis not found）。

3.1.2 'Chassis no'的机能处理

  1. 开始：Chassis no的link按下。
  2. 结果处理：
    • 成功：
      • 该当Chassis的详情页面表示（07_Vehicle Specification画面）。

3.1.2 'Generated document'的机能处理

  1. 开始：Generated document的link按下。
  2. 结果处理：
    • 成功：
      • 文件下载（「Vin Plate」的.trf）。

3.1.3 'Modify'的机能处理

  1. 开始：Modify的link按下。
  2. 结果处理：
    • 成功：
      • 迁移到Modify Document画面。

4. 接口定义 (API Specification)

4.1 UD04SelectGeneratedocumentApi

  • 功能：获取指定底盘的车辆铭牌生成结果及相关元数据。
  • Method: GET
  • Endpoint: /ud04selectgeneratedocumentapi/selectgeneratedocument

Request Parameters

  • chassisNo: String (Path Param)
  • ordernumber: String (Path Param)
  • market: String (Path Param)

6. 实现注意事项 (Implementation Notes)

  1. 状态管理：
    • 使用 React State 管理 vinPlateData, errorMessage, isLoading。
    • ErrorMessage Label 默认隐藏。
  2. 样式处理：
    • Modify Doc Link 的红色样式建议通过 CSS Class (class="text-danger") 动态绑定。
    • S-Note Message 同样使用红色字体以示警示。
  3. 下载功能：
    • Generated document 链接点击时，建议使用 window.location.href 或创建隐藏的 <a> 标签触发下载，确保文件名正确（后端应在 Header 中设置 Content-Disposition）。
  4. 跳转逻辑：
    • Chassis no 点击跳转至 /chassis-detail/${chassisNo}。
    • Modify Doc Link 点击跳转至修改页面（路径需确认，如 /modify-doc/${chassisNo}）。
  5. 安全性：
    • API 请求必须通过 HTTPS 发送。
    • 对 URL 参数进行编码，防止注入攻击。
