 2. 背景 (Background)

 核心功能与目标
本模块用于支持用户对车辆铭牌模板中的变量值进行修改，并保存修改后的数据。主要功能包括：
- 展示当前车辆的VIN及相关字段的当前值
- 允许用户编辑部分字段并提交修改
- 提供下载空白铭牌文件的功能
- 支持跳转至底盘详细信息页面

 面向用户群体
- 车辆配置工程师
- 生产线管理人员
- 质量控制人员

 用户体验考虑
- 界面简洁，重点突出可编辑字段
- 明确区分输入项与输出项
- 提供清晰的操作反馈（如保存成功提示）
- 支持快速访问相关联的数据（如底盘详情、模板文件）

 安全性要求
- 修改操作需校验是否已发布版本存在（防止覆盖未发布版本）
- 所有修改必须经过系统验证后才允许提交
- 操作日志记录（由后端实现）

 4. 功能描述 (Functional Description)

 4.1 修改并保存文档内容

功能说明：  
用户可在“Modified value”栏输入新的字段值，点击“Save”按钮后，系统将对比新旧值并跳转至修改确认页面。

操作步骤：
1. 用户进入 Modify Document 页面，查看当前车辆信息及各变量值。
2. 在“Modified value”列中填写需要更改的字段值。
3. 点击“Save”按钮。
4. 系统执行前端校验，若通过则调用后端 API 进行保存。
5. 成功后跳转至“修改保存页面”，展示所有修改内容。


 4.2 下载空白车辆铭牌文件

功能说明：  
点击链接 `Template: aus/UD_TEST.odt`，下载一个空白的 `.odt` 文件，用于后续打印或编辑。

操作步骤：
1. 用户点击链接 `Template: aus/UD_TEST.odt`。
2. 系统触发文件下载请求。
3. 返回 `trf` 格式的空白铭牌文件（实际为 `.odt` 文件）。
4. 浏览器自动开始下载。

---

 4.3 查看底盘详细信息

功能说明：  
点击底盘编号（如 `JPCT 028321`），跳转至该底盘的详细信息页面。

操作步骤：
1. 用户点击“Chassis no”字段中的链接。
2. 系统发起请求获取该底盘的完整配置信息。
3. 跳转至底盘详情页，展示所有参数和历史记录。

 5. 业务逻辑与校验规则 (Business Logic & Checks)

 5.1 处理流程

 开始：点击“Save”按钮

 前置处理：
- 调用 `GET /api/UD05ModifyDocumentApi/UD05SelectVariableModification`
- 获取当前页面所有 `Modified value` 字段的输入值
- 检查是否有任意字段被修改
- 从数据库加载 `HDOC_ADCA_MODIFICATION` 和 `HDOC_REC_DATA_KOLA_VARIANT` 数据

 空值校验等 (Frontend Check)：
- 若所有 `Modified value` 字段为空且无任何修改：
  - 设置 Message = “NO UNRELEASED VERSION EXISTS!”
  - 终止流程

 5.1.2 API调用 (Backend Check)：
- 调用 `POST /api/UD05ModifyDocumentApi/UD05UpdateHdocAdcaModification`


 5.2 结果处理：
成功：跳转至 `/document/confirm-modify` 页面，显示修改内容列表
失败：弹出错误消息：“保存失败，请检查输入内容”

---
