2. 背景 (Background)
  本模块的核心功能是展示基于上一页查询条件所获取的 `HDOC_VARIABLES` 表中认证参数（Homologation Variables）的数据列表。该页面作为查询流程的输出界面，支持用户对检索结果进行选择、打印、导出等操作，并提供跳转至用户详情页的功能。

  面向的用户群体：
  - 系统管理员
  - 产品工程师
  - 认证管理人员

  用户体验方面的考虑：
  - 支持多行勾选，提升批量操作效率
  - 提供清晰的数据字段展示（如 Variable、Type、Description）
  - 创建人列可点击跳转，增强信息追溯能力
  - 所有按钮具备明确语义，避免误操作

  安全性或特殊要求：
  - 删除操作需确认，防止误删
  - 创建人链接仅限于已登录用户访问，且权限控制由后端统一管理
  - 导出文件不包含敏感信息
  - 所有通信使用 HTTPS 加密

4. 功能描述 (Functional Description)

    4.1 数据展示功能
    功能说明：根据上一页的查询条件，从数据库中加载并展示对应的 HDOC_VARIABLES 数据。
    操作步骤：
      1. 用户在前一页面输入查询条件并提交
      2. 系统调用 `GET /HDOC_VARIABLES/search` 接口获取匹配数据
      3. 将数据渲染为表格形式，每行包含 Variable、Type、Description 等字段
      4. 显示总记录数（Count）于页面底部

    4.2 选择并返回功能
    功能说明：用户勾选一条或多条数据后，点击“Select”按钮，将所选数据回传至上一级页面。
    操作步骤：
      1. 用户勾选一个或多个数据条目
      2. 点击“Select”按钮
      3. 系统收集所有选中项的主键（如 ID 或组合字段）
      4. 跳转至上一级认证参数页面，并自动填充选中数据的信息
      5. 页面提示：“已成功选择 X 条记录”

    4.3 返回功能
    功能说明：点击“Back”按钮返回上一级页面，并恢复原始查询条件。
    操作步骤：
      1. 用户点击“Back”按钮
      2. 系统不保存当前筛选状态
      3. 跳转至认证参数查询页面
      4. 查询条件自动还原为进入本页面前的状态

    4.4 打印功能
    功能说明：将当前检索结果以打印格式输出。
    操作步骤：
      1. 用户点击“Print”按钮
      2. 系统触发浏览器打印对话框
      3. 打印内容包括表头、所有可见列及分页信息
      4. 不包含系统按钮和操作栏

    4.5 下载功能
    功能说明：选中数据条目后点击“Down”按钮，携带该条目的参数跳转至认证参数页面，仅展示匹配对应配置型号的数据。
    操作步骤：
      1. 用户勾选一条或多条数据条目
      2. 点击“Down”按钮
      3. 系统提取选中记录的 Variable 和 Type 字段
      4. 跳转至 `/homologation-variables?variable=XXX&type=YYY`
      5. 新页面仅显示与该变量匹配的配置型号数据

    4.6 导出 Excel 功能
    功能说明：将当前查询结果导出为 CSV 格式文件。
    操作步骤：
      1. 用户点击“Excel”按钮
      2. 系统调用导出接口获取数据
      3. 生成 CSV 文件并触发下载
      4. 文件命名格式：`HDoc_Variables_YYYYMMDD.csv`

    4.7 创建人跳转功能
    功能说明：点击“Created by user”列中的用户名链接，跳转至用户信息查看页面。
    操作步骤：
      1. 用户点击某条记录的“Created by user”字段（如 mg 或 v0c6900）
      2. 系统发起请求至 `/user/profile/{userId}`
      3. 展示该用户的详细信息（姓名、部门、角色等）
      4. 支持返回原页面

5. 业务逻辑与校验规则 (Business Logic & Checks)

   5.1 处理流程

      开始：用户点击 Select / Down / Back / Print / Excel / Created by user 链接
      前置处理：验证当前会话有效性，获取用户权限

      5.1.1 空值校验等 (Frontend Check)：
       若未勾选任何数据且点击“Select”或“Down”：
        设置Message = “请至少选择一条记录”
        终止流程

      5.1.2 API调用 (Backend Check)：
        调用 `GET /UD11HdocvariablesApi/UD11Search` 获取数据

   5.2 结果处理：
       成功：显示提示消息“操作成功”
       失败：显示错误消息“操作失败，请稍后重试”

   5.3 校验详细规格表

   | No. | 检查时机 | 检查对象 | 检查条件 | 错误消息 (Message Content) | 动作 |
   |-----|---------|---------|---------|--------------------------|------|
   | 1   | 点击 Select/Down | 选中项数量 | 无选中项 | “请至少选择一条记录” | 阻止提交 |
   | 2   | 跳转用户详情 | 用户ID | 用户不存在 | “用户信息不存在” | 跳转失败页 |

6. 接口定义 (API Specification)

   UD11HdocvariablesApi
     功能：获取符合查询条件的认证参数列表
     Method：GET
     Endpoint：/api/UD11HdocvariablesApi/UD11Search

     Request [请求格式]
     {
       "variable": "CDB_CADDRESS_LINE1",
       "type": "CDB"
     }

     Response Success (200)
     {
       "data": [
         {
           "Variable": "CDB_CADDRESS_LINE1",
           "Type": "CDB",
           "Description": "CDB customer address line 1",
           "Created_by_user": "mg",
           "Date": "2006-03-21"
         }
       ],
       "totalCount": 3619
     }

     Response Error (400)
     {
       "error": "Invalid parameters",
       "message": "查询参数格式错误"
     }

7. 异常处理 (Exception Handling)

| 异常场景 | 处理方式 | Message显示内容 |
|---------|---------|----------------|
| 网络超时 | 重试一次，若仍失败则提示 | “网络连接失败，请检查网络设置” |
| 数据库异常 | 回滚事务，记录日志 | “系统繁忙，请稍后再试” |
| レコードを選択しなく、ボタン押下する場合 | 返回错误响应 | “No key defined for table.” |
